## 3. 주요 모듈 및 로직 분석
핵심 로직이 위치한 파일별 주요 역할입니다.

* **`core/inspection.py`**: 검사 알고리즘 엔진. OpenCV의 `cv2.threshold` 함수를 사용하여 화소 밝기 변화를 감지.
* **`hardware/device_manager.py`**: 장비와의 인터페이스 통합 관리. 연결 상태 모니터링 수행.
* **`data/logger.py`**: 판정 결과(`Pass/Fail`)를 로컬 서버 DB 및 CSV 파일로 저장.

## 4. 트러블슈팅 가이드
문제가 발생했을 때 아래 절차를 우선 확인하십시오. 모든 로그는 `C:/Logs/uLED/`에 저장됩니다.

| 문제 현상 | 예상 원인 | 해결 방안 |
| :--- | :--- | :--- |
| **카메라 초기화 실패** | USB/GigE 케이블 접촉 불량 | 케이블 재연결 및 IP 대역 재확인 |
| **오탐지(정상 화소 → 불량)** | 조명 밝기 및 주변 환경 노이즈 | `config.yaml`의 `MIN_THRESHOLD` 값 조정 |
| **프로그램 응답 없음** | 메모리 부족 현상 | 작업 관리자에서 `uLED_Inspector.exe` 강제 종료 후 재실행 |

> **더 많은 FAQ 및 해결책은 [Troubleshooting.md](내부 링크) 파일을 참조하세요.**
