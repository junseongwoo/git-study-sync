# 시작 가이드

이 문서는 처음 `uLedAoiConsole`를 실행한 뒤, 실제 화면 기준으로 따라가는 시작 매뉴얼이다.

목표:
- 프로그램이 정상 실행되는지 확인
- 새로운 제품이 들어 왔을 때 레시피를 설정하는 과정을 보여준다.

## Glass Model 설정

순서:
- 레시피의 General 탬을 선택한다.
- 레시피를 만들 glass model을 선택한다.
- Glass Model은 글래스의 크기 및 회전각도를 이용해서 선택하면된다.
- 새로운 크기의 글래스가 들어오면 새로 글래스 모델을 만들어야 한다.
- 나머지 항목들을 입력한다.

### 필수항목

Display Width
Display Height
Display Pixel Size(um)
Gate Pitch, Data Pitch 는 필요없으므로 삭제

## Glass Map Design 설정

개요:
- 이 단계에서는 글래스위에 Cell이 배치된 상태에 따라 Model을 설정하는 단계이다.
- 기존에 동일한 배치의 레시피가 있으면 그대로 읽어와서 사용하면 된다.

순서:
- Recipe 의 Glass Map Window 창에서 Glass Map을 만든다.

## Align 등록

순서:
- 각 Align 카메라를 글래스의 Align 좌표로 옮긴다 (필요)
- Align / Control 탭으로 이동해서 두개의 Align 카메라를 Live로 본다.
- Y, U, V, W 축을 움직여서 양쪽 Align 마크가 화면의 중심에 오도록 이동한다.
- 현재 위치를 Align 위치로 등록한다.

## 점등

순서:
- 첫번째 카메라를 첫번째 셀위로 이동한다 (필요)
- IP 에서 카메라 화면을 보면서 위치가 맞는지 확인
- 이상태에서 Probe 의 Y축과 Z축을 조정해서 점등한다.
- 해당 위치를 점등위치로 등록한다.

## 패턴 등록

순서:
- 패턴 탭에서 패턴을 등록한다.
- Index 번호는 꼭 등록해야 하며 0 based 로 등록한다. (여기에 Bright/Dark 이 왜 필요하지?)
- PG의 패턴 번호도 등록해야 한다. (PG State는 PG의 패턴 번호로 대체한다.)
(여기 패턴 편집 기능이 IP Recipe 편집화면의 패턴 편집화면 + Expoure 여야 한다. Gain은 일단 삭제)
- Points 도 등록한다. 
- 여기도 Index 는 꼭 등록되어야 한다.
- 현재는 1개의 위치만 등록된다 (순서를 Roi 를 앞쪽으로)

## 이미지 촬영조건 세팅

순서:
- Test 에서 PG 테스트를 열고 해당 셀을 점등한다 (모달리스로 변경 필요?)
- IP 에서 밝기를 확인하면서 촬영을 하고 Exposure 를 확정한다.
- 이 값을 레시피의 패턴에 입력한다.

## 이미지 촬영

순서: 
- 아래 내용은 Console의 Recipe Editor 에서 작업한다.
- IP를 실행시킨다.
- 콘솔에서 레시피를 Upload한다.
- IP에 레시피가 세팅 되었는지 확인한다.
- 콘솔에서 패턴 및 셀을 선택한다.
- 카메라를 선택된 셀로 보낸다.
- 콘솔에서 Image Window 를 연다.
- 콘솔 Image Window에서 '촬영' 메뉴를 선택해서 촬영한다.(필요)
- 패턴이 켜지고 이미지가 촬영되고 해당 이미지가 콘솔의 Image Window 에 표시된다.
- IP 에는 해당 패턴에 영상이 제대로 들어온는지 확인.
- 여기서 Roi 를 그린다.
- 모든 패턴 설정이 완료되면 IP에서 영상을 저장한다.
