# RecipeWindow / 명점 검사(WD) 탭 사용자 매뉴얼

## 화면 목적

이 탭은 명점(WD) 검사에 쓰는 공통 기준값을 설정하는 화면입니다. 검사 실행이나 표준맵 생성은 여기서 하지 않고, 상단 `IP` 메뉴에서 수행합니다.

## 설정 방법

1. `검출 설정`의 `명점 임계값(%)`을 입력합니다.
2. `R 기준 RGB 위상 오프셋`에 G와 B의 `Dx`, `Dy`를 입력합니다.
3. 값을 입력한 뒤 다른 항목을 클릭해 입력값을 확정합니다.
4. 상단 `파일 > 유효성 검사`를 실행합니다.
5. 문제가 없으면 `파일 > 저장`을 실행합니다.

## 항목 설명

| 항목 | 설명 |
|---|---|
| 명점 임계값(%) | 명점을 판단하기 위한 밝기 기준값입니다. |
| G (R 기준) Dx/Dy | R 채널 좌표를 기준으로 G 채널의 상대 위치를 설정합니다. |
| B (R 기준) Dx/Dy | R 채널 좌표를 기준으로 B 채널의 상대 위치를 설정합니다. |

## 표준맵을 준비하는 권장 순서

1. 양품 셀을 선택합니다.
2. 상단 `IP > 선택 셀 카메라 촬영` 또는 `선택 셀 폴더 이미지 로드`로 이미지를 현재 buffer에 적재합니다.
3. `IP > 현재 버퍼 분석 (Pitch·Phase·표준맵)`을 실행합니다.
4. 결과 창에서 pitch, phase offset, ROI 후보를 확인하고 recipe에 적용합니다.
5. 표준맵 생성 기능을 실행합니다.
6. 생성 결과와 phase offset을 확인한 뒤 레시피를 저장합니다.

## 결과를 읽는 방법

탭에는 `wd_defects` 결과가 `channel`, `type`, `x`, `y`, `level`로 구성된다고 안내합니다.

- `WD`: 개별 명점 결과입니다.
- `WVL`/`WHL`: 명점이 집중된 세로/가로 line 결과이며, `level`은 해당 line에서의 명점 비율(%)입니다.
- `x/y`: IP 내부 raw index입니다. 사용자용 Row/Column 값과 직접 같지 않을 수 있습니다.

## 주의 사항

- 임계값과 phase offset은 대표 양품 셀을 기준으로 검증한 뒤 저장하십시오.
- phase offset을 임의로 수정하면 RGB 채널 좌표 대응이 바뀌어 검출 결과가 달라질 수 있습니다.
- 이 탭에서는 표준맵 파일을 직접 선택하거나 생성하지 않습니다. 관련 작업은 `IP > 현재 버퍼 분석`의 결과 창에서 진행합니다.
- [추론] 광학계 교체 또는 재정렬 후에는 기존 표준맵과 offset이 더 이상 맞지 않을 수 있으므로 표준맵 재생성과 결과 검증이 필요할 수 있습니다.
