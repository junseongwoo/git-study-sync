# RecipeWindow - 셀 목록 탭 사용자 매뉴얼

## 1. 화면 목적

셀 목록 탭은 검사할 Cell을 확인하고, 각 Cell을 어느 IP가 담당할지 설정하며, 설비가 이동할 예상 좌표를 확인하는 화면입니다.

Cell은 실제 검사 대상 단위입니다. 동일한 `Y Index`를 가진 Cell은 IP 분배와 PG 매핑에서 같은 그룹으로 취급됩니다. 공식 문서상 `YIndex`는 IP 자동 분배와 Split 적용의 기준입니다.

## 2. 먼저 알아둘 용어

| 용어 | 사용자 관점 의미 |
|---|---|
| Cell | 글래스 위에서 검사할 한 영역입니다. |
| Use | 이 Cell을 이번 검사 대상에 포함할지 여부입니다. |
| IP1 / IP2 | 검사 장치/검사 unit 담당 번호입니다. 공식 문서상 IP1은 Unit1Y, IP2는 Unit2Y와 연결됩니다. |
| XIndex | Cell의 가로 실행 그룹 번호입니다. 시스템이 계산하는 값이므로 직접 수정하지 않습니다. |
| YIndex | 같은 XIndex 안의 세로 실행 그룹 번호입니다. IP 배정과 PG 매핑의 기준입니다. |
| 분할 Y | 정렬된 YIndex 그룹 중 IP1에 맡길 앞쪽 그룹 수입니다. 단순 좌표값이 아닙니다. **[추론]** |
| StageX / Y1 / Y2 | 현재 Cell로 이동할 때 사용할 계산된 설비 축 목표값입니다. 읽기 전용입니다. **[추론]** |

| 컨트롤 | 역할 | 언제 사용하나요? | 사용 방법 및 결과 |
|---|---|---|---|

| 셀 삭제 | 선택한 Cell 제거 | 잘못 만든 Cell을 제거할 때 | 삭제할 행을 선택한 뒤 누르고 확인합니다. 삭제 후 검사/PG mapping 영향 여부를 확인합니다. |
| 선택 IP를 셀로 이동 | 선택한 IP를 현재 선택 Cell 위치로 이동 | 좌표 또는 장비 이동을 검증할 때 | 행을 선택하고, 해당 행의 IpNo와 현재 선택 IP가 같은지 확인한 뒤 사용합니다. 실제 모션이 발생할 수 있습니다. **[추론]** |

| IP 자동 할당 | 안전거리 기준으로 IP1/IP2 자동 분배 | Cell map 생성·변경 후 기본 IP 배정이 필요할 때 | 확인 후 누릅니다. 시스템이 YIndex 그룹과 안전거리로 IP를 배정하고 분할 Y를 갱신합니다. |
| 분할 Y | 수동 IP 분할 기준 입력 | 운영자가 정한 IP1/IP2 경계를 적용할 때 | 정수값을 입력한 뒤 반드시 **분할 적용**을 누릅니다. 입력만으로 IP가 바뀌지는 않습니다. **[추론]** |
| 분할 적용 | 분할 Y 기준으로 IP 재배정 | 자동 배정 대신 수동 분할을 적용할 때 | 확인 후 누릅니다. 앞쪽 YIndex 그룹은 IP1, 나머지는 IP2가 됩니다. 안전거리 검사는 다시 하지 않습니다. **[추론]** |
| 좌표 재계산 | 표시용 StageX/Y1/Y2를 최신 기준으로 계산 | GlassSize, 보정값, 이동 도구 또는 Cell 위치 변경 후 | 누른 뒤 읽기 전용 StageX/Y1/Y2 열을 확인합니다. Cell 자체나 X/Y Index는 바꾸지 않습니다. **[추론]** |
| 표준맵 사용 | 표준 dense map 사용 여부 설정 | 표준맵 기반 검사 조건을 사용할 때 | 체크하면 표준맵 사용 설정이 recipe에 저장됩니다. Tooltip상 IP 업로드 시 함께 전달됩니다. |

## 4. Cells 표 읽는 법과 입력 방법

| 열 | 무엇을 확인/입력하나요? | 주의사항 |
|---|---|---|
| CellId | Cell 식별 번호 | 중복되지 않도록 관리합니다. |
| 자동명 | 시스템이 만든 내부 Cell 이름 | 일반적으로 Cell map 생성 결과를 유지합니다. |
| 사용자명 | 현장/장비에서 쓰는 실제 Cell 이름 | 자동명과 실제 명칭이 다를 때 입력합니다. 사용자명이 있으면 운영 표시·IP Job·파일 경로에 우선 사용될 수 있습니다. |
| 사용 | 검사 포함 여부 | 제외하려면 체크를 해제합니다. 삭제보다 안전한 임시 제외 방법입니다. |
| IpNo | 담당 IP 번호 | 자동 할당 또는 분할 적용 후 반드시 확인합니다. IP1/IP2 이외 값은 이동/실행에서 실패할 수 있습니다. **[추론]** |
| XIndex, YIndex | 시스템이 계산한 실행 그룹 | 읽기 전용입니다. 값이 예상과 다르면 Cell map/좌표 원본을 확인합니다. |
| X, Y | Cell 사각형의 글래스 기준 위치값 | 글래스 중심이 `(0,0)`이고 +Y가 위인 좌표계의 좌상단 값입니다. 원본 좌상단 기준 좌표에서 글래스 폭/높이의 절반을 이용해 변환됩니다. 변경은 실행 index·모션 계산에 영향을 줄 수 있으므로 승인된 좌표 기준으로만 수행합니다. |
| StageX, Y1, Y2 | 설비 모션 예상 결과 | 읽기 전용입니다. 0으로 보이면 좌표 계산에 필요한 GlassSize/calibration을 확인합니다. **[추론]** |

## 5. 권장 작업 순서

### Cell map을 새로 만들거나 변경한 경우

1. Cell map/좌표 원본을 확정합니다.
2. 셀 목록에서 Cell 수와 자동명, XIndex/YIndex를 확인합니다.
3. **IP 자동 할당**을 눌러 기본 IP 배정을 수행합니다.
4. 각 YIndex 그룹의 `IpNo`가 현장 배정과 맞는지 확인합니다.
5. GlassSize 또는 보정 기준이 준비된 상태에서 **좌표 재계산**을 누릅니다.
6. `StageX`, `Y1`, `Y2` 값이 예상 범위인지 확인합니다.
7. 필요 시 PG 매핑 탭에서 동일 YIndex의 PG 연결도 확인합니다.
8. recipe를 저장합니다.

### 수동으로 IP 경계를 지정해야 하는 경우

1. 먼저 현재 고유 YIndex 목록을 오름차순으로 확인합니다.
2. IP1에 맡길 앞쪽 그룹 수를 **분할 Y**에 입력합니다.
3. **분할 적용**을 누르고 확인 창에서 내용을 확인합니다.
4. DataGrid의 모든 `IpNo`를 검토합니다.
5. 수동 분할은 안전거리 검사를 다시 하지 않으므로, 안전한 동시 이동/검사 가능 여부를 현장 기준으로 확인합니다. **[추론]**

예: YIndex가 `0, 2, 4`이고 분할 Y에 `2`를 입력하면, YIndex `0, 2`는 IP1, `4`는 IP2가 됩니다. **[추론]**

## 6. 주의사항

- **IP 자동 할당**은 안전거리 기준을 고려하지만, **분할 적용**은 사용자가 입력한 경계를 그대로 적용합니다. 수동 분할 전후에는 반드시 결과를 검토합니다. **[추론]**
- **좌표 재계산**은 Cell을 새로 만들거나 XIndex/YIndex를 재계산하는 기능이 아닙니다. 표시용 모션 목표만 다시 계산합니다. **[추론]**
- StageX/Y1/Y2가 모두 0이라면 실제 목표가 0이라는 뜻으로 단정하지 말고 GlassSize model과 calibration 상태를 확인합니다. **[추론]**
- `사용`을 해제한 Cell은 검사에서 제외될 수 있으므로, 작업 전 Use 상태를 확인합니다.
- 사용자명을 변경하면 운영 로그나 저장 폴더에서 보이는 Cell 이름에 영향을 줄 수 있습니다.
- 실제 설비를 움직이는 기능을 사용하기 전에는 IP 배정, GlassSize, 안전 상태를 확인합니다. **[추론]**
