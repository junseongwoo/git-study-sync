# RecipeWindow / 기본 설정 탭 사용자 매뉴얼

## 화면 목적

기본 설정 탭에서는 현재 레시피가 어떤 글래스 모델과 연결되어 있는지 확인하고, 검사에 필요한 공통 값(화소 정보, 썸네일, Pixel Map, 불량 판정 기준)을 관리합니다.

## 먼저 확인할 항목

1. 왼쪽 `작업 중인 레시피`에서 레시피 이름과 저장 경로를 확인합니다.
2. `기본 설정` 탭에서 `Glass Size ID`와 `Model 상태`를 확인합니다.
3. 탭 제목 옆 `⚠`가 보이거나 Model 상태가 불일치라면, 값 수정 전 원인을 확인합니다.
4. `레시피 이름`과 `버전`을 확인합니다.

## Glass Size Model 사용

| 버튼 | 사용 시점 | 동작 |
|---|---|---|
| 모델 편집 | 현재 참조 model의 설정을 수정해야 할 때 | 해당 GlassSize model 편집 창을 엽니다. |
| 모델 적용 | model 파일의 최신 내용을 현재 레시피 스냅샷에 반영할 때 | model 기준으로 레시피의 GlassSize 정보를 갱신합니다. |
| 모델 복원 | model 파일이 없거나 유실됐을 때 | 레시피 안의 저장된 스냅샷으로 model 파일을 다시 만듭니다. |

주의: GlassSize는 단순 크기 값이 아니라 정렬 mark와 좌표 변환 기준도 포함합니다. 변경 전 현재 레시피와 장비 운영 기준을 확인하십시오.

## 기본 값 입력

- `패턴 번호(PG)`: PG에 전달할 패턴 번호를 입력합니다. 화면 툴팁 기준 범위는 1~25입니다.
- `촬영 회전(도)`: 카메라 입력 후 IP 검사 이미지에 적용할 회전을 설정합니다. 허용 방향은 0/90/180/270도입니다.
- `썸네일 폭(px)`: 검사 결과 thumbnail의 폭을 설정합니다.
- `Export Prefix`: 결과 파일 이름의 recipe 식별 접두어입니다. 같은 레시피의 변경판을 구분할 때 사용합니다.
- `화소 수/크기/Pitch`: 표시 패널과 카메라 기반 검사의 기준 값입니다. 임의 변경 전 GlassSize·카메라 보정·검사 조건과의 관계를 확인하십시오.
- `설명`: 레시피의 용도나 변경 이유를 기록합니다.

## 화소 맵(map.txt) 관리

1. 현재 `화소 맵(map.txt)` 상태를 확인합니다.
2. 외부 map 파일이 있으면 `가져오기...`를 누르고 파일을 선택합니다. 파일은 레시피 폴더의 `map.txt`로 복사됩니다.
3. 전체 화소를 사용하는 기본 사각형 map이 필요하면 `생성`을 누릅니다.
4. 이전 형식 경로가 표시될 때만 `map.txt로 정리`가 나타납니다. 누르면 현재 map을 레시피 폴더의 표준 파일명으로 정리합니다.

## 불량 판정 기준 설정

1. `등급별 불량 종류` 표에서 각 등급에 연결할 불량 종류를 선택합니다.
2. `불량으로 취급할 종류`에서 실제 불량으로 계산할 종류를 체크합니다.
3. 변경 후 상단 `파일 > 유효성 검사`를 실행합니다.
4. 문제가 없으면 `파일 > 저장`을 실행합니다.

## 저장 및 다음 작업

1. `파일 > 유효성 검사`로 필수 항목을 확인합니다.
2. 새 레시피라면 `저장` 시 저장 위치를 선택합니다. 레시피는 `Data/Recipes/<GlassSizeId>/<RecipeId>/recipe.json` 구조로 저장됩니다.
3. 기존 레시피를 복제하려면 `다른 이름으로 저장`을 사용합니다.
4. 기본 설정 후에는 검사 패턴, 셀 목록/셀 맵, Align/Control 탭을 순서대로 확인합니다.

## 주의 사항

- `레시피 이름`은 이 탭에서 읽기 전용입니다. 저장 경로와 레시피 ID가 레시피 식별에 영향을 줍니다.
- 모델 상태가 불일치인데 무심코 `모델 적용` 또는 `모델 복원`을 누르면 기준 데이터가 바뀔 수 있습니다. 어떤 쪽이 최신인지 먼저 확인하십시오.
- `map.txt`는 레시피 폴더에 속하는 파일입니다. 원본 파일만 수정하고 가져오기를 하지 않으면 현재 레시피에 반영되지 않습니다.
- [추론] 불량 등급/종류의 변경은 결과 판정과 export 요약에 영향을 줄 수 있으므로, 대표 이미지로 검사 결과를 검증한 뒤 운영 레시피에 저장하는 것이 안전합니다.
