# RecipeWindow - 컨택 확인 탭 사용자 매뉴얼

## 기능 개요

컨택 확인은 컨택이 성공한 뒤, 컨택터 카메라(CAM3)를 등록한 Y 위치로 이동하며 이미지를 촬영해 컨택 상태를 확인하는 기능입니다. 이 기능은 자동 판정기가 아니라 작업자가 이미지를 확인할 수 있도록 기록을 남기는 절차입니다.

메인 검사에서 `Contact 확인` 옵션을 켜면 각 row의 컨택 성공 후 자동으로 실행됩니다. 자동 실행 중 실패하면 검사는 중지됩니다.

## 화면별 사용 방법

|화면 항목|무엇을 하는가|사용 방법|
|---|---|---|
|현재 위치 추가|CAM3의 현재 Y 위치를 목록에 등록|카메라를 원하는 시야로 이동한 뒤 클릭합니다. `P1`, `P2` 순으로 자동 이름이 붙습니다.|
|선택 삭제|선택한 촬영 위치 삭제|목록에서 행 하나를 클릭한 뒤 누릅니다. 삭제는 즉시 레시피 목록에 반영됩니다.|
|Name|촬영 위치 이름|의미 있는 이름으로 바꿉니다. 예: `Left`, `Center`, `Right`. 파일명 식별에도 사용됩니다.|
|Y (um)|CAM3 Y축 이동 위치|장비에서 확인한 안전 좌표를 µm 단위로 입력합니다. 화면에서 범위를 자동으로 제한하지 않습니다.|
|테스트 촬영|카메라만 1회 촬영|카메라 연결과 화면 품질을 먼저 확인할 때 사용합니다. 축 이동이나 Control flow는 실행하지 않습니다.|
|준비 Flow 전송|컨택 확인 준비 flow만 전송|Control 통신 점검용입니다. 일반 검사에서는 사용하지 않습니다.|
|종료 Flow 전송|컨택 확인 종료 flow만 전송|수동 준비 flow 테스트 뒤 상태를 정리할 때만 사용합니다.|
|Contact Check 실행|전체 순서 실행|카메라 점유 확인, 준비 flow, point별 이동·촬영, 종료 flow를 한 번에 실행합니다.|

## 레시피 설정 절차

1. 장비가 안전 상태인지 확인합니다.
2. CAM3를 첫 번째 확인 위치로 이동합니다.
3. `현재 위치 추가`를 누릅니다.
4. 필요한 모든 시야 위치에 대해 2~3을 반복합니다.
5. 각 행의 이름을 알아보기 쉽게 변경합니다.
6. `Y (um)` 값이 실제 장비의 `ContactorCameraY` 허용 범위 안인지 확인합니다.
7. `테스트 촬영`으로 CAM3가 정상 연결되고 이미지가 보이는지 확인합니다.
8. 실제 이동 순서까지 확인하려면 `Contact Check 실행`을 누릅니다.
9. 메인 검사에서 자동으로 사용할 경우 검사 실행 설정의 `Contact 확인` 옵션을 켭니다.

## 실행 결과와 저장 위치

|실행 방식|저장 위치|확인 목적|
|---|---|---|
|테스트 촬영 / 탭에서 Contact Check 실행|`RuntimeDir\ContactCheck\실행시각` **[추론: 현재 코드]**|레시피 설정·장비 점검|
|메인 glass 검사에서 자동 실행|해당 검사 세션의 `contactimages`|검사 row별 컨택 상태 확인|

자동 검사에서 컨택 확인에 실패하면 `CON-CONTACT-CHECK-FAIL`로 run이 중지됩니다. 먼저 해당 세션의 이미지와 Control/Console 로그를 확인하세요.

## 정상 실행 순서

```text
CAM3를 다른 화면이 사용 중인지 확인
→ CAM3 연결
→ 준비 Flow 전송
→ 각 point: ContactorCameraY 이동 → 촬영·저장
→ 종료 Flow 전송
→ CAM3 연결 해제
```

point 중 하나라도 이동 또는 촬영에 실패하면 이후 point는 진행하지 않습니다. 준비 flow 이후의 오류에도 종료 flow와 카메라 연결 해제는 시도됩니다.

## 주의 사항

- 컨택 확인은 컨택 동작 자체를 수행하지 않습니다. 수동 실행 전에는 장비가 의도한 컨택 상태인지 확인해야 합니다.
- CAM3가 외부 카메라 뷰어, 다른 검사, 다른 사용자의 화면에서 열려 있으면 실행할 수 없습니다. 강제로 카메라를 빼앗지 않습니다.
- `Y (um)`에는 화면상 입력 범위가 없습니다. 잘못된 값은 장비 충돌 또는 Control 거부의 원인이 될 수 있으므로, 장비 사양의 soft limit과 contact-safe 범위를 사용하세요.
- `준비 Flow 전송`, `종료 Flow 전송`은 진단 버튼입니다. 생산 운전에서는 `Contact Check 실행` 또는 메인 검사 자동 실행을 사용하세요.
- 시뮬레이션 모드에서 실제 CAM3가 없으면 성공으로 흉내 내지 않고 실패합니다.

## 문제 해결

|증상|우선 확인|
|---|---|
|카메라가 점유 중이라는 오류|CAM3 뷰어, 다른 검사, 다른 프로그램을 종료합니다.|
|현재 위치 추가 실패|Control 연결과 `ContactorCameraY` 좌표 읽기 상태를 확인합니다.|
|이동 후 촬영 실패|Y 값의 축 한계·안전 범위, Ready flow 응답, CAM3 연결 상태를 확인합니다.|
|메인 검사가 컨택 확인에서 멈춤|`CON-CONTACT-CHECK-FAIL` 로그, session `contactimages`, point 목록, CAM3 점유 상태를 함께 확인합니다.|
|저장 이미지를 찾을 수 없음|수동 실행은 Runtime `ContactCheck` 폴더, 자동 실행은 해당 glass 검사 세션의 `contactimages`를 확인합니다.|
