# RecipeWindow / CA410 탭 사용자 매뉴얼

## 화면 목적

CA410 탭은 CA410 광학 측정을 위해 PG의 R/G/B 전압을 단계별로 바꾸고, 각 조건에서 색도·휘도·Flicker·ELVDD 전류를 확인하는 화면입니다. 이 설정은 IP 이미지 검사 Pattern과 별도로 관리됩니다.

## 처음 설정하는 순서

1. CA410 장비와 PG/Control 연결 상태를 확인합니다.
2. 대상 셀을 선택하고 CA410 측정 위치가 맞는지 확인합니다.
3. `기본 RGB 추가`를 누르거나 `패턴 추가`로 측정 Pattern을 만듭니다.
4. 좌측 `CA410 패턴 목록`에서 Pattern을 선택합니다.
5. R/G/B 시작 전압, 증가 전압, 개수를 입력합니다.
6. `Step 자동 채우기`를 눌러 전압 Step을 생성합니다.
7. 우측 표에서 Step 번호, 전압, 사용 여부를 확인·수정합니다.
8. `Step 점등`과 `Step 측정`으로 대표 Step을 먼저 확인합니다.
9. `결과 창`에서 선택 Pattern 또는 전체 사용 Pattern을 반복 측정합니다.
10. 결과를 확인하고 필요하면 CSV로 내보낸 뒤 레시피를 저장합니다.

## 패턴 관리

| 버튼 | 설명 |
|---|---|
| 패턴 추가 | 빈 Step 목록을 가진 새 CA410 Pattern을 추가합니다. |
| 패턴 삭제 | 선택 Pattern을 삭제합니다. 확인 대화상자가 표시됩니다. |
| 기본 RGB 추가 | R, G, B 이름의 기본 Pattern을 추가합니다. 이미 같은 이름이 있으면 중복 추가하지 않습니다. |

`사용`을 끄면 해당 Pattern은 전체 실행에서 제외됩니다. `순서`는 전체 실행 순서이므로 중복하지 않도록 관리하십시오.

## 전압 Step 자동 생성

각 채널의 시작값과 증가값, Step 개수를 입력하고 `Step 자동 채우기`를 누릅니다.

예를 들어 R 시작 `4.5`, 증가 `-0.1`, 개수 `3`이면 R 전압은 `4.5 → 4.4 → 4.3`으로 생성됩니다. G/B도 같은 방식으로 독립 생성됩니다.

- 개수는 최대 30입니다.
- 개수를 0으로 입력하면 선택 Pattern의 Step이 모두 삭제됩니다.
- 생성 뒤에는 각 Step의 `사용`, 번호, R/G/B 전압을 다시 확인하십시오.

## 단발 시험

### Step 점등

1. 좌측에서 Pattern을 선택합니다.
2. 우측에서 Step을 선택합니다.
3. `Step 점등`을 누릅니다.
4. 확인 대화상자에서 Pattern, Step, R/G/B 전압을 확인하고 진행합니다.

선택한 PG Pattern에 R/G/B 전압을 적용합니다. 측정은 하지 않습니다.

### Step 측정

`Step 측정`은 선택 Step을 점등한 뒤 CA410을 한 번 측정합니다. 결과는 상태 메시지에서 확인합니다. 반복 결과 표에 누적해서 비교하려면 `결과 창`을 사용하십시오.

## 결과 창 사용

`결과 창`을 열면 아래 기능을 사용할 수 있습니다.

- `Run Selected Pattern`: 선택 Pattern에서 사용 중인 Step을 순서대로 측정
- `Run All Used`: 사용 중인 모든 Pattern과 Step을 순서대로 측정
- `Stop`: 진행 중인 반복 측정을 중단 요청
- `Export CSV`: 화면 결과를 CSV로 저장
- `Clear`: 완료된 결과 목록 비우기

결과에서 다음을 확인합니다.

- 입력 조건: Pattern/Step/PG, R/G/B 전압
- 광학 결과: `ca_x`, `ca_y`, `Lv`, Flicker
- 전기 결과: `ELVDD mA`, Raw
- 실패 정보: Error, Message

## 주의 사항

- CA410 장비는 이전 명령의 응답이 끝난 뒤 다음 명령을 보내야 합니다. 실행 중 다른 CA410 조작을 병렬로 하지 마십시오.
- zero calibration이 되지 않은 장비는 측정 오류가 날 수 있습니다.
- `Run All Used`는 사용 체크된 Pattern과 Step만 실행합니다.
- 측정 전에 CA410 헤드가 대상 셀 중심과 측정 Z 위치에 있는지 확인하십시오.
- CA410 조건은 IP 이미지 검사 Pattern과 별도입니다. 한쪽을 수정했다고 다른 쪽이 자동으로 바뀌지 않습니다.
- Simulation Mode에서는 실장비 의존 기능이 정상 완료된 것처럼 보장되지 않습니다.
