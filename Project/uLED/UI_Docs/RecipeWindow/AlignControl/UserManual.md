# RecipeWindow - Align / 제어 탭 사용자 매뉴얼

## 1. 화면 목적

이 화면은 Align 검사 조건과 설비 기준 위치를 관리합니다. 값을 바꾸면 Align 성공 판정, 실제 축 이동, Contact 동작, 검사 카메라 촬영 높이, Glass ID 판독 위치에 영향을 줄 수 있으므로 승인된 값만 사용해야 합니다.

## 2. Align 파라미터 사용 방법

| 항목 | 무엇을 설정하나요? | 값 기준 | 주의사항 |
|---|---|---|---|
| 최대 반복 횟수 | Align이 다시 촬영·보정할 최대 횟수 | 1 이상 | 너무 작으면 수렴 전에 실패할 수 있고, 너무 크면 실패 시 시간이 길어집니다. **[추론]** |
| 허용 오차 X/Y/θ | Align 성공으로 인정할 위치·회전 오차 | 모두 0보다 커야 함 | 값을 줄이면 엄격해지고, 늘리면 통과는 쉬워지지만 정렬 정확도는 낮아질 수 있습니다. **[추론]** |
| 매칭 임계값 2/1 | 두 Align 카메라의 template score 기준 | 일반적인 코드 기준 0.0~1.0 | 높이면 잘못된 매칭은 줄지만 검출 실패가 늘 수 있습니다. **[추론]** |
| 템플릿 영역 | 기준 이미지에서 비교할 마크 부분 | pixel X/Y/W/H | 특징이 뚜렷한 마크만 포함합니다. W/H를 0 또는 음수로 입력하지 않습니다. **[추론]** |
| 탐색 영역 | 현재 이미지에서 마크를 찾을 범위 | pixel X/Y/W/H | template을 포함해야 하며 카메라 이미지 밖으로 벗어나지 않게 설정합니다. **[추론]** |

## 3. Align 기준 위치 사용 방법

| 컨트롤 | 역할 | 사용 방법 |
|---|---|---|
| StageX | Align 기준의 공통 StageX 위치 | 수동 이동으로 검증된 위치에서 **현재값 읽기**를 사용해 기록하는 방법을 권장합니다. |
| Align2 / Align1 UnitY | 각 Align unit의 Y 위치 | Align2는 Unit2Y, Align1은 Unit1Y에 연결됩니다. 두 값을 임의로 바꾸면 Align 카메라가 마크를 보지 못할 수 있습니다. **[추론]** |
| U/V/W | Align 자세/회전 축 기준 | 현장 teach 또는 표준값을 사용합니다. 직접 숫자 입력 전 장비 축 범위를 확인합니다. |
| 현재값 읽기 | 현재 Control 축값을 recipe에 저장 | 장비가 정확한 Align 기준 위치에 있을 때만 누릅니다. |
| Align 위치 이동 | 저장된 위치로 실제 장비 이동 | 실제 이동이 발생합니다. Contact 상태와 이동 안전 상태를 확인한 뒤 사용합니다. **[추론]** |
| 표준 가져오기 | GlassSize 표준값을 현재 recipe에 적용 | 현재 recipe 값이 덮어써질 수 있으므로 변경 전 저장/비교를 권장합니다. |
| 표준으로 내보내기 | 현재 recipe 값을 GlassSize 표준으로 등록 | 다른 recipe의 기준에도 영향을 줄 수 있는 표준 변경 작업입니다. 승인된 경우에만 사용합니다. **[추론]** |
| 표준과 비교 | 현재 recipe와 표준값의 차이 확인 | 탭 제목의 `⚠`가 보이면 먼저 비교하여 차이 항목을 확인합니다. |

## 4. Contact / 촬영 Z / Glass ID 사용 방법

| 항목 | 역할 | 사용 방법 및 주의사항 |
|---|---|---|
| ContactX | contactor의 X 위치 | 실제 Contact 위치에서 **현재값 읽기**로 기록한 뒤, 필요 시 `컨택 위치로 이동`으로 검증합니다. |
| OD (um) | contact flow에 전달하는 OD 값 | 실제 contact 조건과 일치하는 승인값을 사용합니다. 코드상 입력 범위 제한이 없으므로 임의 변경하지 않습니다. **[추론]** |
| Y1/Y2 촬영 Z | 각 검사 unit camera의 촬영 높이 | 현재 Z 위치 읽기로 teach할 수 있습니다. 0 이하 또는 미설정이면 검사 준비에서 오류가 날 수 있습니다. **[추론]** |
| Glass ID Unit | ID를 읽을 camera unit 선택 | Unit1/Y1 또는 Unit2/Y2 중 실제 ID reader가 설치된 쪽을 선택합니다. |
| Glass ID StageX/UnitY | ID 판독 전에 이동할 위치 | 해당 위치에서 ID가 안정적으로 보이는지 실제 이동으로 확인합니다. |

## 5. 권장 작업 순서

1. 탭 제목의 `⚠` 표시와 **표준과 비교**를 확인합니다.
2. 표준값을 사용해야 하면 **표준 가져오기**를 실행합니다.
3. Align image에서 template/search 영역과 match threshold를 확인합니다.
4. 최대 반복·허용 오차는 검증된 recipe 표준값을 사용합니다.
5. 정확한 Align 기준 위치로 장비를 이동한 상태에서 **현재값 읽기**를 실행합니다.
6. **Align 위치 이동**으로 저장값이 실제 목표 위치로 이동하는지 확인합니다.
7. ContactX, Capture Z, Glass ID pose도 각각 실제 위치에서 읽고 이동 검증합니다.
8. recipe를 저장합니다.

## 6. 주의사항

- StageX/UnitY/U/V/W/ContactX/Z 값은 실제 축 이동이나 촬영 높이에 영향을 줍니다. 장비 한계를 모르는 상태에서 수치를 입력하지 않습니다.
- `현재값 읽기`는 단순 조회가 아니라 현재 설비 위치를 recipe 기준값으로 저장하는 기능입니다.
- 템플릿과 탐색 영역은 pixel 좌표입니다. 설비 축 단위(µm)와 혼동하지 않습니다.
- 표준 가져오기는 recipe 값을 덮어쓸 수 있고, 표준 내보내기는 공통 기준을 변경할 수 있습니다.
- 공식 문서상 `ForbidStageXMoveWhileContact=true`는 반드시 유지해야 하는 제어 규칙입니다. 이 값은 현재 이 탭에 직접 노출되지 않습니다.
