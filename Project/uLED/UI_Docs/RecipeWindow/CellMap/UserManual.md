# RecipeWindow - 셀 맵 탭 사용자 매뉴얼

## 1. 화면 목적

셀 맵 탭은 현재 recipe에 등록된 검사 Cell을 글래스 모양 위에서 확인하는 화면입니다. Cell의 배치, 이름, 검사 포함 여부, 담당 IP를 한눈에 확인하고 특정 Cell을 선택하거나 검사 대상에서 제외/복구할 수 있습니다.

## 2. 화면에서 보이는 내용

| 화면 표시 | 의미 |
|---|---|
| 글래스 외곽선 | 현재 GlassSize 기준의 글래스 영역입니다. 꺾인 모서리는 cut mark 방향을 나타냅니다. **[추론]** |
| Cell 사각형 | 현재 실행 Cell의 위치와 크기입니다. |
| Cell 이름 | Cell의 표시 이름입니다. 사용자명이 있으면 그 이름이 우선 사용됩니다. |
| 붉은 계열 Cell | IP1 담당 Cell입니다. **[추론]** |
| 푸른 계열 Cell | IP2 담당 Cell입니다. **[추론]** |
| 회색 대각선 해치 Cell | `Use`가 해제된 검사 제외 Cell입니다. **[추론]** |
| 주황색 테두리 | 현재 선택된 Cell입니다. **[추론]** |
| 화살표 | 장비 설정의 glass 투입 방향입니다. **[추론]** |
| NO GLASS 표시 | Control 상태가 글래스 미존재로 전달된 경우의 상태 표시입니다. **[추론]** |

## 3. 컨트롤 사용 방법

| 컨트롤 | 역할 | 사용 방법 |
|---|---|---|
| Cell 선택 모드 (Use 토글) | 맵 클릭의 목적을 선택 또는 Use 변경으로 전환 | 체크를 끄면 Cell 클릭은 선택입니다. 체크를 켜면 클릭한 Cell의 Use가 반전됩니다. Use를 바꿀 때만 켭니다. **[추론]** |
| 전체 사용/해제 | 모든 Cell을 한 번에 검사 포함/제외 | 클릭 후 확인합니다. 모든 Cell이 사용 중이면 전체 제외, 하나라도 제외 상태면 전체 사용으로 바뀝니다. **[추론]** |
| 미리보기 새로 고침 | 최신 recipe 상태를 맵에 반영 | 셀 목록에서 이름/IP/Use/좌표를 바꾸거나 Cell을 재생성한 뒤 누릅니다. |
| 맵의 Cell | 선택 또는 Use 변경 대상 | 현재 모드에 따라 동작이 다르므로, 클릭 전 Cell 선택 모드 체크 상태를 확인합니다. |

## 4. Cell 선택 방법

1. **Cell 선택 모드** 체크를 해제합니다.
2. 맵에서 원하는 Cell 사각형을 클릭합니다.
3. 클릭한 Cell에 주황색 테두리가 나타나는지 확인합니다.
4. 셀 목록 탭 등에서 같은 Cell 행이 선택됩니다. 이후 선택 Cell 이동, CA410, 에이징 테스트 같은 기능의 대상이 될 수 있습니다. **[추론]**

## 5. 검사 대상 제외/복구 방법

1. 제외 또는 복구할 Cell을 맵에서 찾습니다.
2. **Cell 선택 모드 (Use 토글)**를 체크합니다.
3. 해당 Cell을 클릭합니다.
4. 회색 대각선 해치가 나타나면 검사 제외(Unuse), 해치가 사라지면 검사 포함(Use) 상태입니다. **[추론]**
5. 여러 Cell을 바꾼 뒤에는 필요하면 셀 목록 탭의 `사용` 열로 결과를 다시 확인합니다.
6. 작업이 끝나면 오조작 방지를 위해 Cell 선택 모드를 해제합니다.

## 6. 사용 순서 권장

1. Cell map 생성/재생성 및 IP 배정을 완료합니다.
2. 셀 맵 탭에서 Cell 배치와 IP 색상을 확인합니다.
3. 제외할 Cell만 토글 모드로 Unuse 처리합니다.
4. 일반 모드로 돌아와 필요한 Cell을 선택합니다.
5. Cell을 수정한 뒤에는 **미리보기 새로 고침**으로 최신 상태인지 확인합니다.
6. 최종 Use/IP 상태를 셀 목록 탭에서도 교차 확인하고 recipe를 저장합니다.

## 7. 주의사항

- 토글 모드가 켜진 상태에서 Cell을 클릭하면 선택되지 않고 Use 상태가 바뀝니다. 의도하지 않은 검사 제외를 막기 위해 작업 후 토글 모드를 끕니다. **[추론]**
- 맵은 실행용 `Cells`를 표시합니다. 설계 원본 Cell map을 수정하는 화면은 별도 Coordinate Editor/CellMap 보정 화면일 수 있습니다. **[추론]**
- 붉은색/푸른색은 IP 배정을 보여 주는 표시입니다. 색상만 보고 실제 장비 연결 상태까지 정상이라고 판단하지 않습니다. **[추론]**
- 화면을 크게 보이게 하는 `ZoomFactor` 값은 현재 control 렌더링에 반영되지 않는 것으로 확인됩니다. 확대/축소 효과를 기대하지 말고 창 크기 조절을 사용합니다. **[코드 차이]**
