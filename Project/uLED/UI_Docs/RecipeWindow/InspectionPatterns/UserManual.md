# RecipeWindow / 검사 패턴 탭 사용자 매뉴얼

> 적용 화면: `RecipeWindow > 검사 패턴`  
> 주의: ROI는 선택 Pattern 전용이 아니라 모든 Pattern이 공유하는 현재 공통 ROI입니다.
>
> 표기 규칙: 공식 Docs에 없는 현재 프로그램 구현 세부는 `[추론] (코드 확인)`으로 표시합니다.

## 1. 화면 목적

검사 패턴 탭에서는 다음을 설정합니다.

- R/G/B/W 검사 Pattern의 이름과 종류
- PG 출력 전압
- 카메라 Timeout, Exposure, Gain
- 점 검출 Threshold와 Blob 크기 조건
- 정상 밝기와 A/B/C/D 등급 판정 기준
- 여러 Pattern이 함께 사용할 공통 검사 조건
- 실제 검사에 사용할 공통 ROI

## 2. 화면 영역

| 영역 | 사용 목적 |
|---|---|
| 상단 버튼 | Pattern 추가/삭제, 공통 파라미터 편집 |
| 검사 패턴 목록 | 모든 Pattern을 비교하고 선택 |
| 선택된 패턴 | 선택 Pattern의 상세값 편집 |
| 검사 ROI | 모든 Pattern이 공유하는 ROI 좌표와 크기 편집 |

## 3. 먼저 알아야 할 용어

| 용어 | 의미 |
|---|---|
| Pattern | R/G/B/W 점등과 촬영·검사 조건 한 세트 |
| Point | 촬영 위치와 ROI를 가진 실행 위치 |
| ROI | 원본 이미지에서 실제 검사할 사각 영역 |
| 공통 파라미터 | 여러 Pattern에 동일하게 적용할 검사 조건 |
| Blob | Threshold를 통과해 하나의 연결 영역으로 묶인 밝은 점 후보 |
| 정상레벨 | 정상점 밝기를 비교하기 위한 기준값 |
| Grade | 측정 밝기에 따라 결정되는 A/B/C/D 등급 |

공식 운영 기준에서 실행은 `Pattern × Point` 조합입니다. 현재 Point는 사실상 하나의 공통 ROI로 사용됩니다.

## 4. 검사 패턴 목록 사용법

### 4.1 번호

Pattern 식별 번호입니다. 운영 가이드는 0부터 시작하는 번호를 권장합니다.

- 같은 번호가 두 개이면 Validate/Save가 실패합니다.
- 번호는 전압과 공통 설정을 연결하는 key로도 사용됩니다.
- `[추론] (코드 확인)` 번호를 직접 바꾸면 연결된 전압 번호가 자동으로 함께 바뀌지 않아 Validate 실패나 잔여 데이터가 생길 수 있습니다. 번호 직접 변경 대신 기존 Pattern을 삭제하고 다시 구성하는 절차를 권장합니다.

### 4.2 이름

Pattern을 식별하는 표시 이름입니다. 로그와 검사 결과를 알아보기 쉽게 `R`, `G`, `B`, `W` 또는 설비 표준 이름을 사용하십시오.

### 4.3 종류

선택지는 `R`, `G`, `B`, `W`입니다.

- R/G/B는 해당 채널의 점을 검출하고 좌표를 구성합니다.
- W는 RGB에서 이미 정한 좌표를 사용해 밝기를 측정합니다.
- W를 사용하려면 RGB Pattern이 최소 하나 필요합니다.

### 4.4 R/G/B 전압

PG가 Pattern을 점등할 때 각 채널에 적용할 전압입니다.

- 단위는 V입니다.
- 장비별 허용 범위는 이 화면에서 제한하지 않으므로 Config와 PG 사양을 먼저 확인하십시오.
- 잘못된 전압은 밝기·색·점등 상태에 직접 영향을 줍니다.

### 4.5 노출(us)

카메라 노출 시간입니다.

공식 권장 절차:

1. 외부 카메라 Live 화면에서 실제 점등 영상을 확인합니다.
2. 정상점이 포화되지 않고 어두운 점도 구분되는 노출을 찾습니다.
3. 확정한 값을 이 화면의 `노출(us)`에 입력합니다.

### 4.6 공통 사용

체크하면 해당 Pattern의 검사 조건을 공통값으로 맞춥니다.

- 체크 즉시 공통값이 해당 Pattern에 복사됩니다.
- 공통 관리 항목은 회색으로 흐려지고 편집할 수 없습니다.
- 이름, 종류, 전압, Timeout, Exposure, Gain은 공통값 대상이 아닙니다.
- 체크를 끄면 현재 복사된 값을 시작점으로 다시 개별 편집할 수 있습니다.

## 5. 선택된 패턴 상세값

### 5.1 Timeout / 노출 / Gain

| 값 | 역할 | 설정 시 주의 |
|---|---|---|
| Timeout(ms) | protocol/model의 Pattern timeout 값 | 실제 wait/cancel 소비처와 현장 의미 추가 확인 필요 |
| 노출(us) | 카메라 센서가 빛을 받는 시간 | 너무 크면 포화, 너무 작으면 어두운 점 누락 |
| Gain | 카메라 신호 증폭 | 높이면 신호와 노이즈가 함께 커질 수 있음 |

공식 Docs에는 Timeout과 Gain의 공통 허용 범위가 없습니다. 카메라와 현장 Recipe 기준을 사용하십시오.

### 5.2 임계값

Blob 검출을 위한 밝기 기준입니다.

입력 예:

- 단일값: `30`
- 여러 후보: `20, 25, 30`

여러 후보를 입력하면 각 값으로 검출한 뒤 공식 점수식이 가장 좋은 결과를 자동 선택합니다. 점수가 같으면 더 높은 Threshold가 선택됩니다.

배경 평탄화를 사용하는 현재 검사에서는 공식 최신 현장 기록의 보수적 권장 범위가 20~30입니다. 이 값은 장비·노출·영상에 따라 달라지므로 실제 영상과 검사 결과로 확인해야 합니다.

`[추론] (코드 확인)` 입력 처리:

- 음수는 사용하지 마십시오.
- 숫자가 아닌 항목은 무시될 수 있습니다.
- 유효한 숫자가 하나도 없으면 기존값이 유지될 수 있습니다.
- 쉼표 사용을 권장합니다. 코드상 세미콜론도 처리하지만 공식 UI 예시는 쉼표입니다.

### 5.3 면적 최소/최대

Blob의 pixel 면적 범위입니다.

- 최소값을 키우면 작은 노이즈를 제거하지만 작은 정상점도 사라질 수 있습니다.
- 최대값을 줄이면 서로 붙은 큰 Blob을 제거하지만 큰 정상점도 제외될 수 있습니다.
- `최소 >= 0`, `최대 >= 최소`를 지키십시오.

### 5.4 Blob 폭/높이 최소/최대

Blob 사각 경계의 폭과 높이 범위입니다.

- 최소 폭/높이는 0보다 커야 합니다.
- 최대 폭은 최소 폭 이상이어야 합니다.
- 최대 높이는 최소 높이 이상이어야 합니다.
- 가늘게 늘어난 노이즈나 여러 점이 합쳐진 Blob을 제외할 때 사용합니다.

### 5.5 정상레벨 기준 상위 %

정상 밝기의 기준 위치를 정합니다. 범위는 0~50입니다.

중요: 상위 N%의 평균값이 아닙니다.

- 상위 10% 입력 → 내부적으로 P90 위치의 level을 기준으로 사용
- 상위 20% 입력 → 내부적으로 P80 위치의 level을 기준으로 사용

값을 작게 하면 더 높은 밝기 쪽을 정상 기준으로 삼게 됩니다. 값 변경은 전체 점의 상대 ratio와 grade 분포를 바꿀 수 있으므로 검사 결과를 반드시 비교하십시오.

### 5.6 절대값

체크하지 않음:

- `측정값 / 정상레벨 × 100` 비율로 grade를 판정합니다.
- A/B/C 입력은 %입니다.

체크함:

- A/B/C 입력을 0~255 gray level 절대값으로 해석합니다.
- 정상레벨 기준 상위 %는 사용하지 않아 입력이 잠깁니다.

### 5.7 등급 A/B/C 기준

판정 순서는 다음과 같습니다.

1. 값이 A 기준 이상이면 A
2. 아니고 B 기준 이상이면 B
3. 아니고 C 기준 이상이면 C
4. 그보다 작으면 D

항상 `A >= B >= C` 순서로 입력하십시오.

공식 알고리즘 문서의 기본값과 현재 프로그램 코드 기본값이 서로 다릅니다.

| 기준 | A | B | C | D |
|---|---:|---:|---:|---:|
| 공식 알고리즘 문서 | 90 | 50 | 30 | 20 |
| 현재 코드의 새 Pattern 기본 | 50 | 30 | 10 | 별도 입력 없음 |

따라서 새 Pattern의 자동값을 현장 표준으로 간주하지 말고, 승인된 Recipe 기준을 확인하십시오.

## 6. 개별값과 공통값을 사용하는 방법

### 6.1 Pattern별로 다르게 설정

1. 목록에서 Pattern을 선택합니다.
2. `공통 파라미터 사용`을 끕니다.
3. 임계값, 면적, Blob, 정상레벨/절대값, Grade를 입력합니다.
4. 다른 Pattern을 선택해 같은 방법으로 반복합니다.

### 6.2 여러 Pattern에 같은 조건 적용

1. 상단 `공통 파라미터...`를 누릅니다.
2. 공통 임계값, 정상레벨 또는 절대값, Grade, 면적, Blob 범위를 입력합니다.
3. `닫기`를 누릅니다.
4. 목록에서 공통값을 사용할 Pattern의 `공통 사용`을 체크합니다.
5. 목록과 상세 영역에 같은 값이 표시되고 편집이 잠기는지 확인합니다.

`[추론] (코드 확인)` 공통 창에는 별도 저장/취소가 없습니다. 입력값은 같은 Recipe 편집 데이터에 바로 들어가며, `닫기`는 변경 취소가 아닙니다.

공통 파라미터 창 컨트롤:

| 항목 | 역할 | 주의 |
|---|---|---|
| 임계값 | 공통 Threshold 또는 후보 목록 | 공통창 tooltip의 “object 최다” 설명은 최신 병합 감점 규칙을 생략한 과거 표현 |
| 정상레벨 기준 | 공통 Reference Top % | 절대값 모드에서는 비활성 |
| 절대값 | 공통 grade를 0~255 gray level로 해석 | normal percentile 미사용 |
| 등급 A/B/C | 공통 grade 경계 | `A >= B >= C` 유지 |
| 불량 판정 기준 등급 | 레거시 `DefectCutoffGrade` | 최신 판정 정본은 grade→type→선택 defect type이므로 현재 검사 기준으로 단정 금지 |
| 면적 최소/최대 | 공통 connected component 면적 필터 | 최소/최대 관계 확인 |
| Blob 폭 최소/최대 | 공통 Blob 폭 필터 | 최소/최대 관계 확인 |
| Blob 높이 최소/최대 | 공통 Blob 높이 필터 | 최소/최대 관계 확인 |
| 닫기 | 창 닫기와 공통 사용 Pattern 화면 재반영 | 취소/rollback 버튼이 아님 |

### 6.3 공통값을 시작점으로 복사한 뒤 개별 조정

1. 대상 Pattern을 선택합니다.
2. `공통 값 복사해 오기`를 누릅니다.
3. `공통 파라미터 사용`이 꺼져 있는지 확인합니다.
4. 복사된 값을 Pattern별로 조정합니다.

이 버튼은 공통 사용을 켜지 않고 현재 시점의 공통값만 복사합니다.

## 7. 검사 ROI 설정

### 7.1 숫자로 직접 입력

| 입력 | 의미 |
|---|---|
| ROI X | 원본 이미지에서 좌측 시작 위치 |
| ROI Y | 원본 이미지에서 상단 시작 위치 |
| ROI 폭 | 검사 영역 가로 크기 |
| ROI 높이 | 검사 영역 세로 크기 |

폭과 높이는 반드시 0보다 커야 합니다.

### 7.2 이미지를 보며 설정

1. IP에 검사 Pattern 이미지를 준비합니다.
2. RecipeWindow 상단 `창 > 이미지 창`을 누릅니다.
3. 이미지 창의 `IP > Preview Image` 또는 `IP > Original Image`로 영상을 확인합니다.
4. `ROI > Draw ROI`로 새 ROI를 그리거나 `ROI > Select ROI`로 기존 ROI를 선택합니다.
5. 필요하면 `ROI > Stop Draw`로 그리기 모드를 끝냅니다.
6. 검사 패턴 탭으로 돌아와 X/Y/폭/높이를 확인합니다.
7. Validate 후 저장합니다.

현재 검사 패턴 탭 안의 `이미지 창 열기`와 `현재 위치 적용` 버튼은 화면에 표시되지 않습니다. 상단 `창 > 이미지 창`을 사용하십시오.

`[추론] (코드 확인)` 다중 Point Recipe에서는 검사 패턴 탭이 첫 Point ROI를 표시하고 이미지 창은 현재 `SelectedPoint` ROI를 편집합니다. 공식 운영은 단일 Point 기준이므로, 다중 Point를 사용한다면 이미지 창의 선택 Point와 탭의 첫 Point를 혼동하지 마십시오.

### 7.3 ROI 변경 영향

- ROI를 옮기면 실제 검사 위치가 이동합니다.
- ROI를 넓히면 검사 대상과 처리량이 늘 수 있습니다.
- ROI를 줄이면 panel 일부가 검사에서 빠질 수 있습니다.
- ROI와 display pixel map/pitch가 맞지 않으면 ROI-map 불일치 Light Alarm이 발생할 수 있습니다.
- Pattern을 바꾸어도 ROI는 바뀌지 않습니다.
- `[추론] (코드 확인)` IP는 경계를 벗어난 ROI를 영상 안으로 clamp/clip하지만, 이는 잘못된 설정을 올바른 ROI로 보장하는 기능이 아닙니다.

## 8. Pattern 추가

1. `패턴 추가`를 누릅니다.
2. 새 행이 선택되는지 확인합니다.
3. 번호, 이름, 종류, PG 전압을 확인합니다.
4. Timeout/Exposure/Gain을 설정합니다.
5. 개별 또는 공통 검사 조건을 설정합니다.
6. Validate를 실행합니다.

`[추론] (코드 확인)` 현재 코드가 넣는 초기값:

| 항목 | 초기값 |
|---|---:|
| 번호 | 기존 최대 번호 + 1 |
| 이름 | `Pattern {번호+1}` |
| PG Pattern 번호 | `번호+1` |
| Timeout | 3000 ms |
| Exposure | 1000 µs |
| Gain | 1.0 |
| Threshold | 30 |
| 면적 | 16~400 |
| Blob 폭/높이 | 1~1000 |
| R/G/B 전압 | 각각 4.5 V |

이 값들은 입력 편의를 위한 코드 기본값이며 승인된 공정값이 아닙니다.

## 9. Pattern 삭제

1. 삭제할 행을 선택합니다.
2. `패턴 삭제`를 누릅니다.
3. 확인창의 Pattern 번호와 이름을 확인합니다.
4. 삭제가 맞으면 승인합니다.

`[추론] (코드 확인)` 번호를 직접 변경하지 않은 정상 상태에서는 삭제 시 Pattern 본체뿐 아니라 같은 번호의 전압과 공통 사용 설정도 함께 제거됩니다. 번호 key가 이미 어긋난 상태에서는 잔여 전압이 남을 수 있습니다. 기본 선택은 취소 방향입니다.

마지막 Pattern까지 삭제하면 Validate/Save가 실패합니다.

## 10. 저장 전 점검 절차

1. Pattern이 최소 하나 있는지 확인합니다.
2. Pattern 번호 중복이 없는지 확인합니다.
3. W가 있다면 RGB Pattern도 있는지 확인합니다.
4. Exposure/Gain과 PG 전압을 실제 장비 기준으로 확인합니다.
5. Threshold와 Blob 범위를 확인합니다.
6. Grade가 `A >= B >= C`인지 확인합니다.
7. ROI 폭과 높이가 0보다 큰지 확인합니다.
8. 실제 이미지에서 ROI가 panel을 올바르게 포함하는지 확인합니다.
9. `파일 > 유효성 검사`를 실행합니다.
10. 공식 절차에 따라 저장 후 IP에 Upload/Activate합니다. 현재 코드 차이는 아래 설명을 확인하십시오.
11. 수동 검사로 검출 수와 Grade 분포를 확인합니다.

`[추론] (코드 확인)` 현재 RecipeWindow의 Validate는 공식 문서에 정의된 세부 범위를 모두 검사하지 않을 수 있습니다. “검증 성공”만으로 Threshold, Grade, 전압이 공정에 적합하다고 판단하지 마십시오.

공식 문서는 Upload와 Activate를 구분해 안내합니다. `[추론] (코드 확인)` 현재 IP 구현은 Recipe를 업로드받으면 즉시 current recipe로 설정하므로 별도 Activate 단계가 보이지 않습니다. 현장 배포 버전의 동작을 확인하고, 공식 운전 절차는 임의로 생략하지 마십시오.

## 11. 문제 발생 시 확인

| 증상 | 우선 확인 |
|---|---|
| 점이 너무 적게 검출됨 | ROI, Exposure, Threshold 과다, MinArea/Min W/H 과다 |
| 노이즈가 많이 검출됨 | Exposure/Gain 과다, Threshold 과소, MinArea/Min W/H 과소 |
| 여러 점이 하나로 합쳐짐 | Threshold, MaxArea, Max W/H |
| Grade가 전체적으로 낮음 | Exposure, 정상레벨 기준, A/B/C 값, 절대값 체크 상태 |
| 공통 사용 Pattern 값을 수정할 수 없음 | 정상 동작. 공통 사용을 끄거나 공통창에서 수정 |
| ROI 숫자가 Pattern 선택 후에도 같음 | 정상 동작. ROI는 선택 Pattern별 값이 아님 |
| 저장 실패 | 최소 Pattern/Point, index 중복, ROI W/H 양수 확인 |
| 공통창 닫기를 눌렀는데 취소되지 않음 | 정상 동작. 별도 취소/rollback이 없는 공유 편집 방식 |

## 12. 주의사항

- Pattern과 CA410 측정 Pattern은 별도 계획입니다.
- 공통 설정을 바꾸면 공통 사용 중인 여러 Pattern에 영향을 줍니다.
- ROI 변경은 모든 검사 Pattern에 영향을 줍니다.
- 새 Pattern 기본값과 공식 알고리즘 기본값의 차이를 반드시 확인하십시오.
- 전압과 카메라 값은 장비 허용 범위를 확인한 후 입력하십시오.
- 승인된 Recipe는 변경 전 백업하고, 변경 후 실제 영상과 검사 결과로 검증하십시오.
