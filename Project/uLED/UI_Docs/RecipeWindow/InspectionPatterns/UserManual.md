# RecipeWindow / 검사 패턴 탭 사용자 매뉴얼

## 화면 목적

검사 패턴 탭은 R/G/B/W 등 각 검사 Pattern의 조명·카메라 입력·Blob 검출·등급 판정 조건을 설정하는 화면입니다. ROI는 현재 공통 Point 기준으로 함께 관리합니다.

## 기본 사용 순서

1. 상단 목록에서 수정할 Pattern을 선택합니다.
2. 선택된 패턴 영역에서 이름, 노출, Gain, 검사 기준을 확인합니다.
3. 같은 조건을 여러 Pattern에 적용할 경우 `공통 파라미터 사용`을 켭니다.
4. 공통값을 수정하려면 `공통 파라미터...`를 엽니다.
5. 필요하면 오른쪽 `검사 ROI`의 X/Y/폭/높이를 수정합니다.
6. `파일 > 유효성 검사` 후 저장합니다.

## 패턴 추가와 삭제

- `패턴 추가`: 새 Pattern을 추가합니다. 추가 후 이름, 종류, 전압, 노출, 검사 기준을 확인하십시오.
- `패턴 삭제`: 선택된 Pattern을 삭제합니다. 삭제 전 해당 Pattern이 실제 검사/PG/CA410 조건에서 사용되는지 확인하십시오.

## 개별 설정과 공통 설정

### 개별 설정

`공통 파라미터 사용`을 끈 Pattern은 다음 값을 개별적으로 편집합니다.

- 임계값
- Blob 면적과 폭/높이 범위
- 정상레벨 기준 상위 %
- 절대값 모드
- A/B/C 등급 기준

### 공통 설정

1. 대상 Pattern의 `공통 파라미터 사용`을 켭니다.
2. 상단 `공통 파라미터...`를 클릭합니다.
3. 공통 임계값, 정상레벨 기준 또는 절대값 모드, grade, Blob 필터를 입력합니다.
4. `닫기`를 누릅니다.
5. 창을 닫으면 공통 사용 Pattern들에 값이 반영됩니다.

공통 사용 중인 Pattern은 목록과 상세 영역의 공통 관리 값이 잠겨 있습니다.

## 정상레벨과 등급 설정

- `정상레벨 기준 상위 %`: 정상 밝기를 계산할 때 사용할 상위 영역입니다.
- `절대값`: 체크하면 정상 밝기 대비 비율 대신 gray level 절대값으로 등급 기준을 해석합니다.
- `등급 A/B/C 기준 %`: 각 등급의 하한값입니다.

절대값 모드에서는 정상레벨 기준 상위 %가 사용되지 않아 입력이 잠깁니다.

## ROI 설정

오른쪽 `검사 ROI`에서 X, Y, 폭, 높이를 입력합니다. 이 값은 현재 공통 Point의 ROI입니다.

이미지를 보면서 ROI를 조정하려면 현재 탭의 버튼이 아니라 RecipeWindow 상단 `창 > 이미지 창`을 사용합니다. 공식 가이드의 이미지/ROI 조정 절차를 따르십시오.

## 주의 사항

- 노출은 외부 카메라 Live 프로그램에서 먼저 확정한 뒤 `노출(us)`에 입력합니다.
- Pattern과 Point의 실제 실행 단위는 `Pattern × Point`입니다.
- 공통 설정을 변경하면 공통 사용 중인 모든 Pattern에 영향을 줍니다.
- `공통 값 복사해 오기`는 공통값을 현재 선택 Pattern에 복사합니다.
- [추론] 공통값을 변경한 뒤 창을 닫기 전에 다른 검사 작업을 실행하면 아직 모든 Pattern에 반영되지 않았을 수 있으므로, 공통 창을 닫고 적용 상태를 확인한 뒤 Validate/Save 하십시오.
