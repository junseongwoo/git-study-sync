# ConfigWindow - Heads 탭 사용자 매뉴얼

## 이 탭에서 하는 일

Heads 탭은 Y1/Y2 검사 헤드가 어떤 카메라를 쓰고, Align 후 검사 카메라·CA410이 어느 위치로 이동하며, 어떤 Z 높이에서 안전하게 촬영·측정할지를 설정합니다. 잘못 설정하면 검사 위치 오차뿐 아니라 헤드 간섭 위험이 생길 수 있으므로 장비 셋업 권한자가 설정해야 합니다.

## 설정 전 안전 확인

- 검사 진행 중에는 값을 변경하거나 저장하지 마십시오.
- 축 이동은 저속·수동 확인 상태에서 수행하십시오.
- `Read Axis`/`Read`는 현재 위치를 읽어오는 기능입니다. 축을 원하는 티칭 위치에 먼저 이동해야 합니다.
- Y1=Right/CAM1, Y2=Left/CAM2의 대응을 현장 장비 명칭과 대조하십시오.
- Z 값은 공식 안전 관계인 `Idle Z <= Capture Z <= Measure Z`를 유지하십시오.

## 1. Head Mapping 설정

| 항목 | 사용 방법 | 주의사항 |
|---|---|---|
| Y1 Align Camera | Y1 Align 카메라의 실제 이름을 입력합니다. | 기본 CAM1입니다. 카메라 프로그램의 `UserDefinedName`과 철자·대소문자를 포함해 일치시켜야 합니다. |
| Y2 Align Camera | Y2 Align 카메라의 실제 이름을 입력합니다. | 기본 CAM2입니다. Y1과 바꾸어 입력하지 마십시오. |
| Contact Check Cam | 컨택 확인 전용 카메라 이름을 입력합니다. | 기본 CAM3입니다. Camera Viewer가 이 카메라를 사용 중이면 Contact Check가 시작되지 않을 수 있습니다. |

## 2. Align Camera Geometry 설정

이 표는 Align 영상에서 보인 pixel 오차를 실제 축 보정량으로 바꾸기 위한 카메라 교정 정보입니다. 값의 의미를 모르는 상태에서 수정하지 마십시오.

| 항목 | 설정 방법 | 바꾸면 생기는 영향 |
|---|---|---|
| Camera Name | 위 Head Mapping에 입력한 카메라 이름과 동일하게 입력합니다. | 이름이 다르면 해당 카메라 geometry를 올바르게 적용하지 못할 수 있습니다. |
| Pixel X/Y (um) | 카메라 배율과 해상도를 기준으로 1 pixel의 실제 길이를 입력합니다. 0을 입력하지 마십시오. | 값이 크면 동일한 영상 오차에 대한 축 보정량도 커집니다. |
| +StageX Img UX/UY | Stage X를 +방향으로 작게 이동시킨 뒤 영상에서 관찰되는 방향을 기준으로 입력합니다. | X 보정 방향을 결정합니다. 부호가 반대면 Align 이동도 반대가 됩니다. |
| +Y1 Img UX/UY | Y1을 +방향으로 작게 이동시킨 뒤 영상에서 관찰되는 방향을 기준으로 입력합니다. | Y 보정 방향을 결정합니다. 대각 성분까지 포함하므로 축이 영상에 기울어져 있으면 두 값을 모두 교정해야 합니다. |

저장하면 방향 벡터는 자동으로 길이 1의 벡터로 정리됩니다. 따라서 벡터에는 크기가 아니라 방향을 입력합니다.

## 3. Align 기준 Offset 설정

모든 offset은 **Glass 0deg, 해당 Y 모듈의 Align 카메라 기준**입니다.

### Inspect X / Y

1. Align 카메라로 기준 마크를 중앙에 맞춥니다.
2. 같은 기준 마크가 검사 카메라 중심에 오도록 축을 이동합니다.
3. 그 차이를 해당 Y1 또는 Y2의 Inspect X/Y에 입력합니다.
4. 저장 후 단일 셀로 촬영 중심이 맞는지 검증합니다.

이 값을 바꾸면 해당 헤드가 검사할 모든 셀의 검사 카메라 위치가 함께 바뀝니다. 한 셀만 틀어진 문제가 아니라면 이 값을 우선 확인합니다.

### CA410 Y

1. Align 기준점에서 CA410 측정 중심까지 이동합니다.
2. 해당 Y 헤드의 Y 방향 차이를 CA410 Y에 입력합니다.
3. CA410 단일 측정 위치를 저속으로 검증합니다.

CA410 Y는 CA410 위치에만 영향을 줍니다. 현재 구현은 CA410 X에 Inspect X를 함께 사용하므로, CA410 X 중심이 맞지 않으면 담당 개발자에게 별도 교정 지원을 요청하십시오.

### Escape Y

1. 반대 헤드와 간섭하지 않는 Y 위치로 해당 헤드를 이동합니다.
2. `Read Axis`를 눌러 현재 위치를 가져옵니다.
3. Escape Y Tolerance에는 이 위치를 escape 상태로 인정할 허용 오차를 입력합니다.

Escape Y는 검사 대상이 없는 헤드를 안전 위치로 물리는 기준입니다. 임의의 0 또는 소프트리밋 근처 값을 입력하지 마십시오.

## 4. Z 높이와 대기 시간 설정

| 항목 | 권장 티칭 위치 | 실제 사용 시점 |
|---|---|---|
| Idle Z | Escape Y 영역에서 다른 축을 움직여도 안전한 높이 | 안전/회피 이동 직전 |
| Capture Z | 검사 카메라의 초점과 작업 거리를 만족하는 높이 | 일반 이동 및 카메라 촬영 직전 |
| Measure Z | CA410이 정상적으로 측정하는 높이 | CA410 측정 직전 |
| Capture Z Settle Delay | Capture Z 이동 뒤 영상이 안정될 때까지의 시간 | 검사 촬영 직전 대기 |
| Measure Z Settle Delay | Measure Z 이동 뒤 계측이 안정될 때까지의 시간 | CA410 측정 직전 대기 |

각 Z 입력칸의 `Read` 버튼으로 현재 Z를 읽어옵니다. Capture Z는 레시피에서 별도 높이를 지정한 경우 그 레시피 값이 우선할 수 있으므로, 카메라 높이가 예상과 다르면 RecipeWindow의 Align / 제어 설정도 확인하십시오.

## 5. 저장 후 검증 순서

1. 카메라 이름과 DataGrid의 Camera Name 일치 여부를 확인합니다.
2. Y1, Y2 각각에서 작은 이동으로 Align 보정 방향을 확인합니다.
3. 기준 마크 하나에서 검사 카메라 중심을 확인합니다.
4. 같은 기준 마크에서 CA410 측정 중심을 확인합니다.
5. Escape Y 이동 시 Idle Z가 먼저 확보되는지 확인합니다.
6. 저속 단일 셀 검사와 CA410 측정을 실행합니다.
7. 이상이 없을 때에만 양산 검사에 적용합니다.

## 문제 발생 시 빠른 점검

| 현상 | 확인할 설정 |
|---|---|
| Align 이동이 반대 | 방향 벡터, 카메라 이름 |
| 검사 위치가 전체적으로 일정 방향으로 어긋남 | Inspect X/Y |
| CA410 위치만 어긋남 | CA410 Y, Inspect X |
| 촬영 초점/흔들림 문제 | Capture Z, Capture Z Settle Delay, 레시피 Capture Z |
| CA410 결과 반복성 문제 | Measure Z, Measure Z Settle Delay |
| 회피 이동이 위험하거나 불필요하게 많음 | Escape Y, Idle Z, Escape Y Tolerance |
