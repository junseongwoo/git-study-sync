# Glass Size Model - 시작 선택창 사용자 매뉴얼

## 이 창의 역할

`Tool > Glass Size Model`을 선택하면 먼저 이 창이 나타납니다. 여기서는 편집할 Glass Size Model을 정합니다. Glass Size Model은 제품의 크기, 방향, Align 기준, 셀 좌표와 Motion 계산에 영향을 주는 중요한 운영 데이터입니다.

## 버튼별 사용 방법

|버튼|언제 사용하나요?|결과|
|---|---|---|
|Recipe 모델 열기|현재 열어 둔 Recipe가 사용하는 Glass Size 값을 수정할 때|현재 Recipe의 모델 ID에 해당하는 운영 JSON을 편집 창으로 엽니다.|
|운영 모델 선택|다른 제품 모델을 확인하거나 편집할 때|운영 라이브러리 목록에서 모델을 직접 선택한 뒤 편집 창으로 엽니다.|
|새 모델|새 제품/글래스 규격을 등록할 때|파일명, 설명, 복사 원본을 입력하는 새 모델 창을 엽니다.|
|취소|작업을 시작하지 않을 때|Glass Size Model 편집 창도 닫습니다.|

## 권장 절차

1. `Recipe Model` 행에서 현재 Recipe가 참조하는 모델 ID를 확인합니다.
2. 현재 Recipe의 기준값을 수정하는 작업이면 `Recipe 모델 열기`를 누릅니다.
3. 다른 제품 모델을 다룰 때는 `운영 모델 선택`을 누르고 ID, Description, Width/Height, Panel Angle, Align 정보를 확인합니다.
4. 새 제품이면 `새 모델`을 누르고 File Name을 제품 식별자로 입력합니다.
5. 본 편집 창에서 변경 후 저장할 때, 현재 Recipe에 적용할지 묻는 메시지가 나오면 대상 모델 ID를 다시 확인합니다.
6. 모델 변경·적용 뒤에는 Cell Map, Align 기준, 좌표 계산 결과를 확인합니다.

## 새 모델 창 사용 방법

|입력 항목|사용 방법|
|---|---|
|File Name|필수입니다. 운영 JSON 파일명과 `GlassSizeId`가 됩니다. OS 파일명 금지 문자는 사용할 수 없고, 이미 같은 이름이 있으면 만들 수 없습니다.|
|Desc|모델의 용도·제품 정보를 기록합니다. 필수값은 아닙니다.|
|Copy From Model|유사 제품의 치수·기준·보정 정보를 출발점으로 쓸 때 선택합니다.|
|Target Path|입력한 File Name으로 저장될 예상 위치를 보여 줍니다. 직접 수정할 수 없습니다.|

`Create`는 새 모델 초안을 편집 창에 만드는 단계입니다. **[추론: 현재 코드]** 실제 운영 JSON 파일 반영은 본 편집 창의 Save 작업이 필요합니다.

## 주의 사항

- `Recipe 모델 열기`가 회색으로 비활성화되면, 현재 Recipe에 모델이 없거나 해당 운영 모델 파일을 찾지 못한 상태입니다.
- 시작 선택창의 `운영 모델 선택`은 현재 코드상 선택 모델을 **편집 대상으로 여는 동작**입니다. 선택창의 “Apply to Recipe” 문구만으로 Recipe가 즉시 바뀐 것으로 판단하지 마세요.
- 외부 JSON은 이 창에서 가져오지 않습니다. 본 편집 창의 파일 메뉴 `외부 JSON 가져오기`를 사용하세요.
- Glass Size Model의 값 변경은 Cell 좌표, Align 기준, Motion 좌표 계산에 영향을 줄 수 있습니다. 생산 Recipe에 적용하기 전에는 반드시 검증하세요.
- 파일명은 모델의 식별자입니다. 임시 이름보다 안정적인 제품/규격 ID를 사용하세요.

## 문제 해결

|상황|확인 방법|
|---|---|
|Recipe 모델 열기 버튼이 비활성화됨|현재 Recipe의 GlassSizeId와 운영 라이브러리 파일 존재 여부를 확인합니다.|
|운영 모델을 골랐는데 Recipe가 바뀐 것 같지 않음|정상일 수 있습니다. 이 진입 경로는 편집 대상을 여는 단계이며, Recipe 적용은 별도 저장·적용 흐름에서 확인합니다.|
|새 모델 Create가 비활성화됨|File Name이 비어 있지 않은지, 금지 문자가 없는지, 같은 이름의 파일이 없는지 확인합니다.|
|모델 JSON을 가져오고 싶음|시작창을 닫지 말고 본 GlassSizeWindow의 파일 메뉴에서 외부 JSON 가져오기를 사용합니다.|
