# RecipeFolderBrowserWindow 사용자 매뉴얼

## 레시피 열기 화면

| 컨트롤 | 역할 | 사용 방법 |
|---|---|---|
| Size Model 목록 | Glass Size별 레시피 분류 | 원하는 Glass Size를 선택합니다. 모든 레시피를 보려면 `전체 (All)`을 선택합니다. |
| 검색 입력칸 | 레시피 빠른 검색 | 레시피 이름, 설명, Glass Size ID 또는 경로 일부를 입력합니다. |
| 레시피 목록 | 열 레시피 선택 | 이름과 설명을 확인해 선택합니다. 더블 클릭하면 바로 열립니다. |
| 상태 표시줄 | 결과 개수 또는 선택 경로 확인 | 선택 전에는 레시피 수, 선택 후에는 실제 `recipe.json` 경로를 확인합니다. |
| 폴더 열기 | 레시피 폴더를 탐색기로 열기 | 선택한 레시피의 관련 파일을 확인할 때 사용합니다. |
| 열기 | 선택 확정 | 선택 후 누릅니다. |
| 취소 | 작업 취소 | 선택/입력 내용을 적용하지 않고 닫습니다. |

## 레시피 저장 화면

| 컨트롤 | 역할 | 사용 방법 |
|---|---|---|
| Glass Size ID | 레시피의 상위 분류 선택 | 기존 목록에서 선택하거나 승인된 Glass Size ID를 입력합니다. |
| 레시피 이름 | 새 레시피 폴더명 입력 | 식별하기 쉬운 이름을 입력합니다. 빈 값은 허용되지 않습니다. |
| 저장 경로 | 실제 저장 예정 위치 확인 | 자동 계산된 경로가 의도한 Glass Size/레시피 이름인지 확인합니다. 직접 편집할 수 없습니다. |
| 폴더 열기 | 대상의 상위 폴더 확인 | 대상 폴더가 이미 존재할 때만 열립니다. 새 경로의 폴더 생성 기능은 아닙니다. |
| 저장 | 경로 선택 확정 | 실제 파일 저장은 다음 단계에서 이루어질 수 있습니다. |

## 주의사항

- 이 창은 레시피 삭제·이름 변경 기능을 제공하지 않습니다.
- Open 목록에 보이는 항목도 파일이 손상됐을 수 있으므로, 열기 실패 메시지가 나오면 해당 폴더의 `recipe.json`을 확인하십시오.
- 저장 시 기존 레시피와 같은 이름을 사용할 경우 덮어쓰기 여부는 다음 저장 단계에서 확인하십시오.
