# Auto Align 기능 설명

## 1. 기능 목적

`AutoAlignWindow`는 CAM2 한 대로 Align1과 Align3을 차례로 촬영하고 Glass의 회전 오차인 Theta를 자동으로 보정하는 TEST 화면이다.

이번에 확정한 기준은 다음과 같다.

- Align3는 사용자가 위치를 입력하는 Mark가 아니다.
- Align3는 Align1에서 Glass +Y 방향으로 430mm 떨어진 고정 Mark다.
- CamY2는 Align1 위치에 고정한다.
- Align3을 촬영할 때 StageX만 이동한다.
- Align1과 Align3의 영상 중심을 비교해 Theta를 구한다.
- Theta를 Glass 중심 기준 UVW 이동량으로 바꿔 회전한다.
- 재촬영하고 남은 Theta가 허용오차에 들어올 때까지 반복한다.

기존 `AlignWindow`와 `AlignViewModel`은 변경하지 않는다.

---

## 2. 430의 단위

장비 프로그램의 좌표 단위는 `um`이다.

```text
430mm = 430000um
```

코드에서는 다음 상수를 사용한다.

```csharp
private const double Align3GlassDistanceUm = 430000.0;
```

따라서 화면에서 Align3 StageX를 따로 입력하거나 Glass Size Model에 저장하지 않는다.

---

## 3. Align3 Glass 좌표

Align1 Glass 좌표를 `(Align1X, Align1Y)`라고 하면 Align3 좌표는 다음과 같다.

```text
Align3 Glass X = Align1 Glass X
Align3 Glass Y = Align1 Glass Y + 430000um
```

현재 `370x470_Model`의 예시는 다음과 같다.

```text
Align1 Glass = (170000, -220000)um
Align3 Glass = (170000,  210000)um

Y 차이 = 210000 - (-220000)
       = 430000um
       = 430mm
```

Glass X가 같기 때문에 CAM2 calibration이 정상이라면 CamY2는 변하지 않는다. Glass Y만 변하므로 StageX만 움직인다.

---

## 4. Align3 StageX 자동 계산

계산은 `AutoAlignViewModel.BuildSetup`에서 한다.

### 4.1 Align1 좌표 읽기

다음 값을 읽는다.

- Align1 Glass 좌표
- 기존 Align1 StageX 절대 위치
- 기존 Align1 CamY2 절대 위치
- CAM2 affine calibration

### 4.2 Align3 Glass 좌표 만들기

```csharp
var mark3Glass = new UmPoint(
    mark1Glass.X,
    mark1Glass.Y + Align3GlassDistanceUm);
```

사용자 입력값 없이 Align1에서 정확히 430mm 떨어진 좌표를 만든다.

### 4.3 Glass 좌표를 장비 축 좌표로 변환

```csharp
BridgeAxisTarget mark1Axis = ToBridgeAxes(mark1Glass);
BridgeAxisTarget mark3Axis = ToBridgeAxes(mark3Glass);
```

`ToBridgeAxes`는 CAM2 calibration으로 Glass 좌표를 CamY2와 StageX 장비 좌표로 변환한다.

### 4.4 CamY2 고정 가능 여부 확인

```text
CamY2 변화량 = Align3 계산 CamY2 - Align1 계산 CamY2
```

CamY2 변화량이 10um보다 크면 CamY2를 고정한 채 Align3을 볼 수 없는 calibration이라는 뜻이다. 이 경우 장비를 움직이기 전에 실패 처리한다.

### 4.5 StageX 목표 계산

```text
StageX 이동량 = Align3 계산 StageX - Align1 계산 StageX

Align3 StageX 목표
= 기존에 등록된 Align1 StageX
+ StageX 이동량
```

현재 확인한 calibration에서는 Glass Y와 StageX가 1:1이므로 다음 결과가 나온다.

```text
StageX 이동량 = +430000um
Align3 StageX = Align1 StageX + 430000um
```

단순히 절대 좌표 `430000`으로 이동하는 것이 아니다. 현재 Align1 StageX 위치에서 430mm에 해당하는 이동량을 더한 절대 목표로 이동한다.

---

## 5. 장비 이동 순서

```text
1. 기존 Align 기준 위치로 이동
2. StageX와 CamY2가 Align1 위치인지 확인
3. Align1 촬영
4. StageX만 계산된 Align3 위치로 이동
5. StageX 도착 확인
6. Align3 촬영
7. StageX만 Align1 위치로 복귀
8. StageX 복귀 확인
```

`MoveStageXAsync`가 보내는 이동 명령에는 다음 한 축만 들어 있다.

```csharp
new AxisMove
{
    Axis = Axis.StageX,
    Mode = MoveMode.Abs,
    Value = stageXUm
}
```

`Axis.InspectionUnit2Y`, 즉 CamY2 이동 명령은 만들지 않는다.

---

## 6. 기준 이미지

Auto Align에는 정상 정렬 상태에서 저장한 기준 이미지 두 개가 필요하다.

| Mark | 파일 | 설명 |
|---|---|---|
| Align1 | `align_left.png` | Align1 정상 중심 |
| Align3 | `align_mark3.png` | Align3 정상 중심 |

Align3 기준 이미지를 등록할 때도 CamY2는 고정하고 StageX만 자동 계산 위치로 이동한다.

기준 이미지는 정상 정렬 상태에서 등록해야 한다. 틀어진 현재 이미지를 기준 이미지로 저장하면 틀어진 위치가 정상 위치로 인식된다.

---

## 7. 영상 중심을 Stage 편차로 변환

Align1과 Align3은 각각 기준 이미지와 Template Matching한다.

```text
Pixel X 편차 = 현재 중심 X - 기준 중심 X
Pixel Y 편차 = 현재 중심 Y - 기준 중심 Y
```

`ToStageDelta`가 카메라 Pixel Size와 영상 속 Stage 축 방향을 사용해 Pixel 편차를 Stage X/Y의 `um` 편차로 바꾼다.

촬영 실패 후 이전 이미지가 화면에 남아 있으면 그 이미지를 새 촬영 결과로 사용하지 않는다.

---

## 8. Theta 계산

Theta 계산은 `AlignMarkPairThetaEstimator.Calculate`에서 한다.

### 8.1 정상 기준선

Align1과 Align3 Glass 좌표에 `PanelAngle`을 적용해 기존 Align과 같은 Stage 좌표 방향으로 바꾼다.

```text
기준선 X = Align3 정상 Stage X - Align1 정상 Stage X
기준선 Y = Align3 정상 Stage Y - Align1 정상 Stage Y
```

### 8.2 두 영상의 상대 편차

```text
상대 편차 X = Align3 영상 편차 X - Align1 영상 편차 X
상대 편차 Y = Align3 영상 편차 Y - Align1 영상 편차 Y
```

Glass 전체가 같이 밀린 X/Y 값은 서로 빼는 과정에서 제거된다. 남는 값은 두 Mark를 연결한 선의 기울기 변화다.

### 8.3 기존 선형식

```text
Theta radian
= (기준선 X × 상대 편차 Y - 기준선 Y × 상대 편차 X)
  ÷ 기준선 길이 제곱
```

작은 각도에서 기존 Align 결과와 비교하기 위한 방식이다.

### 8.4 간단 atan2 식

```text
현재선 X = 기준선 X + 상대 편차 X
현재선 Y = 기준선 Y + 상대 편차 Y

cross = 기준선 X × 현재선 Y - 기준선 Y × 현재선 X
dot   = 기준선 X × 현재선 X + 기준선 Y × 현재선 Y

Theta radian = atan2(cross, dot)
```

`cross`의 부호로 회전 방향을 구하고 `dot`으로 두 선이 같은 방향을 향하는 정도를 구한다.

## 9. Theta를 돌리고 맞추는 코드

실제 반복 보정은 `AutoAlignViewModel.RunAsync`의 `while`문에서 실행한다.

### 9.1 현재 Theta 측정

```csharp
AlignThetaMeasurement measurement = await MeasurePairAsync(setup, method);
```

이 메서드는 Align1 촬영, Align3 촬영, Align1 복귀, Theta 계산을 순서대로 실행한다.

### 9.2 허용오차 확인

```csharp
if (Math.Abs(measurement.ThetaDeg) <= ToleranceThetaDeg)
{
    완료 처리
}
```

예를 들어 허용오차가 `0.005deg`라면 `+0.003deg`와 `-0.004deg`는 완료이고 `+0.010deg`는 보정 대상이다.

### 9.3 Theta를 UVW로 변환

```csharp
UvwDelta move = _uvwConverter.ToUvw(
    new XytDelta(0.0, 0.0, measurement.ThetaDeg),
    uvwParameters);
```

X와 Y는 `0`이고 Theta만 전달한다. 따라서 이 TEST 기능은 평행이동이 아니라 Glass 중심 회전만 보정한다.

`CenterPivotUvwConverter`는 각 UVW 축의 회전 계수를 사용한다.

```text
U = U축 회전 계수 × Theta radian
V = V축 회전 계수 × Theta radian
W = W축 회전 계수 × Theta radian
```

### 9.4 U/V/W 상대 이동

`MoveUvwAsync`는 다음 명령을 보낸다.

```text
StageU = 계산된 U, 상대 이동
StageV = 계산된 V, 상대 이동
StageW = 계산된 W, 상대 이동
```

기존 Align과 동일하게 측정된 `+Theta`를 UVW 변환기에 전달한다.

### 9.5 재촬영과 반복

한 번의 이동만으로 완벽하게 맞는다고 가정하지 않는다.

```text
Align1 촬영
→ StageX 430mm 위치 이동
→ Align3 촬영
→ StageX Align1 복귀
→ Theta 계산
→ UVW 회전
→ 다시 Align1부터 촬영
```

잔여 Theta가 허용오차 안에 들어오면 성공한다. 이전 측정보다 Theta가 1.5배 이상 커지면 방향이나 calibration 문제로 보고 발산 오류를 발생시킨다. 최대 보정 횟수 안에 수렴하지 않아도 중단한다.

## 10. 기존 AlignWindow와 차이

| 구분 | 기존 AlignWindow | AutoAlignWindow TEST |
|---|---|---|
| Mark | Align1 + Align2 | Align1 + 고정 Align3 |
| 카메라 | CAM1 + CAM2 | CAM2 한 대 |
| Align3 위치 | 해당 없음 | Align1에서 Glass +Y 430mm |
| 촬영 이동 | 기존 두 카메라 위치 | StageX만 이동 |
| CamY2 | 기존 방식 | Align1 위치 고정 |
| 보정 | Theta 후 X/Y | Theta만 |
| UVW 변환 | CenterPivotUvwConverter | 같은 변환기 |

---

## 11. 실패 조건

- Align1 Glass 좌표가 없음
- 고정 430mm로 만든 Align3 좌표가 선택한 Glass 범위를 벗어남
- Align1 StageX 또는 CamY2 위치가 없음
- CAM2 calibration이 없음
- 430mm 이동 계산 결과 CamY2가 고정되지 않음
- 계산된 기준선이 너무 짧음
- 기준 이미지 또는 ROI가 없음
- 새 촬영 이미지가 없음
- Match Score가 낮음
- Align1과 Align3의 측정 거리 차이가 큼
- StageX 이동 또는 복귀 실패
- UVW 이동 실패
- Theta 발산
- 최대 보정 횟수 초과

각 단계와 계산 결과는 Auto Align 전용 로그에 남긴다.

---

## 12. 실장비 확인 사항

1. 계산 로그의 `GlassDistance`가 `430000um`인지 확인한다.
2. `StageXMove`가 현재 장비에서 `+430000um`으로 계산되는지 확인한다.
3. 계산된 Align3 StageX가 안전 이동 범위인지 확인한다.
4. Align1과 Align3 촬영 사이에 CamY2 실제 위치가 변하지 않는지 확인한다.
5. Align3 촬영 후 StageX가 Align1 위치로 복귀하는지 확인한다.
6. 작은 Theta에서 UVW 회전 부호가 맞는지 확인한다.
7. UVW 보정 후 재측정 Theta가 작아지는지 확인한다.

실장비에서 Theta가 커지면 반복 실행하지 말고 카메라 방향과 UVW 회전 계수를 먼저 확인해야 한다.
