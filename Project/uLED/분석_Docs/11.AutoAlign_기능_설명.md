# Auto Align 기능 설명

## 1. 목적

`AutoAlignWindow`는 CAM2 한 대로 Align1과 Align3을 순서대로 촬영하고 두 점의 기울기를 계산하여 UVW Theta를 자동 보정하는 TEST 화면이다.

기존 `AlignWindow`와 `AlignViewModel`은 변경하지 않는다.

---

## 2. Align3 위치

Align3는 이름이 바뀌지 않는 고정점이다. 따라서 사용자가 입력하는 Mark ID는 없다.

Align3는 Align1과 Align2의 위치를 사용하지 않는다. 다음 두 위치를 별도로 입력한다.

- Align3 Stage X 위치
- Align3 CamY2 위치

두 값은 모두 장비 절대 좌표이며 단위는 `um`이다.

```text
Glass Size Model
└─ AlignMarks
   └─ Align3
      ├─ StageXUm
      └─ CamY2Um
```

저장 형태 예시는 다음과 같다.

```json
{
  "alignMarks": {
    "leftAlignUm": {
      "x": -100000,
      "y": 0
    },
    "rightAlignUm": {
      "x": 100000,
      "y": 0
    },
    "align3": {
      "stageXUm": 250000,
      "camY2Um": 420000
    }
  }
}
```

`AutoAlignWindow`의 `위치 저장` 버튼을 누르면 현재 Recipe가 선택한 Glass Size Model에 두 값을 저장한다.

값이 없을 때 다른 좌표에서 계산하거나 기본값으로 대체하지 않는다. 두 값 중 하나라도 없으면 Auto Align을 중단한다.

---

## 3. 기준 이미지

Align1과 Align3 Auto Align에는 기준 이미지가 2개 필요하다.

| 구분 | 파일 | 설명 |
|---|---|---|
| Align1 | `align_left.png` | 정상 정렬 상태의 Align1 기준 이미지 |
| Align3 | `align_mark3.png` | 정상 정렬 상태의 Align3 기준 이미지 |

기존 Align1과 Align2 기능까지 함께 사용하면 시스템 전체에는 Align1, Align2, Align3 기준 이미지 3개가 필요하다.

기준 이미지는 Glass가 정상적으로 정렬된 상태에서 등록한다.

자동 Align을 실행할 때마다 기준 이미지를 다시 저장하면 안 된다. 틀어진 현재 이미지를 기준 이미지로 덮어쓰면 틀어진 위치가 새로운 정상 기준이 되기 때문이다.

---

## 4. Align1과 Align3 위치 관계

Align1은 기존 Align 기준 위치를 사용한다.

- Align1 Stage X
- Align1 CamY2

Align3는 Auto Align 전용으로 입력한 위치를 사용한다.

- Align3 Stage X
- Align3 CamY2

두 위치는 서로 달라도 된다.

```text
Align1 위치
  Stage X = X1
  CamY2   = Y1

Align3 위치
  Stage X = X3
  CamY2   = Y3
```

Stage X와 CamY2 입력값은 장비를 움직이는 절대 위치다.

Theta 계산에서는 모터 좌표를 영상의 Stage 편차와 바로 섞지 않는다. Align3의 Stage X와 CamY2를 CAM2 좌표 Calibration으로 Glass 좌표로 되돌린 뒤 Panel Angle을 적용하여 기존 Align과 같은 Stage 좌표계 기준선을 만든다.

```text
Align3 Stage X와 CamY2
  ↓ CAM2 좌표 Calibration 역변환
Align3 Glass 좌표
  ↓ Panel Angle 적용
Align3 Stage 계산 좌표
```

두 위치 사이의 거리가 너무 짧으면 작은 영상 오차에도 계산 각도가 크게 흔들릴 수 있으므로 실행을 중단한다.

## 5. 실행 순서

### 5.1 실행 전 확인

다음 항목을 확인한다.

- Align3 기능 사용 여부
- Align3 Stage X 위치
- Align3 CamY2 위치
- Align1 기준 이미지
- Align3 기준 이미지
- Template ROI
- Search ROI
- Match Threshold
- 최대 보정 횟수
- 최소 기준선 길이
- CAM2 연결 상태
- Control Runtime 연결 상태

### 5.2 Align1 위치 이동

기존 Align 기준 위치로 이동한다.

이때 Stage X와 CamY2는 기존 Align1 위치가 된다.

### 5.3 Align1 촬영

CAM2로 Align1을 촬영하고 `align_left.png`와 비교한다.

```text
현재 Align1 이미지
  ↓ Template Matching
Pixel X/Y 편차
  ↓ Camera Geometry
Stage 단위 편차
```

카메라 Pixel 편차는 Pixel Size와 카메라 방향 설정을 이용하여 `um` 단위로 변환한다.

촬영 API가 실패했는데 이전 이미지가 화면에 남아 있는 경우에는 이전 이미지를 새 촬영 결과로 사용하지 않고 실패 처리한다.

### 5.4 Align3 위치 이동

Glass Size Model에 저장된 두 절대 위치로 이동한다.

```text
Stage X → Align3 StageXUm
CamY2   → Align3 CamY2Um
```

두 축을 함께 이동하고, 이동 응답을 받은 뒤 실제 축 위치를 다시 읽는다.

목표 위치와 실제 위치 차이가 허용값보다 크면 촬영하지 않고 실패 처리한다.

### 5.5 Align3 촬영

CAM2로 Align3을 촬영하고 `align_mark3.png`와 비교한다.

Align3의 영상 편차도 `um` 단위 Stage 편차로 변환한다.

### 5.6 Align1 위치 복귀

Align3 촬영이 끝나면 두 축을 모두 Align1 위치로 복귀시킨다.

```text
Stage X → Align1 Stage X
CamY2   → Align1 CamY2
```

Align3 촬영이나 Matching에 실패해도 Align1 복귀를 시도한다.

## 6. Theta 계산

기존 Align과 같은 Stage 좌표계에서 정상 상태의 기준선을 만든다.

```text
기준선 = 변환된 Align3 Stage 좌표 - Align1 Stage 좌표
```

영상에서 찾은 두 Mark의 편차 차이를 계산한다.

```text
편차 차이 X = Align3 편차 X - Align1 편차 X
편차 차이 Y = Align3 편차 Y - Align1 편차 Y
```

Align1과 Align3에 공통으로 발생한 이동은 서로 빼는 과정에서 제거된다. 남은 상대적인 차이로 두 점 사이의 회전 오차를 계산한다.

### 기존 선형식

기존 Align에서 사용하는 작은 각도 계산식이다.

```text
Theta = 기준선과 편차 차이의 외적 ÷ 기준선 길이 제곱
```

작은 회전각에서 계산이 간단하고 기존 Align 결과와 비교하기 쉽다.

### 간단한 atan2 방식

기준선과 현재 측정선 사이의 실제 각도를 `atan2`로 계산한다.

기존 선형식보다 큰 각도에서도 수학적으로 안정적이다.

---

## 7. UVW 보정

계산된 Theta는 Glass 중심 회전용 UVW 파라미터를 이용하여 U, V, W 상대 이동량으로 변환한다.

```text
Theta 오차
  ↓
UVW 변환
  ↓
U, V, W 상대 이동
```

UVW 이동 후 다시 Align1과 Align3을 촬영한다.

잔여 Theta가 허용 오차 안에 들어올 때까지 같은 과정을 반복한다.

```text
Align1 촬영
  ↓
Align3 위치 이동 및 촬영
  ↓
Align1 위치 복귀
  ↓
Theta 계산
  ↓
UVW 보정
  ↓
재측정
```

---

## 8. 실패 조건

다음 경우 UVW 보정을 중단하고 실패 로그를 남긴다.

- Align3 Stage X가 입력되지 않음
- Align3 CamY2가 입력되지 않음
- Align1 또는 Align3 기준 이미지가 없음
- ROI가 설정되지 않음
- Match Score가 기준보다 낮음
- Align1과 Align3 사이 거리가 너무 짧음
- 촬영 실패 후 이전 이미지가 그대로 남음
- Align1과 Align3의 측정 거리 차이가 허용값보다 큼
- CAM2 Live 정지 실패
- Stage X 이동 실패
- CamY2 이동 실패
- Align1 위치 복귀 실패
- UVW 이동 실패
- 보정 후 Theta가 계속 커짐
- 최대 보정 횟수 안에 수렴하지 않음

---

## 9. 버튼 하나로 실행하는 최종 흐름

운영용 버튼은 다음 흐름으로 구성할 수 있다.

```text
자동 Align 및 위치 등록
  1. 설정 확인
  2. Align1 위치 이동
  3. Align1 촬영
  4. Align3 Stage X와 CamY2로 이동
  5. Align3 촬영
  6. Align1 Stage X와 CamY2로 복귀
  7. Theta 계산
  8. UVW 보정
  9. 재촬영 및 잔여 오차 확인
  10. 성공한 최종 U, V, W 위치 읽기
  11. 최종 위치 등록
```

기준 이미지 등록과 자동 Align 위치 등록은 분리해야 한다.

- 기준 이미지 등록: 최초 셋업 또는 카메라 조건 변경 시
- 자동 Align 및 위치 등록: 저장된 기준 이미지로 보정한 후 성공한 축 위치만 저장

## 10. 현재 구현 범위

현재 구현된 항목은 다음과 같다.

- 사용자 입력 Mark ID 제거
- Align3 Stage X 전용 입력
- Align3 CamY2 전용 입력
- 두 값을 Glass Size Model에 저장
- Align1과 Align3 순차 촬영
- Align3 촬영 시 Stage X와 CamY2 동시 이동
- 촬영 후 Stage X와 CamY2를 Align1 위치로 복귀
- 기존 선형식 Theta 계산
- atan2 Theta 계산
- Theta를 UVW 이동량으로 변환
- 반복 보정 및 실패 확인
- 주요 단계 로그 기록

기존 `AlignWindow` 실행과 동일하게 적용한 핵심 기준은 다음과 같다.

- 동일한 Camera Geometry 방식으로 Pixel 편차를 Stage 편차로 변환
- Glass 좌표와 Panel Angle을 적용한 Stage 기준선 사용
- 측정된 `+Theta`를 기존 UVW 변환기에 전달
- UVW 이동 후 재촬영하여 잔여 오차 확인
- 낮은 Match Score에서는 UVW를 움직이지 않음

두 기능의 목적 차이는 다음과 같다.

- 기존 AlignWindow: Align1과 Align2를 동시에 촬영하여 Theta와 X/Y를 모두 보정
- AutoAlignWindow TEST: CAM2로 Align1과 Align3를 순차 촬영하여 Theta만 보정

아직 구현되지 않은 다음 단계는 아래와 같다.

- 성공한 최종 U, V, W 축 위치를 Align 기준 위치로 확정 저장
- 자동 Align 완료 후 Recipe 또는 장비 설정 저장
- X/Y 평행이동 보정

현재 TEST 기능은 `Align1-Align3 Theta 자동 보정`까지 수행한다.

## 11. 실장비 확인 사항

- Align3 Stage X가 실제 안전 이동 범위 안에 있는지 확인
- Align3 CamY2가 실제 안전 이동 범위 안에 있는지 확인
- 두 축 동시 이동 시 간섭이 없는지 확인
- Align3 촬영 후 Align1 위치로 정상 복귀하는지 확인
- 작은 UVW Theta를 사용하여 보정 부호 확인
- 기존 선형식과 atan2 결과 비교
- 반복 보정 시 Theta가 감소하는지 확인
