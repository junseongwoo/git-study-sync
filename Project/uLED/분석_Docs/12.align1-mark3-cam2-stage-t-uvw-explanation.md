Align1-Mark3 CAM2 좌표, Stage 변환, T 및 UVW 계산 설명
작성 목적: 코드 수정 내역이 아닌 Align 계산 원리와 코드 동작 이해
대상: 370 x 470 mm Glass, CAM2 단일 순차 측정 기준

==============================================================
1. 전체 흐름 요약
==============================================================

CAM2 촬영
   ↓
Mark 중심 검출 결과 (Pixel)
   ↓
기준 이미지 중심과 비교하여 Pixel 오차 계산
   ↓
CAM2 Pixel → Stage X/Y 오차(um) 변환
   ↓
Mark1/Mark3의 기준 위치와 오차를 이용해 T 계산
   ↓
계산된 T를 Glass Center 회전 기준의 UVW 이동량으로 변환
   ↓
Stage U/V/W 상대 이동
   ↓
다시 CAM2 측정하여 잔여 T 확인

중요한 구분:
   - CAM2가 직접 제공하는 것은 Pixel 좌표다.
   - T 계산에 사용하는 값은 보정된 Stage 좌표(um)다.
   - UVW는 Glass Center를 회전 중심으로 하여 계산한다.

==============================================================
2. 좌표계의 종류
==============================================================

2.1 CAM2 이미지 좌표(Pixel)

   CAM2 화면 안에서 검출된 Mark 중심이다.
   예: Mark1 CurrentCenter = (1000, 800) pixel

   이 좌표의 X/Y 방향은 화면 방향이며 장비 Stage X/Y와 반드시 같지 않다.
   카메라가 회전되어 장착되었거나 Y 방향이 반대일 수 있다.

2.2 기준 이미지 좌표(Pixel)

   Align Mark를 정상 위치에서 촬영해 저장한 기준 이미지에서 검출된 중심이다.
   예: Mark1 ReferenceCenter = (1000, 800) pixel

   현재 촬영 중심이 (1005, 798)이면:

      Pixel 오차 = Current − Reference
                = (1005−1000, 798−800)
                = (+5, −2) pixel

   이것은 Glass 절대좌표가 아니라 기준 위치에서 벗어난 양이다.

2.3 Glass 좌표

   Glass 중심을 원점으로 한 도면 좌표다.
   370 x 470 Glass 예:

      Mark1 = (-170000, -220000) um
      Mark3 = (-170000, +173000) um
      Mark1→Mark3 도면 거리 = 393000 um

   이 좌표는 Mark가 Glass 위에서 원래 있어야 하는 위치를 나타낸다.

2.4 Stage 좌표

   실제 장비 축 방향 기준 좌표다.
   Glass가 PanelAngle만큼 회전되어 있으면 Glass 좌표를 Stage 좌표로 회전 변환한다.

      x_stage = x_glass*cos(a) - y_glass*sin(a)
      y_stage = x_glass*sin(a) + y_glass*cos(a)

   여기서 a는 PanelAngle이다.

2.5 UVW 좌표

   Glass를 지지하는 세 축의 이동 좌표다.
   T 회전은 한 축만 움직이는 것이 아니라 Glass Center 기준 회전을 만들기 위해
   U/V/W를 함께 상대 이동한다.

==============================================================
3. CAM2 Pixel을 Stage 좌표로 변환하는 이유
==============================================================

CAM2 Pixel 좌표를 그대로 Stage 좌표처럼 사용할 수 없는 이유:

   1) Pixel 단위와 Stage 단위가 다르다.
      - Pixel: 영상 좌표
      - Stage: um 단위 물리 좌표

   2) CAM2 화면의 X/Y 방향이 Stage X/Y 방향과 다를 수 있다.

   3) Pixel 1칸이 실제로 몇 um인지 PixelSize가 필요하다.

따라서 변환은 다음과 같다.

   Pixel 오차 (dx_pixel, dy_pixel)
      → CAM2 방향 벡터 투영
      → PixelSize 곱셈
      → Stage 오차 (dx_stage, dy_stage) um

개념식:

   stageX_pixel = dx_pixel*StagePlusXImageUnitX
                + dy_pixel*StagePlusXImageUnitY

   stageY_pixel = dx_pixel*StagePlusYImageUnitX
                + dy_pixel*StagePlusYImageUnitY

   stageX_um = stageX_pixel * pixelSizeUm
   stageY_um = stageY_pixel * pixelSizeUm

CAM2의 화면 좌우만 보고 +T/-T를 결정하면 안 된다.
반드시 CAM2 Pixel을 Stage 방향으로 변환한 뒤 Stage X/Y 부호를 사용한다.

==============================================================
4. CAM2 단일 순차 측정에서 Stage 이동의 의미
==============================================================

CAM2 한 대로 Mark1과 Mark3을 측정하려면 Mark3 위치로 Stage를 이동해야 한다.

   1) Stage 위치 S1에서 Mark1 촬영
   2) StageX를 D만큼 이동
   3) Stage 위치 S2에서 Mark3 촬영

   S2 = S1 + D

두 촬영 화면의 Pixel 좌표는 같은 CAM2 화면 형식을 사용하지만,
촬영 시점의 Stage 위치가 다르다.

따라서 절대 위치를 구하려면:

   Mark1 전역 Stage 위치 = S1 + PixelToStage(Mark1 Pixel)
   Mark3 전역 Stage 위치 = S2 + PixelToStage(Mark3 Pixel)

   Mark3−Mark1 = 실제 Stage 이동량 + Pixel 측정 오차

raw Pixel 좌표만 빼면 393mm 이동량이 포함되지 않는다.

단, 회전 오차만 구하는 간략 방식에서는 이미 D를 알고 있다고 보고,
Pixel 차이에서 남은 Stage X 오차만 계산하여 D로 나눈다.

==============================================================
5. T를 구하는 두 가지 방식
==============================================================

5.1 방식 A: 절대 2점 좌표 방식

각 Mark의 전역 Stage 좌표를 만든다.

   P1 = Mark1 전역 Stage 좌표
   P3 = Mark3 전역 Stage 좌표

   dx = P3.X − P1.X
   dy = P3.Y − P1.Y

기준선이 Stage Y 방향(수직)이라는 전제라면:

   thetaRad = atan2(dx, dy)
   thetaDeg = thetaRad * 180 / PI

이때 dx는 기준 수직선에서 벗어난 Stage X 성분이고,
dy는 실제 Mark1→Mark3 Stage 방향 거리다.

일반적인 기준선 방향에서도 계산하려면 기준 벡터 R과 측정 벡터 M을 사용한다.

   cross = R.X*M.Y − R.Y*M.X
   dot   = R.X*M.X + R.Y*M.Y

   thetaRad = atan2(cross, dot)

이 방식은 Mark1과 Mark3의 실제 전역 위치를 직접 사용한다.

5.2 방식 B: 잔여 오차 방식(Align3 DistanceOnly TEST 개념)

Stage를 D만큼 이동한 뒤 CAM2 화면에서 두 중심의 차이를 구한다.

   1) Mark1 CurrentCenter 측정
   2) StageX를 D만큼 이동
   3) Mark3 CurrentCenter 측정
   4) Pixel 중심 차이를 CAM2 보정으로 Stage 차이로 변환
   5) Stage X 잔여 오차를 D로 나눔

   thetaRad ≈ deltaX_stage / D
   thetaDeg = thetaRad * 180 / PI

작은 각도에서는:

   atan2(deltaX_stage, D) ≈ deltaX_stage / D

이 방식은 실제 393mm 전체 좌표를 복원하는 대신,
Stage 이동 후 남은 회전 오차만 사용하는 방식이다.

5.3 방식 C: 기준 오차를 사용하는 좌표 기반 방식

각 Mark별 Current−Reference 오차를 Stage로 변환한다.

   e1 = PixelToStage(Mark1 Current − Mark1 Reference)
   e3 = PixelToStage(Mark3 Current − Mark3 Reference)

두 Mark 오차의 차이:

   deltaE = e3 − e1

도면상의 Mark1/Mark3 기준 Stage 선분을 R이라고 하면:

   측정선 M = R + deltaE

   T = angle(R, M)

이 방식은 Mark별 Template 중심 차이를 줄이고,
Mark1과 Mark3의 실제 기준좌표를 함께 사용한다.

==============================================================
6. Mark1을 기준점으로 잡는다는 의미
==============================================================

Mark1을 기준점으로 잡는다는 것은 Mark1의 절대 Pixel 좌표 자체를
Glass 원점으로 사용한다는 뜻이 아니다.

정확한 의미는 다음과 같다.

   Mark1 측정값 = 기준점 또는 기준 오차 e1
   Mark3 측정값 = 비교점 또는 기준 오차 e3
   두 값의 차이  = Glass가 회전하면서 생긴 상대 오차

Glass 전체가 X 방향으로 같이 이동하면 Mark1과 Mark3 오차에 공통으로 들어가므로
두 오차를 빼면 공통 병진 성분이 줄어든다.

회전은 위치에 따라 오차가 달라진다.

   위쪽 Mark1: e1
   아래쪽 Mark3: e3
   회전 성분: e3−e1

따라서 T는 단순히 Mark3 하나의 X 오차만 보는 것이 아니라
두 Mark 오차의 차이를 본다.

==============================================================
7. 기존 AlignWindow의 실제 계산 개념
==============================================================

기존 AlignWindow 실제 Align은 CAM1/CAM2 두 카메라를 사용한다.

   CAM1 → Align Mark1
   CAM2 → Align Mark2

두 카메라가 같은 Align 위치에서 각 Mark를 촬영하고,
각 카메라에서 Current−Reference Stage 오차를 구한다.

   e1 = Mark1 Current−Reference → Stage
   e2 = Mark2 Current−Reference → Stage

그 후 Recipe의 Mark1/Mark2 Glass 좌표를 Stage 좌표로 변환하고,
두 Mark 기준선과 오차 차이를 이용해 T를 계산한다.

따라서 기존 AlignWindow는 CAM1/CAM2의 절대 Pixel 중심을 직접 연결하는 방식이 아니다.
각 Mark의 기준 대비 이동량을 Stage 오차로 바꾼 뒤 두 오차를 비교하는 방식이다.

기존 AlignWindow와 Align3의 핵심 차이:

   기존 AlignWindow:
      두 카메라, 같은 Stage 위치, 각 Mark Current−Reference

   Align3 기본 TEST:
      CAM2 한 대, Stage D 이동, 두 CurrentCenter 차이와 D 사용

   Align3 좌표 기반 TEST:
      CAM2 한 대, Stage D 이동, 각 Mark Current−Reference와
      알려진 Mark Glass 좌표 사용

==============================================================
8. Glass Center와 T 계산의 관계
==============================================================

T를 계산할 때 Glass Center를 직접 넣지 않아도 되는 이유:

   두 Mark의 상대 벡터를 사용하면 공통 원점 이동이 소거되기 때문이다.

즉 T 계산은:

   Mark3 위치 − Mark1 위치

라는 두 점의 상대관계가 핵심이다.

그러나 T를 실제 장비 축 이동으로 바꿀 때는 Glass Center가 반드시 필요하다.

   회전 보정은 Glass Center를 중심으로 발생해야 한다.

Glass Center를 원점으로 두면:

   각 Mark의 회전 이동량 = T × 중심으로부터의 위치 벡터

이 되고, 이를 Stage U/V/W 축의 이동량으로 분해한다.

정리:

   T 계산 단계       = Mark1/Mark3 상대 위치 중심
   UVW 변환 단계     = Glass Center 회전 중심

==============================================================
9. T를 UVW로 변환하는 방법
==============================================================

계산된 T를 바로 Stage W 하나로 보내는 것이 아니다.
Glass Center 기준 회전을 만들기 위해 U/V/W 세 축을 함께 움직인다.

개념적인 흐름:

   1) thetaDeg를 thetaRad로 변환
      thetaRad = thetaDeg * PI / 180

   2) Glass Center 기준 회전으로 각 축의 선형 이동량 계산

   3) U/V/W의 상대 이동값 생성

   4) StageU, StageV, StageW에 동시에 또는 같은 보정 명령으로 전송

현재 370 x 470 설정의 회전 계수는 개념적으로 다음 형태다.

   U ≈ Ku * thetaRad
   V ≈ Kv * thetaRad
   W ≈ Kw * thetaRad

현재 설정의 부호 관계:

   +T → U+, V−, W−
   −T → U−, V+, W+

또한 현재 설정에서는 +T를 CW, −T를 CCW 방향으로 해석한다.
장비의 실제 축 방향 설정이 바뀌면 이 부호 관계도 달라질 수 있다.

예시:

   측정 T = +0.010deg
   Align3 TEST 적용 비율 = 50%
   실제 적용 T = +0.005deg

그러면 +T에 해당하는 U+, V−, W− 방향의 UVW 상대 이동이 계산된다.

중요한 점:

   UVW 변환은 T의 부호를 새로 판단하는 단계가 아니다.
   T 계산 단계에서 정해진 부호를 현재 장비 설정에 맞춰
   U/V/W 이동량으로 바꾸는 단계다.

==============================================================
10. +T와 −T 보정 방향 확인
==============================================================

화면에서 Mark가 왼쪽 또는 오른쪽에 보이는 것만으로 부호를 결정하지 않는다.

판정 기준:

   1) CAM2 Pixel 오차를 Stage 좌표로 변환한다.
   2) deltaE = e3−e1을 계산한다.
   3) 기준선과 비교하여 T 부호를 얻는다.
   4) 현재 UVW 설정으로 T를 이동한다.
   5) 다시 측정한다.

보정 방향이 맞으면:

   abs(T_after) < abs(T_before)

보정 방향이 틀리면:

   abs(T_after) > abs(T_before)

예:

   +0.010deg → +0.005deg: 정상 수렴
   −0.010deg → −0.005deg: 정상 수렴
   +0.010deg → +0.015deg: 부호/UVW 방향 의심
   −0.010deg → −0.015deg: 부호/UVW 방향 의심

0도 근처에서 부호가 바뀌는 것은 정상일 수 있다.
부호보다 abs(T)가 허용오차 안에 들어왔는지를 우선 본다.

==============================================================
11. Align3 50% 반복 보정의 의미
==============================================================

Align3 TEST는 측정 T 전체가 아니라 50%만 적용한다.

   적용T = 측정T * 0.5

이론적으로 측정 오차가 완전히 정확하면:

   T0 = 0.0100deg
   T1 = 0.0050deg
   T2 = 0.0025deg
   T3 = 0.00125deg
   T4 = 0.000625deg

따라서 반복 보정으로 0.001deg 안에 들어갈 수 있다.

실제 반복에서 정체되는 경우:

   - CAM2 매칭 중심 노이즈
   - StageX 393mm 이동 반복오차
   - 백래시
   - 이동 후 정착 부족
   - Template 중심 바이어스
   - Mark1/Mark3 기준거리 설정 오차

393000um에서 0.001deg는 약 6.86um이다.
CAM2 PixelSize가 약 5.34um/pixel이면 약 1.28pixel이다.
따라서 1~2pixel 수준의 오차도 0.001deg 수렴을 방해할 수 있다.

==============================================================
12. 392mm와 393mm의 차이
==============================================================

도면상 Mark1→Mark3 거리가 393000um인데 TEST가 392000um이면:

   계산 거리 배율 차이 = 393000 / 392000 − 1
                       ≈ 0.255%

이 차이는 T 계산의 스케일을 조금 바꾸지만,
반복 보정을 전혀 수렴하지 못하게 만드는 주된 원인이라고 보기는 어렵다.

더 중요한 것은:

   - 실제 Stage 이동량이 입력 D와 같은가
   - Stage 이동 방향이 Mark1→Mark3 기준선과 일치하는가
   - Mark1/Mark3 중심 오차가 반복적으로 재현되는가

이다.

==============================================================
13. T 수렴 상태 해석
==============================================================

13.1 T가 계속 감소

   예: 0.010 → 0.005 → 0.0025 → 0.001

   - 보정 방향이 맞을 가능성이 높다.
   - 50% 보정이 정상적으로 작동한다.
   - 허용오차 안에서 반복을 종료한다.

13.2 T가 일정 값 아래에서 정체

   - 측정 노이즈
   - Stage 반복오차
   - Template 중심 바이어스
   - 이동 정착 부족
   - DistanceOnly 방식의 한계

   점검:
   - Stage를 움직이지 않고 같은 Mark를 5~10회 반복 측정
   - ROI 중심과 Template 등록 위치 확인
   - 이동 후 정착시간 확보
   - Known Coordinate 결과와 비교

13.3 T가 증가

   - 보정 부호 또는 UVW 방향이 반대일 가능성이 높다.
   - 추가 Jog를 중단한다.
   - e3−e1 순서, CAM2 Stage 방향 벡터, CW/CCW 설정,
     U/V/W 실제 +방향을 확인한다.

==============================================================
14. 최종 개념 정리
==============================================================

   CAM2는 Mark 중심을 Pixel로 찾는다.

   Pixel 좌표는 CAM2 보정값을 이용해 Stage X/Y 오차(um)로 변환한다.

   Mark1/Mark3의 Stage 오차 차이와 도면상 기준선을 이용해 T를 구한다.

   T 계산에는 Mark의 상대관계가 중요하고,
   UVW 이동에는 Glass Center가 회전 중심으로 필요하다.

   계산된 T의 부호는 현재 장비 설정의 CW/CCW 및 U/V/W 부호로 변환된다.

   보정 후 최종 판정은 다음 측정에서 abs(T)가 감소하는지로 한다.

   즉:

      CAM2 Pixel
         → Stage 오차
         → Mark1/Mark3 상대 회전각 T
         → Glass Center 기준 UVW
         → 재측정 및 수렴 확인
