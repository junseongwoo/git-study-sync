히프의 정의
히프를 구현하여 보자. 히프는 다원 배열로 표현될 수 있기 때문에 아래와 같이 히프의 각 요
소들~을 구조체 el에팥nt로 정의하고. element의 1자원 배열을 민들어 히프를 구현한다. 여기서
heap-size는 현재 히프 인에 저장된 요소의 개수이다.
#define MAX_ELEHENT 200
typedef struct {
int key;
} element;
typedef struct {
element heap[MAX_ELEHENT] •,
int heap_size;
} HeapType;
위의 정의를 이용하여 히프 heap를 생성하고 싶으면 다음과 같이 하면 된다.
HeapType heap;
또는 다음과 같이 동적으로 생성할 수도 있다.
HeapType *heap = create(); // 메모리 동적 할당을 이용한다.
