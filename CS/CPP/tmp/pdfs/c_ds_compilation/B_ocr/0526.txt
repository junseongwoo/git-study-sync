122.1 병합 정넓 동작 방식
병합 정열 알고리즘을 한마디로 요약하면 '나누고 합쳐라'입니다. 구체적으로는 다음과 같은 순서로
동-작합니다.
정일할 데이터를 반으로 나눕니다.
나원 하위 데이터의 크기가 2 이상이면 이 하위 데이터에 대해 단계 0을 반복합니다.
동일 데이터에서 나원 하위 데이터 물을 병합하여 원래대로 하나의 데이터로 만듭니다. 단. 병합할 때 데이터의
원소는 정일 기훼l 따라 정렬합니다.
0 데이터가 원래대로 모두 하나가 될 때까지 단계 0을 반복합니다.
어렵지 않지요? 병합 정렬은 살벌해 보이는 이름과 달리 상당히 간단한 알고리즘입니다. 다만 이 알
고리즘을 구현할 때 두 하위 데이터를 병합8는 부분에 관심을 조금 더 기울여야 할 필요는 있습니다. 병
합 정렬의 성능을 좌우하는 부분이기 때문입니다.
이제 알고리즘이 동작6는 과정을 보여주는 예제가 등장할 차례입니다. 우선 다음과 같이 정렬되지
않은 데이터가 있다고 가정하고 이를 병합 정렬해보겠습니다.
무엇을 먼저 해야 할까요? 네, 원래의 데이터를 반으로 나눠야 합니다. 그렇게 하려면 알고리즘의
단계를 반복해야 합니다. 다음 그림은 원본 데이터를 하위 데이터로 나누니기는 과정을 보여줍
다 원본 데이터 및 각 하위 데이터에서 보라색으로 표시된 요소는 데이터 중간에 위치한 기준점을
의미합니다.
