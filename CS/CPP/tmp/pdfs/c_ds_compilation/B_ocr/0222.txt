memmove( ) 함수
memmove( ) 함수는 C 언어 표준 함수이며 메모리의 내용을 이동시기는 기능을 수행합니다. 배열처럼 연속
된 데이터를 단번에 아동시길 때 이주 유용합니다. memmove( ) 함수 대신 순환문으로 대처말 수도 있습니
다만 성능이 훨씬 떨어집니다.
memmove( ) 함수의 첫 번째 매개 변수는 원본 데이터가 옮겨갈 새로운 메모리의 주최 두 번째 매개 변수는
원본 데이터가 있는 주최 세 번째는 이동시길 데이터의 양(byte)입니다. 이 함수와 비슷한 기능을 6는
로 메모리를 복사하는 memcpy( )가 있습니다. memmove( )가 원본 데이터를 대상 메모리 주木e •이동•시카
는 반면 memcpy( )는 원본 데이터를 대상 메모리 주소로 •복사•한다는 大삐를 빼면 사용 방법은 동일힙니다
