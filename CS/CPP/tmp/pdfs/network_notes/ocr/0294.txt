데이터 평면의 주요 성분이다.

따라 입력 랑그 인터페이스에서 출력 링크 인터페이스로 패킷을 전달하는 일반적인 패
것 교환 장비를 의미하는 패킷 스위치라는 용어 정의를 나중에 다를 것이다. 링크 계층

드 값에 근거하여 포워팅을 결정한다. 이에 라우터들을 네트워크 계층(3계충)의 장치
라고 한다. (이 구별을 확실히 하기 위하여, 네트워크 계층 데이터그램과 링크 계층 프
레임과 그 관계를 설명한 1.5.2절을 복습하라). 이 장에서 우리 관심사는 네트워크 계
충이므로 패킷 스위치 대신에 라우터라는 용어를 사용한다.

지금까지 네트워크 계층의 데이터와 제어 평면에 대해서 살펴보았다. 포워팅과 라우팅
간의 중요한 차이점과 네트워크 계층의 서비스와 라우터의 입력 링크에서 적절한 출력
링크로 패킷을 실제로 전달하는 기능에 대해서 살펴보자.
상위 레벨의 관점으로 본 일반적인 라우터 구조는 그림 4.4에서 볼 수 있으며, 라
우터의 네가지 요소를 다음과 같이 정의한다.
입력 포트: 입력 포트는 여러 기능을 수행한다. 그림 4.4에서 입력 포트의 맨 왼쪽
상자와 출력 포트의 맨 오른쪽 상자로서 라우터로 들어오는 입력 링크의 물리계층
기능-을 수행한다. 또한 입력 포트는 입력 링크의 반대편에 있는 링크 계층과 상호
운용하기 위해 필요한 링크 계층 기능을 수행한다. 이것은 입력 및 출력 포트에서
중간 상자로 표시된다. 가장 중요한 것은 입력 포트에서 검색 기능을 수행 하는 것
이다. 이는 가장 오른쪽 상자에서 발생한다 여기서 포워팅 테이블을 참조하여 도
착된 패킷이 스위칭 구조를 통해 전달되는 라우터 출력 포트를 결정한다. 제어패
것(예: 라우팅 프로토콜 정보를 전달하는 패것)은 입력 포트에서 라우팅 프로세서
로 전달된다. 여기서 “포다라는 용어는 물리적인 입출력 라우터 인터페이스를 의
미한다. 2장과 3장에서 논의된 네트워크 어플리게이션 및 소켓과 관련된 소프트웨
어 포트와는 분명히 다르다. 실제로 라우터가 지원하는 포트의 수는 비교적 적은
수의 엔터프라이즈 라우터에서 수백개의 10 Gbps 포트를 가지는 ISP 가장자리의
라우터까지 다양하다. 라우터의 입력 회선 수는 많아지는 경향이 있다. 예를 들면
