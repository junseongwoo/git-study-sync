지금까지의 MPLS에 대한 설명에서는 MPLS가 패킷의 IP 주소를 고려하지 않고

MPLS에 관심을 갖게 되는 이유는 스위칭 속도를 잠재적으로 향상시기는 것이 아니라
MPLS가 제공하는 트래픽 관리 기능이다. 앞서 살펴봤듯이, R4는 A로 가는 2개의
MPLS 경로를 갖는다. 만약 전달이 IP 주소를 기반으로 IP 계층까지 수행된다면, 5장
에서 다룬 IP 라우팅 프로토콜은 A로의 최소비용경로 하나만 지정한다. 반면, MPLS
는 표준 IP 라우팅 프로토콜을 사공해서는 불가능한 경로를 이용해 패킷을 전달하는
능력을 제공한다. 이것은 MPLS를 사용해서 트래픽 엔지니어링(traffic engineering)
을 제공하는 간단한 하나의 방식이다[RFC 3346; RFC 3272; RFC 2702; Mao 20(끼.
이때, 네트워크 운영자는 일반 IP 라우팅을 배제하고 동일 목적지로 가는 트래픽의 일
부는 한 경로로, 또 다른 트래픽은 다른 경로로(정책이나 성능 또는 다른 이유로) 전달
되게 할 수 있다.
