텔넷(Telnet): 순서번호와 획인번호 사래 연구
RFC 854에서 정의된 텔넷은 원격 로그인을 위해 사용되는 유명한 애플리케이션 계층
프로토콜이다. 이것은 TCP상에서 동작하며, 한 쌍의 호스트들 사이에서 동작하도록
설계되었다. 2장에서 논의된 대량 데이터 전송 애플리케이션과 달리, 텔넷은 대화형
애플리케이션이다. 이 절에서는 텔넷의 예를 논의하는데, 이것은 TCP 순서와 확인응
답 번호를 설명하는 데 편하기 때문이다. 패스워드를 포함하는 텔넷 연결에서 전송된
데이터는 암호화되지 않아서(8.7절에 논의된 것처럼) 도청 공격에 취약하므퇴 많은
A卜공자들이 텔넷보다 SSH 프로토콜을 선호한다.
호스트 A가 호스트 B와 텔넷 세션을 초기화한다고 가정하자. 호스트 A가 세션을
초기화하므로 클라이언트이고 호스트 B는 서버가 된다. 사용자(클라이언트에서)가 입
력한 각 문자는 원격 호스트에게 송신될 것이다. 원격 호스트는 각 문자의 복사본을 송
신자에게 반송하여 텔넷 사용자의 화면에 표시되게 할 것이다. 이 “반송(echo back)”
은 텔넷 사용자가 보는 문자가 이미 원격 사이트에 수신되고 처리되었음을 나타낸다.
그러므로 각 문자는 사용자가 기를 누르는 시간과 문자가 사용자의 모니터에 표시되는
시간 사이에서 네트워크를 두 번 통과한다.
