로토콜은 송수신자 간에 전송되는 패것률을 조절한다. 라우터에서 프로토콜은 송신지
에서 목적지까지 패킷의 경로로 설정한다. 이들 프로토콜은 인터넷의 모든 영역에서
작동하므로 이 책의 많은 부분에서 컴퓨터 네트워크 프로토콜을 다룬다.
여러분에게 친숙한 컴퓨터 네트워크 프로토콜의 한 예를 보자. 웹 서버에 요청할
때, 즉 웹브라우저에서 웹 페이지의 URL을 입력하면, 어떤 일이 발생하는지 생각해
보자. 그 시나리오를 그림 1.2의 오른쪽에서 볼 수 있다. 먼저 여러분의 컴퓨터가 연결
요청 메시지를 웹 서버에 보내고 응답을 기다린다. 웹 서버는 연결 요청 메시지를 받
고, 연결 응답 메시지를 여러분에게 보낸다. 이제 웹 문서를 요청해도 좋다는 것을 확
인하고, 컴퓨터는 웹 서버에서 얻으려는 웹 페이지의 이름을 GET 메시지에 넣어서 보
낸다. 마지막으로, 웹 서버는 여러분의 컴퓨터로 웹 페이지 내용(웹 파일)을 전송한다.
앞에서 보았던 사람의 네트워킹 예처럼, 메시지 교환과 이들 메시지를 송수신할
때 취한 행동은 프로토콜의 요소를 정의하는 주요인들이다.
프로토콜은 둘 이상의 통신 개체 간에 교환되는 메시지 포맷과 순서뿐 아니라, 메시지
의 송수신과 다른 이벤트에 따른 행동들을 정의한다.”
인터넷과 일반 컴퓨터 네트워크는 많은 프로토콜을 이용한다. 다양한 프로토콜이
여러 가지 통신 목적을 위해 사용된다. 이 책에서 어떤 프로토콜은 간단하지만 어떤 것
은 매우 복잡하다는 것을 알게 될 것이다. 컴퓨터 네트워킹 분야의 전문가가 된다는 것
은 네트워킹 프로토콜이 무엇이고, 왜 필요하며 또한 어떻게 운영되는지 잘 이해한다
는 것과 같다.
