포위팅과 라우팅, 다양한 네트위그 서비스 모-델 식별과 라우터 내부 모습올 특정 김푸
터 네트워크 구조나 프로토콜에 대해 어떠한 설명 없이 다루었다. 이 절에서는 오늘날
인터넷과 IP (lntcrnet Protocol) 네트위그 계층의 핵심적인 측면에 대해 초점을 맞출
것이다.
현재 싸올 중인 IP는 두 가지 버전이 있다. 4.3.1절에서 IPv4 [RFC 7911로 널리
알려진 IP 프로토콜 버전 4를 알아보고, 4.35 절에서 IPv4를 대체하도록 제안된 IP 버
전 6 [RFC 2460, RFC 429니을 살펴볼 것이다. 두 절에서는 인터넷 주소 지정을 주로
다를 것이다. 주제가 다소 건조하고 세부적으로 보이겠지만 인터넷 네트워그 계층이
어떻게 작동하는지 이해하기 위해 위 주제는 중요하다. 인터넷 네트워크 계층을 통달
하려면 IP 주소 지정을 숙달해야 한다!
43.1 1Pv4 데이터그램 형식
인터넷 네트워크 계층 패것을 데이터그램이라고 부르는 것을 떠올리자. IPv4 데이터그
램 문법과 용어의 개요에서부터 IP 이야기를 시작하겠다. 패것 비트 문법과 용어 공부
는 지루하다고 생각하겠지만 데이터그램은 인터넷에서 중요한 역할을 하므로 내용을
잘 읽고, 공부하고, 완벽하게 마스터해야 한다. (프로토콜 헤더가 실제로 흥미가 생기
는 공부거리인지 확인하고 싶다면 [Pomeranz 201이을 살펴보아라.) 1Pv4 데이터그램
형식은 그림 4.16에 있다. 1Pv4 데이터그램의 주요 필드는 다음과 같다.
버전 번호: 4비트로 데이터그램의 IP 프로토콜 버전을 명시한다. 라우터는 버전 번
호를 확인하여 데이터그램의 나머지 부분을 어떻게 해석할지 결정한다. 다른 버전
의 IP는 다른 데이터그램 형식을 사용한다. 1Pv4 데이터그램 형식을 그림 4.16에
서 볼 수 있다. 새로운 버전인 1Pv6 데이터그램 형식은 4.3.5에서 다룬다.
