(패킷을 전송하는) 패킷 교환 네트워크는 여러 가지 면에서 (운송수단을 전송하는)
고속도뢰 도롸 교차로 등의 수송 네트워크와 유사하다. 예를 들어, 수천 킬로미터 떨
어진 목적지 창고로 많은 양의 회물을 이동할 필요가 있는 공장을 고려해 보자. 공장에
서 화물은 세그먼트화되고 트럭 선단에 적재된다. 그 다음 각 트럭은 독립적으로 고속
도뢰 도로, 교차로 등의 네트워크를 통해 목적지 창고로 운행한다. 목적지 창고에서
화물은 트럭에서 내려지고 같이 실려 온 나머지 회물들과 그룹화된다. 따라서 여러 면
에서 패킷은 트럭과 유사하고, 통신 링크는 고속도로 또는 도로와 유사하며, 패것 교환
기는 교차로와 유사하다. 마지막으로 종단 시스템은 빌딩과 유사하다. 트럭이 운송 네
트워크를 통해 경로를 따르는 것처럼, 패킷은 컴퓨터 네트워크를 통한 경로를 따른다.
종단 시스템은 ISP (lnternet Service Provider)를 통해서 인터넷에 집속하는데,
지역 케이블 혹은 전화 회사와 같은 가정 ISP, 법인 ISP, 대학 ISP, 더 나아가 공항, 호
텔, 커피숍, 기타 공공장소 등에서 와이파이 접근을 제공하는 ISP, 스마트폰과 다른 장
치들에 모바일(또는 이동) 접속을 제공하는 셀룰러 데이터 ISP를 포함한다. 각
패킷 스위치와 통신 링크로 이루어진 네트워크다. ISP는 종단 시스템에게 게이를 모뎀
이나 DSL 같은 가정용 초고속 접속, 고속 LAN 접속, 모바일 무선 접속, 56 kbps 다이
얼업 모뎀 접속을 포함하는 다양한 네트워크 접속을 제공한다. 또한 ISP는 웹 사이트
와 비디오 서버를 인터넷에 직접 연결하도록 CP (Content Provider)에게 인터넷 접속
을 제공한다. 인터넷은 종단 시스템을 서로 연결하는 것이므로 종단 시스템에 접속을
제공하는 ISP들도 서로 연결되어야만 한다. 이들 하위 계층 ISP는 레벨 3 커뮤니케이
션즈, AT&T, 스프린트, NI丁와 같은 국가 그리고 국제 상위 계층 ISP를 통해 서로 연
결된다. 상위 계층 ISP는 광 링크로 연결된 고속 라우터로 구성된다. 상위 계층이든 하
위 계층이든 각 ISP 네트워크는 따로 관리되괴 IP 프로토콜을 수행하며(아래 참조) 또
한 네이밍(naming)과 주소배정 방식을 따른다. 1.3절에서 ISP와 그들의 상호연결에
대해 자세히 알아본다.
