문제 2: UDP Ping 실험
이 프로그램 문제에서는 파이썬 언어로 클라이언트 Plng 프로그램을 작성한다. 클라이
언트는 간단한 ping 메시지를 서버로 보내고 서버로부터 대응하는 pong 메시지를 수
신하며, ping 메시지를 보내고 pong 메시지를 받을 때까지의 지연 시간을 결정한다
이 지연을 RIT (round tnp time)라고 한다. 이 클라이언트와 서버가 제공하는 기능으
현대 운영체제에서 기용한 표준 ping 프로그램이 제공하는 기능과 유사하다. 그러나
표준 ping 프로그램은 ICMP (lnternet Control Message Prot()C()1)(5장에서 배우게
를 시용한다. 여기서는 비표준 (그러나 간단한) UDP 기반 ping 프로그램을 생성한다.
ping 프로그램은 UDP를 통해 목적지 서버에게 10개의 ping 메시지를 보낸다. 각
메시지에 대해 클라이언트는 대응되는 pong 메시지가 반환될 때 RTT를 결정하고 출
력한다. UDP는 비신뢰적 프로토콜이기 때문에 클라이언트 또는 서버가 보낸 패킷이
손실될 수 있다. 따라서 클라이언트는 ping 메시지에 대한 응답을 무한정 기다릴 수 없
다. 클라이언트가 서버로부터의 응답을 1초까지 기다리도록 하고, 응답이 오지 않으면
클라이언트는 패킷이 손실되었다고 가정하고 적절한 메시지를 출력한다.
이 문제에서는 서버에 대한 완벽한 코드가 주어진다(보조 웹 사이트에서 찾을 수
있다). 서버 코드와 매우 유사한 클라이언트 코드를 작성하면 되며, 이를 위해서 먼저
서버 코드를 주의 깊게 살펴 보기 바란다. 그 다음 서버 코드에 있는 라인들을 잘라 붙
이기(cut and paste)하여 클라이언트 코드를 작성하면 된다.
문제 3: 메일 클라이언트
이 프로그래밍 문제의 목적은 임의의 수신자에게 전자메일을 보내는 간단한 메일 클라
이언트를 생성하는 것이다. 이 클라이언트는 메일 서버(예: 구글 메일 서버)와 TCP 연
결을 설정하고 SMTP 프로토콜을 이용하여 대회를 나누고 메일 서버를 통해 수신자
(예: 친구)에게 전자메일을 보내고 마지막으로 메일 서버와의 TCP 연결을 종료한다.
이 문제의 경우, 보조 웹 사이트에 클라이언트의 골격 코드가 제공되어 있다. 코드
를 완성한 후 다른 사용자 계정으로 전자메일을 보냄으로써 작성한 클라이언트를 테스
트하면 된다. 또한 다른 서버들(예: 구글 메일 서버와 소속 대학교의 메일 서버)을 통
해서 보내는 것도 해 볼 수 있다.
문제 4: 멀티-스레드 웹 프록AI
이 문제에서는 웹 프록시를 개발한다. 이 프록시는 브라우저로부터 객체에 대한 HTTP
요청을 받으면 해당 객체에 대한 새로운 HITP 요청을 생성해서 기점 서버에게 이 요
청을 보낸다. 프록시가 기점 서버로부터 객체에 대한 대응되는 HTTP 응답을 받으면
이 객체를 포함하는 새로운 HITP 응답을 생성한 후 이것을 클라이언트에게 보낸다.
프록시는 멀티-스레드이고 따라서 동시에 여러 개의 요청을 다룰 수 있다.
이 문제의 경우, 보조 웹 사이트에 프록시 서버에 대한 골격 코드가 제공되어 있
다. 코드를 완성한 후 여러 다른 브라우저가 프록시를 경유해서 웹 객체를 요청하도록
해서 테스트해 보기 바란다.
