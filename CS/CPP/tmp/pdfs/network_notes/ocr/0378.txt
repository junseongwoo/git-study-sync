ISP와의 계약 외에도 2징에서 설명한 바와 같이 회사의 도메인 이름을 얻기 위해
인터넷 등록 기관과 계약을 해야 한다. 예를 들어, 여러분 회사의 이름이 제너두(Xana-
du) 주식회사라면, 자연히 도메인 이름 xanadu.com/ 얻기 위해 시도할 것이다. 또한
여러분 회시는 DNS 시스템에 등록해야 한다. 구체적으로는, 외부인이 서버의 IP 주소
를 얻기 위해 여러분 DNS 서버에 접촉하기를 원할 것이므로, 여러분 DNS 서버의 IP
주소를 등록 기관에 제공해야 한다. 그러면 등록 기관은 2장에서 설명한 .com 최상위
도메인 서버에 여러분 DNS 서버(도메인 이름과 해당 IP 주소)를 추가한다. 이 단계가
완료되면 여러분의 도메인 이름十(예를 들어 www.xanadu.com/을 알고 있는 사용자는
누구나 DNS 시스템을 통해 여러분 DNS 서버의 IP 주소를 얻을 수 있다.
사람들이 여러분의 웹 서버 IP 주소를 검색할 수 있도록 여러분 DNS 서버에 웹
서버의 호스트 이름(예를 들어 www.xanadu.com/과 IP 주소의 사상 항목을 포함시켜
야 한다. 여러분의 메일 서버를 포함하여 회사의 공개적으로 사용 기능한 다른 서버들
에 대해서도 유사한 항목들을 가져야 한다. 이렇게 되면, 만일 앨리스가 여러분의 웹
서버를 방문하기를 원하는 경우, DNS 시스템은 여러분 DNS 서버에 접촉하여 웹 서
비의 IP 주소를 알아낸 후 이를 앨리스에게 제공한다. 이제 앨리스는 여러분의 웹 서버
에 직접적으로 TCP 연결을 설립할 수 있다.
그러나 여전히 전 세계의 외부인이 여러분 웹 서버에 접근할 수 있도록 하기 위한
필수적이고 중요한 단계가 남아 있다. 여러분 우』 서버의 IP 주소를 알아낸 앨리스가 그
IP 주소로 IP 데이터그램(예를 들어 TCP SYN 세그먼트)을 보낼 때 어떤 일이 발생할
지 생각해 보자. 이 데이터그램은 인터넷을 통해 라우팅되어 여러 지을 시스템의 라우
터들을 연속적으로 거친 후 마침내 웹 서버에 도착하게 된다. 라우터들 각각은 이 데이
터그램을 수신하면, 어느 출력 포트로 내보내야 하는지 결정하기 위해 자신의 포워딩
테이블에서 해당 엔트리를 찾는다. 따라서 라우터는 여러분 회사의 주소 범위에 해당
하는 IP 주소 접두부 24비트(또는 다른 길이의 엔트리)의 존재를 알고 있어야 한다. 라
우터는 어떻게 여러분 회사의 주소 접두부를 알게 되는가? 우리가 지금까지 보았듯이,
BGP를 통해서이다. 구체적으로, 여러분의 회사가 지역 ISP와 계약하고 주소 접두부
(즉, 주소 범위)를 할당받을 때, 지역 ISP는 BGP를 사용하여 자신과 연결되어 있는
ISP들에게 여러분의 주소 접두부를 알린다. 연결된 ISP들 역시 BGP를 활용하여 이
알림 정보를 전파한다. 결국, 모든 인터넷 라우터들은 여러분의 주소 접두부(또는 여러
분의 주소 접두부를 포함하는 다른 단위의 접두부)에 대해 알게 되어 여러분의 웹이나
메일 서버를 목적지로 하는 데이터그램들을 적절하게 포워팅할 수 있게 될 것이다.
