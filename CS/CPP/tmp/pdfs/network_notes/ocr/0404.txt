rtinit0(). 에뮬레이션 시작 부쁜에서 한 번 호출된다. 전달 인수를 갖지
않는다. 노드 0의 거리 테이블에 노드 1, 2, 3으로의 직접 비용 1, 3, 7을 각각 반
영해서 초기화해야 한다. 위의 그림에서 모든 링크는 양방향성이고 양방향의 비용
은 동일하다. 거리 테이블과 노드 0 루틴이 필요로 하는 다른 자료구조들을 초기
화한 후에 직접 연결된 이웃들(이 경우엔 1, 2, 시에게 모든 다른 네트워크 노드로
의 최소 비용 경로의 비펑을 전달한다. 이 최소 비용 정보는 과제에 대한 완전한
설명에 있는대로 t01ayer2() 루틴을 호출해서 라우팅 갱신 패킷에 담아 이웃한 노
드에 전달된다. 라우팅 갱신 패킷 형태는 이 과제의 완전한 설명에 기술되어 있다.
rtupdate()(struct rtpkt *rcvdpkt). 노드 0이 직접 연결된 이웃으로부터 라우팅 패
깃을 받았을때 이 루틴을 호출한다. 인수 *rcvdpkt는 수신한 패킷에 대한 포인터
이다. rtupdate0()은 거리 벡터 알고리즘의 핵심이다. 어떤 다른 노드 i에서 받는
라우팅 갱신 패킷의 값들은 모든 다른 네트워크 노드로의 i의 현재 최단 경로 비용
을 담고 있다. rtupdate()()는 자신의 거리 테이블을 갱신하는 데 이 값을 사용한다
(거리 벡터 알고리즘에서 명세한 것처럼). 이 갱신의 결과로 자신으로부터 다른노
드로의 최소 비용이 변경되면, 노드 0은 라우팅 패킷을 직접 연결된 이웃에 보내
서 최소 비용의 변회를 알린다. 거리 벡터 알고리즘에서는, 직접 연결된 노드들만
이 서로 라우팅 패킷을 교환한다는 것을 기억하라. 따라서 노드 1과 2는 서로 통
신하지만 노드 1과 3은 서로 통신하지 않는다.
노드 1, 2, 3을 위해서도 유사한 루틴들이 정의된다. 따라서 여러-분은 다음과 같은 여
덟 개의 프로시저를 전부 작성해야 한다: rtinit()(), rtinitl(), rtinit2(), rtinit3(), rtup-
date()(), rtupdatel(), rtupdate2(),rtupdate3(). 이 루틴들 모두는 앞 페이지 그림에서
본 토폴로지와 비용에 대한 거리 테이부을 분산적이고 비동기적으로 계산하는 방법을
구현한다.
