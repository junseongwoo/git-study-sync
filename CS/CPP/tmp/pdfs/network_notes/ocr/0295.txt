스위칭 구조: 스위칭 구조는 라우터의 입력 포트와 출력 포트를 연결한다. 스위칭
구조는 라우터 내부에 포함되어 있다(네트위크 라우터의 내부 네트워크).
출력 포트: 출력 포트는 스위칭 구조에서 수신한 패킷을 저장하고 필요한 링크 계
층 및 물리적 계층 기능을 수행하여 출력 링크로 패킷을 전송한다. 링크가 양방향
일 때(즉, 양방향으로 트래픽을 전별인 경우, 출력 포트는 일반적으로 동일한 링
그의 입력 포트와 한 쌍을 이룬다.
라우팅 프로세서: 라우팅 프로세서는 제어 평면 기능-을 수행한다. 기존의 라우터
에서는 라우팅 프로토콜(5.3절 및 5.4절에서 학습)을 실행하고 라우팅 테이블과
연결된 링크 상대 정보를 유지 관리하며 라우터의 포워딩 테이블을 계산한다.
SDN 라우터에서 라우팅 프로세서는 원격 컨트롤러와 통신하여 (다른 활-동들과
함께) 원격 컨트롤러에서 계산된 포워딩 테이블 항뚜을 수신하고 라우터의 입력
포트에 이러한 항목을 설치한다. 또한 라우팅 프로세서는 5.7절에서 공부할 네트
위그 관리 기능을 수행한다.
그림 4.4와 같이 라우터의 입력 포트, 출력 포드, 스위칭 구조는 거의 항상 하드웨
어로 구현된다. 하드웨어 구현이 필요한 이유를 이해하기 위해 10 Gbps 입력 링크와
64바이트의 IP 데이터그램으로 입력 포트가 다른 데이터그램이 도착하기 전에 데이터
그램을 처리하는 데는 오직 51.2 ns를 가진다고 생각해보자. 만약 N 포트가 회선 카드
에서 결합되는 경우, 데이터그램 처리 파이프라인은 소프트웨어 구현에 대해 N배 더
빠르게 작동해야 한다. 전달 하드웨어는 라우터 공급 업체의 자체 하드웨어 디자인을
A卜&하거나 구입한 업체의 실리콘 집(예: 인텔(lntel)이나 브로드d(Broadcom)과 같은
회사에서 판매되는 것)으로 구현된다.
