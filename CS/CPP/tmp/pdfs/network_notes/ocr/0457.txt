6.5 • 링크 가상아: 링크 계용으로서의 네트위크
있는지 여부를 구분 못할 수 있다.
두 호스트들 사이의 다이얼업 모ti년1 연길에서 2개의 호스트를 연길한 랑그는 실제
로 전화 네트워크(데이터 전송과 시그널링을 위한 자신의 스위치, 링그, 프로토콜 스택
을 가진 논리적으로 분리된 광역 전화 통신 네트위그)이다. 그러나 인터넷 링크 계층
관점에서 전화 네트위그를 통한 디이일업 연결은 단순히 “선”처럼 보인다. 이런 점에
서 인터넷은 전화 네트워크를 두 인터넷 호스트들 사이의 링크 계층 연결을 제공하는
링크 계층 기술로 간주하여 전화 네트워크를 가상화한다. 인터넷이 전화 네트워크를
오버레이하는 것과 마찬가지로, 인터넷을 오버레이하기 위해서 오버레이 네트워크는
인터넷을 오버레이 노드 간의 연결을 제공하는 방법으로 간주했다.
이 절에서는 다중 프로토콜 레이를 스위4(Multiprotocol Label Switching,
MPLS) 네트워크에 대해서 살펴본다 회선 교환 전화 네트워크와 달리, MPLS는 패킷
교환, 가상회선 네트워크이다. MPLS는 자체적인 패킷 형식과 전달 방식을 시용하며
네트워크 계층이나 링크 계층에 해당한다. 그러나 인터넷 관점에서 MPLS는 전화 네
트워크나 스위치 이더넷처럼 IP 장치를 상호연결하는 데 A卜&되는 링크 계층 기술로
다뤄질 수 있다. 따라서 링크 계층에 대한 설명에서 MPLS를 다를 것이다. 프레임 릴
레이와 ATM 네트워크는 좀 오래된(그러나 여전히 사용되고 있는) 네트워크이고 여기
서는 다뤄지지 않지만, IP 장치를 상호연결하는 데 사용된다. 자세한 내용은 읽기 쉬운
책인 [Goralsk1 1999]를 참조하기 바란다. MPLS에 관한 책들은 다수 있으며, 여기서
는 아주 간단하게 다룬다. MPLS에 대한 자세한 설명은 [Davie 2刪]을 참조하기 바
란다. 여기서는 MPLS의 상세 기술에 대해서 약간 깊이 있게 살펴보겠지만 IP 장치를
상호연결하는 데 MPLS 서버가 어떻게 사용되는지에 대해서 주로 다를 것이다.
65.1 다중프로토콜레이블스위칭(MPLS)
다중 프로토콜 레이블 스위칭(MuItiprotocol Label Switchmg, MPLS)은 가상회선 네
트워크의 주요 개념인 고정 길이 레이블을 도입함으로써 IP 라우터의 전달 속도를 향
상시기려고 한 1990년대 중후반에 있었던 산업계의 노력으로부터 발전했다. MPLS의
목표는 고정 길이 레이블과 가상회선을 기반으로 데이터그램을 전달하기 위해서 목적
지 기반 IP 데이터그램 전달 기반구조를 포기하는 것이 아니라, 가능한 경우에 데이터
그램을 선택적으로 레이블링해서 라우터로 하여금 고정 길이 레이블(목적지 IP 주소가
아닌)을 기반으로 데이터그램을 전달할 수 있도록 목적지 기반 IP 데이터그램 전달 하
부구조를 확장시기는 것이다. 중요한 것은 이 기술이 IP 주소체계와 라우팅을 A卜몸하
는 IP와 긴밀하게 동작한다는 것이다. IETF는 데이터그램 네트워크에 vc 기술을 효
과적으로 통합하는 MPLS 프로토콜 [RFC 3031, RFC 30321을 표준화했다.
이제 MPLS 가능(MPLS-capable) 라우터에 의해 처리되는 링크 계층 프레임의
형식에 대해서 살펴보자. 그림 6.28은 MPLS 기능 장치들 간에 전달되는 링크 계층 프
레임이 2계층(예: 이더넷) 헤더와 3계층(예: IP) 헤더 사이에 작은 MPLS 헤더를 가심
을 보여 준다. RFC 3032는 이러한 링크들을 위한 MPLS 헤더의 형식을 정의하고 있
다. ATM과 프레임 릴레이 네트워크들을 위한 헤더 또한 다른 RFC에 정의되어 있다.
