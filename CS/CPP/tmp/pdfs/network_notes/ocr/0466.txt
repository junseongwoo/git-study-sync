3. DHCP 요청 메시지를 포함한 브로드개스트 이더넷 프레임은 봅의 랩톱이 처음으

트(라우터로 연결된 포트도 포함)로 브로드개스트한다.
4. 라우터는 MAC 주소 00:22:6B:45:IF:IB인 인터페이스로 DHCP 요청 메시지가
포함된 브로드개스트 이더넷 프레임을 수신하고, 이더넷 프레임으로부터 IP 데이
터그램을 추출한다. 데이터그램의 브로드개스트 IP 목적지 주소는 이 IP 데이터그
램이 노드의 상위 계층 프로토콜에 의해서 처리되어야 함을 의미한다. 이렇게 함
으로써 데이터그램의 페이로드(UDP 세그먼트)가 UDP로 역다중화되고(32절),
UDP 세그먼트로부터 DHCP 요청 메시지가 추출될 수 있다. 이제 DHCP 서버는
DHCP 요청 메시지를 갖게 된다.
