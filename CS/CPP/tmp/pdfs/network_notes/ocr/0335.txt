4.4 • 일반적인 포위딩 및 소프트웨어 기반 네트위크(SDN)
마지막으로 위에서 도착한 데이터그램을 호스트 h3 또는 h4로 전달할 수 있도록
s2에 플로우 테이블 항목이 필요하다.

매칭

lngress port = 2 ; IP Dst= 102.0 4
두 번째 예: 부하 균등호KLoad BaIancing)
액션
Forword(3)
Forword(4)
두 번째 예로 h3에서 10.1.*.*로 향하는 데이터그램이 s2와 sl 사이의 링크를 통해 전
달되는 반면, h4에서 10.1.*.*로의 데이터그램은 s2와 s3 사이의 링크를 통해 전달되
는 부하 균등화 시나리오를 고려해 보자. 이 동작은 IP의 목적지 기반 포워팅으로 수행
될 수 없다. 이 경우 s2의 플로우 테이블은 다음과 같다.

매칭
lngress port = 3; IP 05t = 10.1 .*
lngress port = 4; IP Dst = 10.1 .*
액션
Forword(2)
Forword(l)
S2에서 수신한 데이터그램을 hl 또는 h2로 전달하려면 sl에서 플로우 테이블 항
목이 필요하다. 인터페이스 4에서 수신한 데이터그램을 s2에서 인터페이스 3을 통해
sl으로 전달하려면 s3에서 플로우 테를 항목이 필요하다. sl 및 s3에서 이러한 흐름 테
이불 항목을 파악할 수 있는지 확인하자.
세 번째 예: 방화벽
세 번째 예로 s2가 s3에 연결된 호스트에서 보낸 트래픽만 수신하려고 하는 방화벽 시
나리오를 생각해보자.
s2 플로우 테이블(예 3)
IP Src = 10.3.*.* IP Dst = 10.2.0.3
IP Src = 10.3.*.* IP Dst= 10.2.0.4
액션
Forword(3)
Forword(4)
s2의 플로우 테이블에 다른 항목이 없으면 10.3.*.*의 트래픽만 s2에 연결된 호스
트로 전달된다.
