외이어사그 실험문제: HTTP
실험문제 1에서 와이어사그 패것 스니퍼를 간단히 살펴보면서, 프로토콜의 동작을 조
사하기 위해 이미 와이어사그를 A방하있다. 이 실험에서는 HITP 프로토콜의 여러
측면을 살펴본다(기본 GET/reply 상호작용, HTTP 메시지 포맷, 내장된 URL이 있는
대용량 HTML 파일 검색, 지속 및 비지속 연결, HTTP 인중과 보안).
모든 와이어샤그 실험과 마찬가지로, 이 실험에 대한 모든 설명은 웹 사이트
http://www.pearsonglobaleditions.com/kurose에 있다.
외이어샤크 실험문제: DNS
이 실험에서는 DNS의 클라이언트 측에서 인터넷 호스트 네임을 IP 주소로 전환하는
프로토콜을 살펴본다. 2.5절에서 보았듯이 DNS에서 클라이언트 측의 규칙은 상대적
으로 간단하다(클라이언트는 로걸 DNS 서버로 질의를 보내고 역으로 응답을 받는다).
계층적인 DNS 서버는 클라이언트의 질의에 대해 서로 간에 반복적 또는 재귀적으로
통신하기 때문에 DNS 클라이언트 측에서는 인지하지 못한다. 그러나 DNS 클라이언
트 측면에서 이 프로토콜은 아주 단순하다(질의는 로컬 DNS 서버로 보내지며 그 서버
로부터 응답을 받는다). 이 실험에서는 DNS의 동작을 관찰한다.
모든 와이어사크 실험과 마찬가지로, 이 실험에 대한 모든 설명은 웹 사이트
http://www.pearsonglobaleditions.com/kurose에 있다.
