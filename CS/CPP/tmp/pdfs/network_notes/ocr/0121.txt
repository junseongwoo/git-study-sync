2.3 • 인터넷 전자에일
메일 통계를 얻을 수도 있다. 세 번째 단기|인 갱신은 클라이언트가 POP3 세션을 끝내
는 quit 명령이 내려진 후에 일어난다. 에미, 메일 서버는 삭세 표시된 메시지를 삭제
한다.
POP3 트랜책션에서, 사용자 에이전트는 명령을 내리고 서버는 각 명령에 대해 응
답한다. 가능한 응답은 다음과 같은 두 가지가 있다. 측, +OK 는 서버가 이전 명령을
잘 처리했다는 것을 나타낸다(가꿈 서버에서 클라이언트로 가는 데이터가 뒤따른다).
그리고 다른 하나는 -ERR로써 이전 명령에 대해서 무언가 잘못되있다는 것을 나타내
는 데 서버가 사용한다.
인증 단계는 다음과 같은 두 가지 중요한 명령을 갖고 있다. 즉, user 〈싸%자 이
름〉과 pass 〈비밀번호〉이다. 이 두 명령을 설명하기 위해, 포트 번호 110을 이용하여
POP3 서버로 직접 텔넷을 해 보기 바란다. 그리고 이들 명령을 입력해 보라.
mai1Server는 여러분의 메일 서버 이름이라고 가정한다. 그러면 다음과 같은 것을
보게 될 것이다.
telnet mai1Server 110
+OK POP3 server ready
user bob
+OK
pass hungry
+OK user successfully logged on
만약 명령을 잘못 입력하면, POP3 서버는 -ERR 메시지로 응답할 것이다.
이제 트랜책션 단계를 살펴보자. POP3을 이용하는 사용자 에이전트는 “다운로드
후 삭제” 혹은 “다운로드 후 유지”처럼 설정될 수 있다. POP3 싸우자 에이전트가 만드
는 일련의 명령은 이들 두 가지 모드에서 어떤 모드로 사용자 에이전트가 동작하는가
에 따라 다르다. 다운로드 후 삭제 모드에서, 사용자 에이전트는 list, retr, dele
명령을 만든다. 예를 들어, 사용자 메일박스에 두 메시지를 갖고 있다고 하자. 이후 대
화에서 클라이언트를 나타내는 다는 사용자 에이전트고, 서버를 나타내는 노는 메일
서버다. 트랜책션은 다음과 같다.
