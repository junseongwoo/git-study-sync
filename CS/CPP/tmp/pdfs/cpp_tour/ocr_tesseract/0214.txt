10.5 사용자 정의 타입의 입출력

내장 타입과 HE string] YEH EE tostream 라이브러리를 이용하면 프로그
래머가 직접 정의한 타입의 입출력을 정의할 수 있다. 예를 들어 전화번호부에 SAE
항목을 표현하는 간단한 타입인 607를 살펴보자.

struct Entry {
string name;
int number;
};

자를 정의할 수 있다.

ostream& operator<<(ostream& os, const Entry& e)

{

return os << "{\"" << e.name << "\", " << e.number << "}";

}

사용한다.

이에 상응하는 입력 연산자는 형식이 맞는지 확인하고 에러를 처리해야 하므로 좀
더 복잡하다.
