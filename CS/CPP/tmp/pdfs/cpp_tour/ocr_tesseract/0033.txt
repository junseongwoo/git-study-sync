버전과 상수가 아닌 버전으로 두 번 정의하는 불편함을 피할 수 있다.

함수를 constexpriz 정의하려면 함수의 내용이 간단하고 부수 효과가 없어야 하며,
인자로 전달된 정보만 사용해야 한다. 특히 지역 변수가 아닌 변수는 변경할 수 없다.
그러나 루프를 사용하거나 내부에 지역 변수를 정의할 수 있다.

constexpr double nth(double x, int n) // 0<=7)이라고 가정
{
double res = 1;
int i =0;
while (i<n) { // while 루프: 조건이 true 동안 반복(1.7.1절)
res*=x;
+i;
}

return res;

몇 가지 경우에 상수 표현식이 언어의 규칙으로 강제된다(예, 배열의 경계(1.7절), case
의 라벨(1.8절), 템플릿 값 인자(6.2절), constexpr 선언된 상수). 다른 경우에는 컴파일
시간 평가가 성능 관점에서 중요하다. 성능 이슈 외에도 불변성(상태가 변하지 않는
객체)의 개념은 중요한 설계 고려 사항이다.

컬렉션*9이자 하드웨어가 제공하는 기능에 직접적으로 대응한다. char 타입으로
이뤄진 배열의 선언은 다음과 같다.
