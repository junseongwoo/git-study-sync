정규 표현식 특수 문자

.     모든 문자 SHHAYEII=(wildcard)) | \     다음 문자를 특수 문자로 인식

[     문자 클래스 시작                  *    0번 이상(접미 연산)
]     문자 클래스 끝                    +     1번 이상(접미 연산)
{     카운팅 시작                      ?     선택적(0번이나 1번)(접미 연산)

yo 카운팅 끝                       |     CHOKE (or)

«a8 시작                      ^  _ 행의 시작; 반전
드는 일발 ER 들소
)     그룹핑 끝                         $     행의 끝

예를 들어 행의 시작이 0개 이상의 이고, 다음에 1개 이상의 8가 오고, 그 뒤에 (
가 선택적으로 등장하는 패턴은 다음과 같다.

?A?B+C?$
이 패턴에 매치되는 문자열의 예를 살펴보자.

AAAAAAAAAAAABBBBBBBBBC
BC
B

반면 매치되지 않는 예는 다음과 같다.

AAAAA             // Bt 없음

AAAABC         // 맨 앞에 공백
AABBCC           // (가 너무 많음

괄호로 둘러싸인 패턴의 일부분을 부분 패턴이라 한다(503*를 이용해서 따로 뽑아낼
수 있다).
