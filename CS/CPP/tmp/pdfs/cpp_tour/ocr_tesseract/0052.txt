2.3 클래스

데이터와 연산을 분리해 명시하면 데이터를 다양한 방식으로 사용할 수 있는 등의
이점이 있다. 그러나 사용자 정의 타입이 '실세계의 타입'에 기대되는 모든 HAE
갖게 하려면 표현 방식과 연산 사이의 더 강한 연결이 필요할 수도 있다. 특히 사용자
가 메모리 표현에 접근하지 못하게 함으로써 타입을 더 쉽게 사용하고 데이터를 일관
되게 사용해, 추후에 메모리 HAE 쉽게 개선할 수 있다. 이렇게 하려면 타입의 (모두
가 사용하는) 인터페이스와 (외부에서는 접근할 수 없는 데이터를 사용하는) 구현을 분리해
of 한다. 이를 위한 언어의 vA ufo] 바로 클래스다, 클래스는 일련의 멤버를 포함
하는데, 데이터나 함수, 타입을 멤버로 가질 수 있다. 인터페이스는 클래스의 public
멤버로 정의되며, private 멤버는 인터페이스를 통해서만 접근할 수 있다.

class Vector {

public:
Vector(int 5) :elem{new double(s]}, sz{s} { } // Vector 생성
doubles operator[](int 1) { return elem[i]; } // 요소 접근: 첨자 연산
int size() { return sz; }

private:
double* elem; // 24 & 가리키는 포인터
int sz;      // 822 개수

};
