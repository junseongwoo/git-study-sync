source.pdf는 실제파일쪽수(1부터), printed는 이미지에서 확인한 인쇄쪽수. 연속범위도 배열에 실제쪽수 전부 넣어도 된다. 인쇄쪽수 미확인이면 printed:[] 후 limitations에 명시. 각 원문 절/하위개념은 출처 근접 표기되므로 긴 범위를 뭉개지 말고 필요한 하위 제목 블록과 source를 구체화할 수 있다. blocks p에 source가 별도로 있으면 렌더러는 근접표시 지원 예정.

각 장 코드 최소3~최대10개 정도(짧은 원문 장은 더 적어도 됨)를 선택하되 개념을 설명하는 긴 중요 예제는 보존한다. 짧은 발췌라면 excerpt:true와 생략 사실·범위를 명시. 코드 안에 새 주석·헤더 추가 금지. 원문 변수명·함수명·타입·연산자·상수·문자열·출력·주석을 보존. 출력이 없으면 반드시 지정표시를 사용한다. 코드 배치는 해당 절의 설명 바로 옆 code_ref로 한다. 한 코드가 앞뒤 두 페이지에 걸치면 모두 대조한다. 코드 선택을 위해 중요한 구조체/클래스 몸체를 무단 삭제하지 않는다. 원문 '...'는 그대로 사용하며 발췌/불완전예제임을 해설에 명시한다.

상세성 목표: 원문 핵심개념당 적어도 충분한 정의/원리/조건 설명을 남긴다. 한 장(원문20쪽 안팎) 상세설명 약4000~7000한국어자+코드가 보통 적절하나 원문밀도에 따름. 전체 목차의 절·소절을 누락하지 말고 반복설명은 통합한다. 개념·코드에 없는 결과/설명은 채우지 않는다. 책에서 설명하는 C++11/14/17/20의 지원·제안·실험적상태는 원문시점 그대로 보존하며 현재 사실로 보충하지 않는다.
