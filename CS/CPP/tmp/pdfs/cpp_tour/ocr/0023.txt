함수 선언을 보면 반환 타입은 함수 이름 앞에 주어지고, 함수 이름 뒤의 괄호 안에
인자 타입들이 주어진다.
인자 전달 방식은 초기화 방식(3.6.1절)과 비슷한데, 인자의 타입을 확인한 후 필요하
다면 암묵적인 인자 타입 변환을 수행한디월.4절). 다음 예를 보자.
double 52 = sqrt(2);
// double{2}를 인자로 해 sqrt( ) 호출
double 53 = sq「t("th「ee"); // 에러: sqrt( )는 double 타입 인자를 받음
이러한 컴파일 시점 타입 검사와 변환의 가치를 과소평가해서는 안 된다.
함수 선언은 인자의 이름을 포함할 수 있는데, 이는 프로그램의 코드를 읽는 사람에게
도움을 준다. 그러나 함수 선언이 곧 함수 정의인 경우를 제외하면 컴파일러는 인자
이름을 무시한다. 다음 코드를 보자.
double sqrt(double d);
double square( double ) ,•
// d의 제곱근을 반환
// 주어진 인자의 제곱을 반환
함수의 타입은 다음과 같이 반환 값의 타입과 인자의 타입으로 이뤄진다.
double get(const vector<double>& vec, int index);
// 타입: double(const vector<double>&, int)
함수는 다음과 같이 클래스의 멤버일 수 있는데(2.3, 4.2.1절). 이러한 멤버 함수의 타
입은 클래스의 이름도 포함한다.
char& String: :operator[ 1 ( int index) •,
// 타입: char& String: :(int)
우리는 작성한 코드가 이해하기 쉽기를 원하는데, 이는 유지 보수의 용이성을 높이는
첫걸음이다. 그리고 이해하기 쉬운 코드를 만드는 첫걸음은 컴퓨터가 수행할 작업을
의미 있는 (함수와 클래스로 표현되는) 단위로 나누고, 그 단위에 이름을 붙이는 것이다.
