16.3.2.2 void*
c에서는 void*를 대입 연산의 우측 연산 항으로 쓰거나, 모든 포인터 타입의 초것값
0 무. 시용할 수 있다. 반면 c++에서는 항상 그렇진 않다. 다음 예를 보자.
void f(int n)
int* p = malloc(n*sizeof( int) );
/* C++에서는 불허. C++의 "new"로 할당하자. */
가장 다루기 어려운 호환성 문제가 바로 이것일 수 있다. 이렇게 void*를 다른 포인터
타입으로 암묵적 변환하는 것이 항상 해롭진 않다.
char ch;
void* pv = &ch;
int* pi = pv;
*pi = 666;
// C++에서는 허용하지 않음
// ch와 근처의 바이트를 덮어씀
