두 객체가 독립적인 사실에 주의하자. x의 값에 영향을 주지 않고 y의 값을 변경할
수 있다. 예를 들어 x=99는 y의 값을 바꾸지 않는다. 이는 int를 포함한 모든 타입에
서 마찬가지인데, c 언어외는 비슷하고 자바와 *을 비롯한 언어와는 다른 점이다.
두 객체가 같은(공유된) 값을 참조하기 원한다면 다음과 같이 포인터를 이용해 그 사실
을 명시할 수 있다.
int x = 2;
int y= 3;
int* p = &x;
int* q =&y; // 이 시점에서 p!=q이고 *p!=*q
P=q;
// p가 &y가 됨. 이 시점에서 p=q이고, 따라서 (당연히) *P - *q
이를 그림으로 나타내면 다음과 같다.
2
3
2
92
3
int 변수의 주소 88과 92는 필자가 임의로 선택한 값이다. 다시 설명하면 대입 당한
객체는 대입한 객체로부터 값을 가져오고, 결과적으로 독립된 두 객체(여기서는 포인
터)는 같은 값을 갖는다. 즉, p=q의 결과로 p==q가 되고, p=q로 인해 두 포인터 모두
y를 가리킨다.
참조와 포인터 모두 객체를 참조한다/가리킨다. 그리고 메모리상에서 머신 주소로
표현된다. 그러나 이 둘을 사용하는 언어 규칙은 다르다. 참조에 대한 대입은 참조
가 무엇을 참조하는지에 영향을 주는 대신 참조하는 객체 자체에 대한 대입으로
해석된다.
