using 선언을 이용하면 대상 네임스페이스의 이름을 현재 스코프에 선언한 것처럼
사용할 수 있다. using std: :swap 이후로는 swap을 my-code( )에서 선언한 것과 동일
하다.
표준 라이브러리 네임스페이스의 모든 이름에 접근하려면 다음과 같이 using 선언을
사용한다.
using namespace std;
ustng 선언은 명명된 네임스페이스에 속하는 이름을 지시자가 위치한 ^구 교에서 사
용할 수 있게 해준다. 따라서 std에 using 지시자를 시용한 이후로는 std: :cout를
단순히 cout로 쓸 수 있다. 하지만 using 지시자를 시용하면 해당 네임스페이스의
이름을 선택적으로 사용할 수 없으므로 신중히 사&해야 한다. 애플리케이션 전체에
걸쳐 사용하는 라이브러리(예, std)가 있거나 namespace를 사용하지 않는 이1플리게이
션을 개선하는 과정에서 시용할 수 있다.
라이브러리처럼 큰 규모의 프로그램 구성 요소를 조직화할 때 네임스페이스를 사~&할
수 있다. 이를 바탕으로 독립적으로 개발된 구성 요소로 이뤄진 프로그램을 만드는
일을 단순화할 수 있다.
