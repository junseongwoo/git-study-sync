7.1.1 유한 버퍼 문제 the Bounded-Buffer Problem
유한 버퍼 문제는 6.1절에서 소개하였다. 이 문제는 일반적으로 동기화 프리미티브
(primitive) 59] 능력을 설명하기 위하여 사용된다. 어느 특정 구현에 국한됨 없이 이
해결 방법의 일반적인 구조를 제시한다. 이번 장의 끝부분의 연습 문제에서 관련된 프로
그래밍 프로젝트를 제공한다.
우리가 해결하려는 문제에서 소비자와 생산자는 다음과 같은 자료구조를 공유한다.
int n;
semaphore mutex = 1;

semaphore empty = n;
semaphore full = 0

우리는 no 버퍼로 구성된 풀(200])이 있으며 각 버퍼는 한 FE(item)S 저장할 수
있다고 가정한다. mutex 이진 세마포는 버퍼 풀에 접근하기 위한 상호 배제 기능을 제
공하며 1로 초기화된다. empty} full 세마포들은 각각 비어 있는 버퍼의 수와 7 찬
버퍼의 수를 기록한다. 세마포 empty= 값으로 초기화되고, 세마포 6011은 0으로 초
기화된다.

생산자 코드는 그림 7.1에 나와 있고 소비자 코드는 그림 7.2에 보인다. 생산자와 소
비자 코드 간의 대칭성에 주목하라. 우리는 이 코드에서 생산자가 소비자를 위해 FF 찬
버퍼를 생산해내고, 소비자는 생산자를 위해 비어 있는 버퍼를 생산해내는 것으로 해석
할수 스 있

while (true) {
/* produce an item in next_produced */

wait (empty) ;
wait (mutex);

/* add next produced to the buffer x*/

signal (mutex) ;
signal (full);
}
