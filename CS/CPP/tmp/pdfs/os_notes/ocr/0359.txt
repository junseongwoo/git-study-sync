9.6.1.2 IA-32 페이징 IA-32 Paging
IA-32 구조에서 페이지는 4 KB 또는 4 MB이다. IA-32는 4 KB 크기의 페이지를 사용
할 때 2단계 페이징 기법을 사용한다. 32 bits의 선형 주소는 다음과 같이 나눌 수 있다.
페이지 번호
PI
P2
페이지 오프셋
12
이 구조의 주소 변환 기법은 그림 9.16에서 보여준 기법과 유사하다. 그림 9.23은 IA-32
의 주소 변환을 자세하게 나타내고 있다. 10개의 상위 비트는 IA-32 구조에서 페이지 디
렉터리(page directory)라고 부르는 최상위 페이지 테이블의 엔트리를 가리킨다(CR3
레지스터는 현재 프로세스의 페이지 디렉터리를 가리킨다). 페이지 디렉터리 엔트리는
다음 10개에 의해 인덱스 되는(indexed) 하나의 하위 페이지 테이블을 가리킨다. 마지
막 하위 12비트(0~11)는 페이지 테이블이 가리기고 있는 4 KB 페이지의 오프셋을 나타
낸다.
페이지 디렉터리의 엔트리에는 Page Size 플래그가 있는데 만약 값이 설정되면
페이지 프레임이 일반적으로 사용되는 4 KB가 아니라 4 MB라는 것을 의미한다. 만약
이 플래그가 설정되면 페이지 디렉터리는 하위 페이지 테이블을 가리기는 것이 아니라,
직접적으로 4 MB 페이지 프레임을 가리기게 된다. 그리고 선형 주소의 하위 22비트는
4 MB 페이지 프레임에서의 오프셋을 나타낸다.
