한다. 클러스터링은 메모리 참조의 지역성을 인지하는 전략으로서 페이지 폴트가 발생한

페이지 앞 페이지와 폴트 페이지 뒤)로 구성된다. 다른 모든 페이지 폴트의 클러스터 크
기는 7이다.
Windows 10의 가상 메모리 관리의 주요 구성요소는 작업-집합 관리이다. 프로세
스가 생성되면 최소 50페이지의 작업-집합과 최대 345페이지의 작업-집합이 지정된
다. 작업-집합 최솟값은 프로세스가 메모리에 유지하는 것이 보장된 최소 페이지 개수
이다. 메모리가 충분한 경우 작업-세트 최댓값 만큼의 페이지가 할당될 수 있다. 프로세
스가 hard working-set limits가 설정되어 있지 않으면 이 값들은 무시될 수 있다. 사
용 가능한 메모리가 충분하면 프로세스는 작업-세트 최댓값을 초과하여 증가할 수 있
다. 마찬가지로, 프로세스에 할당된 메모리의 양은 메모리가 많이 필요한 기간에는 최솟
값 이하로 줄어들 수 있다.
Windows는 10.4.5.2에 설명된 대로 지역 및 전역 페이지 교체 정책을 조합하여
LRU 근사 클록 알고리즘을 사용한다. 가상 메모리 관리자는 기용 페이지 프레임 리스
트를 유지한다. 이 리스트와 관련하여 사용 가능한 메모리가 충분한지 여부를 나타내는
임계값이 있다. 작업-집합 최댓값 미만인 프로세스에서 페이지 폴트가 발생하면 가상
메모리 관리자는 기용 페이지 리스트에서 페이지를 할당한다. 작업-집합 최댓값에 도달
한 프로세스에서 페이지 폴트가 발생하고, 메모리가 충분한 경우 프로세스에 사용 기능
한 페이지가 할k갂되어 작업-집합 최댓값을 초과할 수 있다. 싸우 가능한 메모리 양이 충
분하지 않은 경우 커널은 프로세스의 작업-집합에서 지역 LRU 페이지 교체 정책을 사
용하여 교체할 페이지를 선택해야 한다.
