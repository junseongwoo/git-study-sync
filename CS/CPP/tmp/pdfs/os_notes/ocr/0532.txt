13.3.1 1단계 디렉터리 sng1e-Leve1 Directory
가장 간단한 디렉터리 구조가 1단계 디렉터리(single-level directory)이다. 여기서는
모든 파일이 다 같이 한 개의 디렉터리 밑에 있으므로 개념이 간단하다(그림 13.7).
그러나, 1단계 디렉터리 구조는 파일이 많아지거나 다수의 사용자가 久卜&하는 시
스템에서는 심각한 제약을 가지고 있다. 같은 디렉터리에 있는 모든 파일이 존재함으로
각 파일들은 유일한 이름을 가져야 한다. 만약 두 사용자가 자신의 데이터에 test
라는 이름을 준다면, 유일한 명명 규칙은 깨지게 된다. 예를 들어, 한 프로그래밍 학급
에 23명의 학생이 그들의 두 번째 과제에 prog2.c이라는 이름을 주고, 나머지 11명은
assign2•c이라는 이름을 줄 수 있는 것이다. 다행히도 대부분의 파일시스템은 파일의
이름으로 255자까지 허용하기 때문에 고유한 파일 이름을 선택하는 것은 생각보다 쉬운
일이다.
심지어 1단계 디렉터리 구조를 한 명의 사용자가 사우한다고 할지라도, 파일의 이름
이 증가함에 따라서 모든 파일의 이름을 기억하는 것은 어려울 수 있다. 한 사용자가 한
컴퓨터 시스템에 수백 개의 파일을 가지고 또 다른 시스템에 그 정도의 추가적인 파일을
가지는 것은 흔한 일인데 그 많은 파일을 기억하는 것은 어려운 일이다.
13.32 2단계 디렉터리 Two-Leve1
우리가 보아온 것처럼, 1단계 디렉터리는 다른 사용자들 사이에서의 파일 이름에 대한
혼란을 가져온다. 이에 대한 해결책은 각 사용자에게 서로 다른 디렉터리를 만들어주는
것이다.

렉터리(user file directory, UFD)를 가지고, UFD는 비슷한 구조로 되어 있지만, 각
