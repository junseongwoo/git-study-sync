자료구조와 프로그래밍 구조를 잘 선택하면 지역성을 향상할 수 있고, 페이지 폴트
율과 작업 집합의 페이지 수를 줄일 수 있다. 예를 들어, 스택은 항상 한쪽 끝만 참조하
므로 지역성이 높다. 반면, 해시 테이블은 참조(reference)를 분산시기므로 지역성이 나
쁘다. 물론, 지역성은 자료구조의 효율을 측정하는 한 요소일 뿐이다. 그 밖의 매우 중요
한 요소들에는 탐색 속도, 총 메모리 참조 횟수, 총 페이지 접근 횟수 등이 있다.
컴파일러와 로더도 페이징에 큰 영향을 미칠 수 있다. 코드와 데이터를 분리하고 재
진입 기능 코드를 생성하는 것은 코드 페이지를 읽기 전용으로 만들어 코드 페이지를 변
경되지 않게 한다. 변경되지 않은 페이지는 교체 시 페이지 아웃 하지 않아도 된다. 적재
기는 하나의 루틴을 페이지 경계에 걸치지 않도록 할당하여 각 루틴이 한 페이지 내에
완전히 들어가도록 할 수 있다. 서로 호출하는 빈도수가 찾은 루틴들끼리는 서로 같은
페이지에 위지시길 수 있다. 이러한 픢음 작업은 bin-packmg 문제의 일종으로 볼 수
있다. 가변 크기의 적재 세그먼트들을 균일한 크기의 페이지들로 묶으면서 페이지 간 참
조가 최소화되도록 하는 것이다. 이러한 방법은 특히 큰 페이지 크기를 갖는 경우에 유
용하다.
