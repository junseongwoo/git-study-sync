설명
테이블에 처장된 행 데이터를 고유하게 식별하기 위한 기본기를 정의한대 하十의 테이를에 8따의
기본기 제으빤 정의할 수 있다.
기본기 제약을 정의하면 DBMS는 자동으로 UNIQUE 인덱스를 생성하며, 기본기를 구성하는
칼럼에는 NULL을 입력할 수 없다.
결국 '기본기 제약 = 고유기 제약 & NOT NULL 제얚이 된다.
테이블에 저장된 행 데이터를 고유하게 식별하기 위한 고유기를 정의한다. 단 NULL은 고유기
제약의 대상이 아니므로, NULL 값을 가진 행이 여러 개가 있더라도 고유기 제약 위반이 되지
않는다.
NULL 값의 입력을 금지한다 디폴트 상대에서는 모든 칼럼에서 NULL을 허가하고 있지만, 이
제약을 지정함으로써 해당 칼럼은 입력 필수가 된다. N(Jr NULL을 CHÆK의 일부분으로 이해할
수도 있다.
입력할 수 있는 값의 범위 등을 제한한다. CHECK 제약으로는 TRUE or FALSE로 평가할 수
있는 논리식을 지정한다.
관계형 데이터베이스에서 테이블 간의 관계를 정의하기 위해 기본기를 다른 테이블의 외래기로
복사하는 경우 외래기가 생성된다.
외래기 지정시 참조 무결성 제약 옵션을 선택할 수 있다.

DEFAULT 의미
데이터 입력 시 칼럼 값을 지정하지 않은 경우에 NULL 값이 입력된다. 하지만 사전에 DEFAULT 값을 정의했다면,
NULL 값 대신 사전에 정의된 기본 값(DEFAULT)이 자동으로 입력된다.
라. 생성된 테이블 구조 확인
테이블을 생성한 후 테이블의 구조가 제대로 만들어졌는지 확인할 필요가 있다. Oracle은 'DESCRIBE 테이불명;
또는 간략히 'DESC 테이블명;'으로 해당 테이블에 대한 정보를 확인할 수 있다. SQL Server의 경우 'sp-help
dbo.테이블명`'으로 해당 테이블에 대한 정보를 확인할 수 있다.
