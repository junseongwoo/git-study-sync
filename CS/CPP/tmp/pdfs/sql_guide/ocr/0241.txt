1. FROM 절 조인 형태
ANSIASO SQL에서 표시하는 FROM 절의 조인 형태는 다음과 같다.
INNER JOIN
- NAWRAL J이N
- 죄NG 조건절
- ON 조건절
- CR(ES J이N
- OUTER J이N
ANSI/ISO 바L에서 규정한 조인 문법은 WHERE 절에 조인 조건을 기술하는 전통적인 방식의 조인 문법과
차이가 있다. 사용자는 기존 WHERE 절의 검색 조건과 테이블 간의 조인 조건을 구분 없이 사용하던 방식을 그대로
사용할 수 있으면서, 추가된 선택 기능으로 테이블 간의 조인 조건을 FROM 절에서 명시적으로 정의할 수 있게
됐다.
INNER J이N은 조인의 DEFAULT 옵션으로 조인 조건을 만족히는 행들만 반환한다. DEFAULT 옵션이므로
생쪄 가능하지법 CROSS J이N, OUTER J이N과는 같이 사용할 수 없다.
NATURAL J이N은 INNER J이N의 하위 개념으로 볼 수 있으며, 두 테이블 간에 동일한 이름을 갖는 모든
칼럼들에 대해 EQUI(=) J이N을 수행한다. NATURAL INNER J이N이라고도 표시할 수 있으며, 결과는
NATURAL J이N과 같다.
ANSI/ISO SQL 표준 방식의 J이N 문법에서 가장 두드러진 특징은 ON 좌절을 통해 J이N 조건과 데이터
제한 조건을 분리해 기술하는 것이다. 전통적인 방식의 J이N 문법에서는 WHERE 절에 J이N 조건과 데이터 제한
조건이 같이 사용돼 용도가 불분명한 경우가 발생할 수 있었는데, 절의 J이N 조건을 FROM 절의 ON
조건절로 분리해 표시함으로써 사용자가 이해하기 쉽도록 한다.
ON 조건절의 경우 NATURAL J이N처럼 J이N 조건이 숨어 있지 않고, 명시적으로 J이N 조건을 구분할 수
있다 또한 NAWRAL J이N이나 USING 조건절처럼 칼럼명이 똑7뇬}야 된다는 제약 없이 칼럼명이 상호 다르더라도
J이N 조건으로 사용할 수 있으므로 다원한 요구 사함에 대해 유연하게 사용할 수 있다. 다만 FROM 절에 테이블이
많이 사용될 경우 다소 *구하게 보여 가독성이 떨어지는 단점이 있다.
그런 측면에서 SQL *의 경우 ON 좌절만 지원하고 NATURAL J이N과 USING 조건절을 지원하지
않고 있는 것으로 보인다. 본 가이드는 ANSI/ISO SQL 기준에 NAWRAL J이N과 USING 좌절이 표시돼 있으므로
이 부분도 설명한다.
