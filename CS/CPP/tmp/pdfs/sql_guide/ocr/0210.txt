5. 집계함수와 NULL 처리
리포트의 민간을 NULL이 아닌 四RO로 표현하기 위해 NVL(Oracle)/ISNULL(SQL Server) 함수를 사용하는
경우가 많다. 다중 행 함수를 사용하는 경우는 오히려 불필요한 부하가 발생하므로 굳이 NVL 함수를 다중 행
함수 인에 사용할 필요가 없다.
다중 행 함수는 입력 값으로 전체 건수가 NULL 값인 경우만 함수의 결과가 NULL이 나끄 전체 건수 중에서
일부만 NULL인 경우는 NULL인 행을 다중 행 함수의 대상에서 제외한다. 예를 들면 1%명 중 10명의 성적이
NULL 값일 때 평균을 구하는 다중 행 함수 AVG를 사용하면 NULL 값이 아닌 %명의 성적에 대해 평균값을
구하게 된다.
