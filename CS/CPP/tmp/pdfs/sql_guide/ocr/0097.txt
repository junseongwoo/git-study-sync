{표 1-2-6]의 주문 데이터를 보면, 개안,법인번호는 개인과 또는 법인과의 식별자가 상속된 값이다. 이때
고객-구분~ 값을 통해 개인과의 식별자가 상속되었는지, 법인과의 식별자가 상속되었는지를 나타낸다(고객
구분코-드 01: 개인과, 02: 법인고객).
그렇다면 [표 1-2丕]에서 주문번호가 11끄1인 주문의 주문자명을 보여주고 싶을 때는 SQL을 다음과 같이
작성해야 한다.
SELECT 8.개인고객명
FO 추문 A, 개인고객 8
A.주문번호 = 11″1
A.고객구분코드 = ' 01 '
A*O A.개인/법인번호 = B.개인번호
ALL
SELECT B.법인명
FO 주문 A, 법인고객 B
A 주문번호 = 11″1
AtO A.고객구분코드 = ' 02
A,O A.개인/법인번호 = B.법인번호
고객구분코드를 알 수 있다면 명확하게 개인과 또는 법인과 테이블을 선택하여 하나의 테이블만 조인하여
바L을 작성할 수 있다. 그렇지 않은 경우라면 위와 같은 SQL이 최선일 것이다. 이때 주의할 점은 개인번호와
법인번호에 중복이 발생되어서는 안 된다는 것이다. 법인번호는 10자리이므로 개인번호가 십억 명을 초과하지 않는
다면 문제가 되지 않겠지만, 만일 그 이상이 된다면 2건의 데이터가 출력될 수 있다. 이에 해당하는 경우라면 반드시
고객구분코드 값을 변수로 받아야 할 것이다. 또한 어차피 개인번호와 법인번호가 중복되지 않는다는 전제가 있다면
다음과 같은 따L도 가능하다.
