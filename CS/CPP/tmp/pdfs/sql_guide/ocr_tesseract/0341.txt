2. TOP A
SQL Servers TOP 절을 사용해 결과 집합으로 출력되는 행의 수를 제한할 수 있다. TOP 절의 표현식은 다음과
같다.

TOP (Expression) [PERCENT] [WITH TIES]

- Expression : 반환할 행 수를 지정하는 숫자이다.

- PERCENT : 쿼리 결과 집합에서 처음 Expression%2] 행만 반환됨을 나타낸다.

- WITH TIES : ORDER BY 절이 지정된 경우에만 사용할 수 있으며, TOP N(PERCENT)2] 마지막 행과 같은
값이 있는 경우 추가 행이 출력되도록 지정할 수 있다.

한 건의 행만 가져오고 싶을 때는
- SELECT TOP(1) PLAYER NAME FROM PLAYER; {3 사용할 수 있다.

두 건 이상의 행을 가져오고 싶을 때는
- SELECT TOP(N) PLAYER NAME FROM PLAYER; Z|: 행의 개수를 지정할 수 있다.
