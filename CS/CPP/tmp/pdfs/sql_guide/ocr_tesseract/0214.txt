제6절 ORDER BY 절

1. ORDER BY 정렬

ORDER BY 절은 SQL 문장으로 조회한 데이터들을 다양한 목적에 맞게 특정 칼럼을 기준으로 정렬-출력하는
데 사용한다.

ORDER BY 절에 칼럼(0010000)명 대신에 SELECT 절에서 사용한 ALIAS 명이나 칼럼 순서를 나타내는 정수도
사용 가능하다. 그리고 별도로 정렬 방식을 지정하지 않으면 기본적으로 오름차순이 적용되며, SQL 문장의 제일
마지막에 위치한다.

SELECT 칼럼명 [ALIASY]

FROM 테이블명

[WHERE 조건식]

[GROUP BY 칼럼(<01000)이나 표현식]

[HAVING 그룹조건식]

[ORDER BY 칼럼(<01000)이나 표현식 [ASC 또는 DESC]] ;

ORDER BY 절은 2가지의 정렬 방식이 있다.
- ASC(Ascending) : 조회한 데이터를 오름차순으로 정렬한다(기본 값이므로 생략 가능).
- DESC(Descending) : 조회한 데이터를 내림차순으로 정렬한다.

[예제] ORDER BY 절의 예로 선수 테이블에서 선수들의 이름, 포지션, 백넘버를 출력하는데 사람 이름을 내림차순으로 정렬해
출력한다.

SELECT  PLAYER_NAME AS 선수명, POSITION AS 포지션, 840 0 AS 백넘버
FROM PLAYER
ORDER BY PLAYER NAME DESC;
