[예제] 일반 그룹 함수를 GROUPING SETS 함수로 변경해 부서별, JOBE 인원수와 급여 합을 구할 때 GROUPING 5615의
인수 순서를 바꾸어 본다.

SELECT CASE GROUPING (B.DNAME) WHEN 1 THEN '시1 Departments’ ELSE B.DNAME END AS DNAME
, CASE GROUPING (A.J0B ) WHEN 1 THEN ‘All Jobs'       ELSE A.JOB END AS 208

, COUNT (*) AS EMP_CNT, SUM (A.SAL) AS SAL_SUM
FROM EMP A, DEPT B
WHERE B.DEPTNO = A.DEPTNO
GROUP BY GROUPING SETS (A.J0B, B.DNAME)
ORDER BY B.DNAME, A.J0B;
