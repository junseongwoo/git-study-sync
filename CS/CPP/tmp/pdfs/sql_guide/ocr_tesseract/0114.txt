[그림 1-2-25] 주문과 주문상세 모델 인조식별자

주문상품 모델 데이터에 액세스한다고 가정해보자. 여러 가지 액세스 패턴이 있겠지만, 가장 기본적인 액세스
패턴을 다음 SQL 같을 것이다.

SELECT *
FROM 주문상품
WHERE 주문번호 = :81;

또는 다음 SQL 같을 것이다.

SELECT *
FROM 주문상품
WHERE 주문번호 = :81
AD HEHE = 1827.
