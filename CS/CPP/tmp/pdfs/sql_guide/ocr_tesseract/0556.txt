다. 묵시적 형변환

인덱스 칼럼을 사용자가 명시적으로 가공하지 않더라도 조건절에서 비교되는 두 값의 데이터 타입이 다르면
내부적으로 형변환이 일어난다.

예를 들어 emp 테이블 deptno 칼럼은 number 형이다. 이 칼럼에 대한 검색조건으로는 숫자형이 옮지만,
3 실수로 다음과 같이 문자형으로 코딩하는 경우가 종종 생긴다.

select * from emp where deptno = '20'
