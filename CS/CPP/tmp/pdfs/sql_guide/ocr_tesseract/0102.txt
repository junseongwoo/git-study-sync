제4 절 Null 속성의 이해

DBMSE 사용하다 보면 Null 값으로 인한 많은 특이사항들을 접하게 된다. Null 값이 가지는 특성을 이해하지
못한다면 데이터 오류를 경험할 수 있으므로 반드시 숙지해야 할 부분 중 하나다. 다음 모델을 보고 사례별로 Null
값에 대해 알아보자.

Null 허용여부를 알 수 없지만, 바커 표기법에서 속성 앞에 동그라미가 Null 허용 속성임을 의미한다. 즉 해당
속성은 Null 값을 가질 수 있는 속성으로 몇 가지 특성이 존재한다.
