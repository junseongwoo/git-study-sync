4. 인덱스 튜닝 기초

1항 인덱스 기본 원리에서 설명했듯이, B Tree 인덱스를 정상적으로 사용하려면 범위 스캔 시작지점을 찾기
위해 루트 블록부터 리프 블록까지의 수직적 탐색 과정을 거쳐야 한다, 만약 인덱스 선두 칼럼이 조건절에 사용되지
않으면, 범위 스캔을 위한 시작점을 찾을 수 없어 옵티마이저는 인덱스 전체를 스캔하거나 테이블 전체를 스캔하는
방식을 선택한다.

인덱스 선두 칼럼이 조건절에 사용되더라도 범위 스캔이 불가능하거나 인덱스를 아예 사용 못하는 경우가 있는데,
어떤 경우인지 살펴보자.
