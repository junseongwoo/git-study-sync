다. Union All 활용

방금 설명한 방식은 사용자가 어떤 버튼(조회, 다음, 이전)을 눌렀는지에 따라 별도의 SQLE 호출하는 방식이다.
Union 41!을 활용하면 다음과 같이 하나의 SQLE 처리하는 것도 가능하다.

SELECT 거래일시, 체결건수, 체결수량, 거래대금
FROM (
SELECT 거래일시, 체결건수, 체결수량, 거래대금
FROM    시간별종목거래

WHERE    :페이지이동 = "NEXT"      — 첫 페이지 출력 시에도 '\6' 입력
AND       종목코드 = isu dd
AND      거래일시 > :trd_time
ORDER BY 거래일시
)
WHERE ROWNM <= 11
UNION ALL
SELECT 거래일시, 체결건수, 체결수량, 거래대금
FROM (

SELECT 거래일시, 체결건수, 체결수량, 거래대금
FROM      시간별종목거래
WERE :H0JR|O}F = PREV’
AD       종목코드 = :154_ 00
AD       거래일시 ¢= :trd_time
ORDER BY 거래일시 DESC
)
WHERE ROWNUM <= 11
ORDER BY 거래일시
