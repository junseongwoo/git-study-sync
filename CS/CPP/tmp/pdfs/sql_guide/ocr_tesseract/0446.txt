기본적으로 58이다.

[예제] sa 로그인을 한 후 SQL 인증을 사용하는 5010라는 로그인(패스워드: 082019)를 생성해 본다. 로그인 후 최초로
접속할 데이터베이스는 AdventureWorks 데이터베이스로 설정한다,

[예제] SQL Server
CREATE LOGIN SQLD WITH PASSWORD='DB2019', DEFAULT_DATABASE=AdventureWorks;
명령이 완료됐습니다.

유저가 속할 데이터베이스로 이동한 후 처리해야 한다.

[예제] 생성된 SQLD 유저로 로그인한다,

[예제 및 실행 결과] Oracle

SQLD 유저가 생성됐지만 아무런 권한도 부여받지 못했기 때문에 로그인을 하면 CREATE SESSION 권한이
없다는 오류가 발생한다. 유저가 로그인을 하려면 CREATE SESSION 권한을 부여받아야 한다.
