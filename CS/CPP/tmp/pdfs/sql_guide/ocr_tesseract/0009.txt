제1장
데이터 모델링의 이해

장 소개

데이터 처리에 있어 원천 저장소를 제공하는 데이터베이스의 설계 기법인 데이터 모델을 이해하고, 엔터티ㆍ 속성
관계-식별자에 대한 표현방법과 이것을 이용하여 표현하는 기술을 이해한다.

장 구성

데이터 모델에 대한 기본적인 개념을 이해할 수 있도록 모델링의 세 가지 관점과 데이터 모델링의 세 가지 요소,
그에 따른 각각의 표기법에 대해 설명한다. 데이터 모델을 완성하는 측면에서 표기법을 기반으로 전개하여야 할
사항들에 대해 엔터티, 속성, 관계, 식별자 순으로 구성하였다.
