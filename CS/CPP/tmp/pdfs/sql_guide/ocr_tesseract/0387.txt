문제 6. 다음 SQL 문장은 몇 행의 결과를 반환하는가?

VAR V_PR NUMBER = 5;
VAR V_PN NUMBER = 2;

SELECT EMPNO, SAL, RN
FROM (SELECT EMPNO, SAL, ROWNUM AS RN
FROM (SELECT EMPNO, SAL FROM EMP ORDER BY SAL, EMPNO)
WHERE ROWNUM <= :V_PR * :V_PN)
WHERE RN >= (:V_PR * (:VPN -1)) +1;

D0                2행             ® 5행              @ 10행

®
