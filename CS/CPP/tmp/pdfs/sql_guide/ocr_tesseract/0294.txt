제2장 SQL 활용

SELECT DISTINCT
TEAM_ID AS 팀코드, PLAYER NAME AS 선수명, POSITION AS 포지션
, BACK NO AS 백넘버, HEIGHT AS 7|

FROM PLAYER
WHERE TEAM_ID = 'K@2'
OR POSITION = 'GK';

만약 = 번째 질문에 대한 SQL 문에서 04104이라는 집합 연산자 대신에 UNION ^11.이라는 집합 연산자를
사용하면 어떻게 될지 한번 수행해 보자.

[예제]

SELECT TEAN_ID AS 팀코드, PLAYER NAME AS 선수명, POSITION AS 포지션
, BACK_NO AS 백넘버, HEIGHT AS 7|
FROM PLAYER
WHERE TEAM_ID = 'K02'
UNION ALL
SELECT TEAM_ID AS 팀코드, PLAYER NAME AS 선수명, POSITION AS 포지션
, BACKNO AS 백넘버, HEIGHT AS 키
FROM PLAYER
WHERE POSITION = 'GK';
