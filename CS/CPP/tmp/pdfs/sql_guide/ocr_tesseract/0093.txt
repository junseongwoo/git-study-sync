[그림 1-2-14] 계층형 데이터 모델 관계 표현

[그림 I1-2-14}2 Sample Schema 제공되는 EMP(ANY) 모델이다. SQLS 공부할 때 자주 등장하는 모델이다.
주로 EMP DEPT 모델을 활용하여 여러 실습을 진행했을 것이다. 하지만 EMP 모델이 계층형 데이터 모델
(Hierarchical Data Model)o|2h= 사실을 대부분 간과한다. 계층형 데이터 모델에 대한 이해 없이 SQLE 공부하다
계층형 쿼리(000ㅁ60 80절)를 만나면 또 한번 난관에 봉착하게 된다.

계층형 데이터 모델이란 무엇일까? 말 그대로 계층 구조를 가진 데이터를 지칭하는 것이다. 비교적 익숙한 EMP
모델을 기반으로 알아보자.
