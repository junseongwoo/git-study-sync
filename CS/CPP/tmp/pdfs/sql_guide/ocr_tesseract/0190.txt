Hl IS NULL 연산자

NULL(ASCII 00)은 값이 존재하지 않는 것으로, 확정되지 않은 값을 표현할 때 사용한다. 따라서 어떤 값보다
크거나 작지도 않고 ' (공백, ASCH 32)이나 0(Zero, ASCII 48)과 달리 비교 자체가 불가능한 값이다. 연산 관련
NULLS] 특성은 다음과 같다.

- NULL 값과의 수치연산은 NULL 값을 리턴한다.

- NULL 값과의 비교연산은 AZ|(FALSE)E 리턴한다,
- 어떤 값과 비교할 수도 없으며, 특정 값보다 크다/작다고 표현할 수 없다.
