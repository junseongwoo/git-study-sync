SELECT WORKER. EMPNO AS 사원번호, WORKER.ENAME AS 사원명, MANAGER ENAME AS 관리자명
FROM EMP WORKER, EMP MANAGER
WHERE MANAGER .EMPNO = WORKER MGR;

순환 관계로 설계된 사원 테이블은 사원과 관리자가 모두 하나의 사원이라는 개념으로 동일시해 같이 입력돼
있다. 이것을 이용해서 다음 문제를 셀프 조인으로 해결해 보면 다음과 같다. '자신과 상위, 차상위 관리자를 같은
줄에 표시하라.' 이 문제를 해결하기 위해서는 FROM 절에 사원 테이블을 두 번 사용해야 한다.
