최신 버전의 05316 및 SQL Server 환경에서는 MERGE UPDATE (WHEN MATCHED THEN 의하) 및
MERGE INSERT #(WHEN NOT MATCHED THEN 이하)을 선택적으로 사용할 수 있다.

[예제] TEAM_TMP 테이블을 이용해 TEAM 테이블의 기존 데이터를 수정한다.

예제

MERGE
INTO TEAM T
USING TEAM_TWP S
ON (T.TEAM_ID = S.TEAM_ID)
WHEN MATCHED THEN
UPDATE
SET T.REGION_NAME = S.REGION_NAME
, T.TEAM_NAME = S_TEAM_NAME
, T.DDD = S.DDD
, T.TEL = S.TEL;

15 행이 병합됐습니다.

[예제] TEAM_TMP 테이블을 이용해 TEAM 테이블에 없는 데이터를 입력한다.

예제

MERGE
INTO TEAM T
USING TEAM_TWP S
ON (T.TEAM_ID = S.TEAM_ID)
WHEN NOT MATCHED THEN
INSERT (T.TEAM_ID, T.REGION_NAME, T.TEAM_NAME, T.STADIUM_ID, 1.000, T.TEL)
VALUES (S.TEAM_ID, S.REGION_NAME, S.TEAM_NAME, S.STADIUM_ID, 5.000, S.TEL);

5 행이 병합됐습니다.
