과목 M QL 고급 활용 및 튜닝

나. SQL Server 힌트
SQL 5607006에서 옵티마이저 힌트를 지정하는 방법으로는 크게 3가지가 있다.

를 Hols 힌트
테이블명 다음에 WITH 절을 통해 지정한다. fastfirstrow, holdlock, nolock 등

WB 조인 힌트
FROM 절에 지정하며 두 테이블 간 조인 전략에 영향을 미친다. 1000, hash, merge, remote 등

| 쿼리 힌트
FAG 맨 마지막에 한번만 지정할 수 있는 쿼리 VEE 다음과 같이 OPTION HE 이용한다.

앞에서 설명했듯이 SQL Server 문법이나 의미적으로 맞지 않게 힌트를 기술하면 프로그램에 에러가 발생한다.
