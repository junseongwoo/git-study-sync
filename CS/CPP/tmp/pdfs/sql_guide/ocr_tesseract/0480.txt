3. SQL 옵티마이저

SQL 올티마이저(0080260)는 사용자가 원하는 작업을 가장 효율적으로 수행할 수 있는 최적의 데이터 액세스
경로를 선택해 주는 2845의 핵심 엔진이다. 옵티마이저의 최적화 단계를 요약하면 다음과 같다.

1. 사용자로부터 전달받은 쿼리를 수행하는 데 후보군이 될만한 실행계획들을 찾아낸다.

2. 데이터 딕셔너리(08913 Dictionary)ell 미리 수집해 둔 오브젝트 통계 및 시스템 통계정보를 이용해 각 실행계획의
예상비용을 산정한다.

3. 최저 비용을 나타내는 실행계획을 선택한다.
