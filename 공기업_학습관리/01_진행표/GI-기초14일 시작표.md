# 전공·NCS 하 수준 · 기초14일 시작표

진단시험 없이 기초부터 시작한다는 요청을 반영했습니다. **매일 전공60분 + NCS30분 + 직접 풀이20분 + 질문·오답10분 =120분**입니다. 어려운 강화 문제는 기본 예제를 설명한 뒤 엽니다.

각 날: 교재의 해당 부분 읽기 → 쉬운 예제 직접 풀이 → 틀린 이유 한 줄 → 다음 날 답 없이 재풀이. 주1·2의 전공15문제·수리10문제·의사소통5문제는 목표량이며, 이미 본 문제를 외워 맞힌 점수와 구분합니다.
