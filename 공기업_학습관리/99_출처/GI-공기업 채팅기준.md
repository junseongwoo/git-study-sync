# 공기업 IT 공부 요청과 커리큘럼 기준

이 노트는 공기업·공공기관 IT, 전산·데이터직의 시험 공부에 관한 사용자 요청을 정리한 문서다. 학습 계획을 수정하거나 새 질문을 기록할 때 아래 기준을 먼저 확인한다.

공기업 준비 대화에서 확인된 학습 배경은 C# 개발 4년과 전자공학 전공이다. 실무 경력 자체를 전공 필기 숙련도로 판단하지 않으며, 공부 수준은 사용자가 지정한 **하**를 적용한다.

## 과목별 커리큘럼

현재 교재에는 아래 10개 과목이 분리되어 있다. 과목마다 개념을 읽고, 손풀이 예제를 재현하고, 연결 문제를 풀고, 틀린 근거를 기록하는 순서로 진행한다.

1. 자료구조·알고리즘
2. 프로그래밍 기초: C++·Python과 코드 해석
3. DB·SQL
4. 운영체제
5. 소프트웨어공학
6. 정보보안
7. 네트워크
8. 컴퓨터구조
9. 빅데이터·AI 기초
10. NCS

사용자는 “자료구조·알고리즘, DB·SQL, 운영체제, 네트워크, 소프트웨어공학·보안이 시험에 다 나오는가”도 질문했다. **학습용 공통 교재 범위와 실제 지원 기관의 공식 출제범위는 구분한다.** 특정 과목의 응시 필요 여부는 지원할 공고의 전형·직무 기준으로 다시 확인한다.

현재 변환할 학습 데이터는 **216회 × 120분 = 432시간**이다. 하루 1회씩 진행하면 216일, 달력 기준 약 31주다. 원본 데이터의 `week`는 주 6회 기준의 36주 구성이라 매일 공부하는 달력 주차와 다를 수 있다. 원본 순서와 과목 연결은 유지하면서 하루 한 노트로 관리한다.

## 하 수준에서 시작하는 방법

처음 14일의 기초 안내는 본 커리큘럼을 이해하기 위한 **선택형 시작 가이드**다. 216회 계획 외에 매일 별도 공부 시간을 더하는 일정으로 사용하지 않는다. 이해가 어려운 날은 해당 일자의 120분 안에서 기초 용어 설명과 쉬운 예제를 먼저 진행하고, 남은 문제는 미완료로 남긴다.

- 이론: 용어의 뜻 → 작은 예제 → 조건을 바꾼 예제 → 짧은 확인 문제.
- 코딩·SQL: 입력과 출력 확인 → 직접 추적 → 독립 풀이 → 경계값 확인 → 실패 원인 기록.
- NCS: 조건 표시 → 풀이 근거 작성 → 보기별 판단 → 시간 기록 → 오답 재풀이.
- 복습: 답을 가리고 설명하거나 다시 풀고, 기억이 불확실한 부분을 다음 복습 대상으로 남긴다.

실제 공부 시간과 완료 여부를 분리한다. 120분을 사용했더라도 완료 기준을 충족하지 못하면 미완료로 기록하며, 시간이 부족한 날은 실제 공부한 분량과 시간을 그대로 남긴다.

## 질문과 복습을 연결하는 운영 흐름

1. 공부 중 생긴 질문을 질문 기록 노트에 적는다.
2. 질문이 생긴 **일별 학습 노트**와 **과목·장 노트**를 연결한다.
3. 답변이나 추가 설명을 해당 장의 보충 메모에 남긴다.
4. 정답을 보고 이해한 상태와, 답 없이 설명하거나 다시 푼 상태를 구분한다.
5. 해결한 질문·오답을 실제 학습일 기준 **1일·7일·21일 복습** 대상으로 정리한다.
6. 복습에서 다시 틀렸다면 원인과 다음 재풀이 계획을 기록한다.

일별 노트에서는 단계별 체크, 최종 완료 속성, 실제 공부 시간, 실제 학습일, 복습 체크를 기록한다. 질문 기록은 새 학습 과제를 무조건 추가하는 목록이 아니라, 기존 120분 안에서 설명·문제·복습의 우선순위를 조정하는 데 사용한다.

## 이전 제안과 현재 기준의 차이

| 이전 제안 또는 자료 | 현재 적용 |
| --- | --- |
| 주당 공부 시간이 없을 때 제안한 주 12시간 또는 주 12~15시간 | 사용자 확정 시간인 **매일 2시간**을 적용한다. 주 7일 진행 시 주 14시간이다. |
| 초기 코딩 연습에서 익숙한 C# 사용 제안 | 이후 사용자 요청에 따라 **C++·Python**을 주력 시험 연습 언어로 적용한다. |
| 기보 중심, 캠코·주금공 병행 등 기관별 추천 | 과거 추천으로 보관한다. 이번 과목별 교재의 요청 기준은 **IBK·기보 등**이다. 지원 우선순위와 실제 전형은 공고로 확인한다. |
| 24주·8주 등 기존 하위 자료의 개별 계획 | 현재 **216회 일별 계획**의 연결 교재·보충 자료로 활용한다. 동일 내용을 독립 일정으로 중복 배정하지 않는다. |
| 합격 전략 마스터 프롬프트의 서류·지원·면접 단계 | 장기 목표의 배경으로만 참고한다. 이번 옵시디언 학습 템플릿과 120분 공부 일정은 전공·NCS·코딩·SQL·복습 중심이다. |

기관별 채용 상태, 마감일, 응시 자격, 필기 과목, 코딩 허용 언어·배점은 **이 요약 작업에서 최신 공고로 재검증하지 않았다.** 과거 답변에 등장한 정보를 현재 모집 조건으로 사용하지 않는다.
