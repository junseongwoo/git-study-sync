# 공기업 학습관리 보강 내역

## 내용

- 기초14일을 독립 수업14개로 확장: 목표·준비지식·용어3개·손풀이예제·전공/NCS연습·접힌정답·완료기준.
- 1주·2주 복습에 전공10문항·NCS5문항의 확인문제와 약점별 돌아갈 수업 연결.
- 본과정216개 일별 노트에 확인문제 또는 구현·복습 체크를 추가. 기존120분 안에서 수행.
- 과목별 핵심 지도, 과제 유형별 공부법, 질문·오답 작성 예시 추가.

## 사용

- 시작 화면에서 다음기초1개·다음본과정1개·복습3개·설명할질문5개를 표시.
- 전체완료율은 전체216보기에서만 계산해 일부목록의0%/100% 오해 제거.
- 완료일·공부시간이 빠진 완료기록을 따로 표시.
- S→A→B순으로 질문 정렬, 주별7개씩 탐색, 반복템플릿 기본폴더 연결.
- 기존 일별노트의 날짜·완료·시간·복습체크·개인 메모는 보존. 시작표 원래 체크도 남김.

## 확인 범위

공기업 자료만 반영했습니다. 새 채용공고를 조사해 전형기준을 변경한 작업은 아닙니다. 파일과 연결·문제답안·집계범위를 검증했습니다. 실제 옵시디언 화면 자동 연결은 시간초과로 실패하여 실제화면 동작은 미검증입니다.
