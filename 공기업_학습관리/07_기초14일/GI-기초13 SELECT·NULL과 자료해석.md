## 핵심 용어 3개

| 용어 | 쉬운 뜻 |
|---|---|
| SELECT | 결과에 보여 줄 열이나 계산값을 정하는 SQL 절이다. |
| WHERE | 참인 조건을 만족하는 행을 남기는 절이다. |
| NULL | 값을 알 수 없거나 없는 상태의 표지다. 숫자 0과 같지 않다. |

## 전공 개념

논리적 손풀이에서는 먼저 표에서 후보 행을 보고 WHERE에 맞는 행을 남긴 뒤 SELECT 열을 적는다. NULL 검사는 `IS NULL`로 한다. `COUNT(*)`는 행 수, `COUNT(열)`은 그 열이 NULL이 아닌 수를 센다. ORDER BY 없이 결과 순서를 보장한다고 추정하지 않는다.

### 단계별 예제

가상 표 `payment`의 초기 상태는 아래와 같다.

| id | amount |
|---:|---:|
| 1 | 100 |
| 2 | NULL |
| 3 | 0 |
| 4 | 200 |

```sql
SELECT id, amount FROM payment
WHERE amount >= 100 ORDER BY id;
```

1. id 1과 4는 amount>=100이 참이다.
2. id 3의 0은 조건을 만족하지 않는다. id 2의 NULL 비교는 UNKNOWN이어서 WHERE에서 남지 않는다.
3. 결과는 (1,100),(4,200) 두 행이며 ORDER BY id로 순서를 정했다.
4. 전체 표의 COUNT(*)는 4, COUNT(amount)는 3이다. NULL을 찾으려면 amount IS NULL을 사용한다.

## NCS 30분 예제 · 자료해석

가상 처리 건수가 작년 200건, 올해 260건이다. ① 변화량은 60건이다. ② 증가율은 60/200=30%다. ③ 올해 건수가 작년의 130%라는 표현도 맞다. ④ “30% 증가”와 “130% 증가”는 다르다. 기준값 대비 비율과 증감률을 구별한다.

## 답을 가리고 직접 풀기

### 직접풀이 1

가상 표 t의 (id,amount)는 (1,50),(2,NULL),(3,150),(4,0),(5,100)이다. `SELECT id FROM t WHERE amount >= 100 ORDER BY id;`의 결과, 전체 COUNT(*)와 COUNT(amount), `WHERE amount IS NULL`의 id를 적어라.

### 직접풀이 2

가상 A지역 처리량은 작년 80건·올해 100건, B지역은 작년 120건·올해 140건이다. 각 지역 변화량과 전체 증가율을 구하라. “올해는 작년의 몇 %인가”도 구별해 적어라.

> [!success]- 직접풀이 1 정답과 이유 · 풀고 나서 펼치기
> 질의 결과 id는 3,5다. 150과 100이 조건을 만족하고 ORDER BY id로 3이 먼저다. COUNT(*)=5, COUNT(amount)=4. IS NULL 결과 id=2다. NULL과 0을 같은 행으로 취급하지 않는다.

> [!success]- 직접풀이 2 정답과 이유 · 풀고 나서 펼치기
> A와 B의 변화량은 각각 20건이다. 작년 전체 200건, 올해 전체 240건이므로 증가율 40/200=20%다. 올해/작년=240/200=120%다. 120%는 현재 규모의 비율이고 증가한 비율은 20%다.
