## 전공 개념

함수 이름만 보고 원래 변수가 바뀐다고 추정하지 않는다. 아래 함수는 정수를 받아 새 계산 결과를 반환한다. 함수 안 매개변수 x와 바깥 이름 n을 구별한다. NCS에서는 증가량과 증가율을 따로 적는다.

### 단계별 예제

```python
def add_two(x):
    return x + 2

n = 5
r = add_two(n)
print(n, r)
```

1. n은 5이고 호출 인자로 5를 넣는다.
2. 함수 안 x가 5를 가리키므로 x+2는 7이다.
3. 반환값 7을 r에 연결한다. 바깥 n에 새 값을 대입한 문장은 없다.
4. 출력은 `5 7`이다. r=add_two(n)과 n=add_two(n)은 대입 대상이 다르다.

## NCS 30분 예제 · 증감률

가상 접수 건수가 80건에서 100건으로 늘었다. ① 증가량은 100-80=20건이다. ② 증가 전 80건을 분모로 적는다. ③ 증가율=20/80×100=25%다. ④ 80×1.25=100으로 검산한다. 20/100=20%는 새 값을 분모로 한 다른 비율이다.

## 답을 가리고 직접 풀기

### 직접풀이 1

아래 코드에서 p와 q의 최종 값을 설명하라.
```python
def twice(x):
    return x * 2
p = 4
q = twice(p) + 1
```

### 직접풀이 2

가상 작년 이용자 150명, 올해 이용자 180명이다. 증가량과 증가율을 구하고, 작년 값에 증가 배수를 곱해 검산하라.

> [!success]- 직접풀이 1 정답과 이유 · 풀고 나서 펼치기
> p=4, q=9다. twice(4)의 반환값은 8이고 바깥 +1로 9가 된다. p를 바꾸는 대입이 없으므로 p는 4다. 함수 반환과 호출자 변수 수정은 같은 일이 아니다.

> [!success]- 직접풀이 2 정답과 이유 · 풀고 나서 펼치기
> 증가량 30명, 증가율 30/150×100=20%다. 검산은 150×1.20=180이다. 올해 180을 분모로 사용하면 “전년 대비 증가율”이라는 질문의 기준을 바꾼다.
