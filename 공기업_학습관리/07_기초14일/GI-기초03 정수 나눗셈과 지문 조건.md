## 전공 개념

언어와 연산자를 함께 읽는다. Python3의 `/`는 실수 나눗셈, `//`는 아래쪽으로 내림한 몫이다. C++17에서 두 정수의 `/`는 0 쪽으로 소수 부분을 버린다. 양수에서는 7//3과 정수 7/3이 모두 2지만, 음수에서는 차이가 생긴다.

### 단계별 예제

1. 양수 7과 3에서 정수 몫은 2, 나머지는 1이다. 2×3+1=7로 검산한다.
2. Python3의 `7 / 3`은 약 2.333…, `7 // 3`은 2다.
3. 음수 -7/3의 수학적 값은 약 -2.333…이다. Python `-7 // 3`은 아래 정수 -3이다.
4. Python `-7 % 3`은 2이고 (-3)×3+2=-7이다. C++17 정수식 `-7 / 3`은 -2, `-7 % 3`은 -1이어서 (-2)×3+(-1)=-7이다. 두 언어의 몫 규칙을 섞지 않는다.

## NCS 30분 예제 · 지문의 대상과 조건

가상 지침: “교육비 지원 신청은 신규 직원만 가능하다. 신청서는 금요일까지 제출해야 한다. 서류가 빠지면 보완 확인 뒤 심사한다.” ① 대상은 신규 직원이다. ② 기한은 금요일까지다. ③ 누락 서류가 있으면 보완 확인이 먼저다. ④ 금요일 제출만으로 지원 확정이라고 말할 수 없다. 지문은 신청·심사 조건을 말하고 승인 결과는 말하지 않았다.

## 답을 가리고 직접 풀기

### 직접풀이 1

Python3에서 `-10 // 3`, `-10 % 3`을 구하고 몫×3+나머지로 검산하라. C++17 정수식 `-10 / 3`과도 비교하라.

### 직접풀이 2

가상 지침: “신청자는 온라인 교육을 이수해야 면담을 예약할 수 있다. 예약 후 담당자 확인을 받아야 일정이 확정된다.” 교육을 이수하고 면담을 예약했지만 확인을 받지 않았다. 일정이 확정되었는지 판단하고 근거 문장을 적어라.

> [!success]- 직접풀이 1 정답과 이유 · 풀고 나서 펼치기
> Python은 몫 -4, 나머지 2다. -4×3+2=-10이다. C++17 정수 나눗셈은 0 쪽으로 버려 몫 -3이다. 같은 수라도 음수 나눗셈의 버림 방향이 다르다.

> [!success]- 직접풀이 2 정답과 이유 · 풀고 나서 펼치기
> 일정 확정을 단정할 수 없다. “담당자 확인을 받아야 일정이 확정된다”는 조건이 남아 있다. 교육 이수와 예약은 확인을 대신하지 않는다.
