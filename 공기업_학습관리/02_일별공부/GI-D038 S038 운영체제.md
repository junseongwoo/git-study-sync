이 연습은 위120분의 손풀이·문제풀이 시간 안에서 합니다. 먼저 내 답과 근거를 적고 해설을 엽니다.

### B04Q07

P1(도착 0, 버스트 7),P2(2,4),P3(4,1), 문맥 교환 0 인 FCFS의 평균 대기 시간은?

1. 2
2. 4
3. 3
4. 10/3

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 2번
> 
> ② 차트 P1 0~7,P2 7~11,P3 11~12. 대기 0,5,7의 평균 4다. ① 이 데이터의 SRTF 평균,③ SJF 평균, ④ 지정 RR q2의 평균이다. 정책별 값을 혼합하지 않는다.

### B04Q08

같은 P1(0,7),P2(2,4),P3(4,1)을 SRTF로 실행한다. 같으면 현재 작업 유지, 문맥 교환 0. P1의 응답·반환·대기 시간은?

1. 0,12,5
2. 5,12,5
3. 0,7,0
4. 0,12,12

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 1번
> 
> ① P1은 0에 최초 실행,12에 완료, 총 CPU7이라 응답 0, 반환 12, 대기 5다. ② 누적 대기를 응답으로 오인,③ 비선점 완료를 혼동, ④ CPU 시간도 대기로 포함했다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
