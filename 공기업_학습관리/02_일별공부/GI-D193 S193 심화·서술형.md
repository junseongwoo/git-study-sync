### B07Q01

IP MTU1500 바이트,IPv4 헤더 20바이트,TCP 헤더 20바이트, 옵션 없음에서 최대 TCP 데이터 크기는?

1. 1500바이트
2. 1518바이트
3. 1460바이트
4. 1440바이트

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 3번
> 
> ③ IP 패킷 안에서 두 헤더 40을 빼면 1460이다. ① IP 전체와 TCP 데이터를 혼동했다. ② 전형적인 Ethernet 프레임 전체 크기다. ④ IPv6 기본 헤더 40과 TCP20을 뺀 예의 값이다.

### B07Q02

1500바이트를 10Mbit/s 링크로 전송, 거리 200km, 전파 속도 2×10 ^8m/s, 큐·처리 0. 한 링크 마지막 비트 도착까지 시간은?

1. 1.2ms
2. 1ms
3. 12ms
4. 2.2ms

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 4번
> 
> ④ 전송 1500×8/10^7 =1.2ms, 전파 200000/(2×10 ^8)=1ms, 합 2.2ms다. ① 전파누락,② 전송 누락,③ byte/bit 또는 단위 변환 오류다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
