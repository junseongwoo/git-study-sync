### B02Q01

C++17 정수 -7/3과 Python3 -7//3의 결과를 순서대로 고르면?

1. -2,-3
2. -3,-3
3. -2,-2
4. -3,-2

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 1번
> 
> C++17은0 방향 버림으로-2, Python //는 아래 방향 내림으로-3이다. ②은 C++에 floor를 적용했고, ③은 Python에0 방향 버림을 적용했고, ④는 두 규칙을 뒤집었다. 나머지도 C++ -1, Python2로 관계식을 검산한다.

### B02Q02

C++에서 부호 있는 int 곱셈이 표현 범위를 넘는다. 일반적인 표준 관점의 올바른 설명은?

1. 항상0이다.
2. 일반적으로 정의되지 않은 동작이므로 특정 결과를 보장할 수 없다.
3. 항상 최솟값으로 포화한다.
4. 반드시 Python처럼 큰 정수로 자동 확장한다.

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 2번
> 
> 부호 있는 overflow를 wrap 결과로 단정하지 않는다. ①·③는 표준 보장 없는 수치를 정했고, ④는 Python 정수 모델을 C++에 옮겼다. 충분한 타입으로 계산 전에 올려야 하는 예와 부호 없는 모듈러 규칙을 함께 복습한다.
