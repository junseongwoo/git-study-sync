### B02Q13

Python a=[10,20,30,40,50]에서 a[1:4]는?

1. [10,20,30,40]
2. [20,30,40,50]
3. [30,40]
4. [20,30,40]

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 4번
> 
> 시작1 포함·끝4 제외로 인덱스1,2,3이다. ①은 시작을0으로, ②은 끝을 포함으로, ③는 시작을2로 잘못 해석했다.

### B02Q14

Python s='가A'에서 len(s)와 len(s.encode('utf-8'))는?

1. 2,4
2. 2,2
3. 4,2
4. 4,4

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 1번
> 
> 코드 포인트가2개이고 UTF-8은 가3바이트+A1바이트로4바이트다. ②은 문자 수와 바이트 수를 같다고 보았고, ③은 두 단위를 반대로, ④는 str 길이를 바이트 길이로 해석했다. 이 문자열에는 결합 문자 등 추가 조건이 없다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
