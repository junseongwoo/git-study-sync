### B06Q13

검색어를 SQL 값으로 안전하게 전달하는 핵심 방법은?

1. 모든 오류를 숨기기만 한다.
2. HTML 출력만 인코딩한다.
3. 파라미터 바인딩으로 명령과 값을 분리한다.
4. 정렬 열을 사용자가 임의 문자열로 넣게 한다.

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 3번
> 
> SQL 주입의 핵심 경계는 명령 구조와 데이터다. 출력 인코딩은 XSS와 연결되고 정렬 열 등 구조 입력에는 허용 목록이 필요하다.

### B06Q14

게시판에 저장한 내용이 조회 시 스크립트로 실행되는 취약점은?

1. 저장형 XSS
2. 단순 네트워크 압축
3. CSRF만
4. 키 회전

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 1번
> 
> 저장된 입력이 브라우저 실행 문맥으로 들어가는 저장형 XSS다. CSRF는 사용자 브라우저의 인증 정보를 이용한 원치 않는 요청과 관련된다.
