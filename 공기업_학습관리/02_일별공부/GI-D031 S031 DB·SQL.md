### B03Q13

동일 그룹 금액이 300,300,200이다. amount DESC만 기준인 RANK와 DENSE_RANK의 결과는?

1. RANK=1,1,3 / DENSE_RANK=1,1,2
2. 둘 다 1,2,3
3. RANK=1,1,2 / DENSE_RANK=1,1,3
4. RANK=1,2,2 / DENSE_RANK=1,2,3

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 1번
> 
> ① RANK는 동률 뒤 번호를 건너뛰고 DENSE_RANK는 다음 금액 수준을 연속 번호로 매긴다. ②는 ROW_NUMBER를 혼동, ③은 두 정의를 뒤집었고 ④는 정렬 금액과 동률 관계를 반영하지 못한다.

### B03Q14

금액 300,300,200을 id1,2,3순으로 정렬하고 ROWS UNBOUNDED PRECEDING부터 CURRENT ROW까지 SUM을 구했다. 누적 합은?

1. 600,600,800
2. 300,300,200
3. 300,600,800
4. 800,800,800

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 3번
> 
> ③ 행위치 프레임에서 첫 행 300, 두 번째까지 600, 세 번째까지 800이다. ①은 금액 동률을 동시에 포함하는 RANGE 상황, ②은 원래 금액, ④는 전체 파티션 합을 매 행 붙인 경우다.
