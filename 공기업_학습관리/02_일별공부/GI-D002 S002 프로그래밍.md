### B02Q07

C++에서 void f(int x){x=9;}이고 int n=3;f(n);을 수행했다. n은?

1. 9
2. 0
3. 3
4. 정의되지 않은 동작

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 3번
> 
> int 값이 지역 매개변수로 복사되어 호출자 n은3이다. ①는 int&처럼 참조 전달을 가정했고, ②은 임의 초기화 규칙을 적용했고, ④는 정상적인 값 전달을 UB와 혼동했다.

### B02Q08

Python 함수가 매개변수 xs에 append(3)한 뒤 xs=[9]를 반환한다. a=[1,2]를 전달하고 반환값을 b에 저장할 때 a,b는?

1. [9],[9]
2. [1,2,3],[9]
3. [1,2],[9]
4. [1,2,3],[1,2,3]

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 2번
> 
> append는 공유 목록 자체를 바꾸고 xs=[9]는 지역 이름을 새 목록에 연결한다. a는[1,2,3],b는[9]다. ①은 지역 재바인딩이 호출자까지 바뀐다는 오류, ③는 공유 객체 변경 누락, ④는 반환값 재바인딩을 무시했다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
