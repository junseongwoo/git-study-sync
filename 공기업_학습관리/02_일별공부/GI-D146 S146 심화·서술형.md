### B02Q10

Python a=[[1],[2]],b=a.copy() 후 b[0].append(9)와 b.append([3])을 수행했다. a는?

1. [[1,9],[2]]
2. [[1],[2]]
3. [[1,9],[2],[3]]
4. [[9],[3]]

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 1번
> 
> 바깥 목록은 별도이나 첫 내부 목록을 공유해[1,9]가 보인다. 바깥 append는 a에 반영되지 않는다. ②은 깊은 복사처럼 읽었고, ③은 바깥까지 공유하는 대입처럼 읽었고, ④는 append를 교체 연산으로 혼동했다.

### B02Q11

Python grid=[[0]*3]*2;grid[0][1]=7 후 두 행은?

1. [0,7,0]과[0,0,0]
2. [7,0,0]과[7,0,0]
3. 오류 때문에 어떤 행도 없다.
4. [0,7,0]과[0,7,0]

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 4번
> 
> 두 행이 동일한 내부 목록을 참조해 같은 변경을 본다. ①은 독립 행 comprehension 결과와 혼동하고, ②은 인덱스1을0으로 잘못 읽었다. ③는 유효한 리스트 수정이므로 틀리다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
