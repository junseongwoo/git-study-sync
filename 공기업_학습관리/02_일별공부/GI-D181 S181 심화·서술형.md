### B05Q13

정수 19~64만 허용할 때 경계 주변 3점 검사를 위한 집합으로 가장 알맞은 것은?

1. 30,40,50
2. 19 하나
3. 0,100 두 개
4. 18,19,20,63,64,65

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 4번
> 
> 하한·상한과 각각의 인접 안팎 값을 확인한다. 다른 집합은 정상 대표값만 있거나 일부 경계를 빠뜨린다. 문제는 이 장의 3점 방식을 명시했다.

### B05Q14

실행 문장 4개와 if 분기문 1개가 있으며 분기 결과는 참·거짓 총 2개로 센다. 양수 입력 테스트 하나가 4개 문장을 모두 실행했으나 if의 참 결과만 실행했다. 문장·분기 커버리지는?

1. 50%,100%
2. 100%,100%
3. 25%,25%
4. 100%,50%

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 4번
> 
> 실행 문장은 4/4, if 결과는 참·거짓 두 개 중 하나이므로 1/2다. 커버리지 분모가 서로 다르다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
