### B06Q16

HttpOnly 쿠키 속성의 주요 역할은?

1. 모든 API 권한을 자동 승인
2. DB 파일을 백업
3. 브라우저의 모든 XSS 동작을 완전히 차단
4. 해당 쿠키의 JavaScript 직접 읽기를 제한

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 4번
> 
> HttpOnly는 스크립트의 쿠키 직접 접근을 제한한다. XSS의 요청 실행 등 모든 영향을 없애지 않고 서버 인가 검사도 대체하지 않는다.

### B06Q17

서명된 일반 JWT payload에 대한 옳은 설명은?

1. 반드시 암호화돼 읽을 수 없다.
2. 디코딩만 하면 신뢰할 수 있다.
3. 읽을 수 있으므로 민감 정보 최소화와 서명·클레임 검증이 필요하다.
4. 만료 시간을 검사할 필요가 없다.

- 내 선택과 근거:

> [!note]- 정답과 이유 확인
> 정답 3번
> 
> 서명과 암호화는 다르다. 해독 가능한 payload와 검증되지 않은 claim을 신뢰하면 안 되며 필요한 만료·발급자·대상 조건을 확인한다.

**완료를 판단할 근거:** 내 중간 계산·추적표·코드·설명 중 하나를 남기세요. 읽기만 끝냈다면 실제시간은 기록하되 완료는 보류합니다.
