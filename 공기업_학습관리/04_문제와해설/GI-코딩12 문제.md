# 코딩12제 문제만

범위와 입력 계약은 각 문제를 따른다. 해설을 열기 전 본인의 중간 상태를 적는다.

# CX01 이동 구간의 최솟값

n k 다음 n개 정수. n=0이면 k=0이며 빈 줄을 출력한다. 그 외 1<=k<=n<=200000, 각 값은 -10^9..10^9. 각 길이 k 구간의 최솟값을 왼쪽부터 출력한다.

## 예제 입력
```text
5 3
4 2 2 5 1
```

## 예제 출력
```text
2 2 1
```

# CX02 겹치지 않는 회의의 최대 개수

n 다음 n개 시작·종료 쌍. 0<=n<=200000, 0<=시작<종료<=10^9. 반열린 구간 [시작,종료)이며 종료 시각에 다음 회의를 시작해도 된다. 한 회의실에서 선택할 최대 개수를 출력한다.

## 예제 입력
```text
4
0 3
1 2
2 4
3 5
```

## 예제 출력
```text
2
```

# CX03 겹치는 문자열 패턴 찾기

첫 토큰은 text, 둘째는 pattern. 영문 소문자만 사용하며 토큰 -는 빈 문자열을 뜻한다. 길이 합<=200000. 일치 시작 인덱스를 0기반으로 출력한다. 일치가 없으면 빈 줄, 빈 패턴은 0..text길이 위치 모두와 일치한다.

## 예제 입력
```text
ababa aba
```

## 예제 출력
```text
0 2
```

# CX04 온라인 연결 여부

n q 다음 q개 연산. 0 u v는 무방향 연결 추가, 1 u v는 현재 연결 여부 질의. 정점1..n, 1<=n<=200000, q<=200000. 질의마다 연결이면1, 아니면0을 줄별 출력한다. 연결 삭제는 없다.

## 예제 입력
```text
4 5
1 1 2
0 1 2
0 2 3
1 1 3
1 4 4
```

## 예제 출력
```text
0
1
1
```

# CX05 값 갱신과 구간 합

n q, n개 초기값, q개 연산. U i delta는 1기반 원소i에 delta 추가, Q l r은 양 끝 포함 구간합. 1<=n<=200000,q<=200000, 초기값/변화량 -10^9..10^9, 1<=l<=r<=n. 질의 결과를 줄별 출력한다.

## 예제 입력
```text
4 3
1 2 3 4
Q 2 4
U 3 -5
Q 1 3
```

## 예제 출력
```text
9
1
```

# CX06 여러 시작점에서 퍼지는 신호

h w 다음 h×w 정수. 1<=h,w<=500. 0은 빈 칸,1은 벽,2는 시작점. 상하좌우 한 칸 이동에1시간. 모든 벽 아닌 칸 도달까지 최소 시간을 출력한다. 미도달 칸이 있으면-1, 벽만 있으면0.

## 예제 입력
```text
2 4
2 0 1 2
0 0 0 0
```

## 예제 출력
```text
2
```

# CX07 0·1 가중치 최단 거리

n m 다음 m개 u v weight. 방향 그래프, 정점1..n, weight는0또는1. 시작점1에서 모든 정점까지 거리를 출력한다. 도달 불가-1. 1<=n<=100000,m<=200000, 중복간선·자기루프 허용.

## 예제 입력
```text
4 4
1 2 1
1 3 0
3 2 0
2 4 1
```

## 예제 출력
```text
0 0 0 1
```

# CX08 음수 간선과 도달 가능한 음수 사이클

n m, m개 u v weight 방향간선. n<=300,m<=4000,가중치-1000..1000,정점1..n. 시작점1에서 도달 가능한 음수 사이클이 있으면 NEGATIVE CYCLE. 없으면 거리 목록이며 미도달은 INF. 1<=n, 자기루프/중복 허용.

## 예제 입력
```text
4 3
1 2 3
2 3 -5
4 4 -1
```

## 예제 출력
```text
0 3 -2 INF
```

# CX09 장애물이 있는 격자 경로 수

h w 다음 h×w 값,0이 통로1이장애물. 1<=h,w<=1000. (0,0)에서(h-1,w-1)까지 오른쪽 또는 아래로만 움직이는 경로 수를 1000000007로 나눈 나머지. 시작/끝이 막히면0.

## 예제 입력
```text
3 3
0 0 0
0 1 0
0 0 0
```

## 예제 출력
```text
2
```

# CX10 두 문자열의 편집 거리

영문 소문자 토큰 두 개, -는 빈 문자열. 각 길이<=1000. 삽입·삭제·치환 각 비용1, 같은 문자 유지0. 첫 문자열을 둘째로 바꿀 최소 비용을 출력한다.

## 예제 입력
```text
kitten sitting
```

## 예제 출력
```text
3
```

# CX11 트리의 최근 공통 조상

n q, n-1개 무방향간선, q개 u v. 정점1..n인 연결 트리이며 루트1. n<=100000,q<=100000. 각 질의의 가장 깊은 공통 조상을 출력한다.

## 예제 입력
```text
5 3
1 2
1 3
2 4
2 5
4 5
4 3
2 4
```

## 예제 출력
```text
2
1
2
```

# CX12 모든 지점 방문 후 복귀

n과 n×n 비용행렬. 정점0..n-1,1<=n<=16. 방향 비용이며 -1은 간선 없음, 나머지는0..1000000, 대각선0. 정점0에서 시작해 모든 정점을 한 번 방문한 후0으로 돌아오는 최소 비용. 불가능-1,n=1이면0.

## 예제 입력
```text
3
0 2 9
4 0 3
1 8 0
```

## 예제 출력
```text
6
```
