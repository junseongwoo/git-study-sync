# CX01 이동 구간의 최솟값

n k 다음 n개 정수. n=0이면 k=0이며 빈 줄을 출력한다. 그 외 1<=k<=n<=200000, 각 값은 -10^9..10^9. 각 길이 k 구간의 최솟값을 왼쪽부터 출력한다.

## 예제 입력
```text
5 3
4 2 2 5 1
```

## 예제 출력
```text
2 2 1
```

## 원리와 중간 상태

덱에 값이 증가하는 인덱스를 남긴다. 뒤의 더 크거나 같은 값은 새 값보다 빨리 만료되어 쓸모가 없다. 만료 인덱스는 앞에서 제거한다.

[4,2,2]→2, [2,2,5]→2, [2,5,1]→1. 동률일 때 오래된 2를 제거해도 최솟값은 같다.

## 복잡도와 오해

O(n) 시간, O(k) 추가 공간. 각 인덱스는 한 번 들어가고 한 번 나간다.

덱에 값만 담으면 어느 구간에서 만료되는지 잃는다. n=0 분기를 먼저 처리한다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=list(map(int,data.split())); n,k=a[:2]; values=a[2:]
    if n==0: return ''
    q=deque(); out=[]
    for i,x in enumerate(values):
        while q and q[0]<=i-k: q.popleft()
        while q and values[q[-1]]>=x: q.pop()
        q.append(i)
        if i>=k-1: out.append(str(values[q[0]]))
    return ' '.join(out)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX02 겹치지 않는 회의의 최대 개수

n 다음 n개 시작·종료 쌍. 0<=n<=200000, 0<=시작<종료<=10^9. 반열린 구간 [시작,종료)이며 종료 시각에 다음 회의를 시작해도 된다. 한 회의실에서 선택할 최대 개수를 출력한다.

## 예제 입력
```text
4
0 3
1 2
2 4
3 5
```

## 예제 출력
```text
2
```

## 원리와 중간 상태

종료 시각이 빠른 회의부터 고른다. 최적 선택의 첫 회의를 더 빨리 끝나는 회의로 바꾸어도 뒤의 선택 가능성을 줄이지 않는 교환 논증이다.

(1,2)를 고른 뒤 (2,4)를 고르면 2개. 먼저 (0,3)을 고르는 것이 항상 더 좋은 것은 아니다.

## 복잡도와 오해

O(n log n) 시간, 입력 저장 O(n). 정렬 후 탐색은 O(n).

길이가 짧은 순서나 시작이 빠른 순서는 이 최적화를 보장하지 않는다. 겹치는 구간 병합과 목적이 다르다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=list(map(int,data.split())); n=a[0]
    meetings=[tuple(a[1+2*i:3+2*i]) for i in range(n)]
    end=-1; count=0
    for s,e in sorted(meetings,key=lambda p:(p[1],p[0])):
        if s>=end: count+=1; end=e
    return str(count)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX03 겹치는 문자열 패턴 찾기

첫 토큰은 text, 둘째는 pattern. 영문 소문자만 사용하며 토큰 -는 빈 문자열을 뜻한다. 길이 합<=200000. 일치 시작 인덱스를 0기반으로 출력한다. 일치가 없으면 빈 줄, 빈 패턴은 0..text길이 위치 모두와 일치한다.

## 예제 입력
```text
ababa aba
```

## 예제 출력
```text
0 2
```

## 원리와 중간 상태

실패함수 pi는 패턴 접두사 중 현재 접미사와 같은 가장 긴 길이다. 불일치하면 이미 비교한 접두사 정보를 재사용한다.

aba의 pi=[0,0,1]. ababa에서 0,2에 일치한다. 일치 뒤 j=pi[j-1]로 돌아가면 겹치는 두 번째 일치를 놓치지 않는다.

## 복잡도와 오해

O(n+m) 시간, O(m+출력수) 공간. 출력 자체의 비용을 포함한다.

일치 후 j=0으로 리셋하면 겹치는 패턴을 놓칠 수 있다. ASCII 조건을 UTF-8 바이트/문자 일반 규칙으로 확대하지 않는다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    t,p=data.split(); t='' if t=='-' else t; p='' if p=='-' else p
    if not p: return ' '.join(map(str,range(len(t)+1)))
    pi=[0]*len(p); j=0
    for i in range(1,len(p)):
        while j and p[i]!=p[j]: j=pi[j-1]
        if p[i]==p[j]: j+=1
        pi[i]=j
    out=[]; j=0
    for i,c in enumerate(t):
        while j and c!=p[j]: j=pi[j-1]
        if c==p[j]: j+=1
        if j==len(p): out.append(str(i-len(p)+1)); j=pi[j-1]
    return ' '.join(out)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX04 온라인 연결 여부

n q 다음 q개 연산. 0 u v는 무방향 연결 추가, 1 u v는 현재 연결 여부 질의. 정점1..n, 1<=n<=200000, q<=200000. 질의마다 연결이면1, 아니면0을 줄별 출력한다. 연결 삭제는 없다.

## 예제 입력
```text
4 5
1 1 2
0 1 2
0 2 3
1 1 3
1 4 4
```

## 예제 출력
```text
0
1
1
```

## 원리와 중간 상태

서로소 집합의 대표를 찾고 작은 집합을 큰 집합에 붙인다. 경로 압축과 크기 기준 결합을 같이 사용한다.

처음1과2는0. 1-2-3을 연결한 뒤1과3은1. 같은 정점4와4는 간선이 없어도1이다.

## 복잡도와 오해

O((n+q)α(n)) 상각 시간, O(n) 공간. α는 매우 천천히 증가하는 함수다.

대표 번호가 정점의 크기 순서여야 할 필요는 없다. 삭제 연산을 같은 DSU 코드로 처리할 수 있다고 가정하지 않는다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=iter(map(int,data.split())); n,q=next(a),next(a); parent=list(range(n+1)); size=[1]*(n+1)
    def find(x):
        while parent[x]!=x: parent[x]=parent[parent[x]]; x=parent[x]
        return x
    out=[]
    for _ in range(q):
        op,u,v=next(a),next(a),next(a); x,y=find(u),find(v)
        if op==1: out.append(str(int(x==y)))
        elif x!=y:
            if size[x]<size[y]: x,y=y,x
            parent[y]=x; size[x]+=size[y]
    return '\n'.join(out)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX05 값 갱신과 구간 합

n q, n개 초기값, q개 연산. U i delta는 1기반 원소i에 delta 추가, Q l r은 양 끝 포함 구간합. 1<=n<=200000,q<=200000, 초기값/변화량 -10^9..10^9, 1<=l<=r<=n. 질의 결과를 줄별 출력한다.

## 예제 입력
```text
4 3
1 2 3 4
Q 2 4
U 3 -5
Q 1 3
```

## 예제 출력
```text
9
1
```

## 원리와 중간 상태

Fenwick tree는 i의 하위 1비트에 해당하는 길이의 부분합을 저장한다. 갱신은 i+=i&-i, prefix는 i-=i&-i로 이동한다.

첫 질의2+3+4=9. 갱신 후 [1,2,-2,4], 둘째 질의1이다. range(l,r)=prefix(r)-prefix(l-1).

## 복잡도와 오해

초기화 O(n log n), 연산당 O(log n), 공간 O(n). 선형 초기화를 사용한 코드가 아니다.

0기반 인덱스를 갱신 함수에 넣으면 i가 증가하지 않을 수 있다. 총합 범위 상한은 제시 입력에서 4×10^14 이내로 signed64에 들어간다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=iter(data.split()); n,q=int(next(a)),int(next(a)); bit=[0]*(n+1)
    def update(i,x):
        while i<=n: bit[i]+=x; i+=i&-i
    def prefix(i):
        s=0
        while i: s+=bit[i]; i-=i&-i
        return s
    for i in range(1,n+1): update(i,int(next(a)))
    out=[]
    for _ in range(q):
        op=next(a); x,y=int(next(a)),int(next(a))
        if op=='U': update(x,y)
        else: out.append(str(prefix(y)-prefix(x-1)))
    return '\n'.join(out)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

```cpp
    }
```

# CX06 여러 시작점에서 퍼지는 신호

h w 다음 h×w 정수. 1<=h,w<=500. 0은 빈 칸,1은 벽,2는 시작점. 상하좌우 한 칸 이동에1시간. 모든 벽 아닌 칸 도달까지 최소 시간을 출력한다. 미도달 칸이 있으면-1, 벽만 있으면0.

## 예제 입력
```text
2 4
2 0 1 2
0 0 0 0
```

## 예제 출력
```text
2
```

## 원리와 중간 상태

모든 시작점을 거리0으로 큐에 넣고 한 번의 BFS를 수행한다. 각 칸의 최초 방문 거리는 시작점 집합으로부터의 최단 거리다.

두 시작점의 파동을 동시에 진행한다. 첫 시작점만 사용하면 오른쪽 칸의 거리를 과대평가한다. 예제의 가장 늦은 칸은2시간이다.

## 복잡도와 오해

O(hw) 시간과 공간. 시작점마다 BFS를 반복하는 O(시작점수×hw) 방식이 아니다.

시작점이 없어 빈 칸만 있으면-1이다. 벽을 미도달 실패로 세지 않는다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=list(map(int,data.split())); h,w=a[:2]; grid=[a[2+i*w:2+(i+1)*w] for i in range(h)]; dist=[[-1]*w for _ in range(h)]; q=deque()
    for r in range(h):
        for c in range(w):
            if grid[r][c]==2: dist[r][c]=0; q.append((r,c))
    while q:
        r,c=q.popleft()
        for dr,dc in [(1,0),(-1,0),(0,1),(0,-1)]:
            nr,nc=r+dr,c+dc
            if 0<=nr<h and 0<=nc<w and grid[nr][nc]!=1 and dist[nr][nc]<0:
                dist[nr][nc]=dist[r][c]+1; q.append((nr,nc))
    values=[dist[r][c] for r in range(h) for c in range(w) if grid[r][c]!=1]
    return str(-1 if -1 in values else max(values,default=0))

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX07 0·1 가중치 최단 거리

n m 다음 m개 u v weight. 방향 그래프, 정점1..n, weight는0또는1. 시작점1에서 모든 정점까지 거리를 출력한다. 도달 불가-1. 1<=n<=100000,m<=200000, 중복간선·자기루프 허용.

## 예제 입력
```text
4 4
1 2 1
1 3 0
3 2 0
2 4 1
```

## 예제 출력
```text
0 0 0 1
```

## 원리와 중간 상태

완화에 성공한0간선은 덱 앞,1간선은 덱 뒤에 넣어 거리 순서를 유지한다. 오래된 거리 기록은 건너뛴다.

1→2 직접 비용1보다 1→3→2 비용0이 작다. 정점거리0,0,0,1이다. 일반 방문배열로 처음 본2를 확정하면 틀린다.

## 복잡도와 오해

O(n+m) 시간, O(n+m) 공간(간선 및 덱). 0/1 조건을 임의 양수 가중치로 확대하지 않는다.

단순 BFS의 간선 수 최단과 가중합 최단은 다르다. 입력은 방향 그래프다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=iter(map(int,data.split())); n,m=next(a),next(a); g=[[] for _ in range(n)]
    for _ in range(m): u,v,w=next(a)-1,next(a)-1,next(a); g[u].append((v,w))
    inf=10**9; dist=[inf]*n; dist[0]=0; q=deque([(0,0)])
    while q:
        u,old=q.popleft()
        if old!=dist[u]: continue
        for v,w in g[u]:
            nd=old+w
            if nd<dist[v]:
                dist[v]=nd
                if w==0: q.appendleft((v,nd))
                else: q.append((v,nd))
    return ' '.join(str(-1 if x==inf else x) for x in dist)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX08 음수 간선과 도달 가능한 음수 사이클

n m, m개 u v weight 방향간선. n<=300,m<=4000,가중치-1000..1000,정점1..n. 시작점1에서 도달 가능한 음수 사이클이 있으면 NEGATIVE CYCLE. 없으면 거리 목록이며 미도달은 INF. 1<=n, 자기루프/중복 허용.

## 예제 입력
```text
4 3
1 2 3
2 3 -5
4 4 -1
```

## 예제 출력
```text
0 3 -2 INF
```

## 원리와 중간 상태

n-1회 완화 후 한 번 더 개선되면 도달 가능한 음수 사이클이 있다. 시작점에서 도달하지 않은 정점의 간선은 완화하지 않는다.

거리0,3,-2,INF. 정점4의 음수 자기루프는 시작점에서 닿지 않아 NEGATIVE CYCLE을 출력하지 않는다.

## 복잡도와 오해

초기화·출력을 포함해 O(nm+n+m) 시간, O(n+m) 공간이다. 간선이 있으면 통상 O(nm)로 쓴다. 변경 없는 단계에서 일찍 끝낼 수 있다.

INF에 음수를 더해 미도달을 가짜 도달로 만들지 않는다. 음수 간선만 있다고 반드시 사이클이 있는 것은 아니다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=iter(map(int,data.split())); n,m=next(a),next(a); edges=[(next(a)-1,next(a)-1,next(a)) for _ in range(m)]; inf=10**15; d=[inf]*n; d[0]=0
    for _ in range(n-1):
        changed=False
        for u,v,w in edges:
            if d[u]!=inf and d[u]+w<d[v]: d[v]=d[u]+w; changed=True
        if not changed: break
    if any(d[u]!=inf and d[u]+w<d[v] for u,v,w in edges): return 'NEGATIVE CYCLE'
    return ' '.join('INF' if x==inf else str(x) for x in d)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX09 장애물이 있는 격자 경로 수

h w 다음 h×w 값,0이 통로1이장애물. 1<=h,w<=1000. (0,0)에서(h-1,w-1)까지 오른쪽 또는 아래로만 움직이는 경로 수를 1000000007로 나눈 나머지. 시작/끝이 막히면0.

## 예제 입력
```text
3 3
0 0 0
0 1 0
0 0 0
```

## 예제 출력
```text
2
```

## 원리와 중간 상태

각 칸의 경로 수는 위와 왼쪽의 합이다. 1차원 배열에서 dp[c]는 위의 이전 행, dp[c-1]은 이번 행 왼쪽 값이다.

중앙 장애물이 있으므로 위쪽 우회와 아래쪽 우회2개. 장애물을 만나면 해당 dp를0으로 재설정한다.

## 복잡도와 오해

O(hw) 시간, O(w) 추가 공간. Python 예제는 전체 입력 토큰 저장에 O(hw) 공간도 사용한다.

장애물의 dp를 이전 값 그대로 남기면 막힌 경로가 이어진다. 최단 거리 문제와 경로 개수 문제를 구별한다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=iter(map(int,data.split())); h,w=next(a),next(a); dp=[0]*w; dp[0]=1; mod=1000000007
    for r in range(h):
        for c in range(w):
            blocked=next(a)
            if blocked: dp[c]=0
            elif c: dp[c]=(dp[c]+dp[c-1])%mod
    return str(dp[-1])

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX10 두 문자열의 편집 거리

영문 소문자 토큰 두 개, -는 빈 문자열. 각 길이<=1000. 삽입·삭제·치환 각 비용1, 같은 문자 유지0. 첫 문자열을 둘째로 바꿀 최소 비용을 출력한다.

## 예제 입력
```text
kitten sitting
```

## 예제 출력
```text
3
```

## 원리와 중간 상태

dp[i][j]는 앞 i문자를 앞 j문자로 바꾸는 비용이다. 삭제·삽입·치환의 마지막 연산을 비교하고 이전 행만 보존한다.

kitten→sitten(치환1)→sittin(치환1)→sitting(삽입1), 총3. 문자열 길이 차이만 답으로 쓰면 틀린다.

## 복잡도와 오해

초기화·입력을 포함해 O(nm+n+m+1) 시간이다. 두 길이가 양수이면 통상 O(nm)로 쓴다. O(m+1) DP 공간이며 입력 문자열 저장은 O(n+m).

대각선은 갱신 전 이전 행 값을 써야 한다. LCS 길이와 편집 거리는 목적과 점화식이 다르다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a,b=data.split(); a='' if a=='-' else a; b='' if b=='-' else b; row=list(range(len(b)+1))

        new=[i]+[0]*len(b)
        for j,y in enumerate(b,1): new[j]=min(row[j]+1,new[j-1]+1,row[j-1]+(x!=y))
        row=new
    return str(row[-1])

if __name__ == "__main__":
```

# CX11 트리의 최근 공통 조상

n q, n-1개 무방향간선, q개 u v. 정점1..n인 연결 트리이며 루트1. n<=100000,q<=100000. 각 질의의 가장 깊은 공통 조상을 출력한다.

## 예제 입력
```text
5 3
1 2
1 3
2 4
2 5
4 5
4 3
2 4
```

## 예제 출력
```text
2
1
2
```

## 원리와 중간 상태

2^k번째 조상 표를 만든다. 깊이 차이를 이진수로 맞춘 후 큰 점프부터 서로 다른 조상으로 함께 올라간다.

4와5의 답2, 4와3의 답1, 조상과자손2와4의 답2. 같은 정점 질의는 그 정점이다.

## 복잡도와 오해

전처리 O(n log n), 질의 O(log n), 공간 O(n log n). BFS로 재귀 깊이를 피한다.

루트 부모를 자기 자신으로 정해 범위 밖0으로 이동하지 않는다. 깊이부터 맞추지 않으면 조상을 잘못 비교한다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=iter(map(int,data.split())); n,q=next(a),next(a); g=[[] for _ in range(n+1)]
    for _ in range(n-1): u,v=next(a),next(a);g[u].append(v);g[v].append(u)
    k=n.bit_length(); up=[[1]*(n+1) for _ in range(k)]; depth=[-1]*(n+1);depth[1]=0; queue=deque([1])
    while queue:
        u=queue.popleft()
        for v in g[u]:
            if depth[v]<0: depth[v]=depth[u]+1;up[0][v]=u;queue.append(v)
    for j in range(1,k):
        for v in range(1,n+1): up[j][v]=up[j-1][up[j-1][v]]
    out=[]
    for _ in range(q):
        u,v=next(a),next(a)
        if depth[u]<depth[v]: u,v=v,u
        gap=depth[u]-depth[v]
        for j in range(k):
            if gap>>j&1:u=up[j][u]
        if u!=v:
            for j in range(k-1,-1,-1):
                if up[j][u]!=up[j][v]:u,v=up[j][u],up[j][v]
            u=up[0][u]
        out.append(str(u))
    return '\n'.join(out)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```

# CX12 모든 지점 방문 후 복귀

n과 n×n 비용행렬. 정점0..n-1,1<=n<=16. 방향 비용이며 -1은 간선 없음, 나머지는0..1000000, 대각선0. 정점0에서 시작해 모든 정점을 한 번 방문한 후0으로 돌아오는 최소 비용. 불가능-1,n=1이면0.

## 예제 입력
```text
3
0 2 9
4 0 3
1 8 0
```

## 예제 출력
```text
6
```

## 원리와 중간 상태

dp[mask][u]는 mask 집합을 방문하고u에서 끝나는 최소비용이다. 미방문 정점으로만 확장하고 마지막에0복귀 간선을 별도 더한다.

0→1→2→0은2+3+1=6. 0→2→1→0은9+8+4=21이다. 복귀비용을 빼면5가 되어 틀린다.

## 복잡도와 오해

O(2^n n^2) 시간, O(2^n n) 공간. 큰 n에서 다항시간 알고리즘인 것처럼 사용하지 않는다.

0비용 간선은 실제 간선이다. if(cost)로 존재 여부를 검사하면0비용을 삭제한다. -1과0을 구분한다.

## Python3
```python
import sys
from collections import deque

def solve(data):
    a=list(map(int,data.split())); n=a[0]; cost=[a[1+i*n:1+(i+1)*n] for i in range(n)]
    if n==1: return '0'
    inf=10**15; dp=[[inf]*n for _ in range(1<<n)]; dp[1][0]=0
    for mask in range(1<<n):
        if not(mask&1): continue
        for u in range(n):
            if dp[mask][u]==inf: continue
            for v in range(n):
                if not(mask>>v&1) and cost[u][v]>=0:
                    nm=mask|1<<v;dp[nm][v]=min(dp[nm][v],dp[mask][u]+cost[u][v])
    ans=min((dp[-1][u]+cost[u][0] for u in range(1,n) if cost[u][0]>=0),default=inf)
    return str(-1 if ans>=inf else ans)

if __name__ == "__main__":
    print(solve(sys.stdin.read()))
```
