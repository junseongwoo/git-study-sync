## B05Q01

'동시 사용자 200명에서 저장 응답시간 95백분위가 2초 이내'에 가장 가까운 분류는?

1. 성능에 관한 비기능 요구사항
2. 기능 요구사항만 해당
3. 소스 버전 관리 규칙
4. 클래스 다중성

정답: 1번

응답시간·부하·백분위는 품질을 측정하는 성능 조건이다. 기능 자체는 저장 가능 여부다. 버전 관리와 다중성은 이 문장의 측정 대상이 아니다.

연결 장: 05-01

## B05Q02

1. 추적성
2. 암호화
3. 문장 커버리지
4. 전역 변수

정답: 1번

추적성은 요구와 구현·검증 산출물의 연결이다. 암호화는 정보 보호, 커버리지는 테스트 측정, 전역 변수는 구현 요소다.

연결 장: 05-01

## B05Q03

2. 백분위는 마지막 값이므로 판정 불가
3. 95백분위 3초이므로 실패

문제에서 백분위 계산 방식을 정했다. 95번째 값 3초가 요구 2초를 넘는다. 평균·최솟값은 다른 통계이고 마지막 값은 100번째다.

## B05Q21

## B05Q25

가상 성능 기준은 응답 20개의 최근접 순위 95백분위가 2초 이하이다. 18개는 1초, 2개는 4초일 때 판정은?

1. 95백분위 4초로 실패
2. 평균 1.3초로 통과
3. 최댓값을 버리고 1초로 통과
4. 표본 20개이므로 계산 불가

정답: 1번

정답 근거: 순위 ceil(20×0.95)=19이며 19번째 응답 4초가 기준 2초를 넘는다.
「평균 1.3초로 통과」 - 평균은 이 계약의 수용 지표가 아니다.
「최댓값을 버리고 1초로 통과」 - 계약에 최댓값 제외 규칙이 없고 19번째 값도 4초다.
「표본 20개이므로 계산 불가」 - 계산 방식과 표본 수가 명시되어 계산할 수 있다.

연결 장: 05-01

v2가 DB의 old 열을 삭제했고 v1은 old 열을 읽는다. 실행 파일만 v1으로 복귀할 때 가장 직접적인 위험은?

1. 원격 저장소 커밋 수가 줄어듦
2. v1과 변경된 DB 스키마가 호환되지 않음
3. 암호화가 항상 풀림
4. 모든 데이터가 자동 복구됨

정답: 2번

정답 근거: v1이 읽는 열이 없어 코드와 스키마 계약을 함께 복구·검증해야 한다.
「모든 데이터가 자동 복구됨」 - 실행 파일 복귀는 삭제된 열과 자료의 복원을 보장하지 않는다.
「원격 저장소 커밋 수가 줄어듦」 - 이 상황의 직접 원인은 DB 열의 계약이다.
「암호화가 항상 풀림」 - 암호화 해제에 관한 조건이 제시되지 않았다.

## B05Q48

배포 승인에는 오류율 조건·권한 시험·DB 호환성 모두 필요하다. 오류율만 통과했다. 올바른 판단은?

1. 한 조건만 맞으면 전체 통과
2. 남은 필수 검증을 확인하기 전 승인을 확정하지 않음
3. 권한 시험은 버전과 무관하므로 생략
4. DB 호환성은 파일 복사로 자동 증명

정답: 2번

정답 근거: AND 규약의 모든 필수 항목에 통과 근거가 필요하다.
「한 조건만 맞으면 전체 통과」 - 모두 필요하다는 규약을 위반한다.
「권한 시험은 버전과 무관하므로 생략」 - 권한 관련 결함이 있을 수 있으며 필수 시험으로 명시됐다.
「DB 호환성은 파일 복사로 자동 증명」 - 파일 복사는 거래와 스키마의 호환성을 증명하지 않는다.
