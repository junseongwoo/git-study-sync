# 자료구조·알고리즘 - 정답과 해설

자체 제작 학습문항. 공식 기출이나 출제 비중을 재현한 것이 아니다. 먼저 답을 가리고 풀이한다.

## B01Q01

i=1..n에서 내부 반복을 i번 수행한다. 가장 타이트한 시간 복잡도는?

1. Θ(1)
2. Θ(log n)
3. Θ(n^2)
4. Θ(n)

정답: 3번

수행 수는 n(n+1)/2이므로 제곱 항이 지배한다. ①은 입력과 무관하지 않아서, ②는 매번 반으로 줄어드는 과정이 없어서, ④은 내부 반복의 누적을 무시해서 틀린다. n=4일 때10회로 손검산한다.

연결 장: 01-01

## B01Q02

용량을 두 배씩 늘리는 동적 배열에 n번 append한다. 일반적인 설명으로 맞는 것은?

1. 각 append의 최악 시간이 항상 O(1)이다.
2. 평균 O(1)이므로 재할당은 일어나지 않는다.
3. n회 전체 시간은 O(n)으로 제한될 수 있고 회당 상각 O(1)이다.
4. 전체 추가 복사 시간은 반드시 Θ(n^2)이다.

정답: 3번

재할당 한 번에는 기존 원소를 복사하므로 O(n)이 될 수 있지만 전체 복사량1+2+4+…은 O(n)이다. ①은 단일 연산 최악과 상각을 혼동한다. ②은 평균이라는 말과 재할당 여부를 연결한 오류다. ④는 매번 전체를 복사하지 않는 두 배 확장 조건을 무시한다.

연결 장: 01-01

## B01Q03

재귀 깊이 n이고 각 호출이 일정한 양의 지역 정보를 저장한다. 입력 저장 공간을 제외한 호출 스택 공간의 가장 타이트한 상한은?

1. O(1)
2. O(log n)
3. O(n^2)
4. O(n)

정답: 4번

동시에 활성인 호출이 n개이고 호출당 공간이 상수이므로 O(n)이다. ①은 재귀 호출 프레임을 누락했고, ②는 깊이가 log n이라는 다른 조건일 때의 값이며, ③는 호출마다 길이 n의 별도 배열을 만든다는 등의 조건이 없다.

연결 장: 01-01

## B01Q04

배열에 n개가 있고 인덱스 k 앞에 새 원소를 넣는다. 재할당을 제외한 뒤 원소 이동 수는? 0<=k<=n.

1. k
2. n-k
3. n+k
4. 항상 1

정답: 2번

인덱스 k부터 n-1까지 n-k개를 오른쪽으로 민다. k=0이면 n개, k=n이면0개로 경계도 맞는다. ①은 앞부분 크기, ③은 필요 없는 원소까지 더한 값, ④는 가운데 삽입을 끝 삽입과 혼동한 값이다.

연결 장: 01-02

## B01Q05

단일 연결 리스트의 노드 삽입이 O(1)이라는 설명에 필요한 대표 조건은?

1. 리스트가 정렬되어 있어야 한다.
2. 원소 수가 소수여야 한다.
3. 삽입 지점의 이전 노드를 이미 알고 있어야 한다.
4. 노드가 연속 주소에 있어야 한다.

정답: 3번

이전 노드를 알고 있으면 몇 개 연결만 바꾼다. 위치를 먼저 찾는 비용이 O(n)일 수 있다. ① 정렬 여부는 연결 변경의 상수 비용과 무관하고, ② 소수는 필요 없으며, ④ 연속 주소는 배열 성질에 가깝다.

연결 장: 01-02

## B01Q09

## B01Q10

## B01Q26

길이 n 배열의 모든 원소를 읽는다. 두 포인터는 각각 0에서 시작해 앞으로만 이동하고 n을 넘지 않는다. 각 이동과 비교가 O(1)이고 별도 선형 재탐색이 없다. 가장 타이트한 전체 시간은?

1. Θ(n)
2. Θ(n log n)
3. Θ(n^2)
4. Θ(1)

정답: 1번

풀이와 보기별 판정
「Θ(n)」 - 정답. 두 포인터 이동 합은 최대 2n이고 원소 n개를 읽는 하한도 있다.
「Θ(n log n)」 - 오답. 포인터가 반씩 줄어드는 단계나 정렬은 주어지지 않았다.

1. 음수 사이클이 있으므로 T도 유한 최단 거리가 없다.
2. A,B만 해당 사이클의 영향을 받고 T의 최단 거리는 5다.
3. T의 최단 거리는 -2다.
4. 음수 간선이 하나 있으면 어떤 최단 경로도 정의할 수 없다.

정답: 2번

풀이와 보기별 판정
「음수 사이클이 있으므로 T도 유한 최단 거리가 없다.」 - 오답. 사이클에서 T로 도달할 수 있어야 T의 거리를 줄일 수 있다.
「A,B만 해당 사이클의 영향을 받고 T의 최단 거리는 5다.」 - 정답. S에서 사이클에 도달하지만 T로 이어지는 경로가 없어 T는 직접 경로 5다.
「T의 최단 거리는 -2다.」 - 오답. -2는 사이클 한 바퀴 비용이며 T까지의 경로 비용이 아니다.
「음수 간선이 하나 있으면 어떤 최단 경로도 정의할 수 없다.」 - 오답. 음수 사이클 영향이 없는 목적지는 유한 최단 거리를 가질 수 있다.

## B01Q48

음수를 포함한 배열에서 합 K인 연속 구간 수를 prefix 빈도로 센다. 길이 0인 구간을 제외하는 올바른 처리 순서는?

1. 현재 prefix-K의 이전 빈도를 답에 더한 뒤 현재 prefix 빈도를 증가시킨다.
2. 현재 prefix 빈도를 증가시킨 뒤 현재 prefix-K를 조회한다.
3. 초기 prefix 0은 저장하지 않는다.
4. 서로 다른 prefix 값만 저장하고 빈도는 모두 1로 둔다.

정답: 1번

풀이와 보기별 판정
「현재 prefix-K의 이전 빈도를 답에 더한 뒤 현재 prefix 빈도를 증가시킨다.」 - 정답. 이전 경계만 세어 i<j를 보장하며 시작 구간도 초기 0으로 포함한다.

「서로 다른 prefix 값만 저장하고 빈도는 모두 1로 둔다.」 - 오답. 같은 prefix가 여러 번 나타나면 서로 다른 시작 경계의 개수가 필요하다.
