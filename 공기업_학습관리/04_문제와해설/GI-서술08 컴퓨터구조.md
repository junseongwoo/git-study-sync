# 컴퓨터구조: 표현·CPU·성능·메모리 계층 서술형

자체 제작 연습문항입니다. 먼저 내 답안을 작성한 뒤 모범답안을 펼치세요.

## W08Q01

고정 8비트 가산기에서 90+60의 이진 결과, 무부호 값, 2의 보수 값, carry와 signed overflow를 계산하라. C++ signed int 연산에도 같은 순환 결과를 보장할 수 있는지 구분하라.

연결 장: [[GI-C08-01 진수·보수·부동소수점·엔디언]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> 90=01011010,60=00111100, 합의 하위 8비트는 10010110이다. 무부호 값은 150, 2의 보수 부호 값은 150-256=-106이다. 합이 256 미만이므로 carry-out=0이다. 부호 범위 최대 127을 넘고 양수+양수가 음수 패턴을 만들어 signed overflow=1이다. 고정 하드웨어 모형의 비트 결과와 C++ 언어 규칙은 별도이며 C++의 부호 있는 표현 범위 밖 덧셈은 정의되지 않은 동작이므로 같은 순환 값을 보장하지 않는다.
> - 이진 결과 10010110: 2점
> - 무부호 150/부호 -106: 3점
> - carry 0/overflow 1과 근거: 3점
> - 하드웨어와 C++ UB 구분: 2점

## W08Q02

전가산기의 S,Cout 논리식을 적고 A=1,B=0,Cin=1을 검산하라. 4:1 MUX의 선택선 수와 S1S0=10에서 선택되는 입력도 적어라.

연결 장: [[GI-C08-02 논리회로·가산기·조합회로·순차회로]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> S=A XOR B XOR Cin이다. Cout=(A∧B)∨(Cin∧(A XOR B)) 또는 AB+ACin+BCin이다. 입력 1,0,1에서 S=0,Cout=1이며 총합 2의 이진 10과 일치한다. 4개 입력을 고르려면 log_24=2개 선택선이 필요하고 00→D0,01→D1,10→D2,11→D3 계약에서 10은 D2를 고른다.
> - 합 XOR 식: 2점
> - carry 식 동치 표현: 3점
> - 입력 결과 (0,1)과 총합 검산: 3점
> - MUX 선택선 2개와 D2: 2점

## W08Q03

현재 명령 주소 100, 길이 4바이트, 다음 PC 기준 상대 변위 -3이며 변위 단위는 4바이트다. 목적 주소를 계산하고, 기준/단위를 바꾸면 답이 왜 달라지는지 설명하라. 이어 base=1024,index=3,scale=4,disp=8의 유효 주소를 계산하라.

연결 장: [[GI-C08-03 CPU·명령어 사이클·레지스터·주소 지정]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> 다음 PC=100+4=104이며 목적=104+(-3)×4=92다. 현재 PC 기준이면 88이고 바이트 단위 변위이면 101이므로 둘은 제시 계약과 다른 답이다. 기준 PC와 변위 단위를 먼저 확인해야 한다. 별도 유효 주소는 base+index×scale+disp=1024+3×4+8=1044다. 주소 계산은 해당 주소의 실제 데이터를 읽는 동작과 구분한다.
> - 다음 PC 104와 목적 92: 4점
> - 기준/단위 오류 88/101 설명: 2점
> - 유효 주소 식과 1044: 3점
> - 주소 계산과 데이터 읽기 구분: 1점

## W08Q04

명령 5,000,000개,CPI 1.6,클럭 2GHz의 실행 시간을 초/ms로 계산하라. 원래 실행 시간의 60%를 3배 빠르게 하는 경우 전체 향상과 무한 개선 상한도 계산하라.

연결 장: [[GI-C08-04 성능 계산  CPI·클럭·처리량·암달의 법칙]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> 총 사이클=5,000,000×1.6=8,000,000이다. 시간=8×10^6/(2×10^9)=0.004초=4ms다. 암달 새 시간 비=(1-0.6)+0.6/3=0.6이고 전체 향상=1/0.6=5/3배다. 개선 부분을 무한히 빠르게 만들면 남는 시간 비 0.4이므로 최대 향상=1/0.4=2.5배다. 개선 전 시간 비율을 사용한다.
> - 총 사이클 8×10^6: 2점
> - 초/ms 변환 0.004/4: 3점
> - 암달 식과 5/3배: 3점
> - 무한 개선 상한 2.5배: 2점

## W08Q05

5단계·명령 8개·사이클 1ns인 이상적 파이프라인의 총시간과, 정확히 4 stall 사이클이 추가된 시간을 계산하라. 비파이프라인은 명령당 5ns일 때 향상비를 구하고 지연/처리율 차이를 설명하라.

연결 장: [[GI-C08-05 파이프라인·해저드·분기·명령 병렬성]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> 이상적 총시간=(5+8-1)×1=12ns, 4stall 추가 시 16ns다. 비파이프라인 총 8×5=40ns로 이상적 향상 40/12=10/3배, stall 모형 향상 40/16=2.5배다. 파이프라인에서 한 명령 통과 지연은 5ns이고 채운 뒤 처리율은 이상적으로 1명령/ns다. 짧은 입력은 채우기/비우기 비용 때문에 단계 수 5만큼의 향상을 얻지 못한다.
> - 이상적 식과 12ns: 3점
> - stall 16ns: 2점
> - 두 향상비 10/3,2.5: 3점
> - 명령 지연과 처리율 구분: 2점

## W08Q06

32비트 바이트 주소,데이터 8KiB,블록 32B,2-way 캐시의 line/set/tag/index/offset을 구하라. 태그 저장 오버헤드를 데이터 용량과 구분하고, L1 miss 10%·L2 local miss 25%의 전체 메모리 도달률도 계산하라.

연결 장: [[GI-C08-06 캐시·주소 분할·지역성·평균 접근 시간]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> line=8192/32=256,set=256/2=128이다. offset=5,index=7,tag=32-5-7=20비트다. 데이터 8KiB는 256line의 실제 데이터이며 태그 20비트×256,valid/dirty/교체 비트 등은 별도 저장 오버헤드다. L2 local miss는 L1을 놓친 요청 중 비율이므로 전체 메모리 도달률=0.1×0.25=0.025=2.5%다.
> - line256/set128: 3점
> - tag20/index7/offset5: 4점
> - 오버헤드와 데이터 용량 구분: 1점
> - 전체 도달률 식과 2.5%: 2점

## W08Q07

64KiB를 유효 16MiB/s로 전송하고 설정 비용 0.2ms가 한 번 있다. 시간 식과 총 ms를 계산하라. DMA 전송 중 버퍼 재사용의 위험과 캐시 일관성 확인 사항을 설명하라.

연결 장: [[GI-C08-07 주기억장치·버스·인터럽트·DMA]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> 64KiB=65536B,16MiB/s=16777216B/s다. 전송시간=1/256초=3.90625ms,총=4.10625ms다. DMA 중 버퍼를 재사용하면 장치와 CPU가 같은 메모리를 동시에 읽고 써 전송 데이터가 바뀔 수 있다. 완료 확인과 소유권/수명 규칙을 지켜야 한다. 장치와 CPU 캐시의 일관성이 자동 보장되는 플랫폼인지 확인하고, 필요한 경우 플랫폼이 정한 캐시 동기화/메모리 장벽/버퍼 정책을 사용한다.
> - KiB/MiB 바이트 환산: 2점
> - 전송 3.90625ms와 총 4.10625ms: 4점
> - 완료/수명/소유권과 동시 수정 위험: 2점
> - 캐시 일관성은 플랫폼 계약 확인: 2점

## W08Q08

2TB 디스크 4개에서 RAID5와 두 mirror 쌍을 stripe한 RAID10의 데이터 용량을 계산하라. RAID10에서 생존하는 두 고장 조합과 실패하는 두 고장 조합을 하나씩 제시하고, RAID와 백업을 구분하라.

연결 장: [[GI-C08-08 저장장치·RAID·병렬 처리·오류 검출 종합]]

### 내 답안


> [!note]- 모범답안과 자가 채점 기준
> 같은 크기·십진 TB·메타데이터 제외 모델에서 RAID5=(4-1)×2=6TB,RAID10=4×2/2=4TB다. mirror 쌍 (D1,D2),(D3,D4)이면 D1,D3 고장은 각 쌍에 하나씩 남아 생존하지만 D1,D2 고장은 첫 쌍 전체가 없어 실패한다. RAID는 특정 장치 고장에 대한 가용성/내구성을 높이는 구성이고 잘못된 삭제·논리 손상·랜섬웨어·시점 복구까지 대체하는 백업은 아니다. 별도 복구 시점/분리 보관 정책을 가진 백업을 유지한다.
> - RAID5 6TB/RAID10 4TB와 모형: 4점
> - 서로 다른 쌍 고장 생존 예: 2점
> - 같은 쌍 고장 실패 예: 2점
> - 논리 손상/삭제와 백업 구분: 2점
