# CT01 검사 수치 합계와 최댓값

분류: 입출력·정수

## 문제와 입출력

첫 줄 n, 다음 줄 n개의 정수 a가 주어진다. 합계와 최댓값을 공백으로 구분해 한 줄에 출력한다.

제약: 1<=n<=200000, -10^9<=a[i]<=10^9. 합계는 signed64비트 범위 안이다.

## 예제 입력

```text
5
-2 7 7 0 -4
```

## 예제 출력

```text
8 7
```

## 풀이 원리

한 번 읽으며 합계와 최댓값을 갱신한다. 최댓값을0으로 초기화하면 음수만 있을 때 틀린다.

## 손으로 추적

합은 -2→5→12→12→8, 최댓값은 -2→7→7→7→7이다.

## 복잡도

시간O(n), 아래 구현의 배열/전체토큰 저장공간O(n).

## 실수와 경계

n=1, 모든 값 음수, 합계가32비트 초과인 입력을 확인한다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main() {
    ios::sync_with_stdio(false); cin.tie(nullptr);
    int n; cin >> n;
    ll sum=0, best=numeric_limits<ll>::lowest();
    for(int i=0;i<n;i++){ ll x; cin>>x; sum+=x; best=max(best,x); }
    cout<<sum<<" "<<best<<"\n";
}
```

## Python3 정답

```python

a = data[1:1+n]
print(sum(a), max(a))
```


# CT02 문자열 연속 구간 압축

분류: 문자열·구현

## 문제와 입출력

영문 소문자로만 이루어진 비어 있지 않은 문자열 한 줄이 주어진다. 같은 문자가 연속된 각 구간을 문자 개수 순으로 압축해 이어 출력한다. 예: aaabbc→a3b2c1.

제약: 1<=문자열길이<=200000. 입력은 공백·숫자·비ASCII문자를 포함하지 않는다.

## 예제 입력

```text
aaabbc
```

## 예제 출력

```text
a3b2c1
```

## 풀이 원리

현재 구간의 첫 위치에서 같은 문자가 끝나는 위치를 찾아 길이를 기록한다. 두 포인터가 앞으로만 이동한다.

## 손으로 추적

i=0의a구간은j=3, 길이3. 다음b구간길이2, 마지막c구간길이1.

## 복잡도

시간O(n), 출력 저장공간O(n).

## 실수와 경계

마지막 구간 누락, 한 글자, 같은 문자만 있는 경우를 확인한다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    string s;cin>>s;
    for(size_t i=0;i<s.size();){
        size_t j=i+1;
        while(j<s.size() && s[j]==s[i]) ++j;
        cout<<s[i]<<j-i;i=j;
    }
    cout<<"\n";
}
```

## Python3 정답

```python
    i=j
print("".join(out))
```


# CT03 장치 코드 빈도 조회

분류: 해시

## 문제와 입출력

첫 줄 n q, 다음 줄 n개의 정수 코드, 다음 줄 q개의 조회 코드가 주어진다. 각 조회 코드의 등장 횟수를 입력 순서대로 한 줄에 하나씩 출력한다.

제약: 1<=n,q<=200000, -10^9<=코드<=10^9.

## 예제 입력

```text
5 3
4 4 -1 7 4
4 0 -1
```

## 예제 출력

```text
3
0
1
```

## 풀이 원리

코드별 횟수를 해시에 누적한다. 없는 키의 횟수는0이다.

## 손으로 추적

4:3,-1:1,7:1. 조회4→3,0→0,-1→1.

## 복잡도

평균시간O(n+q), 공간O(n+q)는전체입력·출력저장포함. 해시 최악비용은별도.

## 실수와 경계

없는 코드 조회, 음수 키, 조회 순서와 횟수 출력을 구분한다.

```cpp

#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int n,q;cin>>n>>q;unordered_map<ll,int> cnt;
```

# CT04 점수와 ID로 정렬

분류: 다중 기준 정렬

## 문제와 입출력

첫 줄 n, 이후 n줄에 서로 다른 정수 ID와 점수가 주어진다. 점수 내림차순, 동점이면 ID 오름차순으로 정렬하여 ID만 한 줄에 하나씩 출력한다.

제약: 1<=n<=200000, 1<=ID<=10^9, 0<=점수<=10^9.

## 예제 입력

```text
4
30 80
10 90
20 80
40 90
```

## 예제 출력

```text
10
40
20
30
```

## 풀이 원리

모든 정렬 기준을 명시한다. Python key=(-score,id), C++은 점수가 다를 때 >, 같으면 ID의 <를 사용한다.

## 손으로 추적

90점은10,40순서. 80점은20,30순서다.

## 복잡도

시간O(n log n), 데이터 저장O(n).

## 실수와 경계

C++비교함수에<=를 쓰지 않는다. ID와 점수의 열 순서를 바꾸지 않는다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int n;cin>>n;vector<pair<ll,ll>> a(n);
    for(auto &p:a)cin>>p.first>>p.second;
    sort(a.begin(),a.end(),[](const auto &x,const auto &y){
        if(x.second!=y.second)return x.second>y.second;
        return x.first<y.first;
    });
    for(auto p:a)cout<<p.first<<"\n";
}
```

# CT06 합이 목표인 인덱스 쌍 수

분류: 정렬·투포인터

## 문제와 입출력

첫 줄 n target, 다음 줄 n개의 정수. i<j이며a[i]+a[j]=target인 인덱스 쌍의 개수를 출력한다. 값이 같아도 인덱스가 다르면 별도 쌍이다.

제약: 1<=n<=200000, |a[i]|,|target|<=10^9. 답은64비트범위.

## 예제 입력

```text
5 4
1 1 3 3 2
```

## 예제 출력

```text
4
```

## 풀이 원리

정렬 후 양끝을 좁힌다. 합이 맞으면 같은 값의 묶음 길이를 곱한다. 양끝 값이 같으면 남은k개에서k(k-1)/2를 더하고 종료한다.

## 손으로 추적

왼쪽1이2개, 오른쪽3이2개이므로4쌍. 가운데2는 혼자라 추가쌍이 없다.

## 복잡도

시간O(n log n), 저장O(n).

## 실수와 경계

서로 다른 값 쌍 수와 인덱스 쌍 수를 혼동하지 않는다. n개의0,target0이면n(n-1)/2다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int n;ll t;cin>>n>>t;vector<ll>a(n);for(auto&x:a)cin>>x;
    sort(a.begin(),a.end());int l=0,r=n-1;ll ans=0;
    while(l<r){ll s=a[l]+a[r];
        if(s<t)++l;else if(s>t)--r;
        else if(a[l]==a[r]){ll k=r-l+1;ans+=k*(k-1)/2;break;}
        else{ll x=a[l],y=a[r],cl=0,cr=0;
            while(l<=r && a[l]==x){++cl;++l;}
            while(r>=l && a[r]==y){++cr;--r;}
            ans+=cl*cr;}
    }cout<<ans<<"\n";
}
```

## Python3 정답

```python
import sys
d=list(map(int,sys.stdin.buffer.read().split()));n,target=d[:2]
a=sorted(d[2:2+n]);l=0;r=n-1;ans=0
while l<r:
    s=a[l]+a[r]
    if s<target:l+=1
    elif s>target:r-=1
    elif a[l]==a[r]:
        k=r-l+1;ans+=k*(k-1)//2;break
    else:
        x,y=a[l],a[r];cl=cr=0
        while l<=r and a[l]==x:cl+=1;l+=1
        while r>=l and a[r]==y:cr+=1;r-=1
        ans+=cl*cr
print(ans)
```

# CT08 막대 동일 길이 절단

분류: 최댓값 파라메트릭 탐색

## 문제와 입출력

첫 줄 n k, 다음 줄 n개의 양의 정수 막대 길이. 정수 길이L>=1로 잘라 총k개 이상을 만들 수 있는 최대L을 출력한다. 불가능하면0. 절단 손실은 없다.

제약: 1<=n<=100000, 1<=k<=10^9, 1<=길이<=10^9.

## 예제 입력

```text
4 11
802 743 457 539
```

## 예제 출력

```text
200
```

## 풀이 원리

가능(L):Σ(length//L)>=k. L이 커질수록 조각수가 줄어드는 단조성으로 마지막 가능한 길이를 찾는다.

## 손으로 추적

L200이면4+3+2+2=11가능,201이면3+3+2+2=10불가.

## 복잡도

시간O(n log M), 공간O(n), M=최대길이.

## 실수와 경계

L=0을 검사하면0으로나눔이다. low=1,답초기0으로 불가능을 처리한다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int n;ll k;cin>>n>>k;vector<ll>a(n);for(auto&x:a)cin>>x;
    ll lo=1,hi=*max_element(a.begin(),a.end()),ans=0;
    while(lo<=hi){ll mid=lo+(hi-lo)/2,cnt=0;
        for(ll x:a)cnt+=x/mid;
        if(cnt>=k){ans=mid;lo=mid+1;}else hi=mid-1;
    }cout<<ans<<"\n";
}
```

## Python3 정답

```python
import sys

    mid=(lo+hi)//2
    if sum(x//mid for x in a)>=k:ans=mid;lo=mid+1
    else:hi=mid-1
print(ans)
```


# CT09 괄호 문자열 판정

분류: 스택·불변식

## 문제와 입출력

문자 (와 )로만 이루어진 비어 있지 않은 한 줄을 읽는다. 올바른 괄호열이면YES, 아니면NO를 출력한다.

제약: 1<=길이<=200000.

## 예제 입력

```text
(()())
```

## 예제 출력

```text
YES
```

## 풀이 원리

열린 괄호 수를 누적한다. 모든 접두사의 균형값이 0 이상이고 마지막에 0이면 올바른 괄호열이다. 한 종류의 괄호에서는 스택 원소 대신 개수만 보관할 수 있다.

## 손으로 추적

(()())의 균형값은 1,2,1,2,1,0이다. )(...는 첫 접두사부터 음수여서 실패한다.

## 복잡도

시간O(n), 추가공간O(1)이며 입력문자열저장O(n).

## 실수와 경계

열림·닫힘의 총개수가 같아도 순서가 틀릴 수 있다. 마지막 균형값이 양수면 닫힘이 부족하다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    string s;cin>>s;int bal=0;bool ok=true;
    for(char c:s){bal+=(c=='('?1:-1);if(bal<0){ok=false;break;}}
    cout<<(ok && bal==0?"YES":"NO")<<"\n";
}
```

## Python3 정답


# CT11 파일 합치기 최소 비용

## 문제와 입출력

첫 줄 n, 다음 줄 n개의 양의 파일 크기. 임의 두 파일을 합칠 때 두 크기의 합만큼 비용이 들고 새 파일 크기도 그 합이다. 모두 하나로 합치는 최소 총비용을 출력한다. 원래 인접 순서를 지킬 필요는 없다.

## 풀이 원리

가장 작은 두 파일을 반복해서 합친다. 최적 병합 트리의 가장 깊은 형제 잎에 가장 작은 두 값을 둘 수 있다는 교환 논리로 이 선택을 정당화한다.

## 손으로 추적

## 문제와 입출력

첫 줄 n m, 이후 m줄의 u v는 u 작업을 v보다 먼저 수행해야 한다는 뜻이다. 가능한 위상 순서 중 사전식으로 가장 작은 정점 번호 순서를 공백으로 출력한다. 사이클로 불가능하면 IMPOSSIBLE을 출력한다.

## 예제 입력

```text
1 3
2 3
3 4
```

## 예제 출력

```text
1 2 3 4
```

## 풀이 원리

진입 차수가 0인 작업 중 가장 작은 번호를 최소 힙에서 꺼낸다. 후속 작업의 차수를 낮추고 새로 0이 된 작업을 힙에 넣는다. 처리한 개수가 n보다 작으면 사이클이 있다.

## 손으로 추적

가능 집합 {1,2}에서 1을 선택하고 다음에 2를 처리한다. 이후 차수가 0이 된 3, 마지막 4를 처리한다.

## 복잡도

## 실수와 경계

일반 큐로도 위상 순서를 만들 수 있지만 사전식 최소는 보장되지 않는다. 사이클 판단을 위해 전체 처리 개수를 확인한다.

## C++17 정답

```cpp
    while(m--){int u,v;cin>>u>>v;g[u].push_back(v);++deg[v];}
    priority_queue<int,vector<int>,greater<int>> h;vector<int>out;
    for(int u=1;u<=n;u++)if(deg[u]==0)h.push(u);
    while(!h.empty()){int u=h.top();h.pop();out.push_back(u);
        for(int v:g[u])if(--deg[v]==0)h.push(v);}
```

# CT15 비음수 망 최단 거리

분류: 다익스트라

## 문제와 입출력

첫 줄 n m s, 이후 m줄에 유향 간선 u v weight가 주어진다. 시작점 s에서 각 정점 1..n까지의 최소 비용을 공백으로 출력한다. 도달할 수 없는 정점은 -1이다.


## 예제 출력

```text

```

## 풀이 원리

힙에서 최소 거리 후보를 꺼내 인접 간선을 완화한다. 꺼낸 거리가 현재 dist와 다르면 오래된 후보이므로 버린다. 모든 가중치가 0 이상이라는 조건이 필요하다.

## 손으로 추적

1에서 먼저 2=10,3=1이 된다. 정점 3을 꺼내 2를 거리 2로 갱신한다. 정점 2를 꺼내 4=4가 된다. 나중에 꺼낸 오래된 2=10 후보는 무시한다.

## 복잡도

이 lazy-heap 구현시간O(n+m log(m+1)), 공간O(n+m).

## 실수와 경계

음수 간선에는 일반 다익스트라를 사용하지 않는다. 0 가중치, 도달 불가, 32비트를 넘는 거리를 확인한다. visited를 후보를 넣는 순간 확정하면 틀릴 수 있다.

# CT16 장치망 최소 연결 비용

## 문제와 입출력

첫 줄 n m, 이후 m줄에 무방향 간선 u v weight가 주어진다. 모든 정점을 연결하는 최소 신장 트리의 비용을 출력한다. 연결할 수 없으면 -1이다. 정점이 하나면 비용은 0이다.


## 풀이 원리

가벼운 간선부터 두 정점이 서로 다른 집합일 때 선택한다. DSU로 사이클을 피하고 경로 압축과 크기 기반 합침을 사용한다. n-1개의 간선을 골랐는지 확인한다.

## 실수와 경계

## C++17 정답

```cpp

#include <vector>
#include <string>
#include <algorithm>

#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>

using ll = long long;
struct DSU{
    vector<int>p,sz;DSU(int n):p(n+1),sz(n+1,1){iota(p.begin(),p.end(),0);}
    int find(int x){while(p[x]!=x){p[x]=p[p[x]];x=p[x];}return x;}
    bool unite(int a,int b){a=find(a);b=find(b);if(a==b)return false;
        if(sz[a]<sz[b])swap(a,b);p[b]=a;sz[a]+=sz[b];return true;}
};
struct Edge{int u,v;ll w;};
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int n,m;cin>>n>>m;vector<Edge>e(m);for(auto&x:e)cin>>x.u>>x.v>>x.w;
    sort(e.begin(),e.end(),[](const Edge&a,const Edge&b){return a.w<b.w;});
    DSU d(n);ll cost=0;int used=0;
    for(auto x:e)if(d.unite(x.u,x.v)){cost+=x.w;++used;}
    cout<<(used==n-1?cost:-1)<<"\n";
}
```

분류: 0/1 DP

## 문제와 입출력

첫 줄 n capacity, 이후 n줄에 물건 무게 w와 가치 v가 주어진다. 각 물건은 최대 한 번 선택한다. 총무게가 capacity 이하인 최대 가치를 출력한다. 아무것도 선택하지 않아도 된다.

제약: 1<=n<=100,0<=capacity<=10000,1<=w<=10000,0<=v<=10^9. 답64비트범위.

## 예제 입력

```text
3 5
2 3
3 4
4 5
```

## 예제 출력

```text
7
```

## 풀이 원리

dp[c]는 지금까지 처리한 물건들로 용량 c 이하에서 얻는 최대 가치다. 물건마다 c를 큰 값부터 내려가며 dp[c-w]+v와 비교한다. 역순 갱신은 현재 물건을 아직 사용하지 않은 이전 상태를 읽게 한다.

## 손으로 추적

첫 두 물건의 무게 합은 2+3=5, 가치 합은 3+4=7이다. 무게 4인 물건의 가치 5보다 크다.

## 복잡도

시간O(n capacity), 공간O(capacity+n)은전체입력저장포함.

## 실수와 경계

용량을 순방향으로 갱신하면 같은 물건을 여러 번 쓰는 효과가 생긴다. capacity=0, 모든 물건의 무게 초과, 32비트를 넘는 가치 합을 확인한다.

## C++17 정답

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <queue>
#include <stack>
#include <unordered_map>
#include <numeric>
#include <limits>
#include <functional>
using namespace std;
using ll = long long;
int main(){
    ios::sync_with_stdio(false);cin.tie(nullptr);
    int n,cap;cin>>n>>cap;vector<ll>dp(cap+1,0);
    while(n--){int w;ll v;cin>>w>>v;
        for(int c=cap;c>=w;c--)dp[c]=max(dp[c],dp[c-w]+v);}
    cout<<dp[cap]<<"\n";
}
```
