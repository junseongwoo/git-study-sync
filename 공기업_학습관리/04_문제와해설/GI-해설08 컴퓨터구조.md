# 컴퓨터구조: 표현·CPU·성능·메모리 계층 - 정답과 해설

## B08Q01

8비트 2의 보수 패턴 11110110의 부호 있는 값은?

1. -9
2. 118
3. 246
4. -10

정답: 4번

부호 없는 값 246에서 256을 빼면 -10이다. 00001010을 반전하고 1을 더해도 같은 패턴이다. ①는 1 추가를 놓친 오류,②은 부호 비트를 떼는 부호-크기 오해,③는 무부호 해석이다.

연결 장: 08-01

1. 12,34,56,78
2. 78,56,34,12

최하위 바이트 78을 먼저 저장하고 56,34,12를 둔다. ①은 big-endian이고,③·④는 바이트 안의 숫자나 비트를 잘못 뒤집었다. 엔디언은 바이트 순서다.

## B08Q27

8비트 가산기의 90+60을 무부호와 2의 보수 부호 해석으로 분석한다. 옳은 설명은? 언어 수준이 아닌 고정 8비트 하드웨어 모형이다.

1. 무부호·부호 모두 정상 150이다.
2. 무부호 150은 정상이며 부호 해석 -106은 signed overflow다.
3. 최상위 carry가 1이므로 부호 오버플로다.
4. 부호 해석은 +106이다.

풀이와 보기별 판정
「무부호 150은 정상이며 부호 해석 -106은 signed overflow다.」 - 정답. 150<256으로 carry는 0이지만 150>127으로 signed overflow가 생긴다.
「무부호·부호 모두 정상 150이다.」 - 오답. 8비트 signed 형은 +150을 표현하지 못한다.
「최상위 carry가 1이므로 부호 오버플로다.」 - 오답. 이 덧셈의 carry는 0이며 carry와 signed overflow는 다른 판정이다.
「부호 해석은 +106이다.」 - 오답. 10010110의 2의 보수 해석은 150-256=-106이다.

연결 장: 08-01
