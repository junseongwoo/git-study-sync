# 매일 사용하는 순서

## 1. 공부1개 열기

[[GI-시작하기]]에서 ‘다음 기초’ 또는 ‘다음 본과정 공부’를 엽니다. 전공·NCS가 하 수준이면 먼저 기초 예제를 풀고, 이해한 부분은 반복하지 않습니다.

## 2. 120분 공부

교재 → 내 풀이 → 해설 → 답 없이 재풀이 순서로 진행합니다. 하루노트의 작은 연습은 기존 문제풀이 시간 안에서 합니다. 시간이 부족하면 중단 위치를 ‘다음 행동’에 적습니다.

## 3. 마지막에 세 값만 기록

노트 위 속성에서 `actual_minutes`에 **이 과제에 쓴 누적 공부시간**을 분으로 적습니다. 예: 어제70분에 오늘50분을 더 공부했다면120으로 기록합니다. 완료 기준을 충족했으면 `completed`를 체크하고 `completed_date`에 처음 완료한 실제 날짜를 입력합니다. 120분을 썼다고 무조건 완료하지 않습니다.

이 과제의 복습시간도 같은 값에 더합니다. 다른 과제를 공부한 시간은 그 과제에 적어 중복 합산을 피합니다. 하루 전체는120분 안에서 배분하고, 한 과제를 여러 날 공부하면 누적값은120을 넘을 수 있습니다. 전체 진행표의 시간 합계는 본과정에 기록한 누적 시간이며 기초14일은 별도로 집계합니다.

시간별 체크는 진행 단계, 위 완료 속성은 과제 전체의 완료입니다. 자동으로 서로 바뀌지는 않습니다. [[GI-진행표.base#기록 확인]]에서 날짜·시간이 빠진 완료 기록을 찾을 수 있습니다.

## 4. 다음 공부로

[[GI-시작하기]]로 돌아오면 다음 미완료 과제가 표시됩니다. 읽기만 한 질문은 그대로 두고, 답 없이 설명되는 질문만 완료 체크합니다.

## 복습 체크

1·7·21일 복습은 최초 완료일로 계산합니다. 답 없이 다시 풀었다면 해당 노트의 `review_1`, `review_7`, `review_21` 중 이번 차례만 체크합니다. 7일을 기다리지 않고 1일 복습을 늦게 했더라도 최초 완료일 기준을 유지합니다. 약하면 체크하지 않고 다음날 다시 풉니다. 복습이 끝나도 최초 `completed_date`는 바꾸지 않습니다. 질문의 복습일은 [[GI-추가질문표.base#질문 복습기한|질문 복습기한]]에서 확인하고, 다시 설명한 뒤 다음 `review_date`를 정하거나 더 필요 없으면 비웁니다.

## 한동안 쉬었을 때

‘다음 공부’는 날짜에 관계없이 가장 앞의 미완료를 보여줍니다. 밀린 양을 몰아하지 않습니다. 예정일을 바꾸려면 [[GI-진행표.base#전체216]]에서 해당 예정일을 편집하세요. 전체 일정이 자동 재배치되지는 않습니다.
