# 사용 설정과 기기 공유

## 기존 옵시디언에서

이 폴더는 바탕화면 `Obsidian/git-study-sync/공기업_학습관리`에 추가했습니다. 옵시디언 빠른 전환에서 `GI-시작하기`를 열면 됩니다. 이번 개선에서 기존 공부 기록을 보존했고, 기본 Templates의 폴더가 비어 있어 이번 템플릿 폴더를 연결했습니다.

진행표는 기본 **Bases** 기능입니다. 이 보관함에서 Bases와 Templates는 이미 활성화되어 있는 것을 확인했습니다. 표에서 완료·실제시간·완료일을 편집하면 해당 Markdown 속성에 저장됩니다. 단계 체크는 세부 과정, `completed` 속성은 최종 과제 완료를 뜻합니다.

## 반복 템플릿

1. 새 노트를 만듭니다.
2. 템플릿 폴더는 `공기업_학습관리/06_템플릿`으로 연결했습니다. 이미 쓰는 다른 템플릿이 있으면 같은 폴더에 두거나 기존 폴더로 이번6개 템플릿을 복사해 사용하세요.
3. 명령 팔레트에서 **Templates: Insert template**로 질문·오답·주간복습 양식을 삽입합니다.
4. `{{date:YYYY-MM-DD}}`는 삽입한 날로 바뀝니다. 예정일은 자동 계산하지 않으므로 필요한 날짜로 고칩니다.

본과정216개 노트는 미리 만들어져 있으므로 매일 새 Daily note를 생성할 필요가 없습니다. 템플릿 변수를 보호하려면 템플릿 파일은 소스 모드에서 수정합니다.

## 여러 기기에서

이 보관함을 사용 중인 동기화 방식으로 PC·휴대폰·패드에 연결하면 같은 노트의 체크와 속성을 공유할 수 있습니다. 이번 작업에서 새 Sync 계정 연결·로그인·기기 설정·Git 커밋·푸시는 수행하지 않았습니다. 기존 보관함에 `obsidian-git` 설정이 있지만 실제 기기 간 전송 성공 여부는 확인되지 않았습니다.

같은 노트를 두 기기에서 동시에 수정하지 않고, 이동 전 동기화 완료를 확인하세요. PC 경로로 된 실습 실행 링크는 PC에서 사용합니다. 교재와 문제 Markdown은 이 폴더에 포함되어 있습니다.

## 채팅에서 새로 얻은 내용

질문노트에 질문·답변 요약·내 설명·확인 예제를 붙이고 관련 단원과 일별 노트를 연결합니다. **채팅 내용이 앞으로 자동으로 들어오지는 않습니다.** ‘이 공기업 질문을 옵시디언에 반영해줘’라고 요청하거나 템플릿에 붙여 넣으면 됩니다.
