# 의사소통: 지문의 범위와 조건을 끝까지 보존하기

이 자료의 지침·메일·보고·회의록은 모두 직접 만든 가상 문서다. 실제 기관 규정이나 기출 원문이 아니다. NCV01~15는 신규 객관식이고 아래 두 손풀이 사례는 별도의 설명 예제다.

## 읽기 전에 물어야 할 것

먼저 발신자, 수신자, 문서 목적을 확인한다. 신청 규칙이면 누가 어떤 신청을 어떤 조건으로 처리하는지가 중심이고, 회의록이면 제안·채택·보류가 중심이다. 선택지를 읽으며 지문에 없는 일반 상식으로 빈칸을 채우지 않는다. 실제 직장의 절차가 달라도 연습 문제에서는 주어진 가상 규칙이 판단 기준이다.

질문의 “반드시 옳은 것”은 지문과 조건이 맞는 모든 경우에서 참이어야 한다. “가능한 것”은 조건을 만족하는 경우 하나를 찾으면 된다. “가장 적절한 요약”은 핵심을 줄이면서 조건·대상·미확정 여부를 바꾸지 않은 문장이다. 이 세 질문을 같은 방식으로 읽지 않는다.

## 긴 지침을 표로 바꾸는 순서

지문에 다음 다섯 칸을 만든다. 대상 / 필요한 조건 / 허용 행동 / 예외 / 예외 뒤에도 남는 의무다. 처음에는 승인·확인 같은 말을 무조건 같은 절차로 묶지 말고, 누가 무엇을 확인하는지 분리한다. 정기 접수와 긴급 접수, 교정본 확인과 문구 확인처럼 기능이 다른 요건은 별개의 열이다.

예외 문장을 만나면 “어느 한 항목에 대한 예외인가”를 적는다. 접수 마감 예외가 자료 확인 면제까지 뜻하는지 확인한다. 지문에 그런 말이 없다면 확대하지 않는다. “기록은 모두 남긴다”처럼 모든 대상에 공통인 의무는 예외 대상에도 적용되는지 마지막에 대조한다.

조건이 여러 개면 AND인지 OR인지 읽는다. “증빙을 내고 담당자가 확인한 경우”는 둘 다 필요하다. 한 조건이 있어도 다른 조건이 없으면 충분하지 않다. “완료 전에는 시작할 수 없다”는 시작→완료라는 필요조건 관계다. 완료했다는 사실만으로 반드시 시작했다고 뒤집지 않는다.

## 보기 하나를 판정하는 짧은 기록

보기마다 근거 위치를 하나 이상 적고, 내용을 네 가지로 분류한다. 지문과 일치 / 지문과 모순 / 정보가 부족해 확정 불가 / 지문의 일부만 보존하고 조건을 누락이다. 질문이 필연을 요구하면 정보 부족인 보기도 오답이다. 모른다는 것과 거짓으로 입증되었다는 것을 구분해야 다음 문제의 추론이 흔들리지 않는다.

“일부”를 “모두”로, “검토 중”을 “확정”으로, “이후”를 “이전”으로, “요청할 수 있다”를 “반드시 받아 준다”로 바꾼 표현을 주의한다. 다만 “일부는”이라는 표현만으로 나머지 전부의 상태를 마음대로 정하지 않는다. 이 자료에서는 별도 제한이 없으면 적어도 해당 사례가 존재한다는 정보로 읽는다.

## 손풀이 예제 1: 대출 연장 예외가 없애는 것은 무엇인가

연습용 가상 동아리 지침: “대출 연장을 신청하려면 반납 예정일 전에 신청서를 내야 한다. 예약자가 있는 책은 연장할 수 없다. 다른 이용자의 예약이 없고 신청 기간을 지켰다면 운영 담당자의 처리 확인을 받은 뒤 연장된다. 다만 운영 담당자가 휴무인 날 접수한 신청은 확인 회신을 다음 운영일에 보낼 수 있다. 회신이 늦어지는 동안 신청이 자동 승인된 것으로 보지 않는다. 모든 신청에는 접수 기록을 남긴다.”

| 확인 항목 | 지문에서 정한 내용 |
| --- | --- |
| 신청 기한 | 반납 예정일 전 |
| 연장 제한 | 예약자가 있으면 불가 |
| 연장 완료 | 조건 충족 뒤 담당자의 처리 확인 |
| 휴무 예외 | 확인 회신을 다음 운영일에 보낼 수 있음 |
| 남는 의무 | 자동 승인 아님, 접수 기록 유지 |

상황: 예약자 없는 책의 신청서를 기한 전에 냈고 그날은 담당자 휴무다. 아직 회신이 없다. 기한·예약 조건은 충족했지만 처리 확인은 아직이다. 따라서 “이미 연장 완료”는 확정할 수 없다. 휴무 예외는 회신 시점에만 적용되어 접수 기록이나 처리 확인을 없애지 않는다. 반대로 예약자가 있는 경우에는 휴무 여부와 관계없이 연장 제한이 남는다.

책을 닫고 확인: “신청 기간을 지켰다”를 “연장 완료”로 바꾸려면 어떤 조건이 더 필요한가? 답은 예약자 없음과 담당자의 처리 확인이다. 신청→완료를 자동 관계로 외우지 않는다.

## 손풀이 예제 2: 제안·확정·확인된 사실을 세 줄로 나누기

가상 편집 회의 메모: “편집자는 자료실 안내판에 색상을 추가하자고 제안했다. 이용자 의견에는 현재 안내판의 글씨가 작다는 지적이 있었다. 회의는 글자 크기를 먼저 바꿔 시험하기로 했으며 색상 추가 여부는 시험 뒤 정하기로 했다. 시험 결과는 아직 없다. 담당자는 크기를 바꾸면 모든 이용자의 탐색 시간이 줄 것이라고 기대했다.”

확인된 사실: 의견에 작은 글씨라는 지적이 있었다. 결정: 글자 크기를 먼저 바꾸어 시험한다. 미결·예측: 색상 추가 여부는 나중에 결정하며 모든 이용자의 시간 단축은 아직 확인하지 않은 기대다. 이 세 줄을 합치더라도 상태를 보존해야 한다.

정확한 요약은 “작은 글씨에 대한 의견을 반영해 크기 변경을 시험하고, 색상 추가는 결과 확인 뒤 결정한다”다. “색상 변경이 확정되었다”는 첫 제안을 채택으로 바꿨다. “모든 이용자의 시간이 이미 줄었다”는 미래 기대를 결과로 바꿨다. “글씨가 작다는 이용자 의견이 없다”는 확인된 지문 사실과 모순된다.

## 문서 배열과 정보 비교의 검산

문서 배열은 첫 문장만 자연스러운지 보지 않는다. “이를”, “이 개선안”, “이 시험 결과”의 선행 내용을 찾고 지시어마다 화살표를 만든다. 문제→방안→검증→결정 순서가 모든 연결을 만족하는지 확인한다. 단지 비슷한 주제의 문단을 붙였다고 올바른 배열이 되는 것은 아니다.

자료 비교에서는 항목 이름, 대상 범위, 기간, 측정·집계 기준이 같은지 읽는다. 지문이 기준 변경을 알려 주면 변화가 실제 업무 변화인지 분류 변경의 결과인지 즉시 단정하지 않는다. 비교 가능한 공통 기준을 먼저 만든다는 제안과, 자료 전체를 버린다는 주장을 구분한다.

## 기초15문항을 공부하는 방법

가상 지침 세트는 첫 문항에서 지문을 표로 정리하고 나머지 두 문항에는 그 표를 재사용한다. 선택지마다 근거 문장과 조건 누락을 적은 뒤 해설을 확인한다. 메일·회의록은 대상과 확정 상태, 배열은 지시어, 추론은 필연과 반례를 확인한다. 정답 번호를 외웠다면 해당 문서의 틀린 보기 하나를 지문에 맞도록 직접 고쳐 쓴다. 고친 문장이 조건을 모두 보존하는지 설명할 수 있을 때 복습을 완료한다.
