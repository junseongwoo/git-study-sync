# 09-05 회귀·분류·학습: 모델은 무엇을 최적화하는가

[[GI-교재09 빅데이터_AI기초|과목 목차]] · [[GI-문제09 빅데이터_AI기초|문제]] · [[GI-해설09 빅데이터_AI기초|해설]]

### 학습 유형
지도학습은 입력과 정답을 이용해 관계를 학습한다. 회귀는 연속 수치 예측, 분류는 범주 예측이 중심이다. 비지도학습은 정답 범주 없이 구조를 찾으며 군집·차원축소가 대표적인 사례다. 강화학습은 행동과 보상의 상호작용을 다루지만 이 교재에서는 우선순위가 낮은 개념 소개에 그친다.

신청액 예측은 회귀, 승인·거절 범주 예측은 분류, 비슷한 거래 패턴의 그룹 탐색은 군집으로 볼 수 있다. 숫자로 표시된 범주를 예측한다고 모두 회귀가 되는 것은 아니다. 결과의 의미와 문제 목적을 본다.

### 선형회귀와 손실
단순 선형모형은 y_pred=w×x+b로 표현할 수 있다. 손실은 예측과 정답의 차이를 수치화한다. MSE는 오차 제곱의 평균, MAE는 절댓값 오차의 평균이다. 제곱 오차는 큰 오류를 더 크게 벌점화한다. 서로 단위와 민감도가 다르므로 숫자 크기만 직접 비교하지 않는다.

### 단계별 계산
x=1,2일 때 실제 y는 4,4,모형은 y_pred=2x+1이라고 하자. 예측은 3,5,오차 y_pred-y는 -1,1이다. MSE=(1+1)/2=1,MAE=(1+1)/2=1이다. 예측 2,5와 실제 3,3이라면 오차는 -1,2,MSE=(1+4)/2=2.5,MAE=(1+2)/2=1.5다. 같은 두 지표가 항상 같지는 않다.

기울기를 학습하는 경사하강법은 손실이 감소하는 방향으로 파라미터를 조금씩 갱신한다. 업데이트를 w_new=w_old-learning_rate×gradient로 쓰고 w_old=2,learning_rate=0.1,gradient=3이라면 w_new=1.7이다. 학습률이 너무 크면 불안정해질 수 있고 너무 작으면 느릴 수 있다. 한 번의 갱신으로 항상 전역 최적값에 도달하는 것은 아니다.

### 로지스틱 회귀와 분류
로지스틱 회귀는 이름에 회귀가 있지만 대표적으로 이진 분류에 쓰인다. 점수 z를 sigmoid(z)=1/(1+exp(-z))로 변환한다. z=0이면 0.5다. 이 값을 기준 임계값과 비교해 범주로 바꿀 수 있다. 출력 수치가 좋은 확률로 해석되려면 학습·보정·분포의 조건도 봐야 한다.

임계값 0.5를 0.7로 올리면 같은 점수에서 양성으로 분류되는 수는 일반적으로 줄어든다. 업무마다 거짓 경보와 놓친 위험의 비용이 다르므로 0.5가 항상 최선은 아니다. 손실함수·학습 파라미터·결정 임계값을 구분한다.

### 다른 모델의 큰 그림
결정트리는 특징 조건으로 데이터를 나누고 잎에서 예측한다. 깊어지면 복잡한 관계를 표현하지만 과적합 위험이 커질 수 있다. k-NN은 가까운 학습 사례를 바탕으로 예측하며 거리와 스케일에 민감하다. 앙상블은 여러 모형을 결합한다. 신경망은 여러 비선형 변환의 파라미터를 학습한다. 어떤 모델도 자료가 잘못되거나 평가가 누수되면 자동으로 신뢰할 수 없다.

### 자가 연습과 풀이
부실 여부를 0·1로 표시했다고 "연속 수치이므로 회귀 문제"라고 단정하면 안 된다. 업무상 두 범주를 구분하는 분류 문제다. 불량률이라는 연속 비율 자체를 예측하는 목표와 구분한다.

### 완료 기준
지도·비지도와 회귀·분류의 차이를 말하고 MSE·MAE·한 번의 경사하강 업데이트를 직접 계산한다. 로지스틱 회귀의 출력과 결정 임계값을 서로 구분해야 한다.

### 응용 계산: 정규화 항의 역할
가상 목적함수를 J=MSE+lambda×(w1^2+w2^2)로 정의하고 절편은 벌점에서 제외한다. MSE=1,w1=2,w2=-1,lambda=0.5라면 J=1+0.5×(4+1)=3.5다. 파라미터 크기에도 비용을 주는 것으로, 학습 오차만 무조건 0으로 만드는 목표와 다르다.

lambda가 커지면 계수 크기를 더 강하게 억제하는 경향이 있지만 모든 데이터에서 검증 성능이 계속 개선되는 것은 아니다. 학습률은 업데이트 크기,lambda는 정규화 강도다. 두 값을 같은 것으로 외우지 않는다. 시험에 손실 합/평균 또는 1/2 계수가 주어지면 그 정의를 따른다.

### 강화 손풀이: 손으로 한 번 경사하강을 수행한다

절편 없는 예측식은 y_hat=wx이고 자료는 (x,y)=(1,2),(2,4)다. 손실은 두 관측의 제곱오차 평균 `L(w)=[(w-2)^2+(2w-4)^2]/2`로 정의한다. 정규화 항은 없다.

**1단계 - 시작점 w=1의 손실.** 예측은 1, 2이고 오차는 -1, -2다. L(1)=(1+4)/2=2.5다. 같은 지점의 MAE는 (1+2)/2=1.5로 MSE와 다르다.

**2단계 - 미분.** `dL/dw=[2(w-2)+4(2w-4)]/2=5w-10`이다. w=1에서 기울기는 -5다.

**3단계 - 학습률 0.1로 갱신.** `w새=w-0.1×기울기=1-0.1×(-5)=1.5`다. 새 예측은 1.5, 3이고 새 손실은 (0.25+1)/2=0.625다. 음수 기울기를 빼므로 w가 증가한다.

**4단계 - 학습률 반례.** 같은 시작점에서 학습률을 1로 바꾸면 w새=6, 손실은 (16+64)/2=40으로 증가한다. 학습률을 크게 하면 항상 빨리 좋은 해에 도달한다는 주장은 틀린다. 이 수치 예시는 모든 모델의 안전 학습률을 알려주지는 않는다.

**정규화 조건.** 만약 목표가 `L(w)+0.1w^2`라면 기울기는 `5w-10+0.2w`다. 처음에는 -4.8, 학습률 0.1의 새 w는 1.48이다. 손실 정의가 바뀌면 계산도 바뀐다. w는 자료로 학습하는 모델 매개변수이고 학습률과 정규화 강도는 학습 절차를 정하는 하이퍼파라미터다. 검증 자료로 절차를 선택한 뒤 시험 자료는 최종 평가에 사용한다.
