# 05-07 규모 산정·일정·위험: 프로젝트 수치를 계산하는 법

[[GI-교재05 소프트웨어공학|과목 목차]] · [[GI-문제05 소프트웨어공학|문제]] · [[GI-해설05 소프트웨어공학|해설]]

### 규모와 노력은 같은 값이 아니다
코드 줄 수는 산출물 크기를 측정하는 한 방법이지만 언어·작성 스타일·재사용에 민감하다. 기능점수는 사용자 관점의 데이터 기능과 거래 기능을 바탕으로 규모를 산정하는 접근이다. 규모가 같아도 팀 경험·품질 요구·도구·연계 복잡도에 따라 노력과 비용이 달라진다. 공식 명칭이나 특정 모델의 계수를 임의로 다른 문제에 적용하지 않는다.

기능점수의 기초 유형은 외부 입력, 외부 출력, 외부 조회, 내부 논리 파일, 외부 인터페이스 파일이다. 입력은 시스템 안의 데이터를 유지하거나 동작을 제어하는 거래다. 출력과 조회는 내부 처리의 성격이 다르며, 내부 논리 파일과 외부 인터페이스 파일은 누가 유지하는지 구분한다. DB의 물리 테이블 개수가 곧 논리 파일 개수인 것은 아니다.

### 가중치가 주어진 계산
본 교재의 연습용 가중치가 입력 3, 출력 4, 조회 3, 내부 파일 7, 외부 인터페이스 파일 5라고 하자. 각 개수가 4, 2, 3, 2, 1이면 비조정 합계는 4×3+2×4+3×3+2×7+1×5=48이다. 이 숫자는 예제에서 주어진 가중치로 계산한 것이며 표준 전체 난이도 표를 대신하지 않는다. 문제에 조정 계수 1.1이 명시된다면 48×1.1=52.8로 계산한다. 계수가 없으면 만들어 넣지 않는다.

### PERT와 임계경로
PERT의 대표적인 기대시간 식은 (낙관시간+4×최빈시간+비관시간)/6이다. 분산의 근사식은 ((비관시간-낙관시간)/6)의 제곱이다. 이는 모델의 가정 아래 쓰는 계산이며 실제 지연 확률을 자동으로 정확히 예측하는 법은 아니다.

가상 작업 A의 세 시간 값이 2, 5, 8일이면 기대시간은 (2+20+8)/6=5일, 분산은 ((8-2)/6)^2=1일^2다. 표준편차는 1일이다. 분산을 1일이라고 쓰지 않고 단위의 제곱을 기억하자.

CPM에서 임계경로는 작업 네트워크의 가장 긴 경로이며 전체 완료 일정을 결정한다. 임계 작업을 늦추면 다른 변화가 없는 한 프로젝트가 늦어진다. 경로가 여러 개 임계가 될 수도 있다. 임계경로는 작업 개수가 가장 많은 경로가 아니라 기간 합계가 가장 큰 경로다.

### 네트워크 예제
A=2일 후 B=3일과 C=5일이 병렬로 시작한다. D=4일은 B·C 모두 끝난 뒤 시작한다. A-B-D는 9일, A-C-D는 11일이다. 전체 기간은 11일이며 A-C-D가 임계경로다. B는 2일 여유가 있다. B를 1일 줄여도 전체 기간은 여전히 11일이다. C를 1일 줄이면 전체 기간은 10일로 줄어든다.

### 위험과 획득가치
위험은 발생 가능성과 영향이 있는 불확실한 사건이다. 위협에 대한 대응은 회피·완화·전가·수용 등을 구분한다. 위험 전가가 책임이나 모든 손실을 완전히 제거한다는 뜻은 아니다. 단순 기대 손실은 확률×손실로 계산할 수 있다. 20% 확률의 1,000만원 손실은 기대값 200만원이다. 극단적 손실·법적 의무·안전 문제는 기대값 하나로 판단하지 않는다.

획득가치에서 PV는 계획된 작업의 예산 가치, EV는 실제 완료 작업의 예산 가치, AC는 실제 투입 비용이다. CPI=EV/AC, SPI=EV/PV다. PV=100, EV=80, AC=90이면 CPI=8/9 약 0.889, SPI=0.8이다. 단순 지표상 비용 효율과 일정 진행이 계획에 못 미친다. EV는 받은 현금이나 단순 지출 합계가 아니다.

### 자가 연습과 풀이
낙관 1, 최빈 4, 비관 7일이면 기대시간은 4일이다. 임계경로 밖의 작업 단축이 항상 전체 기간을 줄이지 않는 이유는 다른 긴 경로가 완료를 결정하기 때문이다.

### 완료 기준
기능점수 문제의 가중치·개수를 대응하고 PERT·경로 합계·CPI·SPI를 계산할 수 있어야 한다. 계산 전에 기간·금액·비율의 단위를 표시하자.

### 응용 계산: 비용 전망의 가정
BAC=전체 승인 예산100,EV=40,AC=50이면 CPI=0.8이다. 앞으로도 같은 비용 효율이 지속된다는 단순 가정의 EAC=BAC/CPI=125다. 남은 작업 비용 예상은 EAC-AC=75다. 완료 예산 차이 VAC=BAC-EAC=-25이므로 예산 초과 전망으로 해석한다. 단위는 모두 같은 금액 단위여야 한다.

이 식은 미래 효율이 같다는 가정의 예측이고 반드시 최종 비용이125가 된다는 사실은 아니다. 남은 업무가 더 쉬워지거나 외부 비용이 바뀌면 다른 식과 근거가 필요하다. EV는 실제 지출이 아니라 완료된 작업의 예산 가치다. 절반의 돈을 썼다고 작업도 절반 끝났다고 계산하지 않는다.

### 강화 일정 손풀이: 병렬 경로가 바뀌는 시점
자원 제한이 없는 가상 일정에서 A=3일, B=4일·C=6일은 A 뒤 병렬, D=2일은 B·C 모두 완료 뒤 시작한다. 빠른 완료는 A 3, B 7, C 9, D 11일이다. 역산하면 D의 최늦은 시작은 9, B는 5, C는 3, A는 0이다. B의 여유는 5-3=2일이다.
C만 4일로 줄이면 A-B-D와 A-C-D가 모두 9일로 공동 임계가 된다. 이때 C만 1일 더 줄여도 B 경로가 9일을 유지하므로 전체는 9일이다. 임계경로가 처음 정해진 뒤 영원히 같다는 가정은 반례로 깨진다. 단축·지연 뒤 네트워크를 다시 계산한다.
가상 독립 작업의 PERT 값이 (2,4,8)이면 기대시간 26/6=13/3일, 분산((8-2)/6)^2=1일^2다. 경로 기대시간 합과 지연 확률은 같지 않다. 획득가치 PV 120·EV 90·AC 100이면 CPI 0.9·SPI 0.75다. EV를 지출 AC로 대체하면 완료 진척을 부풀린다.
