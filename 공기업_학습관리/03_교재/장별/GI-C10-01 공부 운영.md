# 10-01 공부 운영

[[GI-교재10 NCS_교재와175문항|과목 목차]] · [[GI-문제10 NCS_교재와175문항|문제]] · [[GI-해설10 NCS_교재와175문항|해설]]

# IBK·기보 NCS 공부 운영

확인 기준은 2026-10-04다. IBK 2026 하반기 IT의 (구)직업기초능력은 의사소통·문제해결·자원관리·조직이해·수리·정보다. 객관식 40문항·60점이며, 직무수행은 객관식 30문항·30점과 주관식 5문항·10점이다. 필기 총시간은 120분이지만 기관이 영역별 시간을 따로 확정했다고 가정하지 않는다.

IT 코딩은 필기 후 실기 전형에서 알고리즘·DB를 다루며 C,C++,JAVA,Python3,MySQL,Oracle이 안내되어 있다. 코딩 문항 수와 세부 시간은 공식 자료로 확인된 범위 이상으로 단정하지 않는다.

기보 2026 전산은 직업공통 40점·전산 60점이다. NCS는 의사소통·수리·문제해결·디지털 4영역이다. NCS 40점의 50% 미만 시 선발 제외 조건이 있으므로 전산만 준비하는 방식은 피한다. 세부 적용 조건은 공고를 따른다. 이번 기보 공고의 접수와 필기일은 이미 지났으므로 공부 범위의 참고 기준이며, 다음 채용의 일정·규칙을 보장하지 않는다.

## 두 경로의 공통과 차이

공통 3영역인 의사소통·수리·문제해결을 먼저 공부한다. IBK를 우선할 때 자원관리·조직이해·정보를 추가하고, 기보를 우선할 때 디지털을 추가한다. 직업공통능력으로 명칭이 개편되었다고 모든 기관의 시험이 동일한 7영역으로 바뀐 것은 아니다.

기초 구성의 7영역·각 15문항이라는 균등 구성은 연습 설계다. 실제 기관별 출제 비중을 뜻하지 않는다.

## 새 교재의 문항 구성

기초 구성105문항은 기존 NCS 집중 준비 60문항의 재구성과 이번 신규 자원관리·조직이해·정보 각 15문항, 총 45문항을 더한 것이다. 105개 모두를 신규 문항으로 세지 않는다.

진단은 각 영역 첫 3개로 총 21문항, 기본 연습은 각 4~9번으로 총 42문항, 최종 확인은 각 10~15번으로 총 42문항이다. 공유 지문이 진단·연습·최종 확인 사이에 겹치지 않도록 기존 문항의 묶음을 유지했다. 처음 보는 문제의 점수를 남기려면 최종 확인의 문제와 해설을 미리 열지 않는다.

## 풀이 순서

질문이 요구한 대상→필요한 행과 조건→식 또는 배치표→보기 대조→검산의 순서로 푼다. ‘옳은 것/옳지 않은 것’, ‘최대/최소’, ‘가능/반드시’를 먼저 표시한다.

해설을 읽고 이해한 것과 답 없이 풀이를 재현한 것은 다른 성취다. 계산기는 처음 학습의 검산에 활용할 수 있지만 시간 운영 연습은 해당 시험의 허용 규칙에 맞춘다.

## 오답을 실제 행동으로 바꾸기

오답 원인은 해석·조건 누락·계산·시간으로 기록한다. 해석 문제는 질문을 한 줄로 다시 쓰고, 조건 누락은 체크리스트를 만들고, 계산은 단위를 붙인 식을 남긴다. 시간이 부족하면 쉬운 문제 우선 배치와 중단 기준을 정한다. 맞혔어도 근거가 없었다면 다시 풀기로 분류한다.

복습 간격은 1일·7일·21일을 예시로 두되 실제 망각과 일정에 따라 조절한다. 이 간격이 항상 최적이라고 보장하지 않는다. 기록 달력은 이번 학습실의 같은 브라우저에 저장되며 기존 학습실 기록을 자동으로 합치지 않는다. 다른 기기로 이동할 때는 기록 파일을 내보낸 뒤 가져온다.

## 시간 제한과 성취 판단

진단 21문항·42분은 자체 연습 시간이다. IBK 영역만 진단하면 18문항·36분, 기보 영역은 12문항·24분이다. 최종 확인 역시 실제 IBK 40문항이나 기보의 미공개 문항 수를 그대로 복제한 모의고사가 아니다.

점수는 영역별 근거 있는 정답률·미응답률·재풀이 여부와 함께 본다. 유한하고 작은 문제집으로 실제 합격 가능성을 추정하지 않는다.

주 12시간·24주 계획에서는 NCS에 매주 2시간 세션과 혼합 복습의 일부를 배정한다. 초반에는 속도보다 조건 해석, 중반에는 새 지문 적용, 후반에는 미리 보지 않은 문제의 시간 운영을 연습한다. 목표 기관을 선택하면 우선순위를 조정하며 다른 영역을 삭제하지 않는다.


## 이번 전체 강화의 사용 순서

각 영역에 추가10문항을 더해 영역별25개·총175개다. 기존105개 뒤의70개는 강화25~31주 수요일에 연결했다. 지문에서 목표·비교 기준·분모·단위·규칙의 적용 대상을 먼저 표시한다. 같은 지문을 봤던 문제는 최초 풀이와 구분한다. 시간이 부족하면 공통3영역과 우선 기관의 영역부터 진행하고 달력 메모에 대체 영역을 기록한다. 문제를 많이 푸는 것만으로 실제 시험 속도가 보장되지는 않는다.
