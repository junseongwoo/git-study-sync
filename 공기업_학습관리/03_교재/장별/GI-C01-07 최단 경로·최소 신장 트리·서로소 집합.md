# 01-07 최단 경로·최소 신장 트리·서로소 집합

[[GI-교재01 자료구조_알고리즘|과목 목차]] · [[GI-문제01 자료구조_알고리즘|문제]] · [[GI-해설01 자료구조_알고리즘|해설]]

## 문제의 목적부터 구별
최단 경로는 출발점에서 목적지로 가는 비용이 작은 경로를 찾는다. 최소 신장 트리(MST)는 연결된 무방향 가중 그래프의 모든 정점을 연결하는 트리 중 간선 비용 합이 작은 것을 찾는다. 모든 정점을 잇는 비용 최소와 특정 두 점 사이의 경로 최소는 같은 목표가 아니다.

### 1. 다익스트라
가중치가 모두 비음수일 때 아직 확정하지 않은 정점 중 현재 거리가 가장 작은 정점을 선택하여 거리를 확정하고 이웃을 완화한다. 간선 u→v의 비용 w에 대해 dist[u]+w가 dist[v]보다 작으면 갱신하는 것이 완화다. 비음수 조건 때문에 가장 가까운 미확정 정점을 다른 더 먼 경유로 뒤늦게 줄일 수 없다는 논리가 성립한다.

예제 A: 방향 간선 A→B=4, A→C=1, C→B=2, B→D=1, C→D=5.
초기 A=0, 나머지∞. A 처리 후 B=4,C=1. C 처리 후 B=3,D=6. B 처리 후 D=4. D 처리 후 종료한다. 최단 A→D는 A→C→B→D, 비용4다. A→B가 직접 간선이라는 이유로 비용4를 끝까지 고정하면 안 된다.

우선순위 큐 구현에서는 갱신할 때 새 후보를 넣고 예전 후보를 그대로 둘 수 있다. 큐에서 꺼낸 거리 d가 현재 dist[u]와 다르면 오래된 정보이므로 생략한다. 목적지에서 일찍 종료하려면 유효한 현재 후보를 꺼내 거리를 확정한 시점이어야 한다. 단지 목적지를 처음 발견했을 때는 더 짧은 후보가 남아 있을 수 있다.

```python
import heapq
def dijkstra(adj, start):
    dist = [float('inf')] * len(adj)
    dist[start] = 0
    heap = [(0, start)]
    while heap:
        d, u = heapq.heappop(heap)
        if d != dist[u]:
            continue
        for v, w in adj[u]:
            nd = d + w
            if nd < dist[v]:
                dist[v] = nd
                heapq.heappush(heap, (nd, v))
    return dist
```

코드는 비음수 가중치 조건을 외부 입력 계약으로 둔다. 단순 그래프의 대표 시간 표기는 O((V+E) log V)이고, 중복 후보를 허용하는 구현의 힙 크기를 더 일반적으로 잡으면 O((V+E) log(V+E)) 등으로 분석할 수 있다. 복잡도 문항의 구현·간선 모델을 확인한다.

### 2. 음수 간선과 다른 알고리즘
다익스트라를 음수 간선에 무조건 적용하지 않는다. A→B=2,A→C=5,C→B=-4이면 B를2로 먼저 확정하는 기본 다익스트라 논리가 깨지고 실제 최단 값은1이다. 일부 재처리 코드가 특정 사례에서 맞아도 알고리즘의 보장 조건이 회복되는 것은 아니다.

벨만-포드는 모든 간선 완화를 최대 V-1회 반복하여 출발점에서 도달 가능한 최단 거리를 구하고 추가 완화로 도달 가능한 음수 사이클을 감지할 수 있다. 대표 시간 O(VE)다. 음수 사이클에 도달하고 그 이후 목적지까지 갈 수 있다면 그 목적지의 최단 비용을 유한하게 정의할 수 없다. 그래프 어딘가에 음수 사이클이 있다는 것만으로 모든 정점의 거리가 불가능하다고 말하지 않는다.

플로이드-워셜은 경유 정점 k를 순서대로 허용하며 모든 쌍 거리를 갱신하는 O(V^3) 알고리즘이다. 갱신식은 dist[i][j]=min(dist[i][j],dist[i][k]+dist[k][j])이다. “한 출발점”과 “모든 쌍” 요구를 읽어 선택한다.

### 3. 최소 신장 트리
연결된 무방향 그래프의 신장 트리는 V-1개 간선을 갖는다. 크루스칼은 간선을 가중치 오름차순으로 보며 사이클을 만들지 않는 간선을 채택한다. 프림은 현재 트리와 바깥을 연결하는 가장 가벼운 간선을 확장한다. MST는 여러 개일 수 있다. 음수 간선이 있어도 MST 문제 자체는 성립한다.

예제 B: 무방향 A-B=1,B-C=2,A-C=4,C-D=3,B-D=5. 크루스칼은 A-B, B-C, C-D를 선택해 비용6이다. A-C는 이미 같은 연결 요소를 잇기 때문에 제외한다. 선택 간선3개는 정점4개의 V-1이다. MST에서 A→C 경로 비용3이 우연히 최단과 같아도 모든 그래프에서 그러하다는 보장은 없다.

### 4. 서로소 집합(Union-Find)
각 집합의 대표를 find로 얻고 두 집합을 union으로 합친다. 같은 대표이면 이미 연결되어 있어 해당 간선을 더할 때 사이클이 생긴다. 경로 압축과 rank/size 기반 union을 함께 사용하면 연산열의 상각 비용을 매우 작게 제한할 수 있다. 정확히 O(1)이라고 단정하기보다 역 아커만 함수가 등장하는 준상수 상각 분석이라는 정도를 이해하면 기초 학습에 충분하다.

예제 C: 처음 {1},{2},{3},{4}. union(1,2) 후 {1,2}, union(3,4) 후 {3,4}, union(2,3) 후 {1,2,3,4}. find(1)==find(4)이므로 추가 연결(1,4)는 사이클을 만들 후보다. 대표 숫자 자체가 반드시 최솟값이라는 보장은 없다.

### 완료 기준
비가중치 최단은 BFS, 비음수 가중치 최단은 다익스트라, 음수 허용 단일 출발은 벨만-포드, 전체 연결 최소 비용은 MST라는 선택 근거를 말한다. 단절 그래프에는 모든 정점을 잇는 신장 트리가 없으며 크루스칼 결과는 최소 신장 숲이 될 수 있음을 구별한다.

### 보강 실습: 오래된 거리 후보를 건너뛰는 이유
A→B=10,A→C=1,C→B=1이면 A 처리 때 힙에 (10,B),(1,C)가 들어간다. C를 먼저 꺼내 B를 2로 줄이며 (2,B)를 추가한다. 이후 (2,B)를 처리하고 나중의 (10,B)는 dist[B]=2와 달라 낡은 후보로 생략한다. 힙 안에 같은 정점이 두 번 있다는 사실 자체가 오류는 아니다.

서로소 집합은 parent[root]=root를 초기 성질로 둔다. find에서 경로를 줄이고 union은 서로 다른 root를 연결한다. root가 최소 정점 번호여야 한다는 조건이 없으면 대표 숫자 자체로 정답을 비교하지 않는다. 크루스칼은 대표의 같음/다름으로 사이클 후보를 판단할 수 있다.

반례: A-B=2,B-C=2,A-C=3인 무방향 그래프의 MST는 A-B,B-C이고 총 4다. MST 안 A→C 경로는 4지만 원래 그래프의 최단 A→C는 직접 경로 3이다. 최소 신장 트리가 모든 쌍 최단 경로를 담는다는 잘못된 주장을 이 반례로 제거한다.

### 강화 응용: 조건을 바꾸어 다시 증명하기
음수 사이클의 영향은 도달 관계로 결정한다. 방향 간선 S→A=2,A→B=-3,B→A=1,S→T=5가 있고 A/B에서 T로 가는 간선은 없다고 하자. A↔B 합은 -2이며 S에서 도달할 수 있으므로 A,B의 유한 최단 거리는 없다. 그러나 T로 이어지지 않아 S→T의 최단 거리는 5다. 별도의 X↔Y 음수 사이클이 S에서 도달 불가능하다면 S 기준 최단 거리에 영향을 주지 않는다. '음수 사이클이 하나 있으므로 모든 답이 없다'는 문장은 지나치다.

MST의 유일성과 가중치의 유일성도 구별한다. 모든 간선 가중치가 서로 다르면 연결된 무방향 그래프의 MST는 유일하다. 역은 성립하지 않는다. 경로 A-B=1,B-C=1만 있는 그래프는 같은 가중치 두 개가 있어도 신장 트리가 그 경로 하나뿐이라 MST가 유일하다. 삼각형의 모든 가중치가 1이면 어느 두 간선이든 비용 2이고 MST가 세 개다.

다익스트라 구현의 INF를 정수 최대값으로 두고 INF+w를 계산하면 C++ 부호 오버플로가 생길 수 있다. 도달한 거리만 더하거나, 모든 유한 경로 합보다 크고 덧셈 안전한 상한을 계약으로 정한다. 우선순위 큐에서 현재 거리와 다른 후보를 생략할 때 목적지 조기 종료는 유효 후보를 꺼낸 뒤에만 한다.
