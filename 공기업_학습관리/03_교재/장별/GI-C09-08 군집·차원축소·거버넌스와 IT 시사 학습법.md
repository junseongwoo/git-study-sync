# 09-08 군집·차원축소·거버넌스와 IT 시사 학습법

[[GI-교재09 빅데이터_AI기초|과목 목차]] · [[GI-문제09 빅데이터_AI기초|문제]] · [[GI-해설09 빅데이터_AI기초|해설]]

### 군집과 거리
군집은 정답 라벨 없이 비슷한 자료를 묶는 비지도학습이다. k-means는 정해진 k개 중심을 기준으로 자료를 배정하고 중심을 갱신하는 대표적인 접근이다. 초기 중심·거리·스케일·이상치에 영향을 받으며 모든 형태의 군집을 잘 찾는 것은 아니다. 군집 번호 0·1·2에 원래의 의미 있는 순서가 있는 것은 아니다.

유클리드 거리는 두 좌표 차이 제곱 합의 제곱근이다. A=(0,0),B=(3,4)의 거리는 5다. C=(0,2)와의 거리는 2다. 키와 연봉을 그대로 거리로 계산하면 숫자 단위가 큰 연봉이 지배할 수 있어 스케일을 검토한다. 코사인 유사도는 두 벡터 방향의 유사성을 보며 벡터 크기의 영향과는 다르게 동작한다. 영벡터에서는 정의 조건을 확인한다.

### 단계별 k-means 예제
1차원 자료 1,2,8,9에 초기 중심 1·9를 둔다. 가까운 중심으로 배정하면 첫 군집은 1·2,둘째는 8·9다. 새 중심은 (1+2)/2=1.5와 (8+9)/2=8.5다. 다음 배정도 같으면 이 예제에서는 중심이 안정된다. 이것이 어떤 초기값에서도 전역 최적을 반드시 찾는다는 증명은 아니다.

### PCA의 큰 그림
PCA는 데이터의 큰 분산을 설명하는 직교 방향을 찾아 낮은 차원으로 표현하는 대표적인 선형 차원축소 기법이다. 군집과는 목적이 다르다. 원래 특징을 일부 골라 남기는 특징 선택과, 특징들의 선형 결합을 만드는 차원축소도 구별한다. 첫 주성분은 가장 큰 분산 방향을 설명하고 다음 성분은 이전과 직교하면서 남은 분산을 설명한다.

큰 분산이 예측에 가장 중요한 정보라는 보장은 없다. 단위가 다른 입력이면 스케일을 고려하며 PCA도 학습 부분에서 맞춘다. 민감한 정보가 낮은 차원으로 바뀌었다고 익명성이 자동으로 생기는 것은 아니다.

총 분산이 100이고 성분별 설명 분산이 60,25,15라면 첫 두 성분의 누적 설명 비율은 85%다. 목표가 90%라면 두 성분만으로는 부족하다. 이 숫자는 설명 분산이며 분류 정확도 85%라는 뜻이 아니다.

### 데이터 거버넌스와 모델 운영
거버넌스는 소유·책임·정의·품질·권한·계보·보관 등을 관리한다. 메타데이터는 자료의 의미와 생성·변환 정보를 설명한다. 데이터 품질에서는 정확성·완전성·일관성·적시성·유일성 등을 검토할 수 있다. 항목별 측정 기준이 필요하며 "자료가 많으니 품질이 좋다"는 주장은 틀리다.

운영에서 입력 분포가 달라지는 데이터 드리프트와 입력-정답 관계가 달라지는 개념 드리프트를 구분할 수 있다. 모델·자료·특징·설정 버전을 기록하고 성능·오류·편향을 모니터링한다. 설명 가능성·공정성·개인정보·사람의 검토 등은 업무 요구에 맞게 설계한다. 자동 점수가 곧 최종 법적·업무적 판단이라는 뜻은 아니다.

### IT 시사 공부법
IBK IT의 시사 준비는 매일 기사 제목을 많이 외우는 것보다 확인 가능한 원문을 짧게 정리하는 방식이 유용하다. 한국은행·금융위원회·금융감독원·개인정보보호위원회·NIST 등의 공식 발표에서 발표일, 실제 시행일, 기존 개념, 변경 사항, IT 영향, 확인이 필요한 점을 기록한다. 공식 발표와 실제 적용 시점을 구분한다. 특정 올해 사건을 확인 없이 교재에 사실로 만들어 넣지 않는다.

한 주에 두 주제만 골라 "클라우드 장애와 복구", "AI 데이터·보안", "디지털 인증" 같은 전산 개념과 연결하자. 뉴스는 공고 기준일과 시험 시점에 맞춰 갱신하며 기관별 실제 출제 빈도는 공식 안내가 없으면 추정이라고 표시한다.

### 자가 연습과 완료 기준
거래 군집은 행동 패턴 탐색이고 위험 여부 정답을 학습하는 분류와 다르다. PCA 누적 85%는 차원 정보의 요약이고 정확도가 아니다. 거리·중심·분산 비율을 계산하고, 데이터 품질·누수·권한·운영 감시를 함께 설명하면 이 교재의 기초를 통과한다.

### 응용 계산: 중심 거리와 군집 오차
1,2,8,9를 중심 1.5·8.5에 배정하면 각 제곱 거리는 0.25다. 군집 안의 제곱 거리 합은 1이다. 모든 값을 중심 5에 모으면 제곱 거리 합은 16+9+9+16=50이다. 군집 수를 늘리면 이 합은 줄어들 수 있지만 군집 수를 무조건 최대로 고르는 것이 업무에 좋다는 뜻은 아니다.

k-means의 k와 k-NN의 k는 다르다. 전자는 군집 중심 개수,후자는 예측에서 참고하는 이웃 개수다. PCA 성분 수와도 다르다. 같은 기호를 쓴다는 이유로 역할을 혼동하지 않는다. 보고서에는 모델 이름·설정·자료 기간·특징·평가 방식을 함께 적자.

### 강화 손풀이: 군집의 거리와 PCA의 분산은 목표를 자동으로 해결하지 않는다

**군집 한 번 갱신.** 가상 1차원 점 [0, 2, 8, 10]과 초기 중심 2, 8을 사용한다. 더 가까운 중심에 배정하면 [0, 2]와 [8, 10]이다. 각 평균으로 중심을 갱신하면 1, 9다. 갱신한 중심에서 제곱거리 합 SSE는 (0-1)^2+(2-1)^2+(8-9)^2+(10-9)^2=4다. 이 예시에는 거리 동률이 없으며 입력 단위와 특징 스케일은 고정한다.

**PCA 손계산.** 어떤 전처리를 고정한 뒤 공분산 행렬의 고유값이 9, 3, 2라고 가정한다. 전체 분산은 14, 첫 성분의 비중은 9/14, 앞 두 성분 누적은 12/14=6/7 약 85.71%다. 누적 90% 이상이라는 가상 기준에는 세 성분 모두 필요하다. 9와 3만 더해 12라고 보고 이를 12%나 90%로 읽으면 안 된다.

**반례.** 분산이 큰 특징이 예측 목표에 유용하다는 보장은 없다. 측정 단위가 큰 무관한 특징이 PCA의 주요 방향을 차지할 수도 있다. 앞 성분의 분산 보존과 분류 정답률을 같은 지표로 취급하지 않는다. 군집 번호에도 승인/거절 같은 의미가 자동으로 부여되지 않는다.

**운영 실무 조건.** 모델 성능이 갑자기 떨어졌을 때 원천 자료·기간·특징 순서·전처리 버전·모델 버전·평가 대상·라벨 수집 지연을 먼저 함께 확인한다. 예를 들어 열 이름은 같지만 단위가 원에서 천 원으로 바뀌면 같은 모델에도 입력이 달라진다. 계보와 버전을 기록하고 원인을 재현한 뒤 수정한다. 이 내용은 보편적인 학습 보강이며 기관의 공식 IT/디지털 출제범위를 새로 동일시하는 근거가 아니다.
