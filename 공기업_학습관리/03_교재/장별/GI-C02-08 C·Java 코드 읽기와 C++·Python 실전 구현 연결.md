# 02-08 C·Java 코드 읽기와 C++·Python 실전 구현 연결

[[GI-교재02 프로그래밍_Cpp_Python|과목 목차]] · [[GI-문제02 프로그래밍_Cpp_Python|문제]] · [[GI-해설02 프로그래밍_Cpp_Python|해설]]

## 마지막 장의 목적
코딩테스트 주력 언어는 C++ 또는 Python 중 하나를 먼저 안정화하고, 같은 문제를 다른 언어로 다시 구현해 표현의 차이를 확인한다. 두 언어를 공부한다고 문제 수가 두 배가 되는 것은 아니다. 필기용 C·Java 코드 해석은 별도 짧은 연습으로 유지한다.

### 1. C 배열·포인터의 안전한 기본
배열 a에서 a[i]는 유효 범위 안에서 *(a+i)와 대응한다. int a[3]={2,4,6}, int* p=a라면 *(p+1)은4다. 포인터 이동의 한 칸은 해당 타입 원소 하나의 크기이며1바이트라는 뜻이 아니다. 배열 끝 바로 다음 포인터는 만들 수 있는 경우가 있지만 역참조하면 유효 원소 접근이 아니다.

손풀이 예제 A: int가4바이트라는 문제 가정에서 배열 시작 주소1000이면 a[2] 주소는1008이다. int 크기가4라는 조건을 문제에서 주지 않았는데 모든 구현에서 반드시 그렇다고 추측하지 않는다. 두 포인터의 차이는 같은 배열 안 유효한 모델에서 원소 수를 나타내며 바이트 수와 다를 수 있다.

C 문자열은 널 문자로 끝나는 char 배열 모델이다. char s[]="ABC"는 저장에 A,B,C,종료 널의4개가 필요하다. strlen은 종료 널 앞 문자 수3이며 sizeof(s)는 이 선언 지점의 배열 크기4다. char* 포인터 변수의 sizeof는 원래 문자열 길이와 다르다. 이 예제는 ASCII 문자열이다.

### 2. Java의 인스턴스 메서드와 필드
Java에서 일반 인스턴스 메서드 오버라이딩은 실제 객체에 따라 호출된다. static 메서드와 필드 접근을 같은 동적 디스패치 규칙으로 해석하지 않는다. 부모 타입 변수에 자식 객체를 담았을 때 어느 멤버를 호출하는지 종류별로 읽는다.

예제 B: 부모의 인스턴스 메서드 f가1, 자식이 오버라이드한 f가2라고 하자. Parent x=new Child();x.f()는2다. 부모와 자식이 같은 이름의 필드를 각각 선언했다면 x.field 접근은 메서드 오버라이드처럼 동작하지 않는다. 필드 숨김·static 숨김·인스턴스 오버라이딩을 따로 표로 만든다.

Java 배열·객체 변수는 참조를 담으며 매개변수 전달은 값 전달이다. 참조 값의 복사로 같은 객체를 수정할 수 있지만 함수 안 매개변수에 새 객체를 대입한 것만으로 호출자 변수가 새 객체로 바뀌지는 않는다. Python·C# 일반 참조 형 전달 사례와 비교하되 언어의 문법적 참조 전달이라는 다른 개념을 섞지 않는다.

### 3. 두 언어로 같은 답을 구현하기
문제: n개의 정수를 받아 짝수의 합을 출력한다. 0 <= n <= 2,147,483,647이고 n개의 입력이 모두 제공된다고 가정한다. 각 입력값과 모든 중간 누적합 및 최종 합이 64비트 부호 있는 정수 범위 안이라는 입력 계약을 둔다. 최종 합만 범위 안에 있어도 중간 합이 범위를 벗어나면 C++ signed overflow 문제가 생길 수 있으므로 중간 합까지 확인한다. Python은 범위 때문에64비트로 잘리는 타입은 아니지만 입력 계약과 알고리즘은 같은 것으로 맞춘다.

```cpp
#include <iostream>
using namespace std;
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    if (!(cin >> n)) return 0;
    long long sum = 0;
    for (int i = 0; i < n; ++i) {
        long long x;
        cin >> x;
        if (x % 2 == 0) sum += x;
    }
    cout << sum << '\n';
}
```

```python
import sys
def main():
    data = list(map(int, sys.stdin.buffer.read().split()))
    if not data:
        return
    n = data[0]
    a = data[1:]
    if len(a) != n:
        raise ValueError("expected n values")
    print(sum(x for x in a if x % 2 == 0))
if __name__ == "__main__":
    main()
```

예제 C: n=5,a=[-4,3,2,7,0]이면 -4+2+0=-2다. 음수의 홀짝 판정에서 %2==0은 두 언어 모두 짝수 여부를 표현하지만 음수 나머지 일반 값은 다를 수 있다. C++는 입력을 한 개씩 받아 추가 저장 O(1), Python 예제는 전체 배열을 받아 O(n) 공간이다. 정답이 같아도 메모리 모델이 같지는 않다.

### 4. 제출 전 점검표

- 내장 정렬·컨테이너의 복잡도를 전체 비용에 포함한다.
- C++ 코드가 허용한 버전의 문법인지, Python 재귀 깊이가 안전한지 확인한다.
- SQL 코딩은 알고리즘 구현과 별도 문법·실행 순서를 DB 교재에서 연습한다.

### 5. 필기 코드 해석의 실제 순서
먼저 언어·버전·타입 크기 가정을 찾는다. 변수의 초기값과 객체 공유 관계를 그린다. 조건·반복·함수 호출을 한 단계씩 표에 기록한다. 언어가 결과를 보장하지 않는 코드는 임의 결과 대신 미정/정의되지 않은 동작 여부를 검토한다. 마지막으로 출력 형식까지 확인한다. 예제를 외우는 것보다 이 순서를 습관화한다.

### 종합 연습·완료 기준
C 배열 {2,4,6}에서 포인터 p=a+1의 *p는4다. Python의 중첩 얕은 복사에서 내부 객체를 수정하는 문제를 다시 그린다. C++·Python으로 짝수 합 코드를 가린 채 작성하고 [-4,3,2,7,0]→-2, 빈 배열→0을 확인한다. 필기는 결과뿐 아니라 왜 그 값인지 설명하고, 코딩은 새 입력에서도 스스로 구현하면 완료한다.

### 보강 두 언어 실습: 최대 값과 개수
문제: 비어 있지 않은 정수 목록의 최대 값과 그 값의 등장 횟수를 출력한다. Python에서는 best=max(a),count=a.count(best)로 두 번 순회할 수 있고,C++에서는 한 번 순회하며 갱신할 수도 있다. 두 방식 모두 O(n)이며 순회 횟수 상수는 다르다.

```python
def maximum_and_count(a):
    if not a:
        raise ValueError("nonempty input required")
    best = a[0]
    count = 0
    for x in a:
        if x > best:
            best, count = x, 1
        elif x == best:
            count += 1
    return best, count
```

[-3,-1,-1,-5]의 답은(-1,2),[4]의 답은(4,1)이다. 첫 원소부터 순회하므로 count 초기0이고 첫 비교에서1이 된다. 첫 원소 뒤에서 순회한다면 count 초기1이 자연스럽다. 두 설계를 섞으면 중복 카운트나 누락이 생긴다. 불변식은 “읽은 구간의 최대와 그 횟수를 저장한다”다. 같은 논리를 C++ long long 타입으로 다시 구현해 언어 문법과 알고리즘 상태를 분리한다.

### 강화 응용: 조건을 바꾸어 다시 증명하기
C++·C·Java 코드 읽기에서는 대입 앞의 목표 형보다 실제 연산 피연산자의 형을 본다. C++17에서 int a=50000,b=50000; long long p=a*b;는 먼저 int 곱셈을 수행하므로 32비트 int에서 오버플로 위험이 있다. 1LL*a*b나 static_cast<long long>(a)*b처럼 곱셈 전에 확대해야 한다. Java에서도 int 곱셈 뒤 long 대입은 이미 발생한 32비트 순환 결과를 고치지 않으므로 1L*a*b를 쓴다. C++ 부호 오버플로와 Java int 순환은 언어 정의가 다르지만 '연산 전에 확대'라는 구현 지침은 공통이다.

C의 2차원 행 우선 배열은 원소 크기가 고정이고 선언이 int a[2][3]일 때 다음 행까지 3개 원소 간격이다. 함수 인수에서는 행 길이 등 필요한 형 정보를 계약에 포함한다. Python의 list of list는 각 행 객체 참조를 담는 구조여서 모든 행이 하나의 연속 메모리라는 C 배열 공식을 그대로 적용하지 않는다.

실전 합계 함수는 입력 개수 n, 원소 범위, 모든 누적 중간 합의 범위, 잘못된 토큰 처리, 출력 형식까지 적는다. 최종 합이 안전해도 중간 합이 넘을 수 있다. 비교 정렬의 키에서 a-b로 대소를 판별하면 뺄셈 자체가 위험할 수 있어 a<b를 사용한다. 언어별 입력 속도 조정은 정확한 입력 계약과 알고리즘 복잡도를 정한 뒤 적용한다.
