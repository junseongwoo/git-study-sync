# 01-08 그리디·동적 계획법·누적 합·탐색 설계

[[GI-교재01 자료구조_알고리즘|과목 목차]] · [[GI-문제01 자료구조_알고리즘|문제]] · [[GI-해설01 자료구조_알고리즘|해설]]

## 풀이를 고르는 순서
입력 범위→정확한 완전 탐색→중복 계산·단조성·정렬 활용→개선의 순서로 생각한다. 자료구조 이름부터 고르기보다 “무엇을 반복해서 계산하는가”를 적는다. 그리디는 현재의 좋은 선택이 전체의 좋은 결과로 이어짐을 증명해야 하고, 동적 계획법(DP)은 부분 문제의 결과를 상태로 저장한다.

### 1. 그리디와 반례
동전 1,3,4로 6을 만드는 최소 개수를 생각한다. 큰 동전부터 고르면4+1+1로3개지만3+3이면2개다. 큰 동전을 우선하는 규칙은 모든 동전 체계에서 최적이 아니다. 반례 하나가 일반적인 주장 하나를 무너뜨린다. 시험에서 “국내 실제 화폐와 비슷하니 된다”는 감으로 입력 조건을 무시하지 않는다.

구간 일정 선택에서는 한 사람이 겹치지 않게 수행할 수 있는 일정의 최대 개수를 구할 때 종료가 빠른 순서의 선택이 타당한 표준 해법이다. 구간 [s,e)를 사용하면 이전 종료와 다음 시작이 같은 일정은 겹치지 않는다고 정의한다. 일정에 서로 다른 이익이 있어 총이익을 최대화하면 같은 그리디가 일반적으로 최적이 아니며 가중 일정 DP 등을 고려한다.

예제 A: (1,3),(2,4),(3,5),(0,6),(5,7) 중 종료가 빠른 (1,3)→(3,5)→(5,7)를 고르면3개다. 처음 시작이 빠른 (0,6)을 선택하면 뒤에 받을 수 있는 일정이 크게 줄어든다. 가장 짧은 일정 우선도 일반적인 최적 규칙은 아니다.

### 2. DP의 네 가지 필수 항목
상태 정의, 점화식, 초깃값, 계산 순서를 각각 적는다. dp[i]가 “무언가의 답”이라는 모호한 이름보다 “금액 i를 정확히 만드는 최소 동전 수”처럼 의미를 좁힌다. 앞의 동전1,3,4에서 dp[0]=0, 나머지∞, dp[x]=min(dp[x-c]+1) for c<=x이다.

예제 B: 금액1..6의 dp는1,2,1,1,2,2다. dp[5]는 dp[4]+1=2 또는 dp[2]+1=3 또는 dp[1]+1=2 중2, dp[6]은 dp[5]+1=3,dp[3]+1=2,dp[2]+1=3 중2다. 상태 수 A와 동전 종류 m에 비례해 O(Am), 공간 O(A)다. 정수 금액의 값 자체에 비례하는 비용이라는 점도 알아 둔다.

```python
def min_coins(coins, amount):
    inf = amount + 1
    dp = [inf] * (amount + 1)
    dp[0] = 0
    for x in range(1, amount + 1):
        for c in coins:
            if c <= x:
                dp[x] = min(dp[x], dp[x-c] + 1)
    return -1 if dp[amount] == inf else dp[amount]
```

코드는 coins가 양의 정수이고 amount>=0이라는 계약을 둔다. 만들 수 없는 금액은 -1을 반환한다. 0원은 아무 동전도 쓰지 않는 답0이다.

### 3. 0/1 배낭과 갱신 방향
각 물건을 최대 한 번 고르는 0/1 배낭에서 dp[c]는 용량 c 이하의 최대 가치라고 정의할 수 있다. 한 물건의 무게 w·가치 v에 대해 용량을 큰 쪽에서 작은 쪽으로 갱신하면 같은 물건을 중복 사용하지 않는다. 작은 쪽에서 큰 쪽으로 갱신하면 방금 업데이트한 값을 다시 사용하여 무제한 배낭의 효과가 생길 수 있다.

예제 C: 용량4, 물건 하나(무게2,가치3). 큰 용량부터 하면 dp[4]=3,dp[2]=3이다. 작은 용량부터 하면 dp[2]=3을 만든 다음 dp[4]=dp[2]+3=6으로 같은 물건을 두 번 쓴다. 반복 방향은 외워야 하는 장식이 아니라 상태가 “이전 물건까지의 결과”를 참조하는지의 문제다.

### 4. 누적 합·투 포인터
배열 a의 누적 합 p[0]=0,p[i+1]=p[i]+a[i]를 만들면 [l,r) 합은 p[r]-p[l]이다. 전처리 O(n), 질의 하나 O(1)이다. 원소를 자주 수정하면 기본 누적 합 배열의 뒤 구간을 갱신해야 하므로 Fenwick/세그먼트 트리 등 다른 구조를 고려한다.

예제 D: a=[3,1,4,2], p=[0,3,4,8,10]. 인덱스1부터3까지를 포함하는 구간은 [1,4)라서10-3=7이다. 포함 구간과 반열린 구간을 섞지 않는다. 음수가 있어도 누적 합 계산 자체는 유효하다.

두 포인터로 합이 특정 값 이상인 가장 짧은 구간을 찾는 기본 sliding window는 비음수 또는 양수 등 단조성이 성립하는 입력 조건이 필요하다. 음수가 섞이면 오른쪽 확장 시 합이 줄고 왼쪽 제거 시 합이 늘 수 있어 단순 이동 규칙이 깨진다. 정렬된 배열에서 두 수 합을 찾는 투 포인터는 합이 작을 때 왼쪽을 증가, 클 때 오른쪽을 감소시키는 정렬의 단조성을 사용한다.

### 5. 완전 탐색·백트래킹
순열 n!개, 부분집합2^n개를 전부 탐색하는 비용을 먼저 본다. 백트래킹은 현재 후보가 제약을 어긴 순간 더 깊은 가지를 보지 않는다. 잘 가지치기했다고 모든 입력에서 다항 시간이 되는 것은 아니다. 정답을 놓치지 않으려면 가지치기 조건이 확실하게 불가능한 경우를 제외해야 한다.

메모이제이션은 재귀 부분 문제의 답을 저장하고, 테이블 방식은 필요한 순서로 배열을 채운다. 둘 다 동일한 상태·점화식을 구현할 수 있으나 호출 스택·계산 순서·실제로 방문하는 상태가 다를 수 있다. 원래 Fibonacci 재귀는 중복 호출이 많지만 메모이제이션으로 상태 수 n에 비례하게 줄일 수 있다.

### 종합 완료 기준
새 문제에서 입력 크기와 허용 구조를 적고, 완전 탐색의 비용과 개선 근거를 말한다. 그리디에 반례를 시도하고, DP에는 초깃값과 계산 순서를 반드시 적는다. “코드를 읽고 이해”에서 멈추지 않고 본 장 네 예제를 가린 채 재현한 뒤 다른 작은 입력을 만들어 검증한다.

### 보강 손풀이: DP는 상태 의미가 계산 순서를 정한다
한 칸 또는 두 칸을 올라 n칸 계단에 정확히 도착하는 방법 수를 dp[n]으로 정의한다. 빈 경로 하나를 인정해 dp[0]=1,dp[1]=1이고 n>=2에서 dp[n]=dp[n-1]+dp[n-2]다. 마지막 걸음이 1칸인지 2칸인지 나누었고 두 경우가 겹치지 않으므로 더한다. n=2..5의 값은 2,3,5,8이다.

방법 수 합과 최소 비용은 연산이 다르다. 방법 수는 가능한 경우를 더하고 최솟값은 후보 중 min을 쓴다. 상태를 정확히 도착에서 넘어서도 허용으로 바꾸면 초깃값·출력이 달라질 수 있다. 큰 n은 정수 범위나 modulo 요구도 확인한다.

검증 과제: 0/1 배낭의 물건 (2,3) 하나와 용량 4에서 역방향 갱신 결과 3,정방향 결과 6을 재현한다. 누적 합 [0,3,4,8,10]으로 [l,r) 세 구간을 골라 직접 더한 값과 비교한다. 다음 풀이에도 상태·불변식·경계 입력의 세 줄을 문장으로 적는다.

### 강화 응용: 조건을 바꾸어 다시 증명하기
0/1 배낭과 무제한 배낭의 1차원 DP 차이는 용량 순회 방향이다. 물건 하나의 무게 2, 가치 3, 용량 4라고 하자. 0/1 배낭은 이 물건을 한 번만 사용할 수 있다. 용량을 4→2로 내려가며 dp[c]=max(dp[c],dp[c-2]+3)하면 결과 3이다. 2→4로 올라가면 c=2에서 갱신한 dp[2]=3을 c=4가 재사용해 6이 되어 같은 물건 두 번을 쓰는 무제한 모델이 된다. 점화식만 외우지 말고 dp의 '이전 물건 단계' 보존을 확인한다.

연속 부분합의 두 포인터는 비음수 값에서 단조성이 생기는 경우에 유용하다. 음수가 허용되면 오른쪽 확장이 합을 줄이기도 하므로 '합이 목표를 넘었으니 왼쪽을 버린다'가 안전하지 않다. [3,-2], 목표 1에서 처음 3만 보고 버리면 전체 구간 합 1을 놓친다. 정확히 합 K인 구간 수는 누적 합 p[j]-p[i]=K, 즉 이전 p[i]=p[j]-K인 횟수를 저장하는 방법으로 음수도 처리할 수 있다.

예를 들어 [1,-1,1], K=1의 prefix는 0,1,0,1이다. 시작에 빈 prefix 0의 빈도 1을 넣고 각 새 prefix에서 (prefix-K)의 이전 빈도를 더한다. 결과는 1+0+2=3이며 구간 [0,0],[0,2],[2,2]다. 현재 prefix를 먼저 빈도에 넣으면 K=0에서 길이 0인 자기 구간을 잘못 셀 수 있으므로 답 갱신 뒤 저장한다.
