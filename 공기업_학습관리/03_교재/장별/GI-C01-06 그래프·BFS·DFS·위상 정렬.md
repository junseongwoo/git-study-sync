# 01-06 그래프·BFS·DFS·위상 정렬

[[GI-교재01 자료구조_알고리즘|과목 목차]] · [[GI-문제01 자료구조_알고리즘|문제]] · [[GI-해설01 자료구조_알고리즘|해설]]

## 관계를 표현하는 방법
정점은 대상을, 간선은 관계를 나타낸다. 무방향·방향, 가중치 유무, 중복 간선·자기 루프 허용 여부를 먼저 확인한다. 도로가 양방향이라고 해서 모든 그래프의 간선을 양쪽에 기록하면 안 된다. 유향 그래프에서 A→B가 있어도 B→A는 별개다.

### 1. 인접 행렬과 인접 리스트
정점 V개인 인접 행렬은 보통 V×V 크기이며 공간 O(V^2), 두 정점 간 간선 조회 O(1)이다. 정점 u의 이웃을 모두 보려면 행 전체 O(V)를 읽는다. 인접 리스트는 공간 O(V+E)로 희소 그래프에 적합하며 이웃 순회는 차수에 비례한다. 무방향 간선을 양쪽에 저장해 항목 수가2E여도 점근 차수는 같다.

예제 A: 정점1..5, 무방향 간선(1,2),(1,3),(2,4),(3,4),(4,5). 1의 리스트는 [2,3], 2는[1,4], 3은[1,4], 4는[2,3,5], 5는[4]다. 각 리스트를 오름차순으로 정렬해 아래 순서를 정의한다. 이 조건 없이 BFS·DFS의 방문 순서를 단 하나로 고정하지 않는다.

### 2. BFS와 최단 간선 수
BFS는 큐에 시작 정점을 넣고 가까운 레벨부터 방문한다. 가중치가 없거나 모든 간선 비용이 동일한 그래프에서 시작점까지의 최단 간선 수를 구한다. 발견할 때 방문 표시를 하면 같은 정점이 여러 번 큐에 들어가는 일을 막는다.

위 그래프에서 시작1의 큐와 거리를 추적한다.
- 1 처리: 2·3 발견, 거리1, 큐[2,3].
- 2 처리: 4 발견, 거리2, 큐[3,4].
- 3 처리: 4는 이미 발견되어 생략, 큐[4].
- 4 처리: 5 발견, 거리3.
방문 순서는1,2,3,4,5이며 1→5 최단 간선 수는3이다. 경로를 출력하려면 발견 시 부모를 저장한다. 거리만 있으면 모든 경로를 바로 알 수 있는 것은 아니다.

```python
from collections import deque
def bfs(adj, start):
    dist = [-1] * len(adj)
    dist[start] = 0
    q = deque([start])
    while q:
        u = q.popleft()
        for v in adj[u]:
            if dist[v] == -1:
                dist[v] = dist[u] + 1
                q.append(v)
    return dist
```

이 함수는 adj 인덱스 범위 안의 정점을 가정한다. 도달하지 못하는 정점은 -1이다. 인접 리스트에서 각 정점·간선을 일정 횟수만 보므로 O(V+E), 인접 행렬에서 이웃 행을 읽으면 O(V^2)다.

### 3. DFS와 돌아오기
DFS는 갈 수 있는 다음 정점으로 깊이 들어간 후 되돌아온다. 재귀 호출 또는 명시적 스택으로 구현한다. 위 그래프를 이웃 오름차순의 재귀 DFS로 시작하면1,2,4,3,5의 발견 순서다. 4에서 이웃2는 방문되어 생략하고3으로 갔다 돌아온 뒤5로 간다. BFS와 달리 최초 발견 경로가 일반적인 최단 경로라고 보장하지 않는다.

깊이가 큰 그래프는 재귀 한도·호출 스택 문제를 일으킬 수 있다. 반복 DFS에서 이웃을 정방향으로 스택에 넣으면 LIFO 때문에 방문 순서가 재귀 구현과 달라질 수 있다. 같은 순서를 요구한다면 push 순서와 방문 표시 시점을 명시한다. 정확성을 위해 스택을 쓴다는 것과 순서를 재귀와 똑같게 만든다는 것은 별개다.

### 4. 연결 요소와 사이클
무방향 그래프에서 아직 방문하지 않은 정점을 시작으로 BFS/DFS를 반복한 횟수가 연결 요소 수다. 시작점 하나에서 탐색했다고 모든 정점을 방문했다고 결론 내리지 않는다. 무방향 DFS의 사이클 검사에서는 부모로 돌아가는 간선과 실제 사이클 간선을 구별해야 한다.

방향 그래프에서는 재귀 경로에 아직 있는 정점으로 돌아가는 간선이 사이클을 드러낸다. 방문 여부만으로 방향 사이클을 단정하면 교차 간선을 오해할 수 있으므로 미방문·진행 중·완료 상태 등 목적에 맞는 정보를 둔다.

### 5. 위상 정렬
방향 비순환 그래프(DAG)에서 모든 간선 u→v에 대해 u가 v보다 앞에 오도록 나열한다. 결과는 여러 개일 수 있다. Kahn 알고리즘은 진입 차수0의 정점을 큐에 넣고, 꺼낸 정점의 outgoing 간선을 제거하며 새 진입 차수0 정점을 넣는다. 정점 수만큼 꺼내지 못하면 사이클이 있다.

예제 B: A→C, B→C, C→D에서 시작 후보는 A,B다. A B C D 또는 B A C D가 유효하다. C를 먼저 놓으면 A→C 조건을 위반한다. 스택이나 우선순위 큐를 쓰면 후보 선택 순서가 달라질 수 있지만 모든 간선의 선행 조건을 지키면 유효하다.

### 실무 연결·완료 기준
검사 공정의 선후 관계는 DAG 여부를 확인한 후 위상 정렬로 표현할 수 있다. 장비 간 네트워크 경로는 가중치나 비용이 있으면 BFS가 충분하지 않을 수 있다. 두 표현의 공간, 두 탐색의 자료구조, 위상 정렬의 DAG 조건을 말하고 고립 정점까지 포함해 연결 요소 수를 세면 완료한다.

### 보강 손풀이: 도달 가능과 연결성을 따로 확인
정점 1..6에서 간선 (1,2),(2,3),(4,5)만 있다고 하자. 1에서 BFS를 실행하면 1,2,3을 방문하고 4,5,6은 미도달이다. 전체 연결 요소는 {1,2,3},{4,5},{6}의 3개다. 고립 정점 6도 요소 하나다.

같은 간선을 방향 1→2,2→3,4→5로 바꾸면 무방향 연결 요소와 유향 도달 가능은 다른 질문이다. 1에서 3으로 갈 수 있지만 3에서 1로는 못 간다. 강한 연결 요소는 모든 정점 쌍이 서로 도달할 수 있는 집합이라는 추가 정의다. 기본 BFS·DFS에서는 단방향 경로의 존재부터 확인한다.

Kahn 연습에서 A→B,B→A,C가 주어지면 초기 진입 차수 0은 C뿐이다. C를 꺼내도 A·B가 남아 총 정점 수보다 처리 개수가 작다. 이것이 사이클 감지의 근거다. 가장 작은 번호를 먼저 고르는 우선순위 큐는 결과 순서를 정하는 추가 정책이며 DAG 성질을 대신하지 않는다.

### 강화 응용: 조건을 바꾸어 다시 증명하기
유향 그래프 A→C,B→C,C→D,B→E에서 Kahn 위상 정렬의 최초 후보는 A,B다. 작은 문자부터 처리하는 정책이면 A,B,C,D,E가 되지만, B,A,E,C,D도 선후 관계를 모두 만족한다. 위상 순서는 하나일 필요가 없다. 처리한 정점 수가 전체보다 작으면 남은 정점들의 진입 차수를 낮추지 못하게 하는 사이클이 존재한다. 초기 진입 차수 0 정점이 있다고 그래프 전체가 비순환인 것은 아니다. 예를 들어 A↔B와 독립 C가 있으면 C만 처리할 수 있다.

BFS의 최단 거리와 방문 순서도 분리한다. 인접 정점 순서를 바꾸면 부모 선택과 방문 순서는 달라질 수 있지만 동일한 비가중 그래프의 시작점별 최단 간선 수는 같다. 무방향 그래프의 사이클을 DFS로 검사할 때 부모 간선은 제외한다. 유향 그래프에서는 현재 재귀 경로의 진행 중 정점으로 돌아가는 간선을 확인한다. 완료 정점으로 향하는 간선만으로 사이클이라고 결론 내리면 DAG의 합류 구조 A→B,A→C,B→C를 잘못 판정한다.

재귀 DFS를 반복 DFS로 바꾸려면 함수 호출에서 하던 '다음 이웃 위치'를 스택 프레임에 보존하거나, 순서가 필요 없는 도달 가능 문제임을 명시한다. 이웃 역순 push만으로 모든 구현의 발견 시점과 부모가 재귀와 같다고 보장하지 않는다.
