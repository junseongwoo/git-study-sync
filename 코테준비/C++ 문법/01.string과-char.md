# C++ string과 char

- 작성일: 2026-08-04
- 주제: `char`, C 문자열, `std::string`, 동적 할당, `const`

## 1. `char`와 `std::string`의 차이

### `char`: 문자 한 개

`char`는 문자 **한 개**를 저장하는 자료형이다. 문자는 작은따옴표(`'`)로 감싼다.

```cpp
char alphabet = 'A';
char digit = '7';
char space = ' ';
```

```cpp
char value1 = 'A';  // 문자 한 개: 올바름
char value2 = "A";  // 오류: "A"는 문자열
```

### `char[]`: C 방식 문자열

여러 문자를 배열에 저장하면 C 방식 문자열을 만들 수 있다.

```cpp
char word[] = "hello";
```

실제 메모리에는 문자열의 끝을 나타내는 널 문자 `\0`가 자동으로 추가된다.

```text
'h' 'e' 'l' 'l' 'o' '\0'
```

따라서 `"hello"`를 저장하려면 총 6칸이 필요하다.

```cpp
char word[6] = {'h', 'e', 'l', 'l', 'o', '\0'};
```

`\0`가 없으면 `strlen()`, `strcpy()` 같은 C 문자열 함수가 문자열의 끝을 알 수 없다.

### `char*`: 문자를 가리키는 포인터

`char*`는 `char`가 저장된 메모리의 주소를 담는다. C 문자열에서는 보통 첫 번째 문자의 주소를 가리킨다.

```cpp
char word[] = "hello";
char* pointer = word;

cout << pointer;     // hello
cout << pointer[0];  // h
cout << pointer[1];  // e
```

### `std::string`: C++ 방식 문자열

`std::string`은 문자열의 크기와 메모리를 자동으로 관리하는 C++ 클래스다.

```cpp
#include <string>

std::string word = "hello";
word += " world";
word.push_back('!');

cout << word;  // hello world!
```

일반적인 C++ 코드와 코딩 테스트에서는 반환 형식이 별도로 정해져 있지 않다면 `char*`보다 `std::string`을 사용하는 편이 안전하고 편리하다.

| 구분 | `char` | `char*` / `char[]` | `std::string` |
|---|---|---|---|
| 의미 | 문자 한 개 | C 방식 문자열 | C++ 문자열 클래스 |
| 예시 | `'A'` | `"ABC"` | `"ABC"` |
| 길이 | 항상 한 문자 | `strlen(str)` | `str.size()` |
| 결합 | 해당 없음 | `strcat()` | `+`, `+=` |
| 비교 | `==` | `strcmp()` | `==` |
| 메모리 관리 | 불필요 | 직접 관리할 수 있음 | 자동 관리 |

## 2. 자주 사용하는 `std::string` 기능

```cpp
#include <string>
using namespace std;

string str = "hello";
```

### 길이와 빈 문자열 확인

```cpp
size_t length1 = str.size();
size_t length2 = str.length();  // size()와 같은 결과

if (str.empty()) {
    cout << "빈 문자열";
}
```

### 문자 접근

```cpp
cout << str[0];      // h
cout << str.at(1);   // e
cout << str.front(); // 첫 문자 h
cout << str.back();  // 마지막 문자 o
```

- `[]`는 범위를 검사하지 않는다.
- `at()`은 범위를 벗어나면 예외를 발생시킨다.
- 빈 문자열에서는 `front()`, `back()`, `pop_back()`을 사용하면 안 된다.

### 문자와 문자열 추가 및 제거

```cpp
str.push_back('!');  // 문자 한 개 추가
str += " C++";       // 문자열 추가
str.append(" test");

if (!str.empty()) {
    str.pop_back();  // 마지막 문자 제거
}
```

### 부분 문자열

```cpp
string str = "abcdef";

cout << str.substr(2, 3);  // cde: 2번 위치부터 3개
cout << str.substr(2);     // cdef: 2번 위치부터 끝까지
```

### 문자열 검색

```cpp
string str = "hello world";
size_t position = str.find("world");

if (position != string::npos) {
    cout << position;  // 6
}
```

찾지 못하면 `string::npos`를 반환한다.

### 삽입과 삭제

```cpp
string str = "abcd";

str.insert(2, "XX"); // abXXcd
str.erase(2, 2);      // abcd: 2번 위치부터 2개 삭제
```

### 비교

`std::string`은 `==`, `!=`, `<`, `>` 등의 연산자로 내용을 비교할 수 있다.

```cpp
string a = "apple";
string b = "banana";

if (a == "apple") {
    cout << "같음";
}

if (a < b) {
    cout << "a가 사전순으로 앞";
}
```

### 숫자와 문자열 변환

```cpp
string text = to_string(123);       // 숫자 -> 문자열
int number = stoi("123");           // 문자열 -> int
long long big = stoll("123456789"); // 문자열 -> long long
double value = stod("3.14");        // 문자열 -> double
```

## 3. C 문자열 함수

C 문자열 함수를 사용하려면 다음 헤더가 필요하다.

```cpp
#include <cstring>
```

### `strlen()`: 문자열 길이

```cpp
const char* str = "hello";
size_t length = strlen(str);

cout << length;  // 5
```

`strlen()`은 첫 문자부터 `\0` 전까지의 문자 개수를 센다. `\0`는 길이에 포함하지 않는다.

```cpp
char str[100] = "hello";

cout << sizeof(str);  // 100: 배열 전체 크기
cout << strlen(str);  // 5: 실제 문자열 길이
```

`strlen()`의 시간 복잡도는 `O(N)`이므로 반복문의 조건에서 계속 호출하지 않는 편이 좋다.

```cpp
size_t length = strlen(str);

for (size_t i = 0; i < length; i++) {
    // 문자열 처리
}
```

### `strcpy()`: 문자열 복사

```cpp
char destination[20];
const char* source = "hello";

strcpy(destination, source);
cout << destination;  // hello
```

형식은 `strcpy(목적지, 원본)`이며 원본의 `\0`까지 복사한다. 목적지에 충분한 공간이 있어야 한다.

```cpp
char destination[3];
strcpy(destination, "hello");  // 잘못됨: 6칸이 필요함
```

`strcpy()`는 목적지의 크기를 검사하지 않으므로 공간이 부족하면 버퍼 오버플로가 발생할 수 있다.

### `strcmp()`: C 문자열 내용 비교

`char*`끼리 `==`를 사용하면 문자열 내용이 아니라 주소를 비교한다. 내용은 `strcmp()`로 비교한다.

```cpp
const char* a = "apple";
const char* b = "apple";

if (strcmp(a, b) == 0) {
    cout << "같은 문자열";
}
```

```text
strcmp(a, b) == 0  : 두 문자열이 같음
strcmp(a, b) < 0   : a가 사전순으로 앞
strcmp(a, b) > 0   : a가 사전순으로 뒤
```

### `strcat()`: C 문자열 이어 붙이기

```cpp
char destination[20] = "hello";
strcat(destination, " world");

cout << destination;  // hello world
```

목적지에는 두 문자열과 마지막 `\0`가 모두 들어갈 공간이 필요하다.

```text
필요한 크기 = strlen(destination) + strlen(source) + 1
```

## 4. `char*`와 `std::string` 변환

### C 문자열에서 `std::string`으로

```cpp
const char* cString = "hello";
std::string cppString = cString;
```

### `std::string`에서 읽기 전용 C 문자열로

```cpp
std::string cppString = "hello";
const char* cString = cppString.c_str();
```

`c_str()`이 반환한 주소는 원본 `std::string`이 수정되거나 사라지면 더 이상 유효하지 않을 수 있다.

### 수정 가능한 독립적인 `char*`로 복사

```cpp
#include <cstdlib>
#include <cstring>
#include <string>

std::string result = "hello";

char* answer = (char*)malloc(result.size() + 1);

if (answer != nullptr) {
    strcpy(answer, result.c_str());
}
```

## 5. 크기가 달라지는 문자열과 `malloc`

`malloc()`은 전달한 바이트 수만큼 힙 메모리를 동적으로 할당한다.

```cpp
char* answer = (char*)malloc(필요한_문자_개수 + 1);
```

마지막 `+1`은 문자열 끝의 `\0`를 저장하기 위한 공간이다. `malloc()`은 공간만 확보하며 내용을 자동으로 초기화하지 않는다.

문자열 크기가 조건에 따라 달라지면 다음 순서로 처리한다.

1. 필요한 결과 길이를 계산한다.
2. `결과 길이 + 1`만큼 할당한다.
3. 조건에 맞는 문자를 넣는다.
4. 마지막에 `\0`를 넣는다.

### 예제: 영문자만 남기기

```cpp
#include <cctype>
#include <cstdlib>

char* solution(const char* input) {
    size_t resultLength = 0;

    // 1. 필요한 결과 길이 계산
    for (size_t i = 0; input[i] != '\0'; i++) {
        if (std::isalpha(static_cast<unsigned char>(input[i]))) {
            resultLength++;
        }
    }

    // 2. 결과 길이 + 널 문자 한 칸 할당
    char* answer = (char*)malloc(resultLength + 1);

    if (answer == nullptr) {
        return nullptr;
    }

    // 3. 결과 작성
    size_t index = 0;

    for (size_t i = 0; input[i] != '\0'; i++) {
        if (std::isalpha(static_cast<unsigned char>(input[i]))) {
            answer[index++] = input[i];
        }
    }

    // 4. 문자열 끝 표시
    answer[index] = '\0';

    return answer;
}
```

### `std::string`으로 결과를 만든 뒤 반환하기

조건이 복잡하면 `std::string`으로 결과를 완성한 뒤 `char*`로 복사하는 방식이 편하다.

```cpp
char* solution(int number) {
    std::string result;

    if (number % 2 == 0) {
        result = "even: " + std::to_string(number);
    } else {
        result = "odd: " + std::to_string(number);
    }

    char* answer = (char*)malloc(result.size() + 1);

    if (answer == nullptr) {
        return nullptr;
    }

    strcpy(answer, result.c_str());
    return answer;
}
```

### 지역 배열을 반환하면 안 되는 이유

```cpp
char* wrongSolution() {
    char answer[6] = "hello";
    return answer;  // 잘못됨
}
```

지역 배열 `answer`는 함수가 종료될 때 수명이 끝난다. 반환받은 주소는 더 이상 유효하지 않다. 반면 `malloc()`으로 할당한 메모리는 함수가 끝나도 유지된다.

```cpp
char* solution() {
    char* answer = (char*)malloc(6);

    if (answer == nullptr) {
        return nullptr;
    }

    strcpy(answer, "hello");
    return answer;
}
```

`malloc()`으로 할당한 메모리는 원칙적으로 사용이 끝난 뒤 `free()`로 해제한다.

```cpp
char* result = solution();

if (result != nullptr) {
    cout << result;
    free(result);
}
```

`malloc()`과 `free()`가 한 쌍이다. `malloc()`으로 만든 메모리를 `delete[]`로 해제하면 안 된다.

## 6. `const`의 의미

`const`는 해당 이름 또는 포인터를 통해 값을 변경하지 못하게 한다.

```cpp
const int number = 10;
number = 20;  // 오류
```

### `const char*`: 가리키는 문자를 변경할 수 없음

```cpp
const char* pointer = "hello";

pointer[0] = 'H';  // 오류: 가리키는 문자 변경 불가
pointer = "world"; // 가능: 다른 주소를 가리킬 수 있음
```

다음 두 선언은 같은 뜻이다.

```cpp
const char* pointer;
char const* pointer;
```

문자열 리터럴은 수정하면 안 되므로 다음처럼 `const char*`로 받는다.

```cpp
const char* message = "hello";
```

### `char* const`: 포인터 자체를 변경할 수 없음

```cpp
char word[] = "hello";
char other[] = "world";
char* const pointer = word;

pointer[0] = 'H';  // 가능: 문자 변경
pointer = other;   // 오류: 포인터가 가리키는 주소 변경 불가
```

### `const char* const`: 문자와 포인터 모두 변경할 수 없음

```cpp
char word[] = "hello";
const char* const pointer = word;

pointer[0] = 'H';  // 오류
pointer = nullptr; // 오류
```

| 선언 | 가리키는 문자 변경 | 가리키는 주소 변경 |
|---|---:|---:|
| `const char* p` | 불가능 | 가능 |
| `char* const p` | 가능 | 불가능 |
| `const char* const p` | 불가능 | 불가능 |

함수가 입력 문자열을 읽기만 한다면 `const char*`로 받는 것이 좋다.

```cpp
size_t getLength(const char* str) {
    return strlen(str);
}
```

함수가 문자열을 수정해야 한다면 `char*`로 받는다.

```cpp
void changeFirstCharacter(char* str) {
    str[0] = 'X';
}

char word[] = "hello";
changeFirstCharacter(word);

cout << word;  // Xello
```

## 7. 핵심 요약

- `char`는 문자 한 개다.
- `char[]`와 `char*`는 C 방식 문자열을 표현할 때 사용한다.
- C 문자열은 마지막에 반드시 `\0`가 필요하다.
- `std::string`은 크기와 메모리를 자동으로 관리한다.
- `strlen()`은 `\0`를 제외한 문자열 길이를 구한다.
- `strcpy()`는 원본의 `\0`까지 목적지로 복사한다.
- C 문자열의 내용 비교는 `strcmp()`, `std::string` 비교는 `==`를 사용한다.
- `malloc()`으로 C 문자열을 만들 때는 `문자열 길이 + 1`칸을 할당한다.
- `malloc()`으로 할당한 메모리는 `free()`로 해제한다.
- `const char*`는 해당 포인터를 통해 가리키는 문자를 수정할 수 없다는 뜻이다.
