# 1부 - 정렬

## 1. 정렬이 왜 중요한가?

정렬은 데이터를 일정한 순서로 재배치하는 작업이다.

```text
정렬 전: 7 2 9 1 5
오름차순: 1 2 5 7 9
내림차순: 9 7 5 2 1
```

정렬하면 다음 작업이 쉬워진다.

- 최솟값·최댓값과 순위 찾기
- 같은 값끼리 모으기
- 중복 제거
- 두 포인터 사용
- 이분 탐색 적용
- 구간과 일정 처리

정렬 자체가 답이 아니더라도 이후 알고리즘을 가능하게 만드는 전처리가 된다.

---

## 2. `std::sort` 기본 사용법

```cpp
#include <algorithm>
#include <vector>
using namespace std;

vector<int> numbers = {7, 2, 9, 1, 5};

sort(numbers.begin(), numbers.end());
```

결과는 `{1, 2, 5, 7, 9}`다.

### 일부 구간만 정렬

```cpp
sort(numbers.begin() + 1, numbers.begin() + 4);
```

반복자 구간은 `[first, last)`이므로 마지막 반복자가 가리키는 원소는 포함되지 않는다.

### 시간 복잡도

`N`개 원소 정렬은 `O(N log N)`이다.

코딩 테스트에서는 특별히 직접 구현하라는 요구가 없다면 `std::sort`를 우선 사용한다.

---

## 3. 내림차순 정렬

```cpp
#include <functional>

sort(numbers.begin(), numbers.end(), greater<int>());
```

또는 람다식을 사용한다.

```cpp
sort(numbers.begin(), numbers.end(), [](int a, int b) {
    return a > b;
});
```

비교 함수가 `true`를 반환하면 `a`가 `b`보다 앞에 와야 한다는 뜻이다.

---

## 4. 여러 기준으로 정렬하기

학생을 다음 기준으로 정렬한다고 하자.

1. 점수 내림차순
2. 점수가 같으면 이름 오름차순

```cpp
#include <algorithm>
#include <string>
#include <vector>
using namespace std;

struct Student {
    string name;
    int score;
};

sort(students.begin(), students.end(),
    [](const Student& a, const Student& b) {
        if (a.score != b.score) {
            return a.score > b.score;
        }

        return a.name < b.name;
    }
);
```

### 비교 함수에서 하면 안 되는 것

```cpp
return a.score >= b.score; // 잘못된 비교
```

같은 원소끼리 비교했을 때도 `true`가 될 수 있다. 엄격한 순서를 만들려면 동률에서 `false`가 되도록 `<` 또는 `>`를 사용한다.

---

## 5. `pair`와 `tuple` 정렬

`pair`는 기본적으로 `first`, 그다음 `second` 순서로 오름차순 비교된다.

```cpp
vector<pair<int, int>> points = {
    {2, 3}, {1, 5}, {2, 1}
};

sort(points.begin(), points.end());
```

결과:

```text
(1, 5), (2, 1), (2, 3)
```

기본 사전식 순서가 문제의 조건과 같다면 별도의 비교 함수가 필요 없다.

---

## 6. 안정 정렬

안정 정렬은 비교 기준이 같은 원소들의 기존 순서를 유지한다.

```cpp
stable_sort(students.begin(), students.end(),
    [](const Student& a, const Student& b) {
        return a.score > b.score;
    }
);
```

입력 순서가 접수 순서이고, 점수가 같은 사람은 접수 순서를 유지해야 한다면 `stable_sort`가 편리하다.

`sort`는 같은 키의 기존 순서를 보장하지 않는다.

---

## 7. 정렬 후 중복 제거

```cpp
sort(numbers.begin(), numbers.end());

numbers.erase(
    unique(numbers.begin(), numbers.end()),
    numbers.end()
);
```

`unique()`는 연속한 중복을 뒤쪽으로 밀고 새로운 논리적 끝을 반환한다. 따라서 먼저 정렬하고 `erase()`까지 호출해야 실제 크기가 줄어든다.

---

## 8. 전체 정렬이 필요하지 않을 때

### 앞의 K개만 정렬

```cpp
partial_sort(
    numbers.begin(),
    numbers.begin() + k,
    numbers.end()
);
```

앞의 `K`개에는 가장 작은 `K`개가 정렬된 상태로 놓인다.

### K번째 위치만 결정

```cpp
nth_element(
    numbers.begin(),
    numbers.begin() + k,
    numbers.end()
);
```

`numbers[k]`는 전체를 정렬했을 때 그 위치에 올 값이 된다. 앞뒤 구간 전체가 정렬되는 것은 아니다.

---

## 9. 병합 정렬 원리

책에서는 분할 정복 정렬의 첫 예로 병합 정렬을 다룬다.

```text
[7, 2, 5, 1]
  -> [7, 2] [5, 1]
  -> [7] [2] [5] [1]
  -> [2, 7] [1, 5]
  -> [1, 2, 5, 7]
```

1. 배열을 절반으로 나눈다.
2. 각 절반을 재귀적으로 정렬한다.
3. 두 정렬된 배열을 하나로 병합한다.

```cpp
vector<int> mergeSort(const vector<int>& numbers) {
    if (numbers.size() <= 1) {
        return numbers;
    }

    size_t middle = numbers.size() / 2;
    vector<int> left(numbers.begin(), numbers.begin() + middle);
    vector<int> right(numbers.begin() + middle, numbers.end());

    left = mergeSort(left);
    right = mergeSort(right);

    vector<int> result;
    result.reserve(numbers.size());

    size_t i = 0;
    size_t j = 0;

    while (i < left.size() && j < right.size()) {
        if (left[i] <= right[j]) {
            result.push_back(left[i++]);
        } else {
            result.push_back(right[j++]);
        }
    }

    while (i < left.size()) {
        result.push_back(left[i++]);
    }

    while (j < right.size()) {
        result.push_back(right[j++]);
    }

    return result;
}
```

- 시간: `O(N log N)`
- 추가 공간: `O(N)`
- 같은 값에서 왼쪽을 먼저 선택하면 안정 정렬로 구현 가능

---

## 10. 퀵 정렬 원리

퀵 정렬은 피벗을 정하고 작은 값과 큰 값을 나눈 뒤 각 구간을 재귀적으로 정렬한다.

```text
피벗 5
[7, 2, 5, 1, 9]
 -> [2, 1] [5] [7, 9]
```

- 평균 시간: `O(N log N)`
- 최악 시간: `O(N^2)`
- 피벗 선택과 분할 상태에 성능이 크게 좌우됨

실전에서는 직접 구현보다 `std::sort`를 사용한다. C++ 표준은 성능 조건을 규정하지만 내부 구현 방식을 답안에서 특정 알고리즘 하나로 단정하지 않는다.

# 2부 - 이분 탐색

## 11. 이분 탐색의 전제 조건

이분 탐색은 **정렬된 데이터**에서 탐색 범위를 절반씩 줄인다.

```text
1 3 5 7 9 11 13
      ^ 중간값 7
```

찾는 값이 11이면 중간값 7보다 크므로 왼쪽 절반을 버린다.

- 선형 탐색: `O(N)`
- 이분 탐색: `O(log N)`

정렬되지 않은 배열에 이분 탐색을 적용하면 틀린 결과가 나온다.

---

## 12. 직접 구현 - 닫힌 구간 `[left, right]`

```cpp
int binarySearch(const vector<int>& numbers, int target) {
    int left = 0;
    int right = static_cast<int>(numbers.size()) - 1;

    while (left <= right) {
        int middle = left + (right - left) / 2;

        if (numbers[middle] == target) {
            return middle;
        }

        if (numbers[middle] < target) {
            left = middle + 1;
        } else {
            right = middle - 1;
        }
    }

    return -1;
}
```

### 반드시 기억할 세 줄

```cpp
while (left <= right)
left = middle + 1;
right = middle - 1;
```

`middle`을 다시 범위에 포함하면 무한 반복할 수 있다.

### 안전한 중간값

```cpp
int middle = left + (right - left) / 2;
```

`(left + right) / 2`보다 덧셈 오버플로 위험을 줄인다.

---

## 13. 표준 라이브러리 `binary_search`

```cpp
#include <algorithm>

sort(numbers.begin(), numbers.end());

bool exists = binary_search(
    numbers.begin(),
    numbers.end(),
    target
);
```

존재 여부만 필요할 때 사용한다. 위치나 개수가 필요하면 `lower_bound`, `upper_bound`를 사용한다.

---

## 14. `lower_bound`

`lower_bound`는 **target 이상인 첫 위치**를 반환한다.

```text
배열:   1 2 2 2 4 7
target: 2
결과:     ^ 인덱스 1
```

```cpp
auto it = lower_bound(numbers.begin(), numbers.end(), target);
int index = static_cast<int>(it - numbers.begin());
```

모든 값이 target보다 작으면 `end()`를 반환하며, 인덱스로는 `numbers.size()`가 된다.

---

## 15. `upper_bound`

`upper_bound`는 **target보다 큰 첫 위치**를 반환한다.

```text
배열:   1 2 2 2 4 7
target: 2
결과:           ^ 인덱스 4
```

```cpp
auto it = upper_bound(numbers.begin(), numbers.end(), target);
```

### 특정 값의 개수

```cpp
int count = static_cast<int>(
    upper_bound(numbers.begin(), numbers.end(), target)
    - lower_bound(numbers.begin(), numbers.end(), target)
);
```

정렬 비용은 `O(N log N)`, 각 경계 탐색은 `O(log N)`이다.

---

## 16. 첫 위치를 직접 찾는 템플릿

```cpp
int firstAtLeast(const vector<int>& numbers, int target) {
    int left = 0;
    int right = static_cast<int>(numbers.size());

    while (left < right) {
        int middle = left + (right - left) / 2;

        if (numbers[middle] < target) {
            left = middle + 1;
        } else {
            right = middle;
        }
    }

    return left;
}
```

이 코드는 반열린 구간 `[left, right)`를 사용한다. 처음에는 직접 구현보다 STL을 사용하고, 경계 탐색 원리를 이해한 뒤 이 템플릿을 연습한다.

---

## 17. 회전된 정렬 배열

정렬 배열을 어느 지점에서 회전하면 다음과 같이 된다.

```text
원본: 1 2 3 4 5 6 7
회전: 5 6 7 1 2 3 4
```

중간값을 기준으로 왼쪽 또는 오른쪽 중 한쪽은 항상 정렬되어 있다. 정렬된 쪽에 target이 포함되는지 확인해 범위를 줄인다.

```cpp
int searchRotated(const vector<int>& numbers, int target) {
    int left = 0;
    int right = static_cast<int>(numbers.size()) - 1;

    while (left <= right) {
        int middle = left + (right - left) / 2;

        if (numbers[middle] == target) {
            return middle;
        }

        if (numbers[left] <= numbers[middle]) {
            if (numbers[left] <= target && target < numbers[middle]) {
                right = middle - 1;
            } else {
                left = middle + 1;
            }
        } else {
            if (numbers[middle] < target && target <= numbers[right]) {
                left = middle + 1;
            } else {
                right = middle - 1;
            }
        }
    }

    return -1;
}
```

이 코드는 모든 값이 서로 다르다는 조건을 전제로 한다.

# 3부 - 정답 이분 탐색

## 18. 값을 찾는 대신 정답을 찾는다

배열에 존재하는 값을 찾는 것만 이분 탐색이 아니다. 가능한 정답의 범위가 있고, 어떤 값이 가능한지를 빠르게 판별할 수 있다면 정답도 이분 탐색할 수 있다.

```text
작은 값은 가능, 큰 값은 불가능
가능 가능 가능 | 불가능 불가능
              ^ 경계 찾기
```

이를 흔히 **파라메트릭 서치** 또는 **정답 이분 탐색**이라고 한다.

### 문제에서 보이는 신호

- 최댓값의 최솟값
- 최솟값의 최댓값
- 가능한 최대 거리
- 제한 시간 안에 처리 가능한 최소 속도
- M개 이하 구간으로 나누는 최소 상한

---

## 19. 정답 이분 탐색 절차

1. 정답의 최솟값과 최댓값을 정한다.
2. `middle`이 가능한지 검사하는 함수를 만든다.
3. 가능 여부가 한 방향으로만 바뀌는지 확인한다.
4. 최대 가능값 또는 최소 가능값의 경계를 찾는다.

### 공유기 설치 형태

정렬된 집 좌표에 공유기 `required`개를 설치할 때 가능한 최소 거리의 최댓값을 찾는다.

```cpp
bool canInstall(
    const vector<int>& houses,
    int required,
    int minimumDistance
) {
    int installed = 1;
    int lastPosition = houses[0];

    for (int i = 1; i < static_cast<int>(houses.size()); i++) {
        if (houses[i] - lastPosition >= minimumDistance) {
            installed++;
            lastPosition = houses[i];
        }
    }

    return installed >= required;
}

int maximumMinimumDistance(vector<int> houses, int required) {
    sort(houses.begin(), houses.end());

    int left = 1;
    int right = houses.back() - houses.front();
    int answer = 0;

    while (left <= right) {
        int middle = left + (right - left) / 2;

        if (canInstall(houses, required, middle)) {
            answer = middle;
            left = middle + 1;
        } else {
            right = middle - 1;
        }
    }

    return answer;
}
```

- 정렬: `O(N log N)`
- 가능성 검사 한 번: `O(N)`
- 정답 탐색: `O(N log R)`, `R`은 거리 범위

## 20. 단조성이 없으면 사용할 수 없다

가능 여부가 다음처럼 뒤섞이면 이분 탐색할 수 없다.

```text
가능 불가능 가능 불가능
```

반드시 다음 중 하나여야 한다.

vector<int> solution(vector<int> numbers) {

sort(words.begin(), words.end(),

`(x, y)` 좌표를 x 오름차순, x가 같으면 y 오름차순으로 정렬하라. `pair<int, int>`의 기본 정렬을 활용한다.

### S4. K번째 수

배열의 특정 구간을 잘라 정렬한 뒤 K번째 수를 반환하라. 여러 명령을 처리한다.

### S5. 가장 큰 수 만들기

0 이상의 정수들을 이어 붙여 만들 수 있는 가장 큰 수를 문자열로 반환하라.

비교 기준:

```cpp
return a + b > b + a;
```

모든 값이 0인 경우 결과는 `"0"`이어야 한다.

### S6. 중복 제거 후 정렬

정수 배열의 중복을 제거하고 오름차순으로 반환하라. `sort`, `unique`, `erase`를 모두 사용한다.

### S7. 실패율 정렬

스테이지별 실패율을 계산하고 실패율 내림차순, 같으면 스테이지 번호 오름차순으로 반환하라. 실수 비교와 0으로 나누는 경우를 주의한다.

### S8. 파일명 정렬

파일명을 HEAD, NUMBER, TAIL로 나누고 HEAD 대소문자 무시 오름차순, NUMBER 숫자 오름차순으로 안정 정렬하라.

### S9. 구간 병합

시작점과 끝점으로 이루어진 구간들을 시작점 기준으로 정렬하고, 겹치는 구간을 합쳐 반환하라.

### S10. 회의실 개수

회의 시작·종료 시간이 주어질 때 필요한 최소 회의실 수를 구하라. 시작 시간을 정렬하고 현재 종료 시간들은 최소 힙으로 관리한다.

## B. 이분 탐색 문제 B1~B10

### B1. 값 존재 여부

정렬된 정수 배열과 target이 주어질 때 존재 여부를 반환하라. 직접 구현과 `binary_search` 두 방식으로 푼다.

### B2. 삽입 위치

정렬 상태를 유지하며 target을 삽입할 첫 위치를 반환하라.

```cpp
int solution(vector<int> numbers, int target) {
    return static_cast<int>(
        lower_bound(numbers.begin(), numbers.end(), target)
        - numbers.begin()
    );
}
```

### B3. 특정 값의 개수

정렬된 배열에서 target의 등장 횟수를 `O(log N)`에 구하라.

### B4. 첫 위치와 마지막 위치

target이 등장하는 첫 인덱스와 마지막 인덱스를 반환하라. 없으면 `{-1, -1}`을 반환한다.

힌트:

```cpp
int first = lower_bound(...) - begin;
int afterLast = upper_bound(...) - begin;
int last = afterLast - 1;
```

### B5. 가장 가까운 수

정렬된 배열에서 target과 차이가 가장 작은 값을 반환하라. 동률이면 작은 값을 반환한다. `lower_bound`가 가리키는 값과 바로 앞의 값을 비교한다.

### B6. 두 배열의 교집합

두 배열 중 하나를 정렬하고 다른 배열의 각 값에 이분 탐색을 적용해 공통 원소를 구하라. 해시 풀이와 복잡도를 비교한다.

### B7. 회전 배열 탐색

서로 다른 값으로 이루어진 회전 정렬 배열에서 target의 인덱스를 `O(log N)`에 구하라.

### B8. 회전 횟수 찾기

서로 다른 값의 오름차순 배열을 오른쪽으로 여러 번 회전했다. 최솟값의 인덱스를 찾아 회전 상태를 설명하라.

### B9. 제곱근의 정수 부분

음이 아닌 정수 `x`가 주어질 때 `floor(sqrt(x))`를 이분 탐색으로 구하라. `middle * middle`의 오버플로를 막기 위해 `long long`을 사용한다.

### B10. LIS의 길이

수열의 가장 긴 증가하는 부분 수열 길이를 `O(N log N)`에 구하라. 각 값이 들어갈 위치를 `lower_bound`로 찾아 `tails`를 갱신한다.

```cpp
int lengthOfLIS(const vector<int>& numbers) {
    vector<int> tails;

    for (int number : numbers) {
        auto it = lower_bound(tails.begin(), tails.end(), number);

        if (it == tails.end()) {
            tails.push_back(number);
        } else {
            *it = number;
        }
    }

    return static_cast<int>(tails.size());
}
```

`tails` 자체가 실제 LIS 전체를 의미하지는 않지만 길이는 정확하다.

## C. 정답 이분 탐색 P1~P5

### P1. 공유기 설치

집 좌표와 공유기 수가 주어질 때 가장 인접한 두 공유기 사이 거리의 최댓값을 구하라. 앞의 템플릿을 보지 않고 구현한다.

### P2. 예산 상한액

여러 지역의 요청 예산과 총예산이 주어진다. 모든 요청을 만족할 수 없을 때 적용할 수 있는 최대 상한액을 구하라.

판정식:

```cpp
sum += min(request, limit);
```

### P3. 최소 처리 속도

작업량 배열과 제한 시간이 주어진다. 시간 안에 모든 작업을 끝낼 수 있는 최소 처리 속도를 구하라.

올림 나눗셈:

time += (work + speed - 1) / speed;

### P4. 입국 심사

판정 기준: 후보 거리보다 간격이 작은 바위를 탐욕적으로 제거하고 제거 수가 제한 이하인지 확인한다.

### K2. 예방 접종 기록 검색 - 책 실습문제 8 변형

학생 기록은 `(이름 번호, 성 번호, 접종 여부)`로 주어지며 `(이름 번호, 성 번호)` 순서로 정렬되어 있다. 조회한 학생이 목록에 없거나 목록에는 있지만 접종하지 않았다면 예방 접종이 필요하다고 판단하라.

```cpp
struct StudentRecord {
    pair<int, int> name;
    bool vaccinated;
};

bool needsVaccination(
    const vector<StudentRecord>& records,
    pair<int, int> target
) {
    auto it = lower_bound(
        records.begin(),
        records.end(),
        target,
        [](const StudentRecord& record, const pair<int, int>& name) {
            return record.name < name;
        }
    );

    if (it == records.end() || it->name != target) {
        return true;
    }

    return !it->vaccinated;
}
```

확인할 조건:

- 목록에 없는 학생
- 목록에 있고 접종한 학생
- 목록에 있지만 접종하지 않은 학생
- 첫 번째와 마지막 기록 조회

회전 배열 탐색은 책의 실습문제 8이 아니라 추가 심화 문제이며, 이 문서의 17절과 B7·B8에서 별도로 연습한다.

### K6. K번째 원소 선택 - 책 연습문제 21 변형

정렬되지 않은 배열에서 K번째로 작은 값을 찾는다.

- 기본 풀이: 전체 정렬 후 `numbers[k - 1]`
- STL 풀이: `nth_element`
- 심화 풀이: 퀵 셀렉트

```cpp
int kthSmallest(vector<int> numbers, int k) {
    nth_element(
        numbers.begin(),
        numbers.begin() + (k - 1),
        numbers.end()
    );

    return numbers[k - 1];
}
```

`1 <= k <= numbers.size()`인지 먼저 확인한다.

# 5부 - 실수 방지

## 21. 자주 하는 실수

### 정렬하지 않고 이분 탐색

`binary_search`, `lower_bound`, `upper_bound`를 사용하기 전에 같은 비교 기준으로 정렬되어 있어야 한다.

### 범위 규칙을 섞음

- `[left, right]`: `left <= right`, `right = middle - 1`
- `[left, right)`: `left < right`, `right = middle`

한 함수 안에서 두 규칙을 섞지 않는다.

### 비교 함수에서 `<=` 또는 `>=` 사용

```cpp
return a < b;
```

동일한 두 값의 비교는 `false`여야 한다.

### `lower_bound`의 뜻을 “같은 값의 위치”로만 기억

정확한 뜻은 **target 이상인 첫 위치**다. target이 없어도 삽입 위치를 반환한다.

### `upper_bound`와 마지막 위치 혼동

`upper_bound`는 target의 마지막 위치가 아니라 **target보다 큰 첫 위치**다.

### `unique()`만 호출하고 끝냄

실제 크기를 줄이려면 `erase()`까지 필요하다.

### 정답 이분 탐색의 단조성 미확인

가능·불가능이 한 번만 바뀌지 않으면 이분 탐색할 수 없다.

### 곱셈과 누적합 오버플로

시간, 거리, 사람 수, `middle * middle`은 `long long`이 필요한지 확인한다.
