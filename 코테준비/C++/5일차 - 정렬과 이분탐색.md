# 1부 — 정렬

## 1. 정렬이란?

정렬은 데이터를 특정 기준에 따라 순서대로 배치하는 것이다.

```text
입력: {5, 2, 8, 1, 3}
오름차순: {1, 2, 3, 5, 8}
내림차순: {8, 5, 3, 2, 1}
```

정렬하면 다음 작업이 쉬워진다.

- 최솟값과 최댓값 찾기
- 중복 제거
- 순위 결정
- 두 값 비교
- 이분탐색
- 같은 값끼리 모으기

---

## 2. `sort()` 기본 사용법

```cpp
#include <algorithm>
#include <vector>
using namespace std;

sort(numbers.begin(), numbers.end());
```

- `numbers.begin()`: 첫 번째 원소의 위치
- `numbers.end()`: 마지막 원소 **다음**의 위치
- 기본 정렬 순서: 오름차순

```cpp
vector<int> numbers = {5, 2, 8, 1, 3};
sort(numbers.begin(), numbers.end());
// {1, 2, 3, 5, 8}
```

`sort()`는 원본 배열을 직접 변경한다.

원본을 보존해야 한다면 복사본을 정렬한다.

```cpp
vector<int> sortedNumbers = numbers;
sort(sortedNumbers.begin(), sortedNumbers.end());
```

---

## 3. 내림차순 정렬

```cpp
#include <functional>

sort(numbers.begin(), numbers.end(), greater<int>());
```

```cpp
vector<int> numbers = {5, 2, 8, 1, 3};
sort(numbers.begin(), numbers.end(), greater<int>());
// {8, 5, 3, 2, 1}
```

람다식을 사용해도 된다.

```cpp
sort(numbers.begin(), numbers.end(), [](int a, int b) {
    return a > b;
});
```

---

## 4. 문자열 정렬

문자열은 기본적으로 사전식 순서로 정렬된다.

```cpp
vector<string> words = {"banana", "apple", "cat"};
sort(words.begin(), words.end());
// {"apple", "banana", "cat"}
```

대문자와 소문자가 섞이면 문자 코드 순서의 영향을 받는다. 문제 조건을 반드시 확인한다.

---

## 5. 사용자 정의 정렬과 람다식

문자열을 길이가 짧은 순서로 정렬한다.

```cpp
sort(words.begin(), words.end(), [](const string& a, const string& b) {
    return a.size() < b.size();
});
```

람다식의 기본 형태:

```cpp
[](매개변수) {
    return a가 b보다 앞에 와야 하는 조건;
}
```

### 길이가 같으면 사전순

```cpp
sort(words.begin(), words.end(), [](const string& a, const string& b) {
    if (a.size() == b.size()) {
        return a < b;
    }

    return a.size() < b.size();
});
```

### 매우 중요한 비교 함수 규칙

같은 값을 비교했을 때 `false`가 나와야 한다. `<=`나 `>=`를 사용하지 않는다.

```cpp
return a < b;   // 올바른 형태
return a <= b;  // 잘못된 비교 기준
```

비교 함수는 “a를 b보다 앞에 놓을 것인가?”에 답한다고 생각한다.

---

## 6. `pair` 정렬

```cpp
#include <utility>

vector<pair<int, int>> points = {
    {2, 3}, {1, 5}, {2, 1}
};

sort(points.begin(), points.end());
```

기본 정렬 결과:

```text
{1, 5}, {2, 1}, {2, 3}
```

`pair`는 다음 순서로 비교된다.

1. `first`를 비교한다.
2. `first`가 같으면 `second`를 비교한다.

두 번째 값을 내림차순으로 정렬하려면:

```cpp
sort(points.begin(), points.end(), [](const auto& a, const auto& b) {
    if (a.first == b.first) {
        return a.second > b.second;
    }

    return a.first < b.first;
});
```

---

## 7. 정렬 후 중복 제거

`unique()`는 연속된 중복을 뒤쪽으로 보낸 뒤 새로운 끝 위치를 반환한다. 따라서 먼저 정렬해야 한다.

```cpp
sort(numbers.begin(), numbers.end());
numbers.erase(unique(numbers.begin(), numbers.end()), numbers.end());
```

```text
입력: {3, 1, 3, 2, 1}
결과: {1, 2, 3}
```

이 코드는 자주 쓰이므로 하나의 패턴으로 익힌다.

---

## 8. 정렬의 시간복잡도

C++의 `sort()`는 일반적으로 `O(N log N)`이다.

| 방법 | 시간복잡도 |
|---|---:|
| 전체 순회 | `O(N)` |
| `sort()` | `O(N log N)` |
| 단순 이중 반복 정렬 | `O(N²)` |

코딩 테스트에서는 직접 버블 정렬을 구현하기보다 특별한 요구가 없다면 `sort()`를 사용한다.

---

## 9. 정렬 문제에서 자주 하는 실수

- `#include <algorithm>`을 빠뜨린다.
- `sort()`가 원본을 바꾼다는 점을 잊는다.
- 비교 함수에서 `<=` 또는 `>=`를 사용한다.
- 동률일 때의 두 번째 기준을 빠뜨린다.
- 숫자를 문자열로 정렬할 때 숫자 크기와 사전순을 혼동한다.
- `unique()`만 호출하고 `erase()`를 하지 않는다.

정수 배열과 양의 정수 `k`가 주어진다. `k`번째로 작은 수를 반환한다. `k`는 1부터 시작한다.

int solution(vector<int> numbers, int k) {

## S3 — 문자열 길이순 정렬

문자열 배열을 길이가 짧은 순서로 정렬한다. 길이가 같으면 사전순으로 정렬한다.

<details>
<summary>정답</summary>

```cpp
vector<string> solution(vector<string> words) {
    sort(words.begin(), words.end(), [](const string& a, const string& b) {

            return a < b;
        }

        return a.size() < b.size();

}
```

</details>

정수 배열의 중복을 제거하고 오름차순으로 반환한다.

## S6 — 가장 큰 수 만들기

0 이상의 정수 배열을 이어 붙여 만들 수 있는 가장 큰 수를 문자열로 반환한다.

```text
입력: {6, 10, 2}
출력: "6210"

입력: {3, 30, 34, 5, 9}
출력: "9534330"
```

두 문자열 `a`, `b`의 순서는 `a + b`와 `b + a` 중 무엇이 더 큰지로 결정한다.

<details>
<summary>정답</summary>

```cpp
string solution(vector<int> numbers) {
    vector<string> values;

    for (int number : numbers) {
        values.push_back(to_string(number));
    }

    sort(values.begin(), values.end(), [](const string& a, const string& b) {
        return a + b > b + a;
    });

    if (values[0] == "0") {
        return "0";
    }

    string answer = "";

    for (const string& value : values) {
        answer += value;
    }

    return answer;
}
```

모든 숫자가 0이면 `"000"`이 아니라 `"0"`을 반환한다.

</details>

## S7 — 성적 정렬

학생 정보가 `{이름, 점수}`로 주어진다. 점수가 높은 순으로 정렬하고, 점수가 같으면 이름의 사전순으로 정렬해 이름 배열을 반환한다.

```cpp
vector<pair<string, int>> students;
```

<details>
<summary>정답</summary>

```cpp
vector<string> solution(vector<pair<string, int>> students) {
    sort(students.begin(), students.end(), [](const auto& a, const auto& b) {
        if (a.second == b.second) {
            return a.first < b.first;
        }

        return a.second > b.second;
    });

    vector<string> answer;

    for (const auto& student : students) {
        answer.push_back(student.first);
    }

    return answer;
}
```

</details>

## S8 — H-Index

논문별 인용 횟수가 주어진다. `h`번 이상 인용된 논문이 `h`편 이상이고 나머지 논문이 `h`번 이하 인용되었다면 `h`의 최댓값을 반환한다.

```text
입력: {3, 0, 6, 1, 5}
출력: 3
```

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> citations) {
    sort(citations.begin(), citations.end(), greater<int>());

    int answer = 0;

    for (int i = 0; i < citations.size(); i++) {
        int paperCount = i + 1;

        if (citations[i] >= paperCount) {
            answer = paperCount;
        } else {
            break;
        }
    }

    return answer;
}
```

</details>

# 2부 — 이분탐색

## 10. 이분탐색이란?

이분탐색은 **정렬된 탐색 범위**의 절반을 반복해서 버리는 방법이다.

```text
정렬된 배열: {1, 3, 5, 7, 9, 11, 13}
찾을 값: 9

중앙 7 확인 → 9가 더 큼 → 왼쪽 절반 제거
남은 {9, 11, 13}
중앙 11 확인 → 9가 더 작음 → 오른쪽 제거
9 발견
```

순차 탐색은 최대 `N`개를 확인하므로 `O(N)`이다. 이분탐색은 확인할 범위를 계속 절반으로 줄여 `O(log N)`에 찾는다.

| 원소 수 | 이분탐색 최대 비교 횟수의 대략적인 크기 |
|---:|---:|
| 1,000 | 약 10번 |
| 1,000,000 | 약 20번 |
| 1,000,000,000 | 약 30번 |

### 절대 조건

> 값 자체를 찾는 일반 이분탐색에서는 배열이 정렬되어 있어야 한다.

---

## 11. 직접 구현하는 기본 이분탐색

```cpp
int binarySearch(const vector<int>& numbers, int target) {
    int left = 0;
    int right = static_cast<int>(numbers.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (numbers[mid] == target) {
            return mid;
        }

        if (numbers[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}
```

### 변수의 의미

- `left`: 현재 탐색 범위의 왼쪽 끝
- `right`: 현재 탐색 범위의 오른쪽 끝
- `mid`: 중앙 인덱스

### 왜 `mid + 1`, `mid - 1`인가?

`mid`는 이미 확인했으므로 다음 범위에서는 제외해야 한다. 그대로 두면 무한 반복이 발생할 수 있다.

### 안전한 중앙값 계산

```cpp
int mid = left + (right - left) / 2;
```

`(left + right) / 2`도 작은 범위에서는 동작하지만 두 수의 합이 정수 범위를 넘을 수 있다.

## 12. STL `binary_search()`

값의 존재 여부만 필요하면 다음 함수를 사용할 수 있다.

```cpp
bool exists = binary_search(numbers.begin(), numbers.end(), target);
```

반드시 먼저 정렬한다.

```cpp
sort(numbers.begin(), numbers.end());
bool exists = binary_search(numbers.begin(), numbers.end(), target);
```

`binary_search()`는 인덱스를 반환하지 않고 `true` 또는 `false`만 반환한다.

---

## 13. `lower_bound()`

`lower_bound()`는 **target 이상인 첫 번째 원소의 위치**를 반환한다.

```cpp
vector<int> numbers = {1, 2, 2, 2, 4, 7};

auto it = lower_bound(numbers.begin(), numbers.end(), 2);
int index = it - numbers.begin();  // 1
```

쉽게 기억하면:

```text
lower_bound(target) → target이 들어갈 수 있는 가장 왼쪽 위치
```

target이 없어도 삽입 위치를 반환한다.

```cpp
lower_bound({1, 3, 5, 7}, 4) → 인덱스 2
```

---

## 14. `upper_bound()`

`upper_bound()`는 **target보다 큰 첫 번째 원소의 위치**를 반환한다.

```cpp
vector<int> numbers = {1, 2, 2, 2, 4, 7};

auto it = upper_bound(numbers.begin(), numbers.end(), 2);
int index = it - numbers.begin();  // 4
```

### 특정 값의 개수

```cpp
int count = upper_bound(numbers.begin(), numbers.end(), target)
          - lower_bound(numbers.begin(), numbers.end(), target);
```

숫자 2의 범위는 인덱스 `[1, 4)`이므로 개수는 `4 - 1 = 3`이다.

---

## 15. `lower_bound`와 `upper_bound` 비교

| 함수 | 반환하는 위치 |
|---|---|
| `lower_bound` | target 이상인 첫 위치 |
| `upper_bound` | target보다 큰 첫 위치 |

```text
배열:  1  2  2  2  4  7
인덱스 0  1  2  3  4  5

lower_bound(2) → 1
upper_bound(2) → 4
2의 개수       → 4 - 1 = 3
```

반환 위치가 `end()`일 수 있으므로 값을 직접 읽기 전에 확인한다.

```cpp
auto it = lower_bound(numbers.begin(), numbers.end(), target);

if (it != numbers.end()) {
    cout << *it;
}
```

## 16. 첫 번째 위치를 직접 찾기

중복된 target 중 가장 왼쪽 인덱스를 찾는다.

```cpp
int findFirst(const vector<int>& numbers, int target) {
    int left = 0;
    int right = static_cast<int>(numbers.size()) - 1;
    int answer = -1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (numbers[mid] >= target) {
            if (numbers[mid] == target) {
                answer = mid;
            }

            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    return answer;
}
```

target을 찾은 뒤에도 더 왼쪽에 같은 값이 있을 수 있으므로 `right = mid - 1`로 계속 탐색한다.

## 17. 정답을 이분탐색하기

배열에서 특정 값을 찾는 것뿐 아니라, 가능한 정답의 범위를 이분탐색할 수도 있다.

예시:

- 만들 수 있는 랜선 길이의 최댓값
- 예산 상한액의 최댓값
- 작업을 끝낼 수 있는 시간의 최솟값
- 그룹 합의 최댓값을 최소화

핵심은 **판정 함수**다.

```text
정답 후보 mid가 가능한가?
```

가능 여부가 다음처럼 한 방향으로 나뉘어야 한다.

```text
가능 가능 가능 가능 | 불가능 불가능 불가능
```

또는:

```text
불가능 불가능 | 가능 가능 가능 가능
```

이 성질을 단조성이라고 한다.

---

## 18. 최댓값을 찾는 이분탐색 틀

가능한 값 중 가장 큰 값을 찾는다.

```cpp
long long left = 최소후보;
long long right = 최대후보;
long long answer = 초기값;

while (left <= right) {
    long long mid = left + (right - left) / 2;

    if (mid가 가능함) {
        answer = mid;
        left = mid + 1;   // 더 큰 값 도전
    } else {
        right = mid - 1;  // 값을 줄임
    }
}
```

## 19. 최솟값을 찾는 이분탐색 틀

가능한 값 중 가장 작은 값을 찾는다.

```cpp
long long left = 최소후보;
long long right = 최대후보;
long long answer = 최대후보;

while (left <= right) {
    long long mid = left + (right - left) / 2;

    if (mid가 가능함) {
        answer = mid;
        right = mid - 1;  // 더 작은 값 도전
    } else {
        left = mid + 1;   // 값을 늘림
    }
}
```

합계나 곱셈이 포함되면 `int` 범위를 넘을 수 있으므로 `long long`을 적극적으로 사용한다.

---

## 20. 이분탐색에서 자주 하는 실수

- 정렬하지 않은 배열에 이분탐색을 적용한다.
- `left = mid`, `right = mid`로 작성해 무한 반복한다.
- `left < right`와 `left <= right` 템플릿을 섞어 쓴다.
- `lower_bound()` 결과가 `end()`인지 확인하지 않는다.
- 인덱스와 실제 값을 혼동한다.
- 정답 범위의 최솟값과 최댓값을 잘못 정한다.
- 합계를 `int`로 계산해 오버플로가 발생한다.
- 판정 조건이 단조적인지 확인하지 않는다.

처음에는 이 문서의 `left <= right` 틀 하나만 일관되게 사용한다.

# 이분탐색 연습 문제

## B1 — 값 존재 여부

정수 배열과 `target`이 주어진다. target이 존재하면 `true`, 아니면 `false`를 반환한다. 입력 배열은 정렬되어 있지 않을 수 있다.

<details>
<summary>정답</summary>

```cpp
bool solution(vector<int> numbers, int target) {
    sort(numbers.begin(), numbers.end());
    return binary_search(numbers.begin(), numbers.end(), target);
}
```

</details>

## B2 — 직접 이분탐색

오름차순으로 정렬된 배열에서 target의 인덱스를 반환한다. 없다면 `-1`을 반환한다. 모든 값은 서로 다르다.

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> numbers, int target) {
    int left = 0;
    int right = static_cast<int>(numbers.size()) - 1;

    while (left <= right) {
        int mid = left + (right - left) / 2;

        if (numbers[mid] == target) {
            return mid;
        }

        if (numbers[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return -1;
}
```

</details>

## B3 — 삽입 위치

오름차순 배열에서 target 이상인 첫 위치를 반환한다. target이 없다면 오름차순을 유지하며 삽입할 위치를 반환한다.

```text
numbers = {1, 3, 5, 6}, target = 5 → 2
numbers = {1, 3, 5, 6}, target = 2 → 1
numbers = {1, 3, 5, 6}, target = 7 → 4
```

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> numbers, int target) {
    return lower_bound(numbers.begin(), numbers.end(), target) - numbers.begin();
}
```

</details>

## B4 — 특정 숫자의 개수

오름차순 배열에서 target이 등장하는 횟수를 반환한다.

```text
입력: {1, 2, 2, 2, 4, 5}, target = 2
출력: 3
```

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> numbers, int target) {
    auto first = lower_bound(numbers.begin(), numbers.end(), target);
    auto last = upper_bound(numbers.begin(), numbers.end(), target);
    return last - first;
}
```

</details>

## B5 — 범위 안 숫자의 개수

오름차순 배열에서 값이 `low` 이상 `high` 이하인 원소의 개수를 반환한다.

```text
입력: {1, 2, 2, 4, 5, 7}, low = 2, high = 5
출력: 4
```

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> numbers, int low, int high) {
    auto first = lower_bound(numbers.begin(), numbers.end(), low);
    auto last = upper_bound(numbers.begin(), numbers.end(), high);
    return last - first;
}
```

</details>

## B6 — 예산 상한액

각 지역의 예산 요청과 총예산 `budget`이 주어진다. 모든 요청을 그대로 배정할 수 없을 때 일정한 상한액을 정하고, 요청이 상한액보다 크면 상한액만 배정한다. 가능한 상한액의 최댓값을 반환한다.

```text
요청: {120, 110, 140, 150}, 총예산: 485
출력: 127
```

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> requests, int budget) {
    int left = 0;
    int right = *max_element(requests.begin(), requests.end());
    int answer = 0;

    while (left <= right) {
        int mid = left + (right - left) / 2;
        long long total = 0;

        for (int request : requests) {
            total += min(request, mid);
        }

        if (total <= budget) {
            answer = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return answer;
}
```

</details>

## B7 — 랜선 자르기

여러 랜선의 길이가 주어진다. 모든 랜선을 같은 길이로 잘라 최소 `needed`개 이상 만들려고 한다. 가능한 랜선 길이의 최댓값을 반환한다.

```text
랜선: {802, 743, 457, 539}, needed = 11
출력: 200
```

<details>
<summary>정답</summary>

```cpp
long long solution(vector<int> cables, int needed) {
    long long left = 1;
    long long right = *max_element(cables.begin(), cables.end());
    long long answer = 0;

    while (left <= right) {
        long long mid = left + (right - left) / 2;
        long long pieces = 0;

        for (int cable : cables) {
            pieces += cable / mid;
        }

        if (pieces >= needed) {
            answer = mid;
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }

    return answer;
}
```

길이 후보를 0부터 시작하면 `cable / mid`에서 0으로 나누는 오류가 발생하므로 `left = 1`로 시작한다.

</details>

## B8 — 최소 처리 시간

심사관별 한 명 처리 시간이 주어지고 총 `people`명을 처리해야 한다. 모든 심사관은 동시에 일한다. 모든 사람을 처리하는 최소 시간을 반환한다.

```text
times = {7, 10}, people = 6
출력: 28
```

<details>
<summary>정답</summary>

```cpp
long long solution(int people, vector<int> times) {
    long long left = 1;
    long long right = static_cast<long long>(*max_element(times.begin(), times.end())) * people;
    long long answer = right;

    while (left <= right) {
        long long mid = left + (right - left) / 2;
        long long processed = 0;

        for (int time : times) {
            processed += mid / time;

            if (processed >= people) {
                break;
            }
        }

        if (processed >= people) {
            answer = mid;
            right = mid - 1;
        } else {
            left = mid + 1;
        }
    }

    return answer;
}
```

</details>

# 3부 — 정렬과 이분탐색 종합

## 종합 1 — 두 수의 합 존재 여부

정수 배열에서 서로 다른 두 원소를 더해 `target`을 만들 수 있으면 `true`, 아니면 `false`를 반환한다.

정렬 후 각 원소마다 필요한 값을 이분탐색한다.

<details>
<summary>정답</summary>

```cpp
bool solution(vector<int> numbers, int target) {
    sort(numbers.begin(), numbers.end());

    for (int i = 0; i < numbers.size(); i++) {
        int needed = target - numbers[i];

        if (binary_search(numbers.begin() + i + 1, numbers.end(), needed)) {
            return true;
        }
    }

    return false;
}
```

</details>

## 종합 2 — 각 질의의 개수

정수 배열 `numbers`와 질의 배열 `queries`가 주어진다. 각 질의 값이 `numbers`에 몇 번 등장하는지 배열로 반환한다.

```text
numbers = {1, 2, 2, 3, 3, 3}
queries = {2, 3, 4}
출력: {2, 3, 0}
```

<details>
<summary>정답</summary>

```cpp
vector<int> solution(vector<int> numbers, vector<int> queries) {
    sort(numbers.begin(), numbers.end());
    vector<int> answer;

    for (int query : queries) {
        int count = upper_bound(numbers.begin(), numbers.end(), query)
                  - lower_bound(numbers.begin(), numbers.end(), query);
        answer.push_back(count);
    }

    return answer;
}
```

</details>

## 종합 3 — 가장 가까운 수

정수 배열과 target이 주어진다. target과 차이가 가장 작은 수를 반환한다. 차이가 같으면 더 작은 수를 반환한다.

힌트: 정렬 후 `lower_bound()`가 가리키는 값과 바로 이전 값을 비교한다.

<details>
<summary>정답</summary>

```cpp
int solution(vector<int> numbers, int target) {
    sort(numbers.begin(), numbers.end());
    auto it = lower_bound(numbers.begin(), numbers.end(), target);

    if (it == numbers.begin()) {
        return *it;
    }

    if (it == numbers.end()) {
        return numbers.back();
    }

    int rightValue = *it;
    int leftValue = *(it - 1);

    if (target - leftValue <= rightValue - target) {
        return leftValue;
    }

    return rightValue;
}
```

</details>

## 종합 4 — 나무 자르기

나무들의 높이와 필요한 나무 길이 `needed`가 주어진다. 절단기 높이보다 높은 부분만 잘린다. 필요한 길이를 최소한 확보할 수 있는 절단기 높이의 최댓값을 구한다.

```text
나무: {20, 15, 10, 17}, needed = 7
출력: 15
```

이 문제는 정답 코드를 보지 않고 `B7 — 랜선 자르기`의 구조를 변형해 작성한다.

# 추가 훈련 — 정답 없이 풀기

## 추가 1 — 절댓값 정렬

정수를 절댓값이 작은 순서로 정렬한다. 절댓값이 같다면 실제 값이 작은 수를 먼저 배치한다.

```text
입력: {-3, 1, -1, 2, -2}
출력: {-1, 1, -2, 2, -3}
```

## 추가 2 — 단어 중복 제거

문자열 배열의 중복을 제거한 뒤 길이순, 길이가 같으면 사전순으로 반환한다.

## 추가 3 — 마지막 위치

정렬된 배열에서 target이 마지막으로 등장하는 인덱스를 직접 이분탐색으로 구현한다. `upper_bound()`를 사용하지 않는다.

## 추가 4 — K보다 작은 원소 수

정렬된 배열에서 `k`보다 작은 원소의 개수를 `lower_bound()`로 구한다.

## 추가 5 — 공유기 설치

집의 좌표와 설치할 공유기 수가 주어진다. 가장 인접한 두 공유기 사이 거리의 최댓값을 구한다.

## 추가 6 — 최소 운반 용량

순서가 정해진 짐을 하루에 한 번 운반하고 `days`일 안에 모두 옮기려 한다. 필요한 운반 용량의 최솟값을 구한다. 한 짐을 나눌 수 없고 순서를 바꿀 수 없다.

# 자료형과 오버플로 점검

다음 상황에서는 `long long`을 먼저 검토한다.

- 값의 최댓값 × 원소 개수
- 배열 전체의 합
- 처리 시간 × 사람 수
- 랜선 조각 수의 누적
- 정답 범위가 10억 이상

```cpp
long long total = 0;
total += value;
```

곱셈은 계산하기 전에 하나를 `long long`으로 변환한다.

```cpp
long long right = static_cast<long long>(maxTime) * people;
```

# 복습 체크리스트

## 정렬

- [ ] `sort()`가 원본을 변경한다는 것을 안다.
- [ ] 오름차순과 내림차순 코드를 작성할 수 있다.
